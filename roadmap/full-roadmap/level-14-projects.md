# Level 14 · Projects

> **Phase 6 · Frontier & Proof** · 7 modules

> **Source:** the level structure, description, interview/on-the-job weights, session counts, modules, outcomes and capstone text on this page are adapted verbatim from the [CampusX AI Engineering Roadmap 2026](https://ai-engineer-roadmap-2026.vercel.app/level/14/) (retrieved October 17, 2026). The *Free learning resources* and *In this repository* sections are independently curated free worldwide alternatives — this repository is not affiliated with CampusX.

---

Proof, not concepts. Portfolio builds that compose earlier levels. Ship 3–5 public.

## Why this level matters

**Interview weight: 10/10**

The **biggest factor in getting shortlisted**. Without real, **deployed projects**, a resume from a new AI engineer usually gets no response, and most interview conversations are built around them.

**On-the-job weight: 6/10**

Building end-to-end gives you the **instincts the job needs**, but once you’re employed, **real work replaces portfolio projects**.

## Modules

### 01 · Document Q&A platform (P14.1 · 3 sessions)

- **Compose L4 with FastAPI and a retrieval eval;** deploy publicly.

### 02 · Resume ↔ JD screening agent (P14.2 · 2 sessions)

- Demonstrate tool calling and structured output on a real business task.

### 03 · Multi-agent research report system (P14.3 · 3 sessions)

- Show **LangGraph** orchestration and state management (L5).

### 04 · MCP server for a real tool (P14.4 · 2 sessions)

- Connect a model to a calendar/CRM/task manager — the 2026 pattern.

### 05 · Monitored production API (P14.5 · 2 sessions)

- **Tell the ops story:** routing, fallback, cost caps, tracing (L10).

### 06 · Voice or multimodal build (P14.6 · 3 sessions)

- Ship a realtime voice agent or a vision pipeline (L12).

### 07 · Portfolio & positioning (P14.7 · 1 session)

- Write projects up, publish to **GitHub**, record demos, and present the work.
