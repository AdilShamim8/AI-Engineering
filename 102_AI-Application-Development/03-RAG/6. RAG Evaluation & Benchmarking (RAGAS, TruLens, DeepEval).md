# 📌 PART 1 — The RAG Triad Architecture

The RAG Triad isolates the three failure points in any retrieval-augmented system:

```
                      +-------------------+
                      |    User Query     |
                      +-------------------+
                        /               \
        Query-to-Context /                 \ Query-to-Answer
       [Context Relevance]              [Answer Relevance]
                      /                     \
                     v                       v
          +--------------------+        +--------------------+
          | Retrieved Context  | ─────► |  Generated Answer  |
          +--------------------+        +--------------------+
                           Context-to-Answer
                             [Faithfulness]
```

| Triad Metric | What It Answers | How It Is Measured | What a Low Score Means |
|---|---|---|---|
| **Context Relevance** | Did the retriever fetch chunks that actually contain information needed to answer the query? | Ratio of relevant sentences in retrieved chunks to total sentences | Retrieval is returning noisy, irrelevant distractors (Fix chunking or reranking) |
| **Groundedness / Faithfulness** | Is every factual claim in the generated answer directly supported by the retrieved context? | Breakdown of answer into atomic claims; verify each claim against context | **HALLUCINATION ALERT:** Model is inventing facts from its parametric weights |
| **Answer Relevance** | Does the generated answer directly answer what the user asked? | Compare embedding/intent of answer to original query | Model is rambling, evasive, or refusing legitimate requests |

# 📌 PART 2 — The RAGAS Framework Decoded

**RAGAS (Retrieval Augmented Generation Assessment)** is the industry-standard open-source evaluation framework:

### 1. Faithfulness (0.0 to 1.0)
$$\text{Faithfulness} = \frac{|\text{Supported Claims}|}{|\text{Total Claims in Answer}|}$$
1. LLM breaks generated answer into individual atomic factual statements.
2. For each statement, LLM verifies if it is logically entailed by the retrieved context.

### 2. Context Precision
$$\text{Context Precision@K} = \frac{\sum_{k=1}^K (\text{Precision@}k \times v_k)}{\text{Total Relevant Items in Top } K}$$
*(Measures whether the most relevant chunks are ranked at the top of the context)*.

### 3. Context Recall
$$\text{Context Recall} = \frac{|\text{Ground Truth Sentences Attributed to Context}|}{|\text{Total Sentences in Ground Truth}|}$$
