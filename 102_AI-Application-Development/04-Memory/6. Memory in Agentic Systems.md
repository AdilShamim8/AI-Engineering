# 🏛️ FOUNDATION — What Makes Agentic Memory Different

## Chatbot vs Agent — The Memory Difference

```
CHATBOT MEMORY MODEL:
─────────────────────────────────────────────────────────
User sends message
    ↓
AI retrieves relevant memories
    ↓
AI generates response
    ↓
DONE. Session ends. Simple.

Everything fits in ONE interaction loop.
Memory is about USER context (preferences, history).

AGENT MEMORY MODEL:
─────────────────────────────────────────────────────────
User gives MISSION: "Research AI trends, write report, email it"
    ↓
Agent plans steps (PLANNING MEMORY)
    ↓
Step 1: Search web → store results (EXECUTION MEMORY)
    ↓
Step 2: Analyze results → store analysis (INTERMEDIATE STATE)
    ↓
Step 3: Write report → store draft (WORKING MEMORY)
    ↓
Step 4: Server crashes! 💥
    ↓
Agent RESUMES from Step 3 (CHECKPOINT MEMORY)
    ↓
Step 5: Email sent → log completion (AUDIT MEMORY)
    ↓
Learn from this mission (EPISODIC MEMORY)
```

---

## 🎭 The Analogy: The Surgeon vs The Chatbot Doctor

```
CHATBOT = Walk-in Clinic Doctor
  → Patient arrives, doctor answers questions
  → Patient leaves, doctor forgets them
  → Next patient: fresh start, no history
  → Fine for simple questions

AGENT = Surgeon performing a complex operation
  → Multi-hour operation with many precise steps
  → Must remember: what was cut, what was sutured
  → Must resume if interrupted (break, emergency)
  → Multiple specialists involved (multi-agent!)
  → Patient (human) must approve certain decisions
  → Full audit trail for medical records
  → CATASTROPHIC if memory fails mid-operation

THIS is why agentic memory is fundamentally different.
The STAKES are higher. The DURATION is longer.
The COMPLEXITY is greater. Failure is not "wrong answer"
— it's "incomplete dangerous action."
```

---

## The Five Agentic Memory Challenges

```
CHALLENGE 1: DURATION
  Chatbot task: seconds
  Agent task:   minutes → hours → days
  → Memory must persist across time, not just messages

CHALLENGE 2: COMPLEXITY
  Chatbot: answer question
  Agent: execute multi-step plan with tools
  → Must track WHAT was done, not just WHAT was said

CHALLENGE 3: RECOVERY
  Chatbot crash: user re-asks the question
  Agent crash: "please redo my 3-hour research task" 😱
  → Must checkpoint and resume, not restart

CHALLENGE 4: COORDINATION
  Chatbot: 1 AI, 1 user
  Agent: multiple AIs working together
  → Must share memory WITHOUT causing conflicts

CHALLENGE 5: OVERSIGHT
  Chatbot: user can correct any answer
  Agent: actions can be irreversible (email sent, file deleted!)
  → Human must be able to inspect/modify memory BEFORE action
```

# 💾 CONCEPT 1: State Persistence

## 1. What Is It?

> **State Persistence = The mechanism by which an AI agent saves its complete operational state — variables, progress, decisions, tool results — to durable storage, so it can be fully restored after any interruption.**

---

## 2. First-Principles: What IS "State"?

```
EVERY AGENT HAS STATE AT EVERY MOMENT:

┌─────────────────────────────────────────────────────────────┐
│                    AGENT STATE SNAPSHOT                     │
│                  (At any moment in time)                    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  IDENTITY STATE:                                            │
│  → What is my mission?                                      │
│  → Who am I working for? (user_id)                         │
│  → What tools do I have?                                    │
│                                                             │
│  PLANNING STATE:                                            │
│  → What steps did I plan?                                   │
│  → Which steps are done / pending / failed?                 │
│  → What decisions have I made and why?                      │
│                                                             │
│  EXECUTION STATE:                                           │
│  → What tool calls have I made?                             │
│  → What did those tools return?                             │
│  → What intermediate data do I have?                        │
│                                                             │
│  CONTEXT STATE:                                             │
│  → Full conversation history                                │
│  → Retrieved memories relevant to current task             │
│  → Active constraints and rules                             │
│                                                             │
│  META STATE:                                                │
│  → Token budget used                                        │
│  → Time elapsed                                             │
│  → Error count and retry status                             │
│  → Current confidence level                                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘

STATE PERSISTENCE = Saving this entire snapshot to disk/DB
                   at regular intervals AND at key events.
```

## 3. Analogy: The Video Game Save System

```
🎮 Agent State Persistence = Video Game Save System

WITHOUT saves:
  You play for 3 hours → Power cut → Start over from beginning
  "Sorry, you have to redo the entire dungeon!"

WITH saves:
  You play for 3 hours → Save at level 7 → Power cut
  → Resume from level 7 exactly where you left off
  → All inventory, progress, decisions preserved

AGENT WITHOUT STATE PERSISTENCE:
  3-hour research task → Server crash → Start over from scratch
  Every tool call, analysis, and decision = LOST 😱

AGENT WITH STATE PERSISTENCE:
  3-hour research task → Server crash
  → Resume from last checkpoint (Step 5 of 12)
  → All previous tool results, analysis, decisions = INTACT ✅

Key insight:
The "save file" must capture EVERYTHING needed to recreate
the exact state — not just the output, but the PROCESS.
```

---

## 4. State vs Memory — Critical Distinction

```
MEMORY (Long-Term):
  → What the user told us over months
  → User preferences and profile
  → Past interactions and learned knowledge
  → Persists across ALL tasks and sessions
  → Grows slowly over time
  → Example: "User prefers Python over Java"

STATE (Task-Level):
  → What's happening in THIS specific task RIGHT NOW
  → Current step, current tool results, current plan
  → Only lives for the duration of one task/run
  → Resets when task completes
  → Can be checkpointed for recovery
  → Example: "Currently on step 3, web search returned 5 results"

THEY WORK TOGETHER:
  Memory → informs → Planning (state)
  Execution (state) → generates → New memories
  State is TEMPORARY. Memory is PERMANENT.
```

# state_persistence.py
import json
import os
import uuid
import hashlib
from datetime import datetime
from typing import Any, Dict, List, Optional, Union
from dataclasses import dataclass, field, asdict
from enum import Enum
import sqlite3
from pathlib import Path


class AgentStatus(Enum):
    """Possible status values for an agent run."""
    CREATED     = "created"      # Just initialized
    PLANNING    = "planning"     # Creating execution plan
    RUNNING     = "running"      # Actively executing
    PAUSED      = "paused"       # Waiting (human approval, etc.)
    RESUMING    = "resuming"     # Coming back from pause/crash
    COMPLETED   = "completed"    # Successfully finished
    FAILED      = "failed"       # Unrecoverable error
    CANCELLED   = "cancelled"    # Human cancelled


class StepStatus(Enum):
    """Status of an individual step in the plan."""
    PENDING     = "pending"
    IN_PROGRESS = "in_progress"
    COMPLETED   = "completed"
    FAILED      = "failed"
    SKIPPED     = "skipped"
    AWAITING_APPROVAL = "awaiting_approval"


@dataclass
class StepState:
    """
    Complete state of a single execution step.
    Everything needed to know what happened at this step.
    """
    step_id: str
    step_number: int
    name: str
    description: str
    status: str = StepStatus.PENDING.value

    # Execution details
    started_at: Optional[str] = None
    completed_at: Optional[str] = None
    attempt_count: int = 0
    max_attempts: int = 3

    # Results
    result: Optional[Any] = None
    error_message: Optional[str] = None

    # Tool call tracking
    tool_calls: List[Dict] = field(default_factory=list)

    # Dependencies
    depends_on: List[str] = field(default_factory=list)

    # Human approval
    requires_approval: bool = False
    approved_by: Optional[str] = None
    approved_at: Optional[str] = None

    def to_dict(self) -> Dict:
        return asdict(self)

    @classmethod
    def from_dict(cls, data: Dict) -> "StepState":
        return cls(**data)


@dataclass
class AgentState:
    """
    The COMPLETE state of an AI agent at any point in time.
    
    This is the SINGLE SOURCE OF TRUTH for agent state.
    Serialize this → save to DB → restore → agent resumes.
    
    Think of it as the agent's "consciousness snapshot."
    """
    # Identity
    run_id: str
    agent_type: str
    user_id: str

    # Mission
    mission: str
    mission_context: Dict = field(default_factory=dict)

    # Status
    status: str = AgentStatus.CREATED.value
    created_at: str = field(
        default_factory=lambda: datetime.now().isoformat()
    )
    updated_at: str = field(
        default_factory=lambda: datetime.now().isoformat()
    )
    completed_at: Optional[str] = None

    # Planning
    plan: List[Dict] = field(default_factory=list)
    current_step_id: Optional[str] = None
    steps: Dict[str, Dict] = field(default_factory=dict)

    # Execution tracking
    tool_results: List[Dict] = field(default_factory=list)
    intermediate_outputs: Dict[str, Any] = field(default_factory=dict)

    # Conversation / reasoning trace
    messages: List[Dict] = field(default_factory=list)
    reasoning_trace: List[str] = field(default_factory=list)

    # Decisions made
    decisions: List[Dict] = field(default_factory=list)
    assumptions: List[str] = field(default_factory=list)

    # Resources
    tokens_used: int = 0
    token_budget: int = 100_000
    api_calls_made: int = 0

    # Error tracking
    error_count: int = 0
    last_error: Optional[str] = None
    errors: List[Dict] = field(default_factory=list)

    # Final output
    final_output: Optional[Any] = None
    success: Optional[bool] = None

    def update_timestamp(self):
        self.updated_at = datetime.now().isoformat()

    def add_step(
        self,
        name: str,
        description: str,
        depends_on: List[str] = None,
        requires_approval: bool = False
    ) -> StepState:
        """Add a new step to the plan."""
        step = StepState(
            step_id=str(uuid.uuid4()),
            step_number=len(self.steps) + 1,
            name=name,
            description=description,
            depends_on=depends_on or [],
            requires_approval=requires_approval
        )
        self.steps[step.step_id] = step.to_dict()
        self.plan.append({"step_id": step.step_id, "name": name})
        self.update_timestamp()
        return step

    def start_step(self, step_id: str):
        """Mark step as started."""
        if step_id in self.steps:
            step = self.steps[step_id]
            step["status"] = StepStatus.IN_PROGRESS.value
            step["started_at"] = datetime.now().isoformat()
            step["attempt_count"] = step.get("attempt_count", 0) + 1
            self.current_step_id = step_id
            self.update_timestamp()

    def complete_step(self, step_id: str, result: Any = None):
        """Mark step as completed with result."""
        if step_id in self.steps:
            step = self.steps[step_id]
            step["status"] = StepStatus.COMPLETED.value
            step["completed_at"] = datetime.now().isoformat()
            step["result"] = str(result)[:500] if result else None
            self.update_timestamp()

    def fail_step(self, step_id: str, error: str):
        """Mark step as failed."""
        if step_id in self.steps:
            step = self.steps[step_id]
            step["status"] = StepStatus.FAILED.value
            step["error_message"] = error
            self.error_count += 1
            self.last_error = error
            self.errors.append({
                "step_id": step_id,
                "error": error,
                "timestamp": datetime.now().isoformat()
            })
            self.update_timestamp()

    def add_tool_result(
        self,
        tool_name: str,
        input_data: Dict,
        output: Any,
        success: bool = True,
        execution_ms: int = 0
    ):
        """Record a tool call result."""
        self.tool_results.append({
            "tool_name": tool_name,
            "input": input_data,
            "output": str(output)[:1000],
            "success": success,
            "execution_ms": execution_ms,
            "timestamp": datetime.now().isoformat(),
            "step_id": self.current_step_id
        })
        self.api_calls_made += 1
        self.update_timestamp()

    def add_decision(self, decision: str, reasoning: str):
        """Record a decision made by the agent."""
        self.decisions.append({
            "decision": decision,
            "reasoning": reasoning,
            "timestamp": datetime.now().isoformat(),
            "step_id": self.current_step_id
        })
        self.reasoning_trace.append(
            f"DECISION: {decision} | REASON: {reasoning}"
        )
        self.update_timestamp()

    def set_intermediate_output(self, key: str, value: Any):
        """Store intermediate computation result."""
        self.intermediate_outputs[key] = {
            "value": value,
            "stored_at": datetime.now().isoformat(),
            "step_id": self.current_step_id
        }
        self.update_timestamp()

    def get_intermediate_output(self, key: str) -> Optional[Any]:
        """Retrieve an intermediate output."""
        entry = self.intermediate_outputs.get(key)
        return entry["value"] if entry else None

    def get_progress(self) -> Dict:
        """Get task progress summary."""
        total = len(self.steps)
        completed = sum(
            1 for s in self.steps.values()
            if s.get("status") == StepStatus.COMPLETED.value
        )
        failed = sum(
            1 for s in self.steps.values()
            if s.get("status") == StepStatus.FAILED.value
        )

        return {
            "total_steps": total,
            "completed": completed,
            "failed": failed,
            "pending": total - completed - failed,
            "progress_pct": round(completed / max(total, 1) * 100, 1),
            "token_budget_used_pct": round(
                self.tokens_used / max(self.token_budget, 1) * 100, 1
            )
        }

    def to_dict(self) -> Dict:
        """Serialize complete state to dictionary."""
        return asdict(self)

    @classmethod
    def from_dict(cls, data: Dict) -> "AgentState":
        """Restore state from dictionary."""
        return cls(**data)

    def to_json(self) -> str:
        """Serialize to JSON string."""
        return json.dumps(self.to_dict(), default=str, indent=2)

    @classmethod
    def from_json(cls, json_str: str) -> "AgentState":
        """Restore from JSON string."""
        return cls.from_dict(json.loads(json_str))


class StatePersistenceLayer:
    """
    Handles all persistence operations for agent state.
    
    Uses SQLite for local development.
    In production: swap to PostgreSQL.
    
    KEY OPERATIONS:
    save()    → Upsert current state to DB
    load()    → Restore state from DB
    list()    → List all runs for a user
    delete()  → Remove state (GDPR / cleanup)
    history() → Full audit trail of all state changes
    """

    def __init__(self, db_path: str = "./agent_states.db"):
        self.db_path = db_path
        self._initialize_db()
        print(f"✅ State Persistence Layer initialized: {db_path}")

    def _get_connection(self):
        conn = sqlite3.connect(self.db_path)
        conn.row_factory = sqlite3.Row
        conn.execute("PRAGMA journal_mode=WAL")
        return conn

    def _initialize_db(self):
        """Create tables for state storage."""
        with self._get_connection() as conn:
            conn.executescript("""
                -- Main state table: current state of each run
                CREATE TABLE IF NOT EXISTS agent_states (
                    run_id      TEXT PRIMARY KEY,
                    user_id     TEXT NOT NULL,
                    agent_type  TEXT NOT NULL,
                    mission     TEXT NOT NULL,
                    status      TEXT NOT NULL,
                    state_json  TEXT NOT NULL,
                    created_at  TEXT NOT NULL,
                    updated_at  TEXT NOT NULL,
                    version     INTEGER DEFAULT 1
                );

                -- State history: every state change recorded
                CREATE TABLE IF NOT EXISTS state_history (
                    id          INTEGER PRIMARY KEY AUTOINCREMENT,
                    run_id      TEXT NOT NULL,
                    user_id     TEXT NOT NULL,
                    version     INTEGER NOT NULL,
                    state_json  TEXT NOT NULL,
                    change_type TEXT NOT NULL,
                    saved_at    TEXT NOT NULL,
                    FOREIGN KEY (run_id)
                        REFERENCES agent_states(run_id)
                        ON DELETE CASCADE
                );

                -- Indexes for fast lookups
                CREATE INDEX IF NOT EXISTS idx_states_user
                    ON agent_states(user_id);
                CREATE INDEX IF NOT EXISTS idx_states_status
                    ON agent_states(status);
                CREATE INDEX IF NOT EXISTS idx_history_run
                    ON state_history(run_id);
            """)

    def save(
        self,
        state: AgentState,
        change_type: str = "update"
    ) -> int:
        """
        Save agent state to persistent storage.
        Returns the version number.
        
        Uses UPSERT: creates if new, updates if exists.
        Also saves to history table for full audit trail.
        """
        state.update_timestamp()
        state_json = state.to_json()

        with self._get_connection() as conn:
            # Get current version
            existing = conn.execute(
                "SELECT version FROM agent_states WHERE run_id = ?",
                (state.run_id,)
            ).fetchone()

            new_version = (existing["version"] + 1) if existing else 1

            # Upsert main state
            conn.execute("""
                INSERT INTO agent_states
                    (run_id, user_id, agent_type, mission, status,
                     state_json, created_at, updated_at, version)
                VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)
                ON CONFLICT(run_id) DO UPDATE SET
                    status     = excluded.status,
                    state_json = excluded.state_json,
                    updated_at = excluded.updated_at,
                    version    = excluded.version
            """, (
                state.run_id,
                state.user_id,
                state.agent_type,
                state.mission[:200],
                state.status,
                state_json,
                state.created_at,
                state.updated_at,
                new_version
            ))

            # Always save to history
            conn.execute("""
                INSERT INTO state_history
                    (run_id, user_id, version, state_json,
                     change_type, saved_at)
                VALUES (?, ?, ?, ?, ?, ?)
            """, (
                state.run_id,
                state.user_id,
                new_version,
                state_json,
                change_type,
                datetime.now().isoformat()
            ))

            conn.commit()

        return new_version

    def load(self, run_id: str) -> Optional[AgentState]:
        """Load and restore agent state from storage."""
        with self._get_connection() as conn:
            row = conn.execute(
                "SELECT state_json FROM agent_states WHERE run_id = ?",
                (run_id,)
            ).fetchone()

        if not row:
            return None

        return AgentState.from_json(row["state_json"])

    def load_latest_for_user(
        self,
        user_id: str,
        status_filter: List[str] = None
    ) -> Optional[AgentState]:
        """Load the most recent run for a user."""
        query = "SELECT state_json FROM agent_states WHERE user_id = ?"
        params = [user_id]

        if status_filter:
            placeholders = ",".join("?" * len(status_filter))
            query += f" AND status IN ({placeholders})"
            params.extend(status_filter)

        query += " ORDER BY updated_at DESC LIMIT 1"

        with self._get_connection() as conn:
            row = conn.execute(query, params).fetchone()

        return AgentState.from_json(row["state_json"]) if row else None

    def list_runs(
        self,
        user_id: str,
        limit: int = 20
    ) -> List[Dict]:
        """List all runs for a user with summary info."""
        with self._get_connection() as conn:
            rows = conn.execute("""
                SELECT run_id, agent_type, mission, status,
                       created_at, updated_at, version
                FROM agent_states
                WHERE user_id = ?
                ORDER BY created_at DESC
                LIMIT ?
            """, (user_id, limit)).fetchall()

        return [dict(row) for row in rows]

    def load_state_at_version(
        self,
        run_id: str,
        version: int
    ) -> Optional[AgentState]:
        """
        Load state at a SPECIFIC historical version.
        Powerful for debugging: "what was the agent thinking at step 3?"
        """
        with self._get_connection() as conn:
            row = conn.execute("""
                SELECT state_json FROM state_history
                WHERE run_id = ? AND version = ?
            """, (run_id, version)).fetchone()

        return AgentState.from_json(row["state_json"]) if row else None

    def get_state_diff(
        self,
        run_id: str,
        version_a: int,
        version_b: int
    ) -> Dict:
        """
        Compare two versions of state to see what changed.
        Essential for debugging agent behavior.
        """
        state_a = self.load_state_at_version(run_id, version_a)
        state_b = self.load_state_at_version(run_id, version_b)

        if not state_a or not state_b:
            return {}

        return {
            "version_a": version_a,
            "version_b": version_b,
            "status_changed": (
                state_a.status != state_b.status,
                f"{state_a.status} → {state_b.status}"
            ),
            "steps_completed": (
                sum(1 for s in state_b.steps.values()
                    if s.get("status") == "completed") -
                sum(1 for s in state_a.steps.values()
                    if s.get("status") == "completed")
            ),
            "new_tool_calls": (
                len(state_b.tool_results) - len(state_a.tool_results)
            ),
            "tokens_consumed": state_b.tokens_used - state_a.tokens_used,
        }

    def delete_run(self, run_id: str):
        """Delete a run and all its history."""
        with self._get_connection() as conn:
            conn.execute(
                "DELETE FROM agent_states WHERE run_id = ?",
                (run_id,)
            )
            conn.commit()

        print(f"   Resume from: step 2 (analyze)")

# 📸 CONCEPT 2: Checkpointing

## 1. What Is It?

> **Checkpointing = Saving a complete, restorable snapshot of agent state at specific TRIGGER POINTS during execution, so the agent can resume exactly from any checkpoint without repeating completed work.**

---

## 2. First-Principles: When Do You Checkpoint?

```
THE TRIGGER QUESTION:
"When should I save state?"

WRONG ANSWER: "Every message" → Too frequent → Expensive
WRONG ANSWER: "At the end" → Too late → No recovery during task
RIGHT ANSWER: "At meaningful, restorable boundaries"

GOOD CHECKPOINT TRIGGERS:
──────────────────────────────────────────────────
✅ After each step completes (natural boundaries)
✅ Before expensive/irreversible operations
   (before calling paid API, before deleting files)
✅ When token budget reaches 25%, 50%, 75%
✅ After getting human approval
✅ Before each LLM call (for perfect replay)
✅ On error (checkpoint the failure state for debugging)
✅ At time intervals (every 5 minutes for long tasks)
✅ Before yielding to human (pause point)

BAD CHECKPOINT TRIGGERS:
──────────────────────────────────────────────────
❌ Every single token generated (too expensive)
❌ Never (can't recover)
❌ Only at completion (doesn't help mid-task failures)
```

---

## 3. Analogy: Mountain Climbing Base Camps

```
🏔️ Checkpointing = Mountain Base Camps

Without base camps:
  Start at bottom → climb to top → ONE attempt
  If you fall at 80% → restart from the bottom
  Exhausting. Dangerous. Impractical.

With base camps:
  Base Camp 1: Checkpoint at 25% 
  Base Camp 2: Checkpoint at 50%
  Base Camp 3: Checkpoint at 75%
  
  Bad weather at 80%? Retreat to Base Camp 3 (75%)
  Resume from Base Camp 3 when weather clears
  Only lose 5% of progress, not 80%!

The KEY INSIGHT:
  Checkpoints are not just "saves."
  They are SAFE RESUME POINTS.
  Everything before a checkpoint is GUARANTEED.
  Resume from checkpoint = pick up with certainty.

In agents:
  Checkpoint after Step 3 completes
  → Steps 1-3 are GUARANTEED (don't redo them)
  → If Step 5 fails, resume from Step 3 checkpoint
  → Never redo expensive work (API calls, computations)
```

---

## 4. The Checkpoint Strategy Pattern

```
THREE CHECKPOINT STRATEGIES:

STRATEGY 1: EVENT-BASED (Recommended)
  Checkpoint when: specific events occur
  ✅ After each step
  ✅ Before irreversible actions
  ✅ On approval gates
  
  Pros: Checkpoint exactly when needed
  Cons: Must instrument all trigger points

STRATEGY 2: TIME-BASED
  Checkpoint every: N minutes
  ✅ Simple to implement
  ✅ Good for very long tasks
  
  Pros: Guaranteed max data loss of N minutes
  Cons: May checkpoint mid-step (partial state)

STRATEGY 3: HYBRID (Production Best Practice)
  Time-based: every 5 minutes (safety net)
  Event-based: after each step (precision)
  Pre-action: before each tool call
  
  Pros: Best of both worlds
  Cons: Most complex to implement
```

# checkpointing.py
import json
import os
import uuid
import time
import threading
import functools
from datetime import datetime
from typing import Any, Callable, Dict, List, Optional, TypeVar
from dataclasses import dataclass, asdict
from contextlib import contextmanager
from pathlib import Path


@dataclass
class Checkpoint:
    """
    A single checkpoint snapshot.
    Everything needed to restore the agent to this exact moment.
    """
    checkpoint_id: str
    run_id: str
    version: int
    trigger: str              # Why was this checkpoint created?
    step_id: Optional[str]    # Which step was active?
    state_snapshot: Dict      # Complete state at this moment
    created_at: str
    metadata: Dict

    # Checkpoint quality indicators
    is_clean: bool = True     # Was agent in clean state? (between steps)
    is_resumable: bool = True # Can we safely resume from here?

    def to_dict(self) -> Dict:
        return asdict(self)

    @classmethod
    def from_dict(cls, data: Dict) -> "Checkpoint":
        return cls(**data)


class CheckpointTrigger:
    """
    Defines WHEN checkpoints are automatically created.
    """
    STEP_COMPLETED    = "step_completed"
    STEP_FAILED       = "step_failed"
    BEFORE_TOOL_CALL  = "before_tool_call"
    AFTER_TOOL_CALL   = "after_tool_call"
    TOKEN_THRESHOLD   = "token_threshold"
    TIME_INTERVAL     = "time_interval"
    HUMAN_APPROVAL    = "human_approval"
    MANUAL            = "manual"
    BEFORE_IRREVERSIBLE = "before_irreversible"
    ERROR_STATE       = "error_state"
    MISSION_COMPLETE  = "mission_complete"


class CheckpointManager:
    """
    Complete checkpoint management system.

    FEATURES:
    ✅ Event-based checkpointing
    ✅ Time-based automatic checkpointing
    ✅ Smart resume (skip completed steps)
    ✅ Checkpoint comparison and diffing
    ✅ Storage management (keep N checkpoints)
    ✅ Resume validation (safe to resume?)
    """

    def __init__(
        self,
        persistence_layer,           # StatePersistenceLayer instance
        storage_path: str = "./checkpoints",
        max_checkpoints_per_run: int = 50,
        auto_checkpoint_interval_secs: int = 300  # 5 minutes
    ):
        self.persistence = persistence_layer
        self.storage_path = Path(storage_path)
        self.storage_path.mkdir(parents=True, exist_ok=True)
        self.max_checkpoints = max_checkpoints_per_run
        self.auto_interval = auto_checkpoint_interval_secs

        # In-memory checkpoint registry
        self.checkpoints: Dict[str, List[Checkpoint]] = {}

        # Auto-checkpoint background thread
        self._auto_checkpoint_enabled: Dict[str, bool] = {}
        self._auto_checkpoint_threads: Dict[str, threading.Thread] = {}

        print(f"✅ Checkpoint Manager initialized")
        print(f"   Storage: {storage_path}")
        print(f"   Auto-interval: {auto_checkpoint_interval_secs}s")
        print(f"   Max per run: {max_checkpoints_per_run}")

    def create_checkpoint(
        self,
        state: "AgentState",
        trigger: str = CheckpointTrigger.MANUAL,
        metadata: Dict = None,
        is_clean: bool = True
    ) -> Checkpoint:
        """
        Create and save a checkpoint.

        is_clean = True means the agent is between steps
        (not mid-step). Clean checkpoints are safest to resume from.
        """
        checkpoint_id = str(uuid.uuid4())

        # Save state to persistence layer first
        version = self.persistence.save(state, change_type=trigger)

        # Create checkpoint record
        checkpoint = Checkpoint(
            checkpoint_id=checkpoint_id,
            run_id=state.run_id,
            version=version,
            trigger=trigger,
            step_id=state.current_step_id,
            state_snapshot=state.to_dict(),
            created_at=datetime.now().isoformat(),
            metadata=metadata or {},
            is_clean=is_clean,
            is_resumable=self._validate_resumable(state)
        )

        # Save checkpoint to file
        checkpoint_file = (
            self.storage_path / f"{state.run_id}_{version}.json"
        )
        with open(checkpoint_file, "w") as f:
            json.dump(checkpoint.to_dict(), f, indent=2, default=str)

        # Register in memory
        if state.run_id not in self.checkpoints:
            self.checkpoints[state.run_id] = []
        self.checkpoints[state.run_id].append(checkpoint)

        # Prune old checkpoints if over limit
        self._prune_old_checkpoints(state.run_id)

        trigger_short = trigger.split("_")[-1].upper()
        progress = state.get_progress()
        print(
            f"  📸 Checkpoint [{trigger_short}] v{version} | "
            f"Progress: {progress['completed']}/{progress['total_steps']} | "
            f"Tokens: {state.tokens_used}"
        )

        return checkpoint

    def _validate_resumable(self, state: "AgentState") -> bool:
        """
        Check if state is safe to resume from.

        A state is NOT safely resumable if:
        - It's mid-step with partial tool results
        - There are unresolved errors
        - Token budget is exhausted
        """
        if state.tokens_used >= state.token_budget:
            return False
        if state.status == AgentStatus.FAILED.value:
            return False
        return True

    def get_latest_checkpoint(
        self,
        run_id: str,
        require_clean: bool = True
    ) -> Optional[Checkpoint]:
        """
        Get the most recent checkpoint for a run.

        require_clean = True returns the latest CLEAN checkpoint
        (safest for resumption — agent was between steps)
        """
        checkpoints = self.checkpoints.get(run_id, [])

        if not checkpoints:
            # Try loading from disk
            checkpoints = self._load_checkpoints_from_disk(run_id)

        if require_clean:
            clean_checkpoints = [
                cp for cp in checkpoints if cp.is_clean
            ]
            return clean_checkpoints[-1] if clean_checkpoints else None

        return checkpoints[-1] if checkpoints else None

    def restore_from_checkpoint(
        self,
        checkpoint: Checkpoint
    ) -> "AgentState":
        """
        Restore agent state from a checkpoint.

        This is the RESUME operation.
        After this, the agent can continue from exactly where it left off.
        """
        if not checkpoint.is_resumable:
            raise ValueError(
                f"Checkpoint {checkpoint.checkpoint_id} is marked "
                f"as not safely resumable!"
            )

        state = AgentState.from_dict(checkpoint.state_snapshot)
        state.status = AgentStatus.RESUMING.value
        state.update_timestamp()

        print(f"\n🔄 RESUMING FROM CHECKPOINT")
        print(f"   Checkpoint: {checkpoint.checkpoint_id}")
        print(f"   Created at: {checkpoint.created_at}")
        print(f"   Trigger: {checkpoint.trigger}")

        progress = state.get_progress()
        print(f"   Progress at checkpoint: "
              f"{progress['completed']}/{progress['total_steps']} steps")
        print(f"   Will resume from: step after last completed")

        return state

    def get_next_pending_step(
        self,
        state: "AgentState"
    ) -> Optional[str]:
        """
        After restoring from checkpoint, find the NEXT step to execute.

        SMART RESUME:
        → Skip all completed steps
        → Find first pending step whose dependencies are all met
        → This is where execution should continue
        """
        for step_id, step_data in state.steps.items():
            status = step_data.get("status", StepStatus.PENDING.value)

            if status != StepStatus.PENDING.value:
                continue

            # Check dependencies
            deps = step_data.get("depends_on", [])
            deps_met = all(
                state.steps.get(dep, {}).get("status") ==
                StepStatus.COMPLETED.value
                for dep in deps
            )

            if deps_met:
                return step_id

        return None  # All steps done or no available steps

    def start_auto_checkpoint(
        self,
        run_id: str,
        state_getter: Callable,  # Function that returns current state
        interval_secs: int = None
    ):
        """
        Start automatic time-based checkpointing in background.

        state_getter: A function you provide that returns current AgentState
        This is called periodically to snapshot the current state.

        Usage:
        manager.start_auto_checkpoint(
            run_id=state.run_id,
            state_getter=lambda: current_state,
            interval_secs=300
        )
        """
        interval = interval_secs or self.auto_interval
        self._auto_checkpoint_enabled[run_id] = True

        def auto_checkpoint_worker():
            while self._auto_checkpoint_enabled.get(run_id, False):
                time.sleep(interval)
                if not self._auto_checkpoint_enabled.get(run_id, False):
                    break
                try:
                    current_state = state_getter()
                    if current_state:
                        self.create_checkpoint(
                            current_state,
                            trigger=CheckpointTrigger.TIME_INTERVAL,
                            metadata={"interval_secs": interval},
                            is_clean=False  # Might be mid-step
                        )
                except Exception as e:
                    print(f"⚠️ Auto-checkpoint error: {e}")

        thread = threading.Thread(
            target=auto_checkpoint_worker,
            daemon=True,
            name=f"auto-checkpoint-{run_id[:8]}"
        )
        thread.start()
        self._auto_checkpoint_threads[run_id] = thread
        print(f"  ⏰ Auto-checkpoint started (every {interval}s)")

    def stop_auto_checkpoint(self, run_id: str):
        """Stop automatic checkpointing for a run."""
        self._auto_checkpoint_enabled[run_id] = False

    @contextmanager
    def step_checkpoint(
        self,
        state: "AgentState",
        step_id: str
    ):
        """
        Context manager for step-level checkpointing.

        USAGE:
        with checkpoint_manager.step_checkpoint(state, step_id):
            # Do step work here
            # Checkpoint created automatically on success/failure

        This ensures:
        → Checkpoint BEFORE step (for recovery)
        → Checkpoint AFTER step (record completion)
        → Checkpoint on failure (record error state)
        """
        # Pre-step checkpoint
        self.create_checkpoint(
            state,
            trigger=f"before_{step_id}",
            metadata={"step_id": step_id},
            is_clean=True
        )

        try:
            yield  # Execute step

            # Post-step success checkpoint
            self.create_checkpoint(
                state,
                trigger=CheckpointTrigger.STEP_COMPLETED,
                metadata={"step_id": step_id},
                is_clean=True
            )

        except Exception as e:
            # Error checkpoint
            self.create_checkpoint(
                state,
                trigger=CheckpointTrigger.ERROR_STATE,
                metadata={
                    "step_id": step_id,
                    "error": str(e)
                },
                is_clean=False  # Mid-step error = not clean
            )
            raise  # Re-raise the exception

    def _prune_old_checkpoints(self, run_id: str):
        """Keep only the N most recent checkpoints per run."""
        checkpoints = self.checkpoints.get(run_id, [])

        if len(checkpoints) > self.max_checkpoints:
            # Keep the FIRST checkpoint (baseline) and most recent
            to_remove = checkpoints[1:-self.max_checkpoints]

            for cp in to_remove:
                cp_file = (
                    self.storage_path /
                    f"{run_id}_{cp.version}.json"
                )
                if cp_file.exists():
                    cp_file.unlink()

            self.checkpoints[run_id] = (
                [checkpoints[0]] +   # Keep first (baseline)
                checkpoints[-self.max_checkpoints:]
            )

    def _load_checkpoints_from_disk(
        self,
        run_id: str
    ) -> List[Checkpoint]:
        """Load checkpoints from disk storage."""
        checkpoints = []
        pattern = f"{run_id}_*.json"

        for cp_file in sorted(self.storage_path.glob(pattern)):
            try:
                with open(cp_file, "r") as f:
                    data = json.load(f)
                checkpoints.append(Checkpoint.from_dict(data))
            except Exception:
                continue

        return sorted(checkpoints, key=lambda cp: cp.created_at)

    def list_checkpoints(self, run_id: str) -> List[Dict]:
        """List all checkpoints for a run with summary info."""
        checkpoints = (
            self.checkpoints.get(run_id)
            or self._load_checkpoints_from_disk(run_id)
        )

        return [{
            "checkpoint_id": cp.checkpoint_id,
            "version": cp.version,
            "trigger": cp.trigger,
            "created_at": cp.created_at,
            "is_clean": cp.is_clean,
            "is_resumable": cp.is_resumable,
            "step_id": cp.step_id
        } for cp in checkpoints]


# ── USAGE: Complete Agent with Checkpointing ────────────────────
class CheckpointedAgent:
    """
    An agent that uses checkpointing for reliability.
    Shows how state persistence + checkpointing work together.
    """

    def __init__(
        self,
        user_id: str,
        mission: str,
        run_id: str = None
    ):
        self.persistence = StatePersistenceLayer()
        self.checkpoint_mgr = CheckpointManager(self.persistence)

        # Try to resume existing run
        if run_id:
            existing = self.persistence.load(run_id)
            if existing:
                latest_cp = self.checkpoint_mgr.get_latest_checkpoint(
                    run_id, require_clean=True
                )
                if latest_cp:
                    self.state = self.checkpoint_mgr.restore_from_checkpoint(
                        latest_cp
                    )
                    print(f"✅ Resumed existing run: {run_id}")
                    return

        # Create new run
        self.state = AgentState(
            run_id=run_id or str(uuid.uuid4()),
            agent_type="checkpointed_agent",
            user_id=user_id,
            mission=mission
        )

        # Plan the mission
        self._plan()

        # Initial checkpoint
        self.checkpoint_mgr.create_checkpoint(
            self.state,
            trigger=CheckpointTrigger.MANUAL,
            metadata={"event": "agent_initialized"},
            is_clean=True
        )

        # Start auto-checkpointing every 2 minutes
        self.checkpoint_mgr.start_auto_checkpoint(
            run_id=self.state.run_id,
            state_getter=lambda: self.state,
            interval_secs=120
        )

        print(f"✅ New agent run: {self.state.run_id}")

    def _plan(self):
        """Create the execution plan."""
        self.step1 = self.state.add_step(
            "research", "Research the topic"
        )
        self.step2 = self.state.add_step(
            "analyze", "Analyze findings",
            depends_on=[self.step1.step_id]
        )
        self.step3 = self.state.add_step(
            "write", "Write final report",
            depends_on=[self.step2.step_id]
        )

    def execute_step(self, step_id: str):
        """Execute a step with automatic checkpointing."""
        with self.checkpoint_mgr.step_checkpoint(self.state, step_id):
            self.state.start_step(step_id)
            step_data = self.state.steps[step_id]

            print(f"\n▶️  Executing: {step_data['name']}")
            # ... actual step execution here ...
            time.sleep(0.1)  # Simulate work

            self.state.complete_step(step_id, "Step completed")
            print(f"  ✅ Completed: {step_data['name']}")

    def run(self):
        """Run all steps, resuming from checkpoint if available."""
        # Find the next step to execute (smart resume!)
        next_step = self.checkpoint_mgr.get_next_pending_step(self.state)

        if next_step is None:
            print("✅ All steps already completed!")
            return

        print(f"\n🚀 Running agent from step: {next_step}")
        self.state.status = AgentStatus.RUNNING.value

        # Execute each pending step in order
        for step_id, step_data in self.state.steps.items():
            status = step_data.get("status", "pending")

            if status == StepStatus.COMPLETED.value:
                print(f"  ⏭️  Skipping (already done): {step_data['name']}")
                continue

            self.execute_step(step_id)

        self.state.status = AgentStatus.COMPLETED.value
        self.checkpoint_mgr.create_checkpoint(
            self.state,
            trigger=CheckpointTrigger.MISSION_COMPLETE,
            is_clean=True
        )

        print(f"\n🎉 Mission complete!")
        print(f"   Run ID: {self.state.run_id}")
        print(f"   (Use this ID to inspect state later)")

# 🔒 CONCEPT 3: Thread-Level Isolation

## 1. What Is It?

> **Thread-Level Isolation = Each independent execution context (conversation thread, agent run, user session) has its OWN isolated memory space. Actions in one thread CANNOT accidentally read or modify memory in another thread.**

---

## 2. First-Principles: The Shared State Disaster

```
IMAGINE: Two users using the same AI agent simultaneously

USER A: "My name is Rahim"
USER B: "My name is Sara"

WITHOUT isolation:
  Agent stores: name = "Sara" (overwrites "Rahim"!)
  User A asks: "What's my name?"
  Agent: "Sara!" ← COMPLETELY WRONG! 😱
  
  This is a CRITICAL privacy and correctness violation.

WITH isolation:
  Thread A: {name: "Rahim", user_id: "rahim_123"}
  Thread B: {name: "Sara", user_id: "sara_456"}
  
  These NEVER interact. Completely separate.
  User A asks: "What's my name?"
  Agent reads Thread A context → "Rahim!" ✅

THREAD = An isolated execution context.
ISOLATION = The guarantee that threads don't bleed into each other.
```

---

## 3. Four Dimensions of Isolation

```
DIMENSION 1: USER ISOLATION
  User A's memories ≠ User B's memories
  Always scope queries: WHERE user_id = 'rahim_123'

DIMENSION 2: RUN ISOLATION
  Agent run #1 state ≠ Agent run #2 state
  Even for SAME user — different runs don't share working state

DIMENSION 3: TENANT ISOLATION (Multi-tenant apps)
  Company A's data ≠ Company B's data
  Even if using same AI system

DIMENSION 4: TIME ISOLATION
  Session 1 (yesterday) ≠ Session 2 (today)
  Current working context doesn't inherit old session's variables
```

# thread_isolation.py
import threading
import uuid
import hashlib
from datetime import datetime
from typing import Any, Dict, List, Optional
from contextlib import contextmanager
from dataclasses import dataclass, field
from functools import wraps


@dataclass
class ThreadContext:
    """
    The complete identity context for an isolated thread.
    Every thread MUST have one of these.
    """
    thread_id: str             # Unique ID for this execution thread
    user_id: str               # Who owns this thread
    run_id: str                # Which agent run this belongs to
    tenant_id: str = "default" # Which organization/tenant
    session_id: str = ""       # Which conversation session

    # Access control
    allowed_scopes: List[str] = field(default_factory=lambda: [
        "read_own_memory",
        "write_own_memory",
        "read_shared_tools"
    ])

    # Lifecycle
    created_at: str = field(
        default_factory=lambda: datetime.now().isoformat()
    )
    last_active: str = field(
        default_factory=lambda: datetime.now().isoformat()
    )
    is_active: bool = True

    def scope_key(self, resource_type: str) -> str:
        """
        Generate a SCOPED storage key.
        Every storage operation uses this key to prevent cross-thread access.
        
        Format: {tenant}:{user}:{run}:{resource_type}
        
        This makes it STRUCTURALLY IMPOSSIBLE to accidentally
        read another user's data — you'd have to have their exact
        tenant + user + run ID combination.
        """
        components = [
            self.tenant_id,
            self.user_id,
            self.run_id,
            resource_type
        ]
        return ":".join(components)

    def memory_filter(self) -> Dict:
        """
        Return the filter dict that MUST be applied to ALL memory queries.
        This is the core of privacy enforcement.
        """
        return {
            "user_id": self.user_id,
            "tenant_id": self.tenant_id
        }

    def can_access(self, scope: str) -> bool:
        """Check if this thread has access to a scope."""
        return scope in self.allowed_scopes

    def touch(self):
        """Update last active timestamp."""
        self.last_active = datetime.now().isoformat()


# Thread-local storage for context propagation
_thread_local = threading.local()


class ThreadContextManager:
    """
    Manages thread context creation, storage, and retrieval.
    
    DESIGN PATTERN: Context Propagation
    Every function in the call chain can access the current
    thread context without explicitly passing it as parameter.
    
    Like React's Context API, but for Python threads.
    """

    def __init__(self):
        self._contexts: Dict[str, ThreadContext] = {}
        self._lock = threading.Lock()

    def create_context(
        self,
        user_id: str,
        run_id: str = None,
        tenant_id: str = "default",
        session_id: str = None,
        extra_scopes: List[str] = None
    ) -> ThreadContext:
        """
        Create a new isolated thread context.
        Call this at the start of every agent run.
        """
        thread_id = str(uuid.uuid4())

        context = ThreadContext(
            thread_id=thread_id,
            user_id=user_id,
            run_id=run_id or str(uuid.uuid4()),
            tenant_id=tenant_id,
            session_id=session_id or str(uuid.uuid4()),
            allowed_scopes=[
                "read_own_memory",
                "write_own_memory",
                "read_shared_tools",
            ] + (extra_scopes or [])
        )

        with self._lock:
            self._contexts[thread_id] = context

        return context

    @contextmanager
    def active_context(self, context: ThreadContext):
        """
        Context manager that sets the active thread context.
        
        USAGE:
        ctx = thread_mgr.create_context(user_id="rahim_123")
        with thread_mgr.active_context(ctx):
            # All memory operations in here use this context automatically
            agent.execute()
        """
        # Set context in thread-local storage
        old_context = getattr(_thread_local, "context", None)
        _thread_local.context = context

        try:
            yield context
        finally:
            # Restore previous context (handles nested contexts)
            _thread_local.context = old_context
            context.is_active = False

    @staticmethod
    def get_current() -> Optional[ThreadContext]:
        """
        Get the currently active thread context.
        Returns None if no context is active.
        """
        return getattr(_thread_local, "context", None)

    @staticmethod
    def require_current() -> ThreadContext:
        """
        Get current context or raise error if none.
        Use this in functions that REQUIRE a context.
        """
        ctx = getattr(_thread_local, "context", None)
        if ctx is None:
            raise RuntimeError(
                "No active thread context! "
                "Wrap your code with: "
                "'with thread_mgr.active_context(ctx):'"
            )
        return ctx


def require_thread_context(func):
    """
    Decorator that ENFORCES thread context isolation.
    Any function decorated with this MUST be called within
    an active thread context.
    
    Prevents accidental cross-context data access.
    
    USAGE:
    @require_thread_context
    def get_user_memories(query: str):
        ctx = ThreadContextManager.get_current()
        # ctx is guaranteed to be valid here
        return memory_store.search(user_id=ctx.user_id, query=query)
    """
    @wraps(func)
    def wrapper(*args, **kwargs):
        ctx = ThreadContextManager.get_current()
        if ctx is None:
            raise RuntimeError(
                f"Function '{func.__name__}' requires thread context. "
                f"Call within 'with thread_mgr.active_context(ctx):'"
            )
        ctx.touch()  # Update activity timestamp
        return func(*args, **kwargs)
    return wrapper


class IsolatedMemoryStore:
    """
    A memory store with BUILT-IN thread isolation.
    
    DESIGN: Every operation REQUIRES a ThreadContext.
    The store ENFORCES that you can only access your own data.
    
    This makes cross-thread contamination STRUCTURALLY IMPOSSIBLE —
    not just "hopefully won't happen" but "literally cannot happen."
    """

    def __init__(self, backend_store):
        """
        backend_store: Your actual storage (ChromaDB, SQL, etc.)
        """
        self.backend = backend_store
        self._isolation_violations = []  # Audit log of attempts

    def _validate_context(
        self,
        context: ThreadContext,
        required_scope: str
    ) -> bool:
        """Validate that context has required scope."""
        if not context.can_access(required_scope):
            violation = {
                "thread_id": context.thread_id,
                "user_id": context.user_id,
                "attempted_scope": required_scope,
                "timestamp": datetime.now().isoformat()
            }
            self._isolation_violations.append(violation)

            raise PermissionError(
                f"Thread {context.thread_id} (user: {context.user_id}) "
                f"does not have scope: {required_scope}"
            )
        return True

    @require_thread_context
    def store_memory(
        self,
        text: str,
        metadata: Dict = None,
        context: ThreadContext = None
    ) -> str:
        """
        Store a memory. Thread context is AUTOMATICALLY enforced.
        """
        ctx = context or ThreadContextManager.require_current()
        self._validate_context(ctx, "write_own_memory")

        # FORCE user_id and tenant_id into metadata
        # Even if caller tries to write for another user → BLOCKED!
        safe_metadata = {
            **(metadata or {}),
            "user_id": ctx.user_id,          # ENFORCED!
            "tenant_id": ctx.tenant_id,       # ENFORCED!
            "thread_id": ctx.thread_id,
            "run_id": ctx.run_id,
            "stored_at": datetime.now().isoformat()
        }

        memory_id = str(uuid.uuid4())

        if hasattr(self.backend, 'store'):
            self.backend.store(
                memory_id=memory_id,
                text=text,
                metadata=safe_metadata
            )

        return memory_id

    @require_thread_context
    def search_memories(
        self,
        query: str,
        n_results: int = 5,
        context: ThreadContext = None
    ) -> List[Dict]:
        """
        Search memories. ALWAYS scoped to current thread's user.
        """
        ctx = context or ThreadContextManager.require_current()
        self._validate_context(ctx, "read_own_memory")

        # FORCE the user_id filter — cannot be overridden!
        forced_filters = ctx.memory_filter()

        if hasattr(self.backend, 'search'):
            return self.backend.search(
                query=query,
                n_results=n_results,
                filters=forced_filters  # ENFORCED user scoping
            )

        return []

    def get_isolation_audit(self) -> List[Dict]:
        """Get log of all isolation violation attempts."""
        return self._isolation_violations


class ThreadPool:
    """
    Manages multiple concurrent agent threads with isolation.
    
    Enables:
    ✅ Multiple agents running simultaneously
    ✅ Complete isolation between agents
    ✅ Resource limits per thread
    ✅ Monitoring and cancellation
    """

    def __init__(
        self,
        max_concurrent_threads: int = 10
    ):
        self.max_concurrent = max_concurrent_threads
        self.context_manager = ThreadContextManager()
        self.active_threads: Dict[str, ThreadContext] = {}
        self._lock = threading.RLock()

    def spawn_thread(
        self,
        user_id: str,
        run_id: str = None,
        tenant_id: str = "default"
    ) -> ThreadContext:
        """
        Spawn a new isolated thread.
        Enforces concurrent thread limit per user.
        """
        with self._lock:
            # Count active threads for this user
            user_thread_count = sum(
                1 for ctx in self.active_threads.values()
                if ctx.user_id == user_id and ctx.is_active
            )

            if user_thread_count >= self.max_concurrent:
                raise RuntimeError(
                    f"User {user_id} has reached max concurrent "
                    f"thread limit: {self.max_concurrent}"
                )

            context = self.context_manager.create_context(
                user_id=user_id,
                run_id=run_id,
                tenant_id=tenant_id
            )

            self.active_threads[context.thread_id] = context
            print(
                f"  🧵 Thread spawned: {context.thread_id[:8]}... "
                f"(user: {user_id}, "
                f"active: {len(self.active_threads)})"
            )
            return context

    def terminate_thread(self, thread_id: str):
        """Terminate and clean up a thread."""
        with self._lock:
            if thread_id in self.active_threads:
                self.active_threads[thread_id].is_active = False
                del self.active_threads[thread_id]
                print(f"  🛑 Thread terminated: {thread_id[:8]}...")

    def get_active_threads(
        self,
        user_id: str = None
    ) -> List[Dict]:
        """List active threads, optionally filtered by user."""
        with self._lock:
            threads = []
            for ctx in self.active_threads.values():
                if user_id and ctx.user_id != user_id:
                    continue
                threads.append({
                    "thread_id": ctx.thread_id,
                    "user_id": ctx.user_id,
                    "run_id": ctx.run_id,
                    "created_at": ctx.created_at,
                    "last_active": ctx.last_active
                })
            return threads

# 🤝 CONCEPT 4: Multi-Agent Shared Memory

## 1. What Is It?

> **Multi-Agent Shared Memory = A controlled, structured system where multiple AI agents can READ from and WRITE to common memory spaces, enabling collaboration — while preventing conflicts, corruption, and unauthorized access.**

---

## 2. First-Principles: Why Multi-Agent Memory Is Hard

```
SINGLE AGENT: Simple
  One agent reads memory → processes → writes memory
  No conflicts. No race conditions. Clean.

MULTI-AGENT: Hard
  Agent A reads "task status: pending"
  Agent B reads "task status: pending"
  Agent A starts working on task
  Agent B ALSO starts working on same task!
  Agent A writes result
  Agent B overwrites with DIFFERENT result
  CONFLICT! Data corruption! 😱

This is the classic distributed systems problem:
"Concurrent writes to shared mutable state"

Solutions from distributed systems:
1. Locks (only one writer at a time)
2. Versioning (detect conflicts before write)
3. Partitioning (different agents own different memory regions)
4. Message passing (agents communicate through queues, not shared state)
```

---

## 3. Analogy: The Hospital Whiteboard System

```
🏥 Multi-Agent Memory = Hospital Whiteboard System

PROBLEM:
  Doctor, Nurse, and Pharmacist all need to see
  and update patient information.
  Three people → Same information → Coordination needed.

NAIVE APPROACH (chaos):
  All three can write on the whiteboard anytime
  → Doctor writes treatment plan
  → Nurse updates vitals simultaneously
  → Whiteboard becomes messy, conflicting information
  → Medical error risk! 😱

PROPER SYSTEM:
  SHARED MEMORY (whiteboard):
    ✅ All can READ it freely
    
  WRITE RULES:
    Doctor OWNS treatment section (only they write there)
    Nurse OWNS vitals section (only they write there)
    Pharmacist OWNS medication section
    
  COORDINATION:
    Big decisions require consultation
    Changes logged with WHO changed WHAT WHEN
    Conflicts resolved by supervisor

MULTI-AGENT MEMORY = Hospital Whiteboard System
  Each agent owns its section
  Shared read of everything
  Controlled writes with locking
  Full audit trail
```

---

## 4. Memory Space Types in Multi-Agent Systems

```
THREE TYPES OF MEMORY SPACES:

┌──────────────────────────────────────────────────────────────┐
│                    MEMORY SPACE TYPES                        │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  PRIVATE SPACE (Agent-owned):                                │
│  → Only that agent can read AND write                        │
│  → Used for: working state, intermediate results             │
│  → Example: Research agent's search_results variable        │
│                                                              │
│  SHARED READ-ONLY (Global knowledge):                        │
│  → All agents can read, no agent can write                   │
│  → Used for: global facts, user profile, domain knowledge   │
│  → Example: "User's name is Rahim" — all agents know this   │
│                                                              │
│  COLLABORATIVE SPACE (Controlled writes):                    │
│  → All agents can read                                       │
│  → Agents can write to specific sections they OWN           │
│  → Requires locking for conflicting writes                   │
│  → Used for: shared task state, handoff data                │
│  → Example: "Report draft" — writer agent owns it           │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

# multi_agent_memory.py
import threading
import uuid
import time
import json
from datetime import datetime
from typing import Any, Dict, List, Optional, Set
from dataclasses import dataclass, field
from enum import Enum
from collections import defaultdict


class MemoryAccessLevel(Enum):
    """Access levels for memory sections."""
    PRIVATE       = "private"        # Only owner can access
    SHARED_READ   = "shared_read"    # All can read, none can write
    COLLABORATIVE = "collaborative"  # All can read, owner can write


class WriteConflictStrategy(Enum):
    """How to handle write conflicts."""
    REJECT          = "reject"          # Reject conflicting write
    LAST_WRITE_WINS = "last_write_wins" # Override (dangerous!)
    VERSIONED       = "versioned"       # Use versioning
    MERGE           = "merge"           # Try to merge (LLM-based)


@dataclass
class MemorySection:
    """
    A named section of the shared memory space.
    Each section has an owner and access policy.
    """
    section_id: str
    name: str
    owner_agent_id: str
    access_level: str
    content: Dict = field(default_factory=dict)
    version: int = 0
    last_modified_by: str = ""
    last_modified_at: str = ""
    read_count: int = 0
    write_count: int = 0


@dataclass
class MemoryWriteRequest:
    """
    A request to write to shared memory.
    Must go through the MemoryCoordinator for conflict resolution.
    """
    request_id: str
    agent_id: str
    section_id: str
    key: str
    value: Any
    expected_version: int     # Optimistic locking!
    timestamp: str = field(
        default_factory=lambda: datetime.now().isoformat()
    )
    reason: str = ""          # WHY is this agent writing this?


@dataclass
class WriteResult:
    """Result of a write operation."""
    success: bool
    new_version: int
    conflict_detected: bool = False
    conflict_details: str = ""
    merged_value: Any = None


class MemoryCoordinator:
    """
    Central coordinator for multi-agent memory access.

    RESPONSIBILITIES:
    1. Enforce access control (who can read/write what)
    2. Handle write conflicts (versioning, locking)
    3. Provide read consistency (no dirty reads)
    4. Maintain audit log (who wrote what when)
    5. Enable agent handoffs (pass context between agents)

    DESIGN: Inspired by Git's optimistic concurrency control
    Each write specifies the expected version.
    If actual version ≠ expected version → CONFLICT!
    """

    def __init__(
        self,
        conflict_strategy: WriteConflictStrategy = WriteConflictStrategy.VERSIONED
    ):
        self.conflict_strategy = conflict_strategy

        # Memory sections registry
        self.sections: Dict[str, MemorySection] = {}

        # Read-write locks for each section
        self._section_locks: Dict[str, threading.RLock] = defaultdict(
            threading.RLock
        )

        # Registered agents
        self.registered_agents: Dict[str, Dict] = {}

        # Full audit log
        self.audit_log: List[Dict] = []

        # Subscriptions (agents watching for changes)
        self._subscribers: Dict[str, List[str]] = defaultdict(list)

        print("✅ Memory Coordinator initialized")

    def register_agent(
        self,
        agent_id: str,
        agent_type: str,
        capabilities: List[str] = None
    ):
        """Register an agent with the coordinator."""
        self.registered_agents[agent_id] = {
            "agent_id": agent_id,
            "agent_type": agent_type,
            "capabilities": capabilities or [],
            "registered_at": datetime.now().isoformat(),
            "sections_owned": [],
            "sections_accessible": []
        }
        print(f"  🤖 Agent registered: {agent_id} ({agent_type})")

    def create_section(
        self,
        owner_agent_id: str,
        name: str,
        access_level: MemoryAccessLevel = MemoryAccessLevel.COLLABORATIVE,
        initial_content: Dict = None
    ) -> MemorySection:
        """
        Create a new memory section.
        The creating agent becomes the OWNER.
        Only owners can write to COLLABORATIVE sections.
        """
        section_id = str(uuid.uuid4())

        section = MemorySection(
            section_id=section_id,
            name=name,
            owner_agent_id=owner_agent_id,
            access_level=access_level.value,
            content=initial_content or {},
            last_modified_by=owner_agent_id,
            last_modified_at=datetime.now().isoformat()
        )

        self.sections[section_id] = section

        # Track section in owner's profile
        if owner_agent_id in self.registered_agents:
            self.registered_agents[owner_agent_id]["sections_owned"].append(
                section_id
            )

        print(
            f"  📁 Section created: '{name}' "
            f"(owner: {owner_agent_id[:12]}..., "
            f"access: {access_level.value})"
        )

        return section

    def read(
        self,
        requesting_agent_id: str,
        section_id: str,
        key: str = None
    ) -> Optional[Any]:
        """
        Read from a memory section.

        Access rules:
        PRIVATE: Only owner can read
        SHARED_READ: All registered agents can read
        COLLABORATIVE: All registered agents can read
        """
        with self._section_locks[section_id]:
            section = self.sections.get(section_id)
            if not section:
                return None

            # Check access
            if section.access_level == MemoryAccessLevel.PRIVATE.value:
                if requesting_agent_id != section.owner_agent_id:
                    raise PermissionError(
                        f"Agent {requesting_agent_id} cannot read private "
                        f"section owned by {section.owner_agent_id}"
                    )

            # Check agent is registered
            if requesting_agent_id not in self.registered_agents:
                raise ValueError(
                    f"Unknown agent: {requesting_agent_id}. Register first!"
                )

            # Update stats
            section.read_count += 1

            # Log access
            self._log_access("read", requesting_agent_id, section_id, key)

            if key:
                return section.content.get(key)
            return section.content.copy()

    def write(
        self,
        request: MemoryWriteRequest
    ) -> WriteResult:
        """
        Write to a memory section with conflict detection.

        OPTIMISTIC LOCKING PATTERN:
        1. Agent reads current version (e.g., version=5)
        2. Agent computes new value
        3. Agent writes with expected_version=5
        4. If actual version is STILL 5 → write succeeds, version becomes 6
        5. If actual version is 6 (someone else wrote!) → CONFLICT!

        This is the same pattern Git uses for commit detection!
        """
        with self._section_locks[request.section_id]:
            section = self.sections.get(request.section_id)
            if not section:
                return WriteResult(
                    success=False, new_version=0,
                    conflict_details=f"Section {request.section_id} not found"
                )

            # Check write permission
            if section.access_level == MemoryAccessLevel.SHARED_READ.value:
                return WriteResult(
                    success=False, new_version=section.version,
                    conflict_details="Section is read-only"
                )

            if section.access_level in (
                MemoryAccessLevel.PRIVATE.value,
                MemoryAccessLevel.COLLABORATIVE.value
            ):
                if request.agent_id != section.owner_agent_id:
                    return WriteResult(
                        success=False, new_version=section.version,
                        conflict_details=(
                            f"Only owner {section.owner_agent_id} can "
                            f"write to this section"
                        )
                    )

            # VERSION CHECK (Optimistic Locking!)
            if request.expected_version != section.version:
                conflict_msg = (
                    f"Version conflict: expected {request.expected_version}, "
                    f"actual {section.version}. "
                    f"Another agent wrote between your read and write!"
                )

                if self.conflict_strategy == WriteConflictStrategy.REJECT:
                    self._log_access(
                        "write_conflict", request.agent_id,
                        request.section_id, request.key
                    )
                    return WriteResult(
                        success=False,
                        new_version=section.version,
                        conflict_detected=True,
                        conflict_details=conflict_msg
                    )

                elif self.conflict_strategy == WriteConflictStrategy.LAST_WRITE_WINS:
                    # Override anyway (USE WITH CAUTION!)
                    pass  # Fall through to write

            # Perform the write
            section.content[request.key] = request.value
            section.version += 1
            section.write_count += 1
            section.last_modified_by = request.agent_id
            section.last_modified_at = datetime.now().isoformat()

            self._log_access(
                "write", request.agent_id, request.section_id,
                request.key, reason=request.reason
            )

            # Notify subscribers
            self._notify_subscribers(
                request.section_id, request.agent_id, request.key
            )

            return WriteResult(
                success=True,
                new_version=section.version
            )

    def handoff(
        self,
        from_agent_id: str,
        to_agent_id: str,
        handoff_data: Dict,
        handoff_note: str = ""
    ) -> str:
        """
        Structured agent handoff with memory transfer.

        WHEN: Agent A completes its work and passes to Agent B
        WHAT: Creates a new COLLABORATIVE section that Agent B can read
              and adds the handoff data with provenance

        PROVENANCE: Who produced this data and why?
        Critical for multi-agent trust chains.
        """
        # Create handoff section (Agent B reads this)
        handoff_section = self.create_section(
            owner_agent_id=to_agent_id,  # To-agent gets ownership
            name=f"handoff_{from_agent_id[:8]}_to_{to_agent_id[:8]}",
            access_level=MemoryAccessLevel.COLLABORATIVE,
            initial_content={
                "from_agent": from_agent_id,
                "to_agent": to_agent_id,
                "data": handoff_data,
                "note": handoff_note,
                "handoff_at": datetime.now().isoformat(),
                "provenance": {
                    "produced_by": from_agent_id,
                    "at": datetime.now().isoformat(),
                    "reason": handoff_note
                }
            }
        )

        self._log_access(
            "handoff", from_agent_id, handoff_section.section_id,
            reason=f"Handoff to {to_agent_id}: {handoff_note}"
        )

        print(
            f"\n  🤝 HANDOFF: {from_agent_id[:12]} → {to_agent_id[:12]}"
        )
        print(f"     Note: {handoff_note}")
        print(f"     Data keys: {list(handoff_data.keys())}")

        return handoff_section.section_id

    def subscribe_to_changes(
        self,
        agent_id: str,
        section_id: str
    ):
        """
        Subscribe to changes in a memory section.
        Agent gets notified when the section is modified.
        """
        if agent_id not in self._subscribers[section_id]:
            self._subscribers[section_id].append(agent_id)

    def _notify_subscribers(
        self,
        section_id: str,
        writer_agent_id: str,
        key: str
    ):
        """Notify all subscribers of a change."""
        subscribers = self._subscribers.get(section_id, [])
        for subscriber_id in subscribers:
            if subscriber_id != writer_agent_id:
                print(
                    f"  📣 Notified {subscriber_id[:12]}... "
                    f"of change to section {section_id[:8]}... "
                    f"key: {key}"
                )

    def _log_access(
        self,
        operation: str,
        agent_id: str,
        section_id: str,
        key: str = None,
        reason: str = ""
    ):
        """Append to audit log."""
        self.audit_log.append({
            "operation": operation,
            "agent_id": agent_id,
            "section_id": section_id,
            "key": key,
            "reason": reason,
            "timestamp": datetime.now().isoformat()
        })

    def get_audit_log(
        self,
        agent_id: str = None,
        section_id: str = None,
        last_n: int = 50
    ) -> List[Dict]:
        """Get filtered audit log."""
        logs = self.audit_log

        if agent_id:
            logs = [l for l in logs if l["agent_id"] == agent_id]
        if section_id:
            logs = [l for l in logs if l["section_id"] == section_id]

        return logs[-last_n:]

    def show_memory_map(self):
        """Visual representation of the shared memory space."""
        print(f"\n{'='*60}")
        print("SHARED MEMORY MAP")
        print(f"{'='*60}")

        for section in self.sections.values():
            access_icons = {
                "private": "🔒",
                "shared_read": "📖",
                "collaborative": "🤝"
            }
            icon = access_icons.get(section.access_level, "❓")

            print(f"\n{icon} Section: {section.name}")
            print(f"   Owner:   {section.owner_agent_id[:16]}...")
            print(f"   Access:  {section.access_level}")
            print(f"   Version: v{section.version}")
            print(f"   Keys:    {list(section.content.keys())}")
            print(f"   Reads:   {section.read_count}  "
                  f"Writes: {section.write_count}")

        print(f"\nTotal audit log entries: {len(self.audit_log)}")
        print(f"{'='*60}\n")

# 👤 CONCEPT 5: Human-in-the-Loop Memory Updates

## 1. What Is It?

> **Human-in-the-Loop (HITL) Memory Updates = A system where AI agents pause at critical decision points and REQUEST human review, correction, or approval of their memory state before proceeding — especially before irreversible actions.**

---

## 2. First-Principles: When AI Cannot Decide Alone

```
THE FUNDAMENTAL TRUTH:
AI agents are POWERFUL but they can be WRONG.
When they're wrong about a FACT that shapes their actions,
the consequences can be serious.

EXAMPLES OF DANGEROUS MEMORY ERRORS:
  Memory: "Client budget is $5,000"    ← Actually $50,000
  Agent action: Proposes $4,000 solution
  Result: Wildly undersells, client confused 😱

  Memory: "User wants Python solution" ← Actually they said Go
  Agent: Writes 500 lines of Python
  Result: Wasted hours, frustrated user 😱

  Memory: "Delete old records after 30 days"
  Agent: Starts deleting records
  Memory was WRONG: Policy is 365 days!
  Result: Catastrophic data loss 😱

FOR THESE CASES:
  Human must be able to:
  1. SEE what the agent believes (inspect memory)
  2. CORRECT wrong memories BEFORE the agent acts
  3. APPROVE actions before they happen
  4. AUDIT what happened after the fact
  5. OVERRIDE agent decisions at any point
```

---

## 3. Analogy: The New Employee Approval System

```
👔 HITL = New Employee Approval Workflow

A new employee (AI agent) is capable but:
  → Might misremember meeting outcomes
  → Might have outdated information
  → Shouldn't send important emails without review
  → Shouldn't delete files without approval

WORKFLOW:
  New employee: "I'm going to email the client with this proposal"
  ↓
  Manager sees: [PENDING APPROVAL: email to client]
  Manager reviews the proposal and the memory it's based on:
    "Wait — you have the budget as $5k. It's $50k. Fix this."
  ↓
  Employee updates memory: {budget: "$50,000"}
  Employee: "Updated! Shall I send now?"
  Manager: "Yes, approved."
  ↓
  Email sent ✅

This is EXACTLY what HITL memory updates look like.
The "manager" is the human user.
The "employee" is the AI agent.
```

from enum import Enum


class HITLTrigger(Enum):
    """When to request human input."""
    BEFORE_IRREVERSIBLE  = "before_irreversible"
    MEMORY_UNCERTAINTY   = "memory_uncertainty"
    HIGH_STAKES_DECISION = "high_stakes_decision"

    REJECT     = "reject"
    MODIFY     = "modify"
    DELEGATE   = "delegate"
    POSTPONE   = "postpone"


@dataclass
class HITLRequest:
    """
    A request for human review/approval.
    Created by the AI agent, resolved by a human.
    """
    request_id: str
    run_id: str
    agent_id: str
    user_id: str

    title: str
    description: str

    # Risk assessment
    risk_level: str             # low, medium, high, critical
    is_reversible: bool         # Can this action be undone?
    estimated_impact: str       # What happens if approved/rejected?

    # Status tracking
    status: str = "pending"     # pending, approved, rejected, modified
    created_at: str = field(
        default_factory=lambda: datetime.now().isoformat()
    )
    expires_at: Optional[str] = None    # Auto-reject if not reviewed by

    # Human response
    human_response: Optional[str] = None
    human_action: Optional[str] = None
    memory_corrections: Dict = field(default_factory=dict)
    resolved_at: Optional[str] = None
    resolved_by: Optional[str] = None


@dataclass
class MemoryCorrection:
    """
    A human-provided correction to agent memory.
    """
    correction_id: str
    run_id: str
    request_id: str
    user_id: str

    # What was wrong and what the correct value is
    memory_path: str        # e.g., "intermediate_outputs.budget"
    old_value: Any          # What the agent had
    new_value: Any          # What it should be
    correction_reason: str
    corrected_by: str

class HITLMemoryManager:
    """
    Complete Human-in-the-Loop memory management system.

    CAPABILITIES:
    ✅ Create review requests with full context
    ✅ Pause agent execution at approval gates
    ✅ Apply human memory corrections
    ✅ Track all human interventions
    ✅ Notify humans of pending requests
    ✅ Auto-reject expired requests
    ✅ Learn from corrections over time
    """

    def __init__(
        self,
        notification_callback: Callable = None,
        auto_approve_low_risk: bool = False
    ):
        """
        notification_callback: Function to call when human review needed
                               (e.g., send email, push notification, UI update)
        auto_approve_low_risk: Automatically approve low-risk requests
        """
        self.notification_callback = notification_callback
        self.auto_approve_low_risk = auto_approve_low_risk

        # Pending requests awaiting human review
        self.pending_requests: Dict[str, HITLRequest] = {}

        # Historical requests (resolved)
        self.resolved_requests: List[HITLRequest] = []

        # Corrections applied to agents
        self.corrections_log: List[MemoryCorrection] = []

        # Learned patterns from corrections
        self.correction_patterns: Dict[str, List] = {}

        print("✅ HITL Memory Manager initialized")

    def create_review_request(
        self,
        state: "AgentState",
        trigger: HITLTrigger,
        title: str,
        description: str,
        proposed_action: str,
        action_payload: Dict,
        risk_level: str = "medium",
        is_reversible: bool = True,
        estimated_impact: str = "",
        memory_keys_to_review: List[str] = None
    ) -> HITLRequest:
        """
        Create a review request and pause agent execution.
        The agent MUST wait for human response before proceeding.
        """
        # Build the memory state snapshot for human review
        memory_state = {
            "mission": state.mission,
            "current_step": state.current_step_id,
            "progress": state.get_progress(),
            "key_decisions": state.decisions[-5:],
            "recent_tool_results": state.tool_results[-3:],
            "intermediate_outputs": {}
        }

        # Include specific memory keys if requested
        if memory_keys_to_review:
            for key in memory_keys_to_review:
                output = state.get_intermediate_output(key)
                if output is not None:
                    memory_state["intermediate_outputs"][key] = output

        request = HITLRequest(
            request_id=str(uuid.uuid4()),
            run_id=state.run_id,
            agent_id=state.agent_type,
            user_id=state.user_id,
            trigger=trigger.value,
            title=title,
            description=description,
            memory_state=memory_state,
            proposed_action=proposed_action,
            action_payload=action_payload,
            risk_level=risk_level,
            is_reversible=is_reversible,
            estimated_impact=estimated_impact
        )

        # Auto-approve if low risk and enabled
        if self.auto_approve_low_risk and risk_level == "low":
            request.status = "approved"
            request.human_action = HITLAction.APPROVE.value
            request.resolved_at = datetime.now().isoformat()
            request.resolved_by = "system_auto"
            print(f"  ✅ Auto-approved low-risk request: {title}")
            self.resolved_requests.append(request)
            return request

        # Store pending request
        self.pending_requests[request.request_id] = request

        # Pause agent (mark state as awaiting approval)
        state.status = AgentStatus.PAUSED.value
        state.update_timestamp()

        # Notify human
        if self.notification_callback:
            self.notification_callback(request)
        else:
            self._default_notification(request)

        print(f"   Request ID: {request.request_id}")
        print(f"   Title:      {title}")
        print(f"   Risk:       {risk_level.upper()}")
        print(f"   Action:     {proposed_action}")
        print(f"   Reversible: {is_reversible}")

        return request

    def process_response(
        self,
        request_id: str,
        action: HITLAction,
        response: str = "",
        memory_corrections: Dict = None,
        human_id: str = "human_user"
    ) -> Dict:
        """
        Process a human's response to a review request.

        memory_corrections format:
        {
          "intermediate_outputs.budget": 50000,
          "decisions[-1].reasoning": "User confirmed this approach",
          "mission_context.deadline": "2025-08-01"
        }

        Returns: {
          "approved": bool,
          "corrections_applied": int,
          "can_resume": bool,
          "reason": str
        }
        """
        request = self.pending_requests.get(request_id)
        if not request:
            return {
                "approved": False,
                "corrections_applied": 0,
                "can_resume": False,
                "reason": f"Request {request_id} not found"
            }

        # Record the response
        request.human_action = action.value
        request.human_response = response
        request.memory_corrections = memory_corrections or {}
        request.resolved_at = datetime.now().isoformat()
        request.resolved_by = human_id

        corrections_applied = len(memory_corrections or {})

        if action == HITLAction.APPROVE:
            request.status = "approved"
            print(f"  ✅ Request APPROVED by {human_id}")
            print(f"     Response: {response}")

        elif action == HITLAction.REJECT:
            request.status = "rejected"
            print(f"  ❌ Request REJECTED by {human_id}")
            print(f"     Reason: {response}")

        elif action == HITLAction.MODIFY:
            request.status = "modified"
            print(f"  ✏️  Request MODIFIED by {human_id}")
            print(f"     Corrections: {corrections_applied} changes")

        # Move to resolved
        del self.pending_requests[request_id]
        self.resolved_requests.append(request)

        # Log correction patterns for learning
        if memory_corrections:
            for path, new_value in memory_corrections.items():
                self._learn_from_correction(path, new_value)

        return {
            "approved": action in (HITLAction.APPROVE, HITLAction.MODIFY),
            "corrections_applied": corrections_applied,
            "can_resume": action in (HITLAction.APPROVE, HITLAction.MODIFY),
            "reason": response
        }

    def apply_corrections_to_state(
        self,
        state: "AgentState",
        request_id: str
    ) -> List[MemoryCorrection]:
        """
        Apply human corrections from a resolved request to agent state.
        
        Returns list of corrections applied.
        """
        # Find in resolved requests
        request = next(
            (r for r in self.resolved_requests
             if r.request_id == request_id),
            None
        )

        if not request or not request.memory_corrections:
            return []

        corrections_applied = []

        for path, new_value in request.memory_corrections.items():
            # Parse the correction path
            old_value = self._get_nested(state, path)

            # Apply the correction
            success = self._set_nested(state, path, new_value)

            if success:
                correction = MemoryCorrection(
                    correction_id=str(uuid.uuid4()),
                    run_id=state.run_id,
                    request_id=request_id,
                    user_id=state.user_id,
                    memory_path=path,
                    old_value=old_value,
                    new_value=new_value,
                    correction_reason=request.human_response or "",
                    corrected_by=request.resolved_by or "human"
                )
                corrections_applied.append(correction)
                self.corrections_log.append(correction)

                print(
                    f"  ✏️  Correction applied: {path}\n"
                    f"     {old_value} → {new_value}"
                )

        # Resume agent
        if corrections_applied:
            state.status = AgentStatus.RESUMING.value
            state.update_timestamp()
            print(
                f"  ✅ {len(corrections_applied)} corrections applied. "
                f"Agent can resume."
            )

        return corrections_applied

    def _get_nested(self, obj: Any, path: str) -> Any:
        """Get a value from a nested path like 'a.b.c'."""
        parts = path.split(".")
        current = obj if isinstance(obj, dict) else vars(obj)

        for part in parts:
            if isinstance(current, dict):
                current = current.get(part)
            elif hasattr(current, part):
                current = getattr(current, part)
            else:
                return None

        return current

    def _set_nested(self, obj: Any, path: str, value: Any) -> bool:
        """Set a value at a nested path."""
        parts = path.split(".")
        current = obj if isinstance(obj, dict) else obj

        try:
            for part in parts[:-1]:
                if isinstance(current, dict):
                    current = current[part]
                else:
                    current = getattr(current, part)

            final_key = parts[-1]
            if isinstance(current, dict):
                current[final_key] = value
            else:
                setattr(current, final_key, value)
            return True
        except Exception:
            return False

    def _learn_from_correction(self, path: str, new_value: Any):
        """Learn patterns from human corrections."""
        if path not in self.correction_patterns:
            self.correction_patterns[path] = []
        self.correction_patterns[path].append({
            "corrected_to": new_value,
            "at": datetime.now().isoformat()
        })

    def get_pending_requests(
        self,
        user_id: str = None
    ) -> List[Dict]:
        """Get all pending requests awaiting human review."""
        requests = list(self.pending_requests.values())

        if user_id:
            requests = [r for r in requests if r.user_id == user_id]

        return [{
            "request_id": r.request_id,
            "title": r.title,
            "risk_level": r.risk_level,
            "trigger": r.trigger,
            "proposed_action": r.proposed_action[:80],
            "created_at": r.created_at,
            "is_reversible": r.is_reversible
        } for r in requests]

    def generate_correction_insights(self) -> Dict:
        """
        Analyze patterns in human corrections.
        What does the agent consistently get wrong?
        """
        if not self.corrections_log:
            return {"message": "No corrections yet"}

        correction_frequency = {}
        for corr in self.corrections_log:
            path = corr.memory_path
            correction_frequency[path] = (
                correction_frequency.get(path, 0) + 1
            )

        frequently_corrected = sorted(
            correction_frequency.items(),
            key=lambda x: x[1],
            reverse=True
        )

        return {
            "total_corrections": len(self.corrections_log),
            "most_corrected_fields": frequently_corrected[:5],
            "recommendation": (
                "Consider adding validation for frequently corrected fields: "
                + ", ".join([f[0] for f in frequently_corrected[:3]])
            ) if frequently_corrected else "No patterns yet"
        }

# complete_agentic_system.py
"""
The COMPLETE agentic memory system combining all 5 concepts.
This is what a production-grade agent system looks like.
"""


class ProductionAgenticMemorySystem:
    """
    Orchestrates all agentic memory mechanisms:
    
    1. State Persistence    → Never lose progress
    2. Checkpointing        → Resume from anywhere
    3. Thread Isolation     → Privacy and correctness
    4. Multi-Agent Memory   → Coordination without conflict
    5. HITL Updates         → Human oversight and correction
    
    THIS IS THE ARCHITECTURE.
    Build your AI agents on top of this foundation.
    """

    def __init__(
        self,
        db_path: str = "./production_agents.db",
        checkpoint_path: str = "./checkpoints",
        require_hitl_for_high_risk: bool = True
    ):
        # Layer 1: State Persistence
        self.persistence = StatePersistenceLayer(db_path)

        # Layer 2: Checkpointing
        self.checkpoint_mgr = CheckpointManager(
            persistence_layer=self.persistence,
            storage_path=checkpoint_path,
            max_checkpoints_per_run=100,
            auto_checkpoint_interval_secs=300
        )

        # Layer 3: Thread Isolation
        self.thread_pool = ThreadPool(max_concurrent_threads=50)
        self.thread_context_mgr = ThreadContextManager()

        # Layer 4: Multi-Agent Memory
        self.memory_coordinator = MemoryCoordinator(
            conflict_strategy=WriteConflictStrategy.VERSIONED
        )

        # Layer 5: HITL
        self.hitl_manager = HITLMemoryManager(
            auto_approve_low_risk=not require_hitl_for_high_risk
        )

        print("\n✅ Production Agentic Memory System initialized")
        print("   Components: State + Checkpoint + Isolation + "
              "MultiAgent + HITL")

    def create_agent_run(
        self,
        user_id: str,
        agent_type: str,
        mission: str,
        tenant_id: str = "default",
        resume_run_id: str = None
    ) -> tuple:
        """
        Create (or resume) an isolated agent run.
        Returns (state, thread_context).
        """
        # Layer 3: Create isolated thread
        thread_ctx = self.thread_pool.spawn_thread(
            user_id=user_id,
            tenant_id=tenant_id
        )

        # Check for resumption
        if resume_run_id:
            state = self.persistence.load(resume_run_id)
            if state:
                latest_cp = self.checkpoint_mgr.get_latest_checkpoint(
                    resume_run_id,
                    require_clean=True
                )
                if latest_cp:
                    state = self.checkpoint_mgr.restore_from_checkpoint(
                        latest_cp
                    )
                    print(f"✅ Resuming run: {resume_run_id}")
                    return state, thread_ctx

        # Create new run
        state = AgentState(
            run_id=str(uuid.uuid4()),
            agent_type=agent_type,
            user_id=user_id,
            mission=mission
        )

        # Layer 1: Initial state save
        self.persistence.save(state, change_type="created")

        # Layer 2: Initial checkpoint
        self.checkpoint_mgr.create_checkpoint(
            state,
            trigger=CheckpointTrigger.MANUAL,
            metadata={"event": "run_created"},
            is_clean=True
        )

        # Layer 4: Register with coordinator
        self.memory_coordinator.register_agent(
            agent_id=state.run_id,
            agent_type=agent_type
        )

        print(f"✅ Agent run created: {state.run_id[:12]}...")
        return state, thread_ctx

    def execute_step_safely(
        self,
        state: "AgentState",
        step_id: str,
        execution_fn: Callable,
        require_approval: bool = False,
        risk_level: str = "low"
    ) -> bool:
        """
        Execute a single step with full safety guarantees:
        - Checkpointed before and after
        - HITL approval if required
        - Error recovery with checkpoint
        """
        step_data = state.steps.get(step_id, {})
        step_name = step_data.get("name", step_id)

        # Check if human approval needed
        if require_approval or risk_level in ("high", "critical"):
            request = self.hitl_manager.create_review_request(
                state=state,
                trigger=HITLTrigger.BEFORE_IRREVERSIBLE,
                title=f"Approve step: {step_name}",
                description=f"Agent wants to execute: {step_name}",
                proposed_action=step_name,
                action_payload=step_data,
                risk_level=risk_level,
                is_reversible=risk_level in ("low", "medium")
            )

            # In production: wait for async human response
            # For demo: simulate immediate approval
            print(f"  ⏸️  Waiting for human approval...")
            return False  # Returns False = waiting for approval

        # Execute with checkpointing
        try:
            with self.checkpoint_mgr.step_checkpoint(state, step_id):
                state.start_step(step_id)
                result = execution_fn(state)
                state.complete_step(step_id, result)
                self.persistence.save(state, change_type="step_completed")
            return True

        except Exception as e:
            state.fail_step(step_id, str(e))
            self.persistence.save(state, change_type="step_failed")
            print(f"  ❌ Step failed: {step_name} — {e}")
            return False

# 🎯 INTERVIEW QUESTIONS + STRONG ANSWERS

### ❓ Q1: "What is agent state and why is state persistence important?"

**💬 Strong Answer:**
> "Agent state is the complete snapshot of everything an agent knows and has done at any moment in time — its mission, execution plan, step progress, tool call results, intermediate computations, decisions made, and resource usage. State persistence is critical for three reasons. First, reliability: agent tasks can run for hours, and without persistence, any server crash or network interruption means starting over from scratch — losing all expensive API calls and computations. Second, observability: persisted state creates a full audit trail of what the agent did and why, which is essential for debugging and compliance. Third, resumability: with persisted state, you can implement intelligent resume that skips already-completed steps rather than redoing work. In production, I'd persist state to a database after every step completion, using database transactions to ensure atomic saves that prevent corrupt partial states."

---

### ❓ Q2: "Explain checkpointing in AI agents. How does it differ from state persistence?"

**💬 Strong Answer:**
> "State persistence is the general mechanism of saving agent state to durable storage. Checkpointing is the specific strategy of when and how to create clean, restorable snapshots for recovery purposes. The key distinction is that a checkpoint is a GUARANTEED safe resume point — the agent was between steps, all previous work is complete, and resuming from this checkpoint will never cause duplicate actions. Not every state save is a clean checkpoint — a state saved mid-step might be in an invalid intermediate state. The most important checkpointing principle is: only checkpoint between steps, not during them. This prevents the dual-execution problem where resuming causes an action to be performed twice — like sending an email again or deleting a file again. I implement this with a context manager pattern that saves a clean checkpoint before a step starts and another after it completes, ensuring the latest clean checkpoint always represents a stable state."

---

### ❓ Q3: "Why is thread-level isolation necessary in multi-user AI agent systems?"

**💬 Strong Answer:**
> "Thread-level isolation ensures that when multiple users or agent runs execute concurrently, each execution context has a completely private view of memory. Without it, three serious problems occur. First, privacy violation: Agent A processing User A's data could accidentally retrieve User B's memories if queries aren't properly scoped. Second, state corruption: two agent runs writing to the same memory location simultaneously create race conditions and corrupt data. Third, debugging becomes impossible: without isolation, it's unclear which agent caused which state change. The implementation has two layers. At the storage layer, every query is forced to include a user_id filter that is injected automatically by the infrastructure — not just by convention. At the execution layer, I use thread-local storage to propagate the context automatically through all function calls, so developers don't need to manually pass user_id everywhere. I enforce this with a decorator that raises an error if any memory function is called without an active thread context."

---

### ❓ Q4: "How does multi-agent shared memory work? What prevents conflicts?"

**💬 Strong Answer:**
> "Multi-agent shared memory requires a coordinator that manages access to shared state through three mechanisms. First, memory space partitioning: each section of shared memory has an owner who is the only one who can write to it, while all agents can read. This eliminates most write conflicts by design. Second, optimistic locking: when an agent writes, it specifies the version number it read. If another agent wrote in the meantime, the version won't match and the write is rejected — forcing the writing agent to re-read and retry. This is the same pattern Git uses for commit conflict detection. Third, structured handoffs: when one agent completes work and another takes over, it creates a formal handoff record with provenance — who produced the data, when, and why. This creates a clear chain of custody for information that crosses agent boundaries. The coordinator also maintains a full audit log of all reads and writes, enabling complete reproducibility and debugging of multi-agent interactions."

---

### ❓ Q5: "What is Human-in-the-Loop memory and when should you use it?"

**💬 Strong Answer:**
> "Human-in-the-Loop memory management is a system where AI agents pause execution and request human review before acting on potentially wrong memory or before taking high-risk actions. Three triggers justify requiring human review: when the action is irreversible — like sending an email, deleting a file, or making a payment — you should always pause and verify the agent's memory assumptions; when the agent has low confidence in key facts that drive the action; and when the stakes are high enough that a wrong assumption causes significant harm. The implementation has two critical features. First, the review request shows the human not just what the agent wants to do, but exactly which memory facts it's basing that decision on — this lets the human verify and correct the memory before approval. Second, corrections are applied with full provenance — who corrected what and why — and these corrections are analyzed over time to identify systematic errors the agent makes, which can then be fixed in the agent's instructions or fine-tuning."
