# 📘 PART A — SHORT-TERM MEMORY

## Core Definition

> **Short-Term Memory = Everything the AI can see and use RIGHT NOW, in THIS session.**

Short-term memory allows the AI to maintain context, coherence, and flow within a single conversation. Without it, every message would be treated as the first message.

---

## A1. Conversation Buffer 💬

### What is it?

> **Conversation Buffer = Store EVERY message from the entire conversation and pass them ALL to the LLM every time.**

This is the **simplest** and most common form of short-term memory. You keep all messages in a list and include all of them in every API call.

### 🎭 Analogy: The Court Stenographer

```
A court stenographer writes down EVERYTHING said in court.
Every word. Every sentence. Every response.
When the judge needs to review, they read the COMPLETE transcript.

That's a Conversation Buffer.
You keep the COMPLETE, UNEDITED history of the conversation.
```

### How It Works — Step by Step

```
Message 1: User says "My name is Rahim"
Buffer: [
  {"role": "user", "content": "My name is Rahim"}
]
↓ Sent to LLM

Message 2: AI says "Nice to meet you Rahim!"
Buffer: [
  {"role": "user", "content": "My name is Rahim"},
  {"role": "assistant", "content": "Nice to meet you Rahim!"}
]
↓ Sent to LLM

Message 3: User says "What is my name?"
Buffer: [
  {"role": "user", "content": "My name is Rahim"},
  {"role": "assistant", "content": "Nice to meet you Rahim!"},
  {"role": "user", "content": "What is my name?"}
]
↓ Sent to LLM
→ LLM reads ALL messages → answers "Your name is Rahim" ✅
```

### 💻 Code — Conversation Buffer

```python
# conversation_buffer.py
from openai import OpenAI

class ConversationBuffer:
    """
    Simplest possible short-term memory.
    Store ALL messages. Pass ALL messages every time.
    """
    
    def __init__(self, system_prompt: str = "You are a helpful assistant."):
        self.client = OpenAI()
        self.system_prompt = system_prompt
        
        # THE BUFFER — This IS the short-term memory
        # It holds every single message in this session
        self.buffer = []
    
    def chat(self, user_message: str) -> str:
        """
        Send a message and get a response.
        The ENTIRE buffer is sent with every call.
        """
        # Step 1: Add user message to buffer
        self.buffer.append({
            "role": "user",
            "content": user_message
        })
        
        # Step 2: Build the full message list
        # System prompt + ALL previous messages + current message
        full_messages = [
            {"role": "system", "content": self.system_prompt}
        ] + self.buffer   # ← ALL messages, every single time
        
        # Step 3: Send EVERYTHING to the LLM
        response = self.client.chat.completions.create(
            model="gpt-4o-mini",
            messages=full_messages
        )
        
        ai_response = response.choices[0].message.content
        
        # Step 4: Add AI response to buffer too
        self.buffer.append({
            "role": "assistant",
            "content": ai_response
        })
        
        # Let's track how large our buffer is growing
        total_messages = len(self.buffer)
        print(f"[Buffer Size: {total_messages} messages]")
        
        return ai_response
    
    def get_buffer(self):
        """Show all stored messages."""
        return self.buffer
    
    def clear_buffer(self):
        """Clear memory — start fresh."""
        self.buffer = []
        print("Buffer cleared!")
    
    def get_token_estimate(self):
        """
        Rough estimate of tokens used.
        (Real tokenization uses tiktoken library)
        """
        total_chars = sum(len(m["content"]) for m in self.buffer)
        estimated_tokens = total_chars // 4  # rough: 4 chars ≈ 1 token
        return estimated_tokens


# Usage
if __name__ == "__main__":
    bot = ConversationBuffer()
    
    print(bot.chat("My name is Rahim"))
    print(bot.chat("I am building a Python project"))
    print(bot.chat("What is my name?"))          # Remembers! ✅
    print(bot.chat("What am I building?"))       # Remembers! ✅
    
    # After many messages...
    print(f"\nEstimated tokens in buffer: {bot.get_token_estimate()}")
    # This grows and grows! → The problem with simple buffer
```

### ✅ Pros and ❌ Cons

```
✅ PROS:
  → Extremely simple to implement
  → Perfect conversation continuity
  → LLM has full context of everything said
  → No information lost within a session

❌ CONS:
  → GROWS INFINITELY with each message
  → Costs MORE money as conversation gets longer
     (You pay for ALL previous tokens every time!)
  → Hits token limit eventually
  → Slow responses as buffer grows larger

Example of the cost problem:
  Message 1:  100 tokens sent
  Message 10: 1,000 tokens sent
  Message 50: 5,000 tokens sent
  Message 100: 10,000 tokens sent ← 100x the first message!
```

## A2. Sliding Window Memory 🪟

### What is it?

> **Sliding Window = Only keep the LAST N messages. When new messages come in, old messages slide OUT.**

This solves the infinite growth problem of conversation buffer by setting a limit.

### 🎭 Analogy: The Moving Train Window

```
Imagine you are on a train looking out the window.

Conversation Buffer = A camera recording EVERYTHING since you
                      boarded the train. Thousands of hours.

Sliding Window = You can only see what's CURRENTLY in the 
                 window. As the train moves, old scenery 
                 disappears. New scenery appears.
                 
You can only see the LAST K meters of scenery.
Old stuff is gone. New stuff always comes in.
```

### How It Works — Step by Step

```
[Window size = 3 messages]

Step 1: Message comes in
Messages: [M1, M2, M3]
Window:   [M1, M2, M3]  ← all fit

Step 2: Another message comes in
Messages: [M1, M2, M3, M4]
Window:   [M2, M3, M4]  ← M1 slides OUT! 👋

Step 3: Another message
Messages: [M1, M2, M3, M4, M5]
Window:   [M3, M4, M5]  ← M1, M2 gone forever

The window always shows only the most RECENT messages.
```

### 💻 Code — Sliding Window Memory

```python
# sliding_window_memory.py
from openai import OpenAI
from collections import deque

class SlidingWindowMemory:
    """
    Short-term memory with a fixed window size.
    Only keeps the last N messages.
    Solves the infinite growth problem!
    """
    
    def __init__(
        self,
        window_size: int = 10,    # Keep last 10 messages
        system_prompt: str = "You are a helpful assistant."
    ):
        self.client = OpenAI()
        self.system_prompt = system_prompt
        self.window_size = window_size
        
        # Using deque with maxlen = automatic sliding window!
        # When deque is full and new item added → oldest item removed
        self.window = deque(maxlen=window_size)
        
        # Track total messages seen (even those removed from window)
        self.total_messages_seen = 0
    
    def chat(self, user_message: str) -> str:
        """
        Chat with sliding window memory.
        Only last N messages are sent to LLM.
        """
        # Step 1: Add user message to window
        # If window is full → oldest message automatically removed
        self.window.append({
            "role": "user",
            "content": user_message
        })
        self.total_messages_seen += 1
        
        # Step 2: Build messages with only the window content
        full_messages = [
            {"role": "system", "content": self.system_prompt}
        ] + list(self.window)  # Only the WINDOW, not everything
        
        # Step 3: Call LLM
        response = self.client.chat.completions.create(
            model="gpt-4o-mini",
            messages=full_messages
        )
        
        ai_response = response.choices[0].message.content
        
        # Step 4: Add AI response to window
        self.window.append({
            "role": "assistant",
            "content": ai_response
        })
        
        print(f"[Window: {len(self.window)}/{self.window_size} messages used]")
        print(f"[Total seen: {self.total_messages_seen}]")
        
        return ai_response
    
    def peek_window(self):
        """Show what's currently in the window."""
        print(f"\n=== CURRENT WINDOW ({len(self.window)} messages) ===")
        for i, msg in enumerate(self.window):
            role = msg["role"].upper()
            content = msg["content"][:50] + "..." if len(msg["content"]) > 50 else msg["content"]
            print(f"[{i+1}] {role}: {content}")
        print("=" * 40)


# See the sliding window in action:
if __name__ == "__main__":
    # Small window size to clearly see the effect
    bot = SlidingWindowMemory(window_size=4)
    
    bot.chat("My name is Rahim")
    bot.chat("I love Python")
    bot.chat("I am 28 years old")
    bot.peek_window()  # Shows: all 3 messages (in pairs: user + ai)
    
    bot.chat("Tell me about JavaScript")
    bot.chat("Now tell me about databases")
    bot.peek_window()  # The name and Python messages may be gone!
    
    # Now test:
    response = bot.chat("What is my name?")
    print(f"\nAI Response: {response}")
    # If "Rahim" slid out of window → AI doesn't know! ⚠️
    # This is the TRADE-OFF of sliding window
```

### Sliding Window — The Core Trade-Off

```
PROBLEM IT SOLVES:           PROBLEM IT CREATES:
──────────────────           ───────────────────
✅ Fixed memory cost         ❌ Loses old context
✅ Predictable token usage   ❌ Forgets early messages
✅ Always fast responses     ❌ "Amnesia" for long chats
✅ No token limit issues     ❌ User frustrated if AI
                                forgets important old info

The SOLUTION to this trade-off:
→ Combine Sliding Window (short-term) 
  WITH Long-Term Memory (external DB)
→ Important facts from old messages 
  get saved to long-term memory before sliding out!
```

### Choosing the Right Window Size

```
Window Too Small:
  → AI forgets important context mid-conversation
  → Frustrating user experience
  → "But I just told you that!" moments

Window Too Large:
  → Expensive (more tokens per call)
  → Slower responses
  → Noise from irrelevant old messages

Sweet Spot (general guidelines):
  → Simple Q&A bot: 6-10 messages
  → Customer support: 10-20 messages  
  → Coding assistant: 20-30 messages
  → Complex agent: 30-50 messages (+ long-term memory)
```

## A3. Session-Level State 🗂️

### What is it?

> **Session-Level State = Structured data about the CURRENT SESSION — not just messages, but organized information about what's happening RIGHT NOW.**

This is different from just storing messages. It's about storing **structured metadata** about the session itself.

### 🎭 Analogy: The Check-In Form at a Hotel

```
When you check into a hotel, they record:
  → Your name (who you are)
  → Room number (where you are)
  → Check-in time (when you arrived)
  → Preferences: smoking/non-smoking (what you want)
  → Loyalty member status (history)
  → Current charges on the room (what's happened so far)

This SESSION STATE helps every staff member serve you 
without you needing to re-explain everything.

That's Session-Level State in AI.
It's structured, organized, and specific to THIS visit.
```

### What Session State Stores

```
SESSION STATE OBJECT = {
  
  // WHO
  "user_id": "rahim_123",
  "user_name": "Rahim",
  "authentication_status": "verified",
  
  // WHAT
  "current_task": "debugging Flask API",
  "task_status": "in_progress",
  "current_topic": "authentication middleware",
  
  // WHERE IN THE FLOW
  "conversation_turn": 7,
  "last_intent": "asking_for_code_example",
  "pending_clarifications": ["which Python version?"],
  
  // CURRENT CONTEXT
  "active_tools": ["code_interpreter", "web_search"],
  "files_uploaded": ["app.py", "config.py"],
  "language_preference": "Python",
  
  // SESSION META
  "session_id": "sess_abc123",
  "session_start": "2025-07-16T10:30:00",
  "total_tokens_used": 4523,
  "last_active": "2025-07-16T10:45:00"
}
```

### 💻 Code — Session-Level State

```python
# session_state.py
from dataclasses import dataclass, field, asdict
from datetime import datetime
from typing import Optional, List
from openai import OpenAI
import json

@dataclass
class SessionState:
    """
    Structured state for a single AI session.
    Like a rich "context object" beyond just messages.
    """
    # User Identity
    user_id: str
    user_name: Optional[str] = None
    
    # Task Context
    current_task: Optional[str] = None
    task_status: str = "idle"  # idle, in_progress, completed
    current_topic: Optional[str] = None
    
    # Conversation Meta
    session_id: str = field(default_factory=lambda: f"sess_{datetime.now().timestamp()}")
    session_start: str = field(default_factory=lambda: datetime.now().isoformat())
    conversation_turn: int = 0
    total_tokens_used: int = 0
    
    # User's Current Context
    files_uploaded: List[str] = field(default_factory=list)
    active_tools: List[str] = field(default_factory=list)
    language_preference: str = "Python"
    
    # Pending Items
    pending_questions: List[str] = field(default_factory=list)
    last_intent: Optional[str] = None
    
    def increment_turn(self):
        self.conversation_turn += 1
    
    def update_task(self, task: str):
        self.current_task = task
        self.task_status = "in_progress"
    
    def complete_task(self):
        self.task_status = "completed"
    
    def add_tokens(self, count: int):
        self.total_tokens_used += count
    
    def to_prompt_text(self) -> str:
        """Convert session state to injectable prompt text."""
        parts = []
        
        if self.user_name:
            parts.append(f"User's name: {self.user_name}")
        if self.current_task:
            parts.append(f"Current task: {self.current_task} (Status: {self.task_status})")
        if self.current_topic:
            parts.append(f"Currently discussing: {self.current_topic}")
        if self.files_uploaded:
            parts.append(f"Files in context: {', '.join(self.files_uploaded)}")
        if self.language_preference:
            parts.append(f"Preferred language: {self.language_preference}")
        if self.pending_questions:
            parts.append(f"Pending questions: {', '.join(self.pending_questions)}")
        
        return "\n".join(parts) if parts else "No session context yet."
    
    def to_dict(self):
        return asdict(self)
    
    def save_to_file(self, filepath: str):
        """Persist session state to disk."""
        with open(filepath, 'w') as f:
            json.dump(self.to_dict(), f, indent=2)
    
    @classmethod
    def load_from_file(cls, filepath: str):
        """Restore session state from disk."""
        with open(filepath, 'r') as f:
            data = json.load(f)
        return cls(**data)


class SessionAwareBot:
    """
    AI bot that uses structured session state.
    """
    
    def __init__(self, user_id: str, user_name: str):
        self.client = OpenAI()
        self.state = SessionState(user_id=user_id, user_name=user_name)
        self.messages = []  # The conversation buffer
    
    def chat(self, user_message: str) -> str:
        # Update state
        self.state.increment_turn()
        self.state.last_intent = self._detect_intent(user_message)
        
        # Build context-aware system prompt
        system_prompt = f"""You are a helpful AI assistant.

=== CURRENT SESSION STATE ===
{self.state.to_prompt_text()}
Turn Number: {self.state.conversation_turn}
=================================

Use this session information to give personalized, 
contextual responses. Remember the user's current task and context.
"""
        
        # Add message to buffer
        self.messages.append({"role": "user", "content": user_message})
        
        # Build full message list
        full_messages = [
            {"role": "system", "content": system_prompt}
        ] + self.messages[-10:]  # Last 10 messages
        
        # Call LLM
        response = self.client.chat.completions.create(
            model="gpt-4o-mini",
            messages=full_messages
        )
        
        ai_response = response.choices[0].message.content
        
        # Update state from response
        tokens_used = response.usage.total_tokens
        self.state.add_tokens(tokens_used)
        
        # Add response to buffer
        self.messages.append({"role": "assistant", "content": ai_response})
        
        return ai_response
    
    def _detect_intent(self, message: str) -> str:
        """Simple intent detection (can be much more sophisticated)."""
        message_lower = message.lower()
        if any(word in message_lower for word in ["debug", "error", "fix", "bug"]):
            return "debugging"
        elif any(word in message_lower for word in ["explain", "what is", "how does"]):
            return "learning"
        elif any(word in message_lower for word in ["build", "create", "implement"]):
            return "building"
        return "general"
    
    def update_task(self, task: str):
        """Call this when user starts a new task."""
        self.state.update_task(task)
        print(f"Session state updated: Task = '{task}'")


# Usage
if __name__ == "__main__":
    bot = SessionAwareBot(user_id="rahim_123", user_name="Rahim")
    bot.update_task("Build a Flask REST API")
    
    print(bot.chat("Where should I start?"))
    print(bot.chat("I'm having trouble with routing"))
    
    print(f"\nSession Summary:")
    print(f"  Turns: {bot.state.conversation_turn}")
    print(f"  Tokens Used: {bot.state.total_tokens_used}")
    print(f"  Last Intent: {bot.state.last_intent}")
```

# 📗 PART B — LONG-TERM MEMORY

## Core Definition

> **Long-Term Memory = Information that persists BEYOND a single session, stored in an external system, retrieved when needed in future sessions.**

This is what makes AI go from "stateless tool" to "intelligent collaborator."

---

## B1. Persistent User Data 👤

### What is it?

> **Persistent User Data = Basic facts about the USER that stay true over long periods and should always be remembered.**

This is the most stable form of long-term memory. User data rarely changes.

### What Falls Under Persistent User Data

```
PERSISTENT USER DATA EXAMPLES:
────────────────────────────────────────────────────────
IDENTITY:
  → "User's name is Rahim Ahmed"
  → "User ID: rahim_123"
  → "Account created: January 2025"
  → "Language: Bengali + English"

PROFESSIONAL CONTEXT:
  → "Job title: Software Engineer"
  → "Company: TechCorp Bangladesh"
  → "Years of experience: 3 years"
  → "Tech stack: Python, React, PostgreSQL"

PERSONAL CONTEXT:
  → "Timezone: Asia/Dhaka (UTC+6)"
  → "Preferred response language: English"
  → "Skill level: Intermediate developer"
  → "Learning goal: Become an AI Engineer"

CONSTRAINTS:
  → "Uses Mac, not Windows"
  → "Free tier user, no paid API access"
  → "Prefers beginner-friendly explanations"
```

### 💻 Code — Persistent User Data System

```python
# persistent_user_data.py
import json
import os
from datetime import datetime
from typing import Optional, Dict, Any


class PersistentUserStore:
    """
    Stores basic user facts that persist forever.
    Simple implementation using JSON file.
    Production: Use PostgreSQL, MongoDB, or similar.
    """
    
    def __init__(self, storage_path: str = "./user_data"):
        self.storage_path = storage_path
        os.makedirs(storage_path, exist_ok=True)
    
    def _get_user_file(self, user_id: str) -> str:
        return f"{self.storage_path}/{user_id}_profile.json"
    
    def create_user(self, user_id: str, initial_data: Dict) -> Dict:
        """Create a new user profile."""
        user_profile = {
            "user_id": user_id,
            "created_at": datetime.now().isoformat(),
            "last_updated": datetime.now().isoformat(),
            "data": initial_data
        }
        
        filepath = self._get_user_file(user_id)
        with open(filepath, 'w') as f:
            json.dump(user_profile, f, indent=2)
        
        print(f"✅ User profile created for: {user_id}")
        return user_profile
    
    def get_user(self, user_id: str) -> Optional[Dict]:
        """Retrieve user profile."""
        filepath = self._get_user_file(user_id)
        
        if not os.path.exists(filepath):
            return None
        
        with open(filepath, 'r') as f:
            return json.load(f)
    
    def update_user(self, user_id: str, updates: Dict):
        """Update specific fields in user profile."""
        profile = self.get_user(user_id)
        
        if not profile:
            print(f"User {user_id} not found!")
            return
        
        # Update the fields
        profile["data"].update(updates)
        profile["last_updated"] = datetime.now().isoformat()
        
        filepath = self._get_user_file(user_id)
        with open(filepath, 'w') as f:
            json.dump(profile, f, indent=2)
        
        print(f"✅ Updated profile for {user_id}: {list(updates.keys())}")
    
    def get_user_prompt_context(self, user_id: str) -> str:
        """

        return "\n".join(context_lines)

            print(f"✅ User {user_id} data permanently deleted")
        else:
            print(f"User {user_id} not found")
```

## B2. Historical Interactions 📜

### What is it?

> **Historical Interactions = A record of PAST conversations, questions asked, topics explored, and problems solved — retrievable by semantic search.**

This is **episodic memory** — the "diary" of all past conversations.

### 🎭 Analogy: The Doctor's Patient History

```
Every time you visit a doctor, they record:
  → Date of visit
  → Symptoms described
  → Diagnosis made
  → Treatments prescribed
  → Outcome and follow-up

Next visit (even 2 years later):
  Doctor opens file → reads history → says:
  "I see last time you had a similar issue and we tried X.
  This time let's try Y instead."

THAT is historical interaction memory.
The AI remembers WHAT you discussed, WHEN, and WHAT happened.
```

### How Historical Interactions Work

```
STORING:
──────────────────────────────────────────────
After each session:
  1. Take conversation transcript
  2. Use LLM to extract key interaction facts:
     "User debugged a Flask authentication bug"
     "User learned about JWT tokens"
     "Problem was solved with flask-jwt-extended library"
  3. Embed these facts as vectors
  4. Store in vector DB with timestamp + user_id

RETRIEVING:
──────────────────────────────────────────────
When new session starts and user says:
  "Remember that Flask issue I had?"
  
  1. Convert query to embedding vector
  2. Search vector DB for similar past interactions
  3. Found: "User debugged Flask authentication bug"
  4. Inject into context: "Previous interaction: ..."
  5. AI responds with full context! 🎯
```

### 💻 Code — Historical Interaction Memory

```python
# historical_interactions.py
import chromadb
from openai import OpenAI
from datetime import datetime
import json
from typing import List, Dict


class HistoricalInteractionMemory:
    """
    Stores and retrieves past interaction summaries.
    Uses vector search for semantic retrieval.
    """
    
    def __init__(self, user_id: str):
        self.user_id = user_id
        self.openai = OpenAI()
        
        # Vector database for semantic search
        self.chroma = chromadb.PersistentClient(path="./long_term_memory")
        self.collection = self.chroma.get_or_create_collection(
            name="historical_interactions",
            metadata={"hnsw:space": "cosine"}
        )
    
    def embed(self, text: str) -> List[float]:
        """Convert text to embedding vector."""
        response = self.openai.embeddings.create(
            model="text-embedding-3-small",
            input=text
        )
        return response.data[0].embedding
    
    def extract_interaction_summary(
        self, 
        conversation: List[Dict]
    ) -> List[str]:
        """
        Use LLM to extract key facts from a conversation.
        Input: Full conversation
        Output: List of atomic, memorable facts
        """
        conv_text = "\n".join([
            f"{m['role'].upper()}: {m['content']}"
            for m in conversation
        ])
        
        prompt = f"""Analyze this conversation and extract key interaction facts.

Focus on:
- Problems solved or attempted
- Topics learned or discussed
- Decisions made
- Technologies/tools used
- Outcomes and results

Conversation:
{conv_text}

Return a JSON list of 3-7 atomic facts.
Example: ["User debugged Flask JWT authentication", "Learned about token expiry"]
Return ONLY the JSON list, nothing else."""
        
        response = self.openai.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{"role": "user", "content": prompt}],
            temperature=0
        )
        
        try:
            facts = json.loads(response.choices[0].message.content)
            return facts if isinstance(facts, list) else []
        except:
            return []
    
    def save_interaction(
        self, 
        conversation: List[Dict],
        session_id: str
    ):
        """
        After a session ends, extract and store interaction facts.
        This runs in BACKGROUND (cold path).
        """
        print("📝 Extracting interaction memories...")
        
        facts = self.extract_interaction_summary(conversation)
        
        for i, fact in enumerate(facts):
            # Create unique ID for this memory
            memory_id = f"{self.user_id}_{session_id}_{i}"
            
            # Convert fact to embedding
            embedding = self.embed(fact)
            
            # Store in vector DB
            self.collection.add(
                ids=[memory_id],
                embeddings=[embedding],
                documents=[fact],
                metadatas=[{
                    "user_id": self.user_id,
                    "session_id": session_id,
                    "timestamp": datetime.now().isoformat(),
                    "type": "interaction_fact"
                }]
            )
            
            print(f"  ✅ Stored: {fact}")
        
        return facts
    
    def recall_relevant(
        self, 
        query: str, 
        n_results: int = 5,
        min_relevance: float = 0.5
    ) -> List[Dict]:
        """
        Find past interactions relevant to current query.
        Returns list of relevant memories with metadata.
        """
        # Convert query to vector
        query_embedding = self.embed(query)
        
        # Search for similar vectors (same user only!)
        results = self.collection.query(
            query_embeddings=[query_embedding],
            n_results=n_results,
            where={"user_id": self.user_id}  # ← CRITICAL: scope to user!
        )
        
        if not results["documents"][0]:
            return []
        
        # Format results
        memories = []
        for i, (doc, meta, dist) in enumerate(zip(
            results["documents"][0],
            results["metadatas"][0],
            results["distances"][0]
        )):
            relevance = 1 - dist  # Convert distance to similarity
            
            if relevance >= min_relevance:
                memories.append({
                    "memory": doc,
                    "timestamp": meta.get("timestamp", "unknown"),
                    "relevance": round(relevance, 3)
                })
        
        return memories
    
    def format_for_prompt(self, memories: List[Dict]) -> str:
        """Format retrieved memories for injection into prompt."""
        if not memories:
            return ""
        
        lines = ["\n=== RELEVANT PAST INTERACTIONS ==="]
        for mem in memories:
            timestamp = mem["timestamp"][:10]  # Just date
            relevance = mem["relevance"]
            lines.append(f"• [{timestamp}] {mem['memory']} (relevance: {relevance})")
        lines.append("==================================\n")
        
        return "\n".join(lines)


# Usage Example:
if __name__ == "__main__":
    memory = HistoricalInteractionMemory(user_id="rahim_123")
    
    # Simulate saving a past session
    past_conversation = [
        {"role": "user", "content": "I have a bug in my Flask app. JWT tokens aren't working"},
        {"role": "assistant", "content": "Let's debug this. What error are you seeing?"},
        {"role": "user", "content": "InvalidSignatureError when verifying the token"},
        {"role": "assistant", "content": "This usually means the SECRET_KEY is different. Check your config."},
        {"role": "user", "content": "You're right! I had two different SECRET_KEYs. Fixed now!"},
        {"role": "assistant", "content": "Great! Always use environment variables for secrets."}
    ]
    
    memory.save_interaction(past_conversation, session_id="sess_001")
    
    # Now retrieve in a new session
    relevant = memory.recall_relevant("I'm having JWT authentication issues again")
    print(memory.format_for_prompt(relevant))
    # Output: Past interaction about Flask JWT bug → User fixes it with SECRET_KEY
```

```python
# user_preferences.py
from openai import OpenAI
import json
import os
from typing import Dict, List


class UserPreferencesMemory:
    """
    Automatically learns and stores user preferences
    from their interactions over time.
    """
    
    def __init__(self, user_id: str, storage_path: str = "./user_prefs"):
        self.user_id = user_id
        self.openai = OpenAI()
        self.storage_path = storage_path
        os.makedirs(storage_path, exist_ok=True)
        
        # Load existing preferences or start fresh
        self.preferences = self._load_preferences()
    
    def _get_filepath(self) -> str:
        return f"{self.storage_path}/{self.user_id}_preferences.json"
    
    def _load_preferences(self) -> Dict:
        filepath = self._get_filepath()
        if os.path.exists(filepath):
            with open(filepath, 'r') as f:
                return json.load(f)
        
        # Default preference structure
        return {
            "communication_style": {},
            "technical_level": {},
            "format_preferences": {},
            "domain_interests": {},
            "interaction_patterns": {},
            "last_updated": None,
            "update_count": 0
        }
    
    def _save_preferences(self):
        """Persist preferences to disk."""
        self.preferences["last_updated"] = \
            __import__('datetime').datetime.now().isoformat()
        self.preferences["update_count"] += 1
        
        with open(self._get_filepath(), 'w') as f:
            json.dump(self.preferences, f, indent=2)
    
    def extract_preferences_from_conversation(
        self,
        conversation: List[Dict]
    ) -> Dict:
        """
        Use LLM to identify new preferences revealed in conversation.
        """
        conv_text = "\n".join([
            f"{m['role'].upper()}: {m['content']}"
            for m in conversation
        ])
        
        prompt = f"""Analyze this conversation and identify user preferences.

Look for:
1. How they like information presented (bullets, code, analogies)
2. Their technical level in different areas
3. Topics they care about or avoid
4. Their communication style preferences
5. Patterns in how they ask questions

Conversation:
{conv_text}

Return a JSON object with ONLY newly learned preferences.
Example format:
{{
  "communication_style": {{"prefers_bullet_points": true}},
  "technical_level": {{"python": "intermediate", "databases": "beginner"}},
  "format_preferences": {{"wants_code_examples": true}},
  "domain_interests": {{"ai_ml": "high", "devops": "medium"}},
  "interaction_patterns": {{"asks_followup_why": true}}
}}

Return ONLY a JSON object. If no clear preferences found, return {{}}"""
        
        response = self.openai.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{"role": "user", "content": prompt}],
            temperature=0
        )
        
        try:
            new_prefs = json.loads(response.choices[0].message.content)
            return new_prefs if isinstance(new_prefs, dict) else {}
        except:
            return {}
    
    def update_preferences(self, new_preferences: Dict):
        """Merge new preferences into existing ones."""
        for category, prefs in new_preferences.items():
            if category in self.preferences and isinstance(prefs, dict):
                # Merge, not replace — preserve old preferences
                self.preferences[category].update(prefs)
        
        self._save_preferences()
        print(f"✅ Preferences updated for {self.user_id}")
    
    def learn_from_conversation(self, conversation: List[Dict]):
        """Full pipeline: extract preferences and save."""
        new_prefs = self.extract_preferences_from_conversation(conversation)
        if new_prefs:
            self.update_preferences(new_prefs)
    
    def get_preference_prompt(self) -> str:
        """
        Convert stored preferences into LLM prompt instructions.
        This makes the AI AUTOMATICALLY adapt to the user.
        """
        lines = ["=== USER PREFERENCES (Apply These) ==="]
        
        # Communication style
        comm = self.preferences.get("communication_style", {})
        if comm.get("prefers_bullet_points"):
            lines.append("• Use bullet points in responses")
        if comm.get("likes_analogies"):
            lines.append("• Use real-world analogies to explain concepts")
        
        # Format preferences
        fmt = self.preferences.get("format_preferences", {})
        if fmt.get("wants_code_examples"):
            lines.append("• Always include code examples")
        if fmt.get("prefers_concise"):
            lines.append("• Keep responses concise and to the point")
        
        # Technical level
        tech = self.preferences.get("technical_level", {})
        for skill, level in tech.items():
            lines.append(f"• User's {skill} level: {level}")
        
        # Domain interests
        domains = self.preferences.get("domain_interests", {})
        high_interest = [d for d, v in domains.items() if v == "high"]
        if high_interest:
            lines.append(f"• High interest areas: {', '.join(high_interest)}")
        
        lines.append("========================================")
        
        return "\n".join(lines) if len(lines) > 2 else ""
    
    def manually_set_preference(self, category: str, key: str, value):
        """Let users explicitly set their own preferences."""
        if category not in self.preferences:
            self.preferences[category] = {}
        
        self.preferences[category][key] = value
        self._save_preferences()
        print(f"✅ Set preference: {category}.{key} = {value}")
```

### What is it?

This is different from user data — it's about **what the user KNOWS and has BUILT**, not just who they are.

### 🎭 Analogy: The Research Notebook

```
A scientist keeps a research notebook.
Every experiment → result recorded
Every discovery → written down
Every failure → documented with why

Years later, the notebook is GOLD.
It captures all accumulated knowledge
from years of work.

Knowledge Accumulation in AI = 
The AI's growing notebook about your 
domain, projects, and expertise.
```

### What Knowledge Accumulation Stores

```
PROJECT KNOWLEDGE:

DOMAIN EXPERTISE LEARNED:
```

```python
# knowledge_accumulation.py
import chromadb
from openai import OpenAI
from datetime import datetime
import json
from typing import List, Dict, Optional
import uuid


class KnowledgeAccumulator:
    """
    Accumulates and retrieves domain-specific knowledge
    that builds up over time through user interactions.
    
    Think of this as the AI's growing "expertise database"
    about the user's specific work and domain.
    """
    
    # Categories of knowledge we track
    KNOWLEDGE_TYPES = [
        "project_fact",      # Specific project details
        "technology_choice", # What tools/tech they use
        "past_decision",     # Decisions made and why
        "domain_rule",       # Rules and patterns established
        "expertise_level",   # User's knowledge in an area
        "lesson_learned"     # Things learned from mistakes
    ]
    
    def __init__(self, user_id: str):
        self.user_id = user_id
        self.openai = OpenAI()
        
        # Vector DB for semantic knowledge search
        self.chroma = chromadb.PersistentClient(path="./knowledge_store")
        self.collection = self.chroma.get_or_create_collection(
            name="knowledge_base",
            metadata={"hnsw:space": "cosine"}
        )
    
    def embed(self, text: str) -> List[float]:
        response = self.openai.embeddings.create(
            model="text-embedding-3-small",
            input=text
        )
        return response.data[0].embedding
    
    def add_knowledge(
        self,
        fact: str,
        knowledge_type: str = "project_fact",
        source: str = "conversation",
        confidence: float = 1.0
    ) -> str:
        """
        Add a new knowledge fact to the accumulator.
        Returns the memory ID.
        """
        knowledge_id = str(uuid.uuid4())
        embedding = self.embed(fact)
        
        self.collection.add(
            ids=[knowledge_id],
            embeddings=[embedding],
            documents=[fact],
            metadatas=[{
                "user_id": self.user_id,
                "knowledge_type": knowledge_type,
                "source": source,
                "confidence": confidence,
                "timestamp": datetime.now().isoformat(),
                "access_count": 0
            }]
        )
        
        print(f"✅ Knowledge stored [{knowledge_type}]: {fact[:60]}...")
        return knowledge_id
    
    def extract_knowledge_from_conversation(
        self,
        conversation: List[Dict]
    ) -> List[Dict]:
        """
        Extract structured knowledge facts from a conversation.
        Returns list of {fact, type, confidence} objects.
        """
        conv_text = "\n".join([
            f"{m['role'].upper()}: {m['content']}"
            for m in conversation
        ])
        
        prompt = f"""Extract structured knowledge facts from this conversation.

Knowledge types to look for:
- project_fact: Specific details about user's project/system
- technology_choice: What technologies/tools they use and why
- past_decision: Decisions made with rationale
- domain_rule: Rules, conventions, patterns established
- expertise_level: User's skill level in specific areas
- lesson_learned: Insights from problems solved

Conversation:
{conv_text}

Return a JSON array of knowledge objects:
[
  {{
    "fact": "User's API uses PostgreSQL on port 5432",
    "type": "project_fact",
    "confidence": 0.95
  }},
  {{
    "fact": "User chose REST over GraphQL due to team's familiarity",
    "type": "past_decision", 
    "confidence": 0.9
  }}
]

Return ONLY the JSON array. Max 8 items. Focus on durable, 
reusable knowledge that will help in future sessions."""
        
        response = self.openai.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{"role": "user", "content": prompt}],
            temperature=0
        )
        
        try:
            knowledge_items = json.loads(response.choices[0].message.content)
            return knowledge_items if isinstance(knowledge_items, list) else []
        except:
            return []
    
    def accumulate_from_conversation(
        self,
        conversation: List[Dict],
        session_id: str
    ):
        """Full pipeline: extract knowledge from conversation and store."""
        print(f"\n📚 Accumulating knowledge from session {session_id}...")
        
        knowledge_items = self.extract_knowledge_from_conversation(conversation)
        
        stored_count = 0
        for item in knowledge_items:
            if isinstance(item, dict) and "fact" in item:
                self.add_knowledge(
                    fact=item["fact"],
                    knowledge_type=item.get("type", "project_fact"),
                    source=f"session_{session_id}",
                    confidence=item.get("confidence", 0.8)
                )
                stored_count += 1
        
        print(f"✅ Accumulated {stored_count} knowledge facts")
        return stored_count
    
    def recall_knowledge(
        self,
        query: str,
        n_results: int = 5,
        knowledge_type: Optional[str] = None
    ) -> List[Dict]:
        """
        Retrieve relevant knowledge for current context.
        """
        query_embedding = self.embed(query)
        
        # Build filter
        where_filter = {"user_id": self.user_id}
        if knowledge_type:
            where_filter["knowledge_type"] = knowledge_type
        
        results = self.collection.query(
            query_embeddings=[query_embedding],
            n_results=n_results,
            where=where_filter
        )
        
        if not results["documents"][0]:
            return []
        
        knowledge_list = []
        for doc, meta in zip(
            results["documents"][0],
            results["metadatas"][0]
        ):
            knowledge_list.append({
                "fact": doc,
                "type": meta.get("knowledge_type"),
                "confidence": meta.get("confidence"),
                "timestamp": meta.get("timestamp", "")[:10]
            })
        
        return knowledge_list
    
    def get_knowledge_summary_prompt(self, query: str) -> str:
        """Get knowledge context formatted for prompt injection."""
        knowledge = self.recall_knowledge(query)
        
        if not knowledge:
            return ""
        
        lines = ["\n=== ACCUMULATED KNOWLEDGE (About User's Work) ==="]
        
        # Group by type
        grouped = {}
        for k in knowledge:
            ktype = k["type"]
            if ktype not in grouped:
                grouped[ktype] = []
            grouped[ktype].append(k["fact"])
        
        for ktype, facts in grouped.items():
            readable_type = ktype.replace("_", " ").title()
            lines.append(f"\n{readable_type}:")
            for fact in facts:
                lines.append(f"  • {fact}")
        
        lines.append("=================================================\n")
        return "\n".join(lines)
```

# 📙 PART C — WORKING / EXECUTION MEMORY

## Core Definition

> **Working Memory = Temporary, task-specific storage used DURING the execution of a complex task. It's the AI's "scratchpad" while doing work.**

This is the most misunderstood type. It's not about conversations. It's about **AI agents doing tasks**.

### 🎭 Analogy: The Surgeon During an Operation

```
During surgery, a surgeon needs to track:
  → Steps completed so far (step 1 done ✅, step 2 in progress)
  → Current instrument being used (scalpel, sutures...)
  → Test results received (blood pressure: 120/80)
  → What's left to do (close wound, apply bandage)
  → Any unexpected findings ("found additional blockage")

This information is CRITICAL during the operation.
But when the operation is over → it gets documented and cleared.

THAT is Working/Execution Memory.
Active, structured, task-specific, temporary.
```

## C1. Intermediate Outputs 📋

### What is it?

> **Intermediate Outputs = The partial results and outputs produced DURING a multi-step task, stored so the agent can use them in the next step.**

### Real-World Example

```
TASK: "Research AI trends, write a report, and send it"

Step 1: Search the web for AI trends
  → Intermediate Output: Raw search results text
  → Stored in working memory as: intermediate_outputs["search_results"]

Step 2: Summarize the search results  
  → Reads: intermediate_outputs["search_results"]
  → Intermediate Output: Summary paragraph
  → Stored as: intermediate_outputs["summary"]

Step 3: Format as report
  → Reads: intermediate_outputs["summary"]
  → Output: Formatted report
  → Stored as: intermediate_outputs["report"]

Step 4: Send the report
  → Reads: intermediate_outputs["report"]
  → Task complete!
```

### 💻 Code — Intermediate Outputs Storage

```python
# working_memory.py — Part 1: Intermediate Outputs
from typing import Any, Optional, Dict
from datetime import datetime
import json


class IntermediateOutputStore:
    """
    Stores partial results during multi-step task execution.
    Like a clipboard that agents pass results between steps.
    """
    
    def __init__(self, task_id: str):
        self.task_id = task_id
        self.outputs: Dict[str, Any] = {}
        self.output_history: list = []  # Track the order of outputs
    
    def store(self, key: str, value: Any, description: str = ""):
        """
        Store an intermediate output with a named key.
        
        Args:
            key: Name for this output (e.g., "search_results")
            value: The actual output (text, dict, list, anything)
            description: Human-readable description
        """
        self.outputs[key] = {
            "value": value,
            "description": description,
            "stored_at": datetime.now().isoformat(),
            "type": type(value).__name__
        }
        
        self.output_history.append({
            "key": key,
            "description": description,
            "timestamp": datetime.now().isoformat()
        })
        
        print(f"  📦 Stored output: '{key}' ({type(value).__name__})")
    
    def get(self, key: str) -> Optional[Any]:
        """Retrieve a stored output by key."""
        if key in self.outputs:
            return self.outputs[key]["value"]
        print(f"  ⚠️ Output '{key}' not found!")
        return None
    
    def get_all_keys(self) -> list:
        """See what outputs are currently stored."""
        return list(self.outputs.keys())
    
    def get_summary_for_prompt(self) -> str:
        """
        Convert current intermediate outputs into 
        a summary for the LLM to read.
        """
        if not self.outputs:
            return "No intermediate outputs yet."
        
        lines = ["=== INTERMEDIATE OUTPUTS ==="]
        for key, data in self.outputs.items():
            value_preview = str(data["value"])[:100]
            if len(str(data["value"])) > 100:
                value_preview += "..."
            lines.append(f"• {key}: {value_preview}")
        lines.append("============================")
        
        return "\n".join(lines)
    
    def clear(self, key: str = None):
        """
        Clear specific output or all outputs.
        Called when task is complete.
        """
        if key:
            if key in self.outputs:
                del self.outputs[key]
                print(f"  🗑️ Cleared output: '{key}'")
        else:
            self.outputs = {}
            print(f"  🗑️ All intermediate outputs cleared")
```

### What is it?

```
  📁 File Reader Tool → Returns: file contents
```

```python
# working_memory.py — Part 2: Tool Results
from typing import Any, Dict, List, Optional
from datetime import datetime
from enum import Enum


class ToolStatus(Enum):
    SUCCESS = "success"
    FAILURE = "failure"
    PENDING = "pending"
    SKIPPED = "skipped"


class ToolResultMemory:
    """
    Stores results from all tool calls during agent execution.
    Allows agent to reference previous tool outputs.
    """
    
    def __init__(self, task_id: str):
        self.task_id = task_id
        self.tool_calls: List[Dict] = []  # Ordered list of all calls
        self.call_count = 0
    
    def record_tool_call(
        self,
        tool_name: str,
        input_params: Dict,
        result: Any,
        status: ToolStatus = ToolStatus.SUCCESS,
        error_message: str = None,
        execution_time_ms: int = 0
    ) -> str:
        """
        Record a tool call and its result.
        Returns a call_id for reference.
        """
        self.call_count += 1
        call_id = f"call_{self.call_count:03d}"
        
        tool_record = {
            "call_id": call_id,
            "tool_name": tool_name,
            "input": input_params,
            "result": result,
            "status": status.value,
            "error": error_message,
            "execution_time_ms": execution_time_ms,
            "timestamp": datetime.now().isoformat()
        }
        
        self.tool_calls.append(tool_record)
        
        status_icon = "✅" if status == ToolStatus.SUCCESS else "❌"
        print(f"  {status_icon} Tool [{call_id}] {tool_name}: {status.value}")
        
        return call_id
    
    def get_tool_result(self, call_id: str) -> Optional[Any]:
        """Retrieve result of a specific tool call."""
        for call in self.tool_calls:
            if call["call_id"] == call_id:
                return call["result"]
        return None
    
    def get_latest_result(self, tool_name: str) -> Optional[Any]:
        """Get the most recent result from a specific tool."""
        for call in reversed(self.tool_calls):
            if call["tool_name"] == tool_name:
                return call["result"]
        return None
    
    def get_all_results_for_prompt(self) -> str:
        """Format all tool results for LLM consumption."""
        if not self.tool_calls:
            return "No tools called yet."
        
        lines = ["=== TOOL CALL RESULTS ==="]
        
        for call in self.tool_calls:
            status_icon = "✅" if call["status"] == "success" else "❌"
            result_preview = str(call["result"])[:150]
            if len(str(call["result"])) > 150:
                result_preview += "..."
            
            lines.append(
                f"\n{status_icon} [{call['call_id']}] {call['tool_name']}"
            )
            lines.append(f"   Input: {call['input']}")
            lines.append(f"   Result: {result_preview}")
        
        lines.append("=========================")
        return "\n".join(lines)
    
    def get_failed_calls(self) -> List[Dict]:
        """Get all failed tool calls for retry logic."""
        return [c for c in self.tool_calls if c["status"] == "failure"]
    
    def get_success_rate(self) -> float:
        """Calculate tool success rate."""
        if not self.tool_calls:
            return 0.0
        successes = sum(
            1 for c in self.tool_calls
            if c["status"] == "success"
        )
        return successes / len(self.tool_calls)
```

```python
# working_memory.py — Part 3: Task Progress Tracking
from typing import List, Dict, Optional, Callable, Any
from datetime import datetime
from enum import Enum
from dataclasses import dataclass, field


class StepStatus(Enum):
    PENDING = "pending"
    IN_PROGRESS = "in_progress"
    COMPLETED = "completed"
    FAILED = "failed"
    SKIPPED = "skipped"


@dataclass
class TaskStep:
    """Represents a single step in a task."""
    step_id: str
    name: str
    description: str
    status: StepStatus = StepStatus.PENDING
    result: Optional[Any] = None
    error: Optional[str] = None
    started_at: Optional[str] = None
    completed_at: Optional[str] = None
    attempt_count: int = 0
    max_attempts: int = 3
    depends_on: List[str] = field(default_factory=list)


class TaskProgressTracker:
    """
    Tracks the progress of a multi-step task.
    The AI agent's "project management system."
    """
    
    def __init__(self, task_id: str, task_description: str):
        self.task_id = task_id
        self.task_description = task_description
        self.steps: Dict[str, TaskStep] = {}
        self.step_order: List[str] = []  # Maintain insertion order
        self.task_started_at = datetime.now().isoformat()
        self.task_status = "in_progress"
    
    def add_step(
        self,
        step_id: str,
        name: str,
        description: str,
        depends_on: List[str] = None,
        max_attempts: int = 3
    ) -> TaskStep:
        """Add a step to the task."""
        step = TaskStep(
            step_id=step_id,
            name=name,
            description=description,
            depends_on=depends_on or [],
            max_attempts=max_attempts
        )
        self.steps[step_id] = step
        self.step_order.append(step_id)
        return step
    
    def start_step(self, step_id: str):
        """Mark a step as started."""
        step = self.steps.get(step_id)
        if step:
            step.status = StepStatus.IN_PROGRESS
            step.started_at = datetime.now().isoformat()
            step.attempt_count += 1
            print(f"  🔄 Starting step: {step.name} (attempt {step.attempt_count})")
    
    def complete_step(self, step_id: str, result: Any = None):
        """Mark a step as completed with its result."""
        step = self.steps.get(step_id)
        if step:
            step.status = StepStatus.COMPLETED
            step.result = result
            step.completed_at = datetime.now().isoformat()
            print(f"  ✅ Completed step: {step.name}")
    
    def fail_step(self, step_id: str, error: str):
        """Mark a step as failed."""
        step = self.steps.get(step_id)
        if step:
            step.status = StepStatus.FAILED
            step.error = error
            print(f"  ❌ Failed step: {step.name} — {error}")
    
    def can_start_step(self, step_id: str) -> bool:
        """
        Check if a step's dependencies are all completed.
        This is dependency-aware execution.
        """
        step = self.steps.get(step_id)
        if not step:
            return False
        
        for dep_id in step.depends_on:
            dep_step = self.steps.get(dep_id)
            if not dep_step or dep_step.status != StepStatus.COMPLETED:
                return False
        
        return step.status == StepStatus.PENDING
    
    def get_next_steps(self) -> List[TaskStep]:
        """Get all steps that are ready to be executed."""
        return [
            self.steps[sid]
            for sid in self.step_order
            if self.can_start_step(sid)
        ]
    
    def get_progress_summary(self) -> Dict:
        """Get a summary of task progress."""
        total = len(self.steps)
        completed = sum(
            1 for s in self.steps.values()
            if s.status == StepStatus.COMPLETED
        )
        failed = sum(
            1 for s in self.steps.values()
            if s.status == StepStatus.FAILED
        )
        
        return {
            "total_steps": total,
            "completed": completed,
            "failed": failed,
            "pending": total - completed - failed,
            "progress_pct": (completed / total * 100) if total > 0 else 0
        }
    
    def get_progress_for_prompt(self) -> str:
        """Format progress for LLM prompt injection."""
        lines = [f"\n=== TASK PROGRESS: {self.task_description} ==="]
        
        status_icons = {
            StepStatus.PENDING: "⏳",
            StepStatus.IN_PROGRESS: "🔄",
            StepStatus.COMPLETED: "✅",
            StepStatus.FAILED: "❌",
            StepStatus.SKIPPED: "⏭️"
        }
        
        for step_id in self.step_order:
            step = self.steps[step_id]
            icon = status_icons[step.status]
            lines.append(f"{icon} {step.name}: {step.description}")
            
            if step.status == StepStatus.FAILED and step.error:
                lines.append(f"   Error: {step.error}")
            
            if step.attempt_count > 1:
                lines.append(
                    f"   Attempts: {step.attempt_count}/{step.max_attempts}"
                )
        
        progress = self.get_progress_summary()
        lines.append(
            f"\nProgress: {progress['completed']}/{progress['total_steps']} "
            f"({progress['progress_pct']:.0f}%)"
        )
        lines.append("==========================================\n")
        
        return "\n".join(lines)
```

```python
# complete_working_memory.py
from typing import Any, Dict, List, Optional
from datetime import datetime
from dataclasses import dataclass, field
import json


@dataclass
class AgentState:
    """
    Complete state of an AI agent at any point in time.
    The agent's "awareness" of itself and its task.
    """
    # Task Context
    current_goal: str = ""
    current_strategy: str = ""
    current_step_name: str = ""
    
    # Decision State
    decisions_made: List[Dict] = field(default_factory=list)
    hypotheses: List[str] = field(default_factory=list)
    assumptions: List[str] = field(default_factory=list)
    
    # Resource State
    tools_available: List[str] = field(default_factory=list)
    tools_exhausted: List[str] = field(default_factory=list)
    budget_tokens_used: int = 0
    budget_tokens_limit: int = 100000
    
    # Execution State
    retry_count: int = 0
    max_retries: int = 3
    is_stuck: bool = False
    needs_human_input: bool = False
    
    # Confidence
    confidence_level: float = 1.0  # 0.0 to 1.0
    uncertainty_areas: List[str] = field(default_factory=list)
    
    def add_decision(self, decision: str, reasoning: str):
        """Record a decision and why it was made."""
        self.decisions_made.append({
            "decision": decision,
            "reasoning": reasoning,
            "timestamp": datetime.now().isoformat()
        })
    
    def add_assumption(self, assumption: str):
        """Track what assumptions are being made."""
        self.assumptions.append(assumption)
    
    def lower_confidence(self, reason: str, amount: float = 0.1):
        """Reduce confidence when something is uncertain."""
        self.confidence_level = max(0.0, self.confidence_level - amount)
        self.uncertainty_areas.append(reason)
    
    def exhaust_tool(self, tool_name: str):
        """Mark a tool as no longer available."""
        if tool_name in self.tools_available:
            self.tools_available.remove(tool_name)
        if tool_name not in self.tools_exhausted:
            self.tools_exhausted.append(tool_name)
    
    def check_budget(self) -> bool:
        """Check if we still have token budget remaining."""
        return self.budget_tokens_used < self.budget_tokens_limit
    
    def to_prompt_text(self) -> str:
        """Convert agent state to prompt-injectable text."""
        lines = ["=== AGENT STATE ==="]
        lines.append(f"Current Goal: {self.current_goal}")
        lines.append(f"Strategy: {self.current_strategy}")
        lines.append(f"Confidence: {self.confidence_level:.0%}")
        
        if self.decisions_made:
            lines.append("\nKey Decisions Made:")
            for d in self.decisions_made[-3:]:  # Last 3 decisions
                lines.append(f"  • {d['decision']}: {d['reasoning']}")
        
        if self.assumptions:
            lines.append(f"\nWorking Assumptions: {', '.join(self.assumptions[-3:])}")
        
        if self.uncertainty_areas:
            lines.append(f"\nUncertain About: {', '.join(self.uncertainty_areas)}")
        
        if self.needs_human_input:
            lines.append("\n⚠️ HUMAN INPUT REQUIRED")
        
        lines.append(
            f"\nBudget: {self.budget_tokens_used}/{self.budget_tokens_limit} tokens"
        )
        lines.append("===================")
        
        return "\n".join(lines)


class CompleteWorkingMemory:
    """
    Full working memory system combining:
    - Intermediate Outputs
    - Tool Results
    - Task Progress
    - Agent State Variables
    
    This is the complete "execution context" for an AI agent.
    """
    
    def __init__(self, task_id: str, task_description: str, agent_goal: str):
        self.task_id = task_id
        
        # All four components working together
        self.outputs = IntermediateOutputStore(task_id)
        self.tool_results = ToolResultMemory(task_id)
        self.progress = TaskProgressTracker(task_id, task_description)
        self.agent_state = AgentState(current_goal=agent_goal)
    
    def get_full_context_prompt(self) -> str:
        """
        Build complete working memory context for agent.
        This is injected into every LLM call during execution.
        """
        parts = []
        
        # Agent's own state
        parts.append(self.agent_state.to_prompt_text())
        
        # Task progress
        parts.append(self.progress.get_progress_for_prompt())
        
        # Available intermediate outputs
        if self.outputs.outputs:
            parts.append(self.outputs.get_summary_for_prompt())
        
        # Recent tool results
        if self.tool_results.tool_calls:
            recent_calls = self.tool_results.tool_calls[-3:]  # Last 3
            temp_store = ToolResultMemory(self.task_id)
            temp_store.tool_calls = recent_calls
            parts.append(temp_store.get_all_results_for_prompt())
        
        return "\n".join(parts)
    
    def save_checkpoint(self, filepath: str):
        """
        Save complete working memory state.
        Allows resuming a task after interruption.
        """
        checkpoint = {
            "task_id": self.task_id,
            "saved_at": datetime.now().isoformat(),
            "outputs": {
                k: {**v, "value": str(v["value"])}
                for k, v in self.outputs.outputs.items()
            },
            "tool_calls": self.tool_results.tool_calls,
            "progress": {
                step_id: {
                    "name": step.name,
                    "status": step.status.value,
                    "result": str(step.result) if step.result else None,
                    "error": step.error
                }
                for step_id, step in self.progress.steps.items()
            }
        }
        
        with open(filepath, 'w') as f:
            json.dump(checkpoint, f, indent=2)
        
        print(f"💾 Checkpoint saved: {filepath}")
```

```python
def run_research_agent(topic: str):
```

# ⚠️ PART E — FAILURE MODES

```
SHORT-TERM MEMORY FAILURES:
───────────────────────────────────────────────────────────────
❌ Conversation Buffer Explosion
   Problem: Store everything → context grows to 100K tokens
   → Costs $10 per conversation, slow responses
   Fix: Switch to sliding window + compress old messages

❌ Sliding Window Amnesia
   Problem: Window too small → forgets critical early context
   → User said name in message 1, window is now at 15-25
   Fix: Extract critical facts to long-term memory before sliding

❌ Session State Staleness
   Problem: Session state not updated after tool calls
   → Agent thinks task is pending when it already completed
   Fix: Always update state after EVERY action

LONG-TERM MEMORY FAILURES:
───────────────────────────────────────────────────────────────
❌ User Data Privacy Leak
   Problem: No user_id filter → User A sees User B's memories
   Fix: ALWAYS filter by user_id in every query — no exceptions

❌ Stale Historical Interactions
   Problem: Old interaction says "user uses Django"
   → User switched to FastAPI 6 months ago
   Fix: Add contradiction detection + timestamp-aware retrieval

❌ Preference Assumption
   Problem: AI learns "user prefers verbose answers" 
   → Actually user just asked ONE long question that day
   Fix: Require multiple observations before storing preference

❌ Knowledge Accumulation Drift
   Problem: Accumulate knowledge for years → old facts conflict
   → "User uses Python 3.8" stored but user upgraded to 3.12
   Fix: Regular knowledge graph pruning + conflict resolution

WORKING MEMORY FAILURES:
───────────────────────────────────────────────────────────────
❌ Lost Intermediate Outputs
   Problem: Agent crashes mid-task → all working memory lost
   → Task must restart from scratch
   Fix: Regular checkpointing to persistent storage

❌ Tool Result Overflow
   Problem: 50 tool calls → tool results take up entire context
   → LLM loses track of actual task
   Fix: Summarize old tool results, keep only recent ones

❌ Task Progress Desync
   Problem: Step marked "completed" but result was wrong
   → Agent proceeds on wrong foundation
   Fix: Validate step results before marking complete

❌ Infinite Retry Loop
   Problem: Agent keeps retrying failed step indefinitely
   → Wastes tokens, never progresses
   Fix: max_attempts limit + escalation to human
```

# 🎯 PART F — INTERVIEW PREP

### ❓ Q1: "Name the three types of AI memory and explain each in 30 seconds."

**💬 Strong Answer:**
> "The three types are short-term, long-term, and working memory. Short-term memory is the context window — what the LLM sees during the current session. It's fast but temporary, lost when the session ends. Long-term memory is persistent external storage — typically a vector database — that stores user data, preferences, past interactions, and accumulated knowledge across all sessions. Working memory is the task-specific scratchpad used during agent execution — it holds intermediate outputs, tool results, task progress, and agent state variables while a complex task is being performed. Together, these three types give an AI system the memory capabilities needed for production applications."

---

### ❓ Q2: "What is the difference between a Conversation Buffer and a Sliding Window, and when would you use each?"

**💬 Strong Answer:**
> "A Conversation Buffer stores the complete history of every message in the current session and passes it all to the LLM on every call. It gives perfect recall within a session but grows infinitely, making it expensive and slow for long conversations. A Sliding Window keeps only the last N messages, giving you predictable token costs and response times, but it can lose important early context when messages slide out. In practice, I'd use a Conversation Buffer for short, focused sessions like simple Q&A bots, and a Sliding Window for long-running conversations. The best production approach combines Sliding Window with Long-Term Memory — when messages slide out, we first extract and save key facts to a vector database, so nothing truly important is lost."

---

### ❓ Q3: "What is Working Memory in AI agents and why is it different from the other memory types?"

**💬 Strong Answer:**
> "Working memory is the task-execution-specific memory used by AI agents during the performance of a complex multi-step task. It differs from short-term memory, which manages conversation flow, and long-term memory, which handles persistent user knowledge. Working memory has four components: intermediate outputs which store partial results between steps, tool results which record what each tool call returned, task progress tracking which monitors which steps are complete, pending, or failed, and agent state variables which capture the agent's current goal, confidence level, and decisions made. Critically, working memory is ephemeral by design — it exists for the duration of one task and is cleared when the task completes or fails, though it should be checkpointed for recovery purposes."

---

### ❓ Q4: "What are the four types of long-term memory in a production AI system?"

**💬 Strong Answer:**
> "The four types are: First, persistent user data — stable facts about the user like name, job, timezone, and skill level that rarely change and are always injected into the prompt. Second, historical interactions — past conversations and problems solved, stored as vector embeddings and retrieved semantically when relevant. Third, user preferences — learned behavioral patterns like format preferences and communication style, extracted automatically from interactions over time. Fourth, knowledge accumulation — domain-specific facts, project details, past decisions, and rules that build up over months of interaction, making the AI increasingly useful for that specific user's work."
