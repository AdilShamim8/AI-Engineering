## 1️⃣ What Is This?

**Simple English:**

The Think → Act → Observe loop is the **most fundamental building block** of every intelligent agent.

It is the smallest possible loop that can produce intelligent behavior.

```
WITHOUT LOOP (Dumb Reflex):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Input → Reaction
No thought. No learning. Always same response to same input.
Like a smoke alarm — fire = alarm. Always. Forever.

WITH LOOP (Intelligent Agent):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Input →
    THINK: "What does this mean? What should I do?"
    ACT:   "Do that thing"
    OBSERVE: "What happened? Was it what I expected?"
    THINK again based on observation →
    ACT again →
    OBSERVE again →
    ...Until goal is reached

Fire = Think → "Is this a real fire or just toast?"
       Act → "Check visually"
       Observe → "Just toast. Cancel alarm."
```

## 2️⃣ First Principles — Why THREE Steps?

```
THINK ALONE (without act):
━━━━━━━━━━━━━━━━━━━━━━━━━━━
Pure reasoning. Beautiful ideas.
But nothing changes in the world.
Philosophy without engineering.

ACT ALONE (without think):
━━━━━━━━━━━━━━━━━━━━━━━━━━━
Random action. No purpose.
A bull in a china shop.
Like spamming keyboard shortcuts hoping something works.

OBSERVE ALONE (without think or act):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Just watching. Learning nothing.
Like reading a recipe but never cooking.

THINK + ACT (without observe):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Plans and executes but NEVER checks results.
Blind execution. No feedback learning.
Like cooking with eyes closed forever.

THINK + ACT + OBSERVE (complete):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ Reason about what to do (Think)
✅ Do it (Act)
✅ See what happened (Observe)
✅ Update understanding
✅ Reason again with NEW information
This creates LEARNING and ADAPTATION.
```

## 5️⃣ What "Think" Actually Contains

Most beginners think THINK is just "decide what to do."
A senior engineer knows it contains MUCH more:

```
THE FULL THINK PHASE BREAKDOWN:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. SITUATION ASSESSMENT
   "What is my current state?"
   "What do I know that is relevant?"
   "What has changed since the last loop?"

2. GOAL ALIGNMENT CHECK
   "Is my current trajectory still toward the goal?"
   "Has the goal changed or been clarified?"

3. OPTION GENERATION
   "What are ALL the things I could do now?"
   "What tools are available?"
   "What approaches have I NOT tried?"

4. OPTION EVALUATION
   "Which option is most likely to make progress?"
   "What are the risks of each option?"
   "What is the expected output of each?"

5. ACTION SELECTION
   "I choose [action] because [reasoning]"
   "I expect this to produce [expected_result]"

6. EXPECTATION SETTING
   "If this works, the next state will be [X]"
   "If this fails, I should try [Y]"

WHY EXPECTATION SETTING MATTERS:
Comparing expectation vs actual observation
is what creates LEARNING in the loop!
If actual = expected → confirmation of model
If actual ≠ expected → update your model!
```

## 6️⃣ What "Observe" Actually Does

```
THE FULL OBSERVE PHASE BREAKDOWN:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. RAW RESULT PARSING
   Convert action output to structured information
   "The search returned: [list of facts]"

2. EXPECTATION COMPARISON
   Compare actual vs expected from Think phase
   "Expected: 5 results. Got: 0 results." ← Surprise!
   "Expected: 200ms response. Got: timeout." ← Problem!

3. GOAL PROGRESS MEASUREMENT
   "Are we closer to the goal than before?"
   "By how much? Can we quantify it?"

4. STATE UPDATE
   Incorporate new information into current state
   "Now I know that API X is unavailable"
   "Now I know the data has 50,000 rows, not 500"

5. SURPRISE DETECTION
   "Did anything unexpected happen?"
   "Does this change what I need to do next?"
   Surprises are HIGH-INFORMATION EVENTS.
   Surprises should get extra attention in next Think phase.

6. COMPLETION ASSESSMENT
   "Is the goal now achieved?"
   "Can the goal even be achieved with current approach?"
   "Should I stop and report what I have?"
```

## 7️⃣ Technical Implementation — The Core Loop

```python
from langchain_openai import ChatOpenAI
from langchain_core.messages import SystemMessage, HumanMessage, AIMessage
from typing import List, Dict, Optional, Any
from dataclasses import dataclass, field
from enum import Enum
import json
import time

llm = ChatOpenAI(model="gpt-4o", temperature=0)
fast_llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)


# ═══════════════════════════════════════════════════
# DATA MODELS — The Think→Act→Observe State Machine
# ═══════════════════════════════════════════════════
class LoopPhase(Enum):
    THINK = "think"
    ACT   = "act"
    OBSERVE = "observe"


@dataclass
class ThinkOutput:
    """Structured output from the THINK phase"""
    reasoning: str           # Why am I doing this?
    chosen_action: str       # What will I do?
    action_type: str         # "tool_call" | "reasoning" | "final_answer"
    tool_name: Optional[str] # Which tool (if tool_call)
    tool_input: Optional[str]# Input for tool (if tool_call)
    expected_result: str     # What do I expect to happen?
    confidence: float        # How confident am I? (0.0-1.0)
    goal_progress: str       # How does this move toward goal?


@dataclass
class ObserveOutput:
    """Structured output from the OBSERVE phase"""
    raw_result: str          # What actually happened
    expectation_met: bool    # Did it match what we expected?
    surprise: Optional[str]  # What was unexpected (if anything)
    new_information: str     # What new info did we gain?
    goal_distance: str       # "closer" | "same" | "farther"
    is_goal_achieved: bool   # Are we done?
    next_think_hint: str     # What should we focus on in next Think?


@dataclass  
class LoopIteration:
    """Record of one complete Think→Act→Observe cycle"""
    iteration_number: int
    think: ThinkOutput
    action_result: str
    observe: ObserveOutput
    duration_ms: float


@dataclass
class AgentState:
    """Complete state of the agent across all iterations"""
    goal: str
    current_phase: LoopPhase
    iteration_count: int
    max_iterations: int
    iterations: List[LoopIteration] = field(default_factory=list)
    accumulated_knowledge: str = ""  # Everything learned so far
    is_complete: bool = False
    final_answer: Optional[str] = None


# ═══════════════════════════════════════════════════
# TOOL REGISTRY — Available actions
# ═══════════════════════════════════════════════════
class ToolRegistry:
    """Registry of all tools available to the agent"""
    
    def __init__(self):
        self.tools = {
            "search": self._search,
            "calculate": self._calculate,
            "analyze": self._analyze,
            "write": self._write,
            "verify": self._verify,
        }
    
    def _search(self, query: str) -> str:
        """Simulated web search"""
        prompt = f"Provide realistic search results for: {query}"
        return fast_llm.invoke(prompt).content
    
    def _calculate(self, expression: str) -> str:
        """Mathematical calculation"""
        try:
            result = eval(expression.replace("^", "**"))
            return f"Result: {result}"
        except Exception as e:
            return f"Calculation error: {e}"
    
    def _analyze(self, data: str) -> str:
        """Data analysis"""
        prompt = f"Analyze this data and provide key insights: {data}"
        return fast_llm.invoke(prompt).content
    
    def _write(self, instructions: str) -> str:
        """Content writing"""
        prompt = f"Write content based on: {instructions}"
        return fast_llm.invoke(prompt).content
    
    def _verify(self, claim: str) -> str:
        """Fact verification"""
        prompt = f"Verify this claim with evidence: {claim}"
        return fast_llm.invoke(prompt).content
    
    def execute(self, tool_name: str, tool_input: str) -> str:
        if tool_name in self.tools:
            return self.tools[tool_name](tool_input)
        return f"Error: Tool '{tool_name}' not found"
    
    def get_tools_description(self) -> str:
        return """Available tools:
        - search(query): Search for current information
        - calculate(expression): Perform math calculations  
        - analyze(data): Analyze and extract insights from data
        - write(instructions): Write content or documents
        - verify(claim): Verify factual claims"""


# ═══════════════════════════════════════════════════
# THE THINK→ACT→OBSERVE LOOP ENGINE
# ═══════════════════════════════════════════════════
class ThinkActObserveEngine:
    """
    The core iterative reasoning engine.
    Implements the fundamental Think→Act→Observe loop.
    """
    
    def __init__(
        self,
        llm,
        tools: ToolRegistry,
        max_iterations: int = 10
    ):
        self.llm = llm
        self.tools = tools
        self.max_iterations = max_iterations
    
    # ──────────────────────────────────────────────
    # THINK PHASE
    # ──────────────────────────────────────────────
    def think(self, state: AgentState) -> ThinkOutput:
        """
        Reason about what to do next.
        Uses all accumulated knowledge + history.
        """
        
        # Build history summary from previous iterations
        history = ""
        if state.iterations:
            recent = state.iterations[-5:]  # Last 5 iterations
            history = "\n".join([
                f"Iteration {it.iteration_number}:\n"
                f"  Did: {it.think.chosen_action}\n"
                f"  Result: {it.action_result[:200]}...\n"
                f"  Learned: {it.observe.new_information}"
                for it in recent
            ])
        
        prompt = f"""
        You are an intelligent AI agent solving a problem iteratively.
        
        GOAL: {state.goal}
        
        CURRENT ITERATION: {state.iteration_count + 1} of {state.max_iterations}
        
        {self.tools.get_tools_description()}
        
        ACCUMULATED KNOWLEDGE:
        {state.accumulated_knowledge or "No information gathered yet. This is the first iteration."}
        
        RECENT ITERATION HISTORY:
        {history or "No previous iterations. This is the first."}
        
        Now THINK carefully:
        1. What is the current situation?
        2. What do I still need to learn or do to achieve the goal?
        3. What is the BEST next action?
        4. What do I expect to happen?
        
        IMPORTANT: If you have enough information to give a final answer,
        choose action_type "final_answer" and provide the answer in 
        tool_input field.
        
        Return JSON:
        {{
            "reasoning": "Step-by-step thinking about what to do",
            "chosen_action": "Description of the action",
            "action_type": "tool_call|final_answer",
            "tool_name": "search|calculate|analyze|write|verify|null",
            "tool_input": "Exact input for the tool OR the final answer",
            "expected_result": "What I expect to happen",
            "confidence": 0.85,
            "goal_progress": "How this moves toward the goal"
        }}
        """
        
        response = self.llm.invoke(prompt).content
        if "```json" in response:
            response = response.split("```json")[1].split("```")[0]
        
        data = json.loads(response.strip())
        
        think_output = ThinkOutput(
            reasoning=data["reasoning"],
            chosen_action=data["chosen_action"],
            action_type=data["action_type"],
            tool_name=data.get("tool_name"),
            tool_input=data.get("tool_input", ""),
            expected_result=data["expected_result"],
            confidence=data.get("confidence", 0.7),
            goal_progress=data["goal_progress"]
        )
        
        print(f"\n💭 THINK [{state.iteration_count + 1}]:")
        print(f"   Reasoning: {think_output.reasoning[:100]}...")
        print(f"   Action: {think_output.chosen_action}")
        print(f"   Confidence: {think_output.confidence:.0%}")
        print(f"   Expects: {think_output.expected_result[:80]}...")
        
        return think_output
    
    # ──────────────────────────────────────────────
    # ACT PHASE
    # ──────────────────────────────────────────────
    def act(self, think_output: ThinkOutput) -> str:
        """
        Execute the action chosen in Think phase.
        Could be a tool call, reasoning, or final answer.
        """
        
        print(f"\n⚡ ACT:")
        
        if think_output.action_type == "final_answer":
            print(f"   Type: FINAL ANSWER")
            return f"FINAL_ANSWER: {think_output.tool_input}"
        
        elif think_output.action_type == "tool_call":
            print(f"   Tool: {think_output.tool_name}")
            print(f"   Input: {think_output.tool_input[:80]}...")
            
            start = time.time()
            result = self.tools.execute(
                think_output.tool_name or "search",
                think_output.tool_input or ""
            )
            elapsed = (time.time() - start) * 1000
            
            print(f"   ✅ Got result in {elapsed:.0f}ms")
            return result
        
        else:
            # Pure reasoning action
            print(f"   Type: REASONING")
            prompt = f"Reason about: {think_output.tool_input}"
            return self.llm.invoke(prompt).content
    
    # ──────────────────────────────────────────────
    # OBSERVE PHASE
    # ──────────────────────────────────────────────
    def observe(
        self,
        state: AgentState,
        think_output: ThinkOutput,
        action_result: str
    ) -> ObserveOutput:
        """
        Process and interpret the action result.
        Update understanding. Assess progress.
        """
        
        # Special case: final answer was given
        if action_result.startswith("FINAL_ANSWER:"):
            return ObserveOutput(
                raw_result=action_result,
                expectation_met=True,
                surprise=None,
                new_information="Goal achieved — final answer provided",
                goal_distance="achieved",
                is_goal_achieved=True,
                next_think_hint="Goal is complete"
            )
        
        prompt = f"""
        You are observing the result of an AI agent's action.
        
        GOAL: {state.goal}
        
        WHAT THE AGENT DID:
        {think_output.chosen_action}
        
        WHAT THE AGENT EXPECTED:
        {think_output.expected_result}
        
        WHAT ACTUALLY HAPPENED (result):
        {action_result[:1500]}
        
        ACCUMULATED KNOWLEDGE SO FAR:
        {state.accumulated_knowledge[:1000] if state.accumulated_knowledge else "None yet"}
        
        Evaluate this observation:
        
        Return JSON:
        {{
            "raw_result": "One sentence summary of what happened",
            "expectation_met": true/false,
            "surprise": "What was unexpected (null if nothing surprising)",
            "new_information": "Key new facts or insights gained",
            "goal_distance": "closer|same|farther",
            "is_goal_achieved": true/false,
            "next_think_hint": "What should next iteration focus on?"
        }}
        """
        
        response = fast_llm.invoke(prompt).content
        if "```json" in response:
            response = response.split("```json")[1].split("```")[0]
        
        data = json.loads(response.strip())
        
        observe_output = ObserveOutput(
            raw_result=data["raw_result"],
            expectation_met=data["expectation_met"],
            surprise=data.get("surprise"),
            new_information=data["new_information"],
            goal_distance=data["goal_distance"],
            is_goal_achieved=data["is_goal_achieved"],
            next_think_hint=data["next_think_hint"]
        )
        
        # Expectation gap detection
        expectation_icon = "✅" if observe_output.expectation_met else "⚠️"
        progress_icon = {
            "closer": "📈", "same": "➡️", "farther": "📉"
        }.get(observe_output.goal_distance, "❓")
        
        print(f"\n👁️ OBSERVE:")
        print(f"   Result: {observe_output.raw_result[:100]}...")
        print(f"   Expectation met: {expectation_icon}")
        if observe_output.surprise:
            print(f"   ⚠️ SURPRISE: {observe_output.surprise[:100]}")
        print(f"   Progress: {progress_icon} {observe_output.goal_distance}")
        print(f"   New info: {observe_output.new_information[:100]}...")
        
        return observe_output
    
    # ──────────────────────────────────────────────
    # MAIN LOOP
    # ──────────────────────────────────────────────
    def run(self, goal: str) -> Dict:
        """
        Run the complete Think→Act→Observe loop.
        Keeps iterating until goal is achieved or limit reached.
        """
        
        print(f"\n{'='*60}")
        print(f"🎯 GOAL: {goal}")
        print(f"📏 Max iterations: {self.max_iterations}")
        print(f"{'='*60}")
        
        # Initialize state
        state = AgentState(
            goal=goal,
            current_phase=LoopPhase.THINK,
            iteration_count=0,
            max_iterations=self.max_iterations
        )
        
        start_time = time.time()
        
        # THE MAIN LOOP
        while (not state.is_complete and 
               state.iteration_count < state.max_iterations):
            
            loop_start = time.time()
            
            print(f"\n{'─'*60}")
            print(f"ITERATION {state.iteration_count + 1}")
            print(f"{'─'*60}")
            
            # ═══ THINK ═══
            state.current_phase = LoopPhase.THINK
            think_output = self.think(state)
            
            # ═══ ACT ═══
            state.current_phase = LoopPhase.ACT
            action_result = self.act(think_output)
            
            # ═══ OBSERVE ═══
            state.current_phase = LoopPhase.OBSERVE
            observe_output = self.observe(state, think_output, action_result)
            
            # Record this iteration
            iteration = LoopIteration(
                iteration_number=state.iteration_count + 1,
                think=think_output,
                action_result=action_result,
                observe=observe_output,
                duration_ms=(time.time() - loop_start) * 1000
            )
            state.iterations.append(iteration)
            
            # Update accumulated knowledge
            if observe_output.new_information:
                state.accumulated_knowledge += f"\n• {observe_output.new_information}"
            
            # Check if done
            if observe_output.is_goal_achieved:
                state.is_complete = True
                
                # Extract final answer
                if action_result.startswith("FINAL_ANSWER:"):
                    state.final_answer = action_result[13:].strip()
                else:
                    state.final_answer = action_result
                
                print(f"\n🎉 GOAL ACHIEVED in {state.iteration_count + 1} iterations!")
            
            state.iteration_count += 1
        
        # If we ran out of iterations without completing
        if not state.is_complete:
            print(f"\n⚠️ Max iterations ({self.max_iterations}) reached")
            # Synthesize best answer from what we have
            synthesis_prompt = f"""
            Goal: {goal}
            
            We ran out of iterations. Based on accumulated knowledge:
            {state.accumulated_knowledge}
            
            Provide the best possible answer with what we have.
            Clearly note what information might be incomplete.
            """
            state.final_answer = self.llm.invoke(synthesis_prompt).content
        
        # Final summary
        total_time = time.time() - start_time
        print(f"\n{'='*60}")
        print(f"📊 LOOP SUMMARY")
        print(f"   Iterations used: {state.iteration_count}/{self.max_iterations}")
        print(f"   Total time: {total_time:.1f}s")
        print(f"   Avg per iteration: {total_time/max(state.iteration_count,1):.1f}s")
        
        # Show expectation accuracy
        expectations_met = sum(
            1 for it in state.iterations 
            if it.observe.expectation_met
        )
        print(f"   Expectations met: {expectations_met}/{len(state.iterations)}")
        
        surprises = [
            it.observe.surprise 
            for it in state.iterations 
            if it.observe.surprise
        ]
        if surprises:
            print(f"   Surprises encountered: {len(surprises)}")
            for s in surprises:
                print(f"     • {s[:60]}...")
        
        print(f"{'='*60}")
        
        return {
            "goal": goal,
            "answer": state.final_answer,
            "iterations_used": state.iteration_count,
            "completed": state.is_complete,
            "iterations": state.iterations,
            "accumulated_knowledge": state.accumulated_knowledge
        }


# ═══════════════════════════════════════════════════
# RUN IT
# ═══════════════════════════════════════════════════
tools = ToolRegistry()
engine = ThinkActObserveEngine(llm, tools, max_iterations=8)

result = engine.run(

         "and give me 3 specific project ideas with tech stacks"
)

print(f"\n✅ FINAL ANSWER:\n{result['answer']}")

## 9️⃣ Failure Modes

```
❌ FAILURE 1: Observation Blindness
   What: Agent runs Act but doesn't truly USE the observation
   Example: Search returns "API unavailable"
            Next Think: "Let me search for the same thing again"
            Agent ignores the observation entirely!
   Why: Observation not properly integrated into state
   Fix: Observation MUST update accumulated_knowledge
        Next Think MUST explicitly reference recent observations

❌ FAILURE 2: Think Without New Information
   What: Each Think reaches the same conclusion
   Example: "I don't have enough info. Let me search X."
            After 5 searches: "I don't have enough info. Let me search X."
            Identical loop — no progress
   Why: Agent isn't learning from observations
        Observations show no new information
   Fix: Track "unique_queries_made" — don't repeat same search
        If last 3 observations gave same info → change strategy

❌ FAILURE 3: Action Without Think
   What: Agent skips the reasoning step and just acts
   Example: Pattern-matching to "whenever I see X, I do Y"
            Without asking "should I do Y right now?"
   Why: Speed optimization gone wrong
        Or system prompt not enforcing Think phase
   Fix: Require structured Think output before every Act
        Enforce the ThinkOutput schema

❌ FAILURE 4: Observation Overload
   What: Observation contains too much information
   Example: Agent searches and gets 50,000 words of results
            Next Think: overwhelmed, no clear next step
   Why: Observe phase doesn't summarize properly
   Fix: Observe must extract KEY INSIGHTS not raw data
        "Top 3 most relevant facts" not "all information found"
        Always compress: raw result → structured insights
```

## 1️⃣ What Is This?

**Simple English:**

This is the **strategic** loop. It sits one level ABOVE Think→Act→Observe.

```
Think→Act→Observe:             Plan→Execute→Evaluate→Revise:
━━━━━━━━━━━━━━━━━━━━━━━━━━      ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Tactical loop                  Strategic loop
"What do I do right now?"      "Is my overall approach working?"
Happens at each step           Happens after each phase
Fast, reactive                 Slower, reflective
                               Operates on the PLAN itself
```

> **The key difference:**
> Think→Act→Observe improves one step at a time.
> Plan→Execute→Evaluate→Revise improves the **entire strategy**.

## 5️⃣ What Makes Evaluation POWERFUL — The 5 Evaluation Dimensions

```
MOST AGENTS ONLY EVALUATE:
  "Did I achieve the goal?" YES/NO

GREAT AGENTS EVALUATE 5 DIMENSIONS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. EFFECTIVENESS: "Did I achieve the goal?"
   Score: 0-10
   Example: "Achieved 7/10 key objectives"
   
2. EFFICIENCY: "How much did it cost to achieve it?"
   Metrics: API calls, time, tokens, tool uses
   Example: "Used 15 LLM calls when 8 should suffice"
   
3. QUALITY: "Is the output actually good?"
   Subjective assessment
   Example: "Answer is accurate but poorly organized"
   
4. ROBUSTNESS: "How many errors occurred?"
   Error rate, retries needed
   Example: "3 out of 8 steps needed retry"
   
5. ALIGNMENT: "Did I do what was asked?"
   Match between intent and execution
   Example: "Asked for brief summary, produced 2000 words"
   
THESE 5 DIMENSIONS CREATE RICH EVALUATION
THAT ENABLES SPECIFIC, TARGETED REVISION
```

@dataclass
class EvaluationScore:
    """Multi-dimensional evaluation of execution"""
    effectiveness: float      # 0-10: Did we achieve goal?
    efficiency: float         # 0-10: Resource usage
    quality: float            # 0-10: Output quality
    robustness: float         # 0-10: Error handling
    alignment: float          # 0-10: Matched user intent
    
    @property
    def overall(self) -> float:
        """Weighted average — effectiveness matters most"""
        weights = {
            "effectiveness": 0.35,
            "efficiency": 0.15,
            "quality": 0.30,
            "robustness": 0.10,
            "alignment": 0.10
        }
        return (
            self.effectiveness * weights["effectiveness"] +
            self.efficiency * weights["efficiency"] +
            self.quality * weights["quality"] +
            self.robustness * weights["robustness"] +
            self.alignment * weights["alignment"]
        )

        print(f"   Efficiency:    {scores.efficiency}/10")
        print(f"   Quality:       {scores.quality}/10")
        print(f"   Robustness:    {scores.robustness}/10")
        print(f"   Alignment:     {scores.alignment}/10")
        print(f"   {'─'*30}")
        print(f"   OVERALL:       {scores.overall:.1f}/10")
        
        report = EvaluationReport(
            scores=scores,
            strengths=data["strengths"],
            weaknesses=data["weaknesses"],
            root_causes=data["root_causes"],
            specific_improvements=data["specific_improvements"],
            should_revise=data["should_revise"],
            revision_priority=data["revision_priority"]
        )
        
        if report.weaknesses:
            print(f"\n   ⚠️ Weaknesses found: {len(report.weaknesses)}")
            for w in report.weaknesses[:3]:
                print(f"      • {w}")
        
        return report
    
    def compute_convergence(
        self,
        evaluation: EvaluationReport,
        threshold: float
    ) -> float:
        """
        Compute convergence score.
        How close are we to "good enough"?
        """
        convergence = evaluation.scores.overall / 10.0
        print(f"\n   🎯 Convergence: {convergence:.0%} "
              f"(threshold: {threshold:.0%})")
        return convergence

# PLAN EXECUTOR — Runs one plan iteration
# ═══════════════════════════════════════════════════
class PlanExecutor:
    def __init__(self, llm):
        self.llm = llm
    
    def execute_step(
        self,
        step: Dict,
        context: str
    ) -> Dict:
        """Execute one plan step"""
        
        prompt = f"""
        Execute this strategic plan step:
        
        Step: {step['title']}
        Action: {step['action']}
        Tool: {step.get('tool', 'reason')}
        Success Criteria: {step.get('success_criteria', 'Complete the action')}
        
        Available context:
        {context[:2000]}
        
        Execute completely. Return structured result.
        """
        
        try:
            result = self.llm.invoke(prompt).content
            success = len(result) > 50  # Simple success check
            
            return {
                "step_id": step["step_id"],
                "title": step["title"],
                "status": "success" if success else "partial",
                "output": result,
                "error": None
            }
        except Exception as e:
            return {
                "step_id": step["step_id"],
                "title": step["title"],
                "status": "failed",
                "output": "",
                "error": str(e)
            }
    
    def run_plan(self, plan: List[Dict], goal: str) -> List[Dict]:
        """Execute all steps in a plan"""
        
        results = []
        context = f"Goal: {goal}\n\nPrevious results:"
        
        for step in plan:
            print(f"\n   ⚡ Step {step['step_id']}: {step['title']}")
            result = self.execute_step(step, context)
            results.append(result)
            
            status_icon = {
                "success": "✅", "partial": "⚠️", "failed": "❌"
            }.get(result["status"], "?")
            print(f"   {status_icon} {result['status']}")
            
            # Add result to context for next step
            context += f"\n\n[{step['step_id']}] {result['output'][:400]}"
        
        return results

    Plan → Execute → Evaluate → Revise loop.

    """

        self,

        self.max_revisions = max_revisions

    def run(self, goal: str) -> Dict:
        """Full PEER loop execution"""
        
        print(f"\n{'='*65}")
        print(f"🎯 PEER LOOP STARTING")
        print(f"Goal: {goal}")
        print(f"Max revisions: {self.max_revisions}")
        print(f"Convergence target: {self.convergence_threshold:.0%}")
        print(f"{'='*65}")
        
        evaluation_history = []
        revision_history = []
        current_evaluation = None
        convergence_score = 0.0
        revision_num = 0
        
        while revision_num <= self.max_revisions:
            
            print(f"\n{'─'*65}")
            if revision_num == 0:
                print(f"📋 ITERATION 1: INITIAL PLAN")
            else:
                print(f"📋 ITERATION {revision_num + 1}: REVISION {revision_num}")
            print(f"{'─'*65}")
            
            # ═══ PLAN ═══
            print(f"\n🗺️ PLAN PHASE")
            plan = self.planner.create_plan(
                goal=goal,
                previous_evaluation=current_evaluation,
                revision_history=revision_history if revision_history else None
            )
            print(f"   Created {len(plan)}-step plan")
            for step in plan:
                print(f"   • [{step['step_id']}] {step['title']}")
            
            # ═══ EXECUTE ═══
            print(f"\n⚡ EXECUTE PHASE")
            results = self.executor.run_plan(plan, goal)
            
            success_count = sum(
                1 for r in results if r["status"] == "success"
            )
            print(f"   Completed: {success_count}/{len(results)} steps successful")
            
            # ═══ EVALUATE ═══
            print(f"\n📊 EVALUATE PHASE")
            evaluation = self.evaluator.evaluate(
                goal, plan, results, self.convergence_threshold
            )
            evaluation_history.append(evaluation)
            current_evaluation = evaluation
            
            # Compute convergence
            convergence_score = self.evaluator.compute_convergence(
                evaluation, self.convergence_threshold
            )
            
            # Check convergence
            if convergence_score >= self.convergence_threshold:
                print(f"\n✅ CONVERGED! Score {convergence_score:.0%} >= "
                      f"threshold {self.convergence_threshold:.0%}")
                break
            
            # Check if max revisions reached
            if revision_num >= self.max_revisions:
                print(f"\n⚠️ Max revisions ({self.max_revisions}) reached")
                break
            
            if not evaluation.should_revise:
                print(f"\n✅ Evaluator: No revision needed")
                break
            
            # ═══ REVISE ═══
            print(f"\n🔄 REVISE PHASE")
            revision_num += 1
            revision = self.revisor.create_revision(
                evaluation, plan, revision_num
            )
            revision_history.append(revision)
        
        # Final output synthesis
        print(f"\n{'='*65}")
        print(f"📊 PEER LOOP COMPLETE")
        print(f"   Total iterations: {revision_num + 1}")
        print(f"   Final score: {convergence_score:.0%}")
        print(f"   Converged: {convergence_score >= self.convergence_threshold}")
        
        # Score improvement over iterations
        if len(evaluation_history) > 1:
            first_score = evaluation_history[0].scores.overall
            last_score = evaluation_history[-1].scores.overall
            improvement = last_score - first_score
            print(f"   Score improvement: {improvement:+.1f}/10")
        
        print(f"{'='*65}")
        
        return {
            "goal": goal,
            "iterations": revision_num + 1,
            "final_convergence_score": convergence_score,
            "converged": convergence_score >= self.convergence_threshold,
            "evaluation_history": evaluation_history,
            "revision_history": revision_history
        }

## 7️⃣ Failure Modes — PEER Loop

```
❌ FAILURE 1: Biased Self-Evaluation
   Problem: The same LLM that executed also evaluates
            It rates its own work too generously
   Example: Poor output scored 8.5/10 by its own evaluation
            True quality is 4/10
   Fix: Use SEPARATE, more critical evaluator prompt
        Add: "You must find at least 3 specific weaknesses"
        Use adversarial evaluation framing

❌ FAILURE 2: Evaluation Without Root Cause
   Problem: Evaluation identifies what is wrong but not WHY
   Example: Weakness: "Output was too short"
            No root cause → Revision doesn't know what to change
   Fix: Every weakness MUST have a paired root cause
        "Output was short BECAUSE the search step only returned 
         summaries without full articles"

❌ FAILURE 3: Revision Groundhog Day
   Problem: Each revision makes the same changes
            Performance stays flat across iterations
   Example: Revision 1: "Search more thoroughly"
            Revision 2: "Search more thoroughly" (again!)
            Revision 3: "Search more thoroughly" (again!)
   Fix: Track revision history, FORBID repeating same changes
        "Your revisions must be fundamentally different from: [history]"

❌ FAILURE 4: Over-Revising What Works
   Problem: Revision changes EVERYTHING, even the parts working well
   Example: Quality was 9/10. Efficiency was 4/10.
            Revision changes the whole quality approach too!
            Next iteration: Quality drops to 6/10, efficiency: 5/10
   Fix: Explicit STRENGTHS section that revisor must preserve
        "These elements MUST remain unchanged: [strengths]"

❌ FAILURE 5: Ignoring Convergence Score
   Problem: Agent keeps revising even when already good enough
   Example: Score = 9.1/10 after iteration 1
            Agent revises 3 more times, ends at 8.7/10
            Wasted compute, actually got WORSE
   Fix: Set convergence_threshold and HONOR it
        "If score > threshold, STOP. Done is better than perfect."
```

## 1️⃣ What Is This?

**Simple English:**
Error-Driven Replanning is a **specialized loop that activates ONLY when something breaks** — and then intelligently recovers.

```
NORMAL LOOP (no errors):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Think → Act → Observe → Think → Act → Observe...

ERROR-DRIVEN REPLANNING (when errors hit):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Think → Act → ERROR! →
    ERROR CLASSIFIER: "What type of error is this?"
    ERROR DIAGNOSIS: "Why did it happen?"
    RECOVERY STRATEGY: "How do I fix it?"
    REPLAN: "New plan that avoids this error"
→ Think → Act → Observe (now with better plan)
```

> **The key insight:**
> Errors are not just failures to handle.
> **Errors are information.**
> They tell you exactly what's wrong with the current approach.
> Error-driven replanning turns failures into improvements.

## 4️⃣ Technical Implementation — Error Recovery System

```python
from langchain_openai import ChatOpenAI
from typing import Dict, Optional, List, Callable, Any
from dataclasses import dataclass, field
from enum import Enum
import json
import time
import traceback

llm = ChatOpenAI(model="gpt-4o", temperature=0)


# ═══════════════════════════════════════════════════
# ERROR DATA MODELS
# ═══════════════════════════════════════════════════
class ErrorType(Enum):
    TRANSIENT = "transient"
    LOGICAL = "logical"
    DATA = "data"
    RESOURCE = "resource"
    SEMANTIC = "semantic"
    UNKNOWN = "unknown"


class RecoveryStrategy(Enum):
    RETRY = "retry"
    LOCAL_FIX = "local_fix"
    PARTIAL_REPLAN = "partial_replan"
    FULL_REPLAN = "full_replan"
    ASK_USER = "ask_user"
    SKIP = "skip"
    DEGRADE = "degrade"


@dataclass
class ErrorEvent:
    """Complete record of an error occurrence"""
    error_id: str
    task_id: str
    task_title: str
    error_message: str
    error_traceback: str
    error_type: ErrorType
    diagnosis: str
    recovery_strategy: RecoveryStrategy
    recovery_action: str
    recovery_succeeded: bool
    timestamp: float = field(default_factory=time.time)
    retry_count: int = 0


# ═══════════════════════════════════════════════════
# ERROR CLASSIFIER — Determines error type
# ═══════════════════════════════════════════════════
class ErrorClassifier:
    """
    Classifies errors into types for appropriate treatment.
    Uses both rule-based and LLM-based classification.
    """
    
    def __init__(self, llm):
        self.llm = llm
        
        # Rule-based patterns for fast classification
        # (faster and cheaper than LLM for known patterns)
        self.transient_patterns = [
            "timeout", "rate limit", "429", "503", "502",
            "connection reset", "temporary", "retry", "too many requests"
        ]
        self.resource_patterns = [
            "not found", "unavailable", "deprecated", "quota exceeded",
            "permission denied", "api key", "unauthorized"
        ]
        self.data_patterns = [
            "invalid format", "parse error", "unexpected type",
            "missing field", "schema", "json decode", "key error"
        ]
    
    def classify(
        self,
        error: Exception,
        task: Dict,
        context: str
    ) -> tuple[ErrorType, str]:
        """
        Returns: (error_type, diagnosis_explanation)
        """
        
        error_msg = str(error).lower()
        traceback_str = traceback.format_exc().lower()
        combined = error_msg + " " + traceback_str
        
        # Rule-based fast path
        if any(pattern in combined for pattern in self.transient_patterns):
            return (
                ErrorType.TRANSIENT,
                f"Temporary service issue: {str(error)[:100]}"
            )
        
        if any(pattern in combined for pattern in self.resource_patterns):
            return (
                ErrorType.RESOURCE,
                f"Resource unavailable: {str(error)[:100]}"
            )
        
        if any(pattern in combined for pattern in self.data_patterns):
            return (
                ErrorType.DATA,
                f"Data format mismatch: {str(error)[:100]}"
            )
        
        # LLM-based classification for ambiguous errors
        prompt = f"""
        Classify this AI agent error:
        
        Task that failed: {task.get('title', 'Unknown')}
        Error message: {str(error)}
        
        Error types:
        - transient: Temporary issue, retry will likely work
        - logical: Wrong approach/tool, need different strategy
        - data: Data format/content mismatch, need preprocessing
        - resource: Tool/API unavailable, need alternative
        - semantic: Misunderstood the goal, need clarification
        
        Return JSON:
        {{
            "error_type": "transient|logical|data|resource|semantic",
            "diagnosis": "Why did this error occur?",
            "evidence": "What in the error message led to this classification?"
        }}
        """
        
        response = self.llm.invoke(prompt).content
        if "```json" in response:
            response = response.split("```json")[1].split("```")[0]
        
        result = json.loads(response.strip())
        
        error_type_map = {
            "transient": ErrorType.TRANSIENT,
            "logical": ErrorType.LOGICAL,
            "data": ErrorType.DATA,
            "resource": ErrorType.RESOURCE,
            "semantic": ErrorType.SEMANTIC
        }
        
        return (
            error_type_map.get(result["error_type"], ErrorType.UNKNOWN),
            result["diagnosis"]
        )


# ═══════════════════════════════════════════════════
# ERROR RECOVERY ENGINE
# ═══════════════════════════════════════════════════
class ErrorRecoveryEngine:
    """
    Handles errors intelligently.
    Matches error type to appropriate recovery strategy.
    """
    
    def __init__(self, llm, max_retries: int = 3):
        self.llm = llm
        self.max_retries = max_retries
        self.classifier = ErrorClassifier(llm)
        self.error_memory: List[ErrorEvent] = []  # Never make same mistake twice!
    
    def select_strategy(
        self,
        error_type: ErrorType,
        retry_count: int,
        error_impact: int  # How many remaining tasks are affected?
    ) -> RecoveryStrategy:
        """Map error type to recovery strategy"""
        
        if error_type == ErrorType.TRANSIENT:
            if retry_count < self.max_retries:
                return RecoveryStrategy.RETRY
            else:
                return RecoveryStrategy.DEGRADE  # Retry exhausted → degrade
        
        elif error_type == ErrorType.LOGICAL:
            return RecoveryStrategy.PARTIAL_REPLAN  # Never retry logical!
        
        elif error_type == ErrorType.DATA:
            return RecoveryStrategy.LOCAL_FIX  # Add data preprocessing
        
        elif error_type == ErrorType.RESOURCE:
            return RecoveryStrategy.LOCAL_FIX  # Use alternative tool
        
        elif error_type == ErrorType.SEMANTIC:
            if error_impact > 5:
                return RecoveryStrategy.FULL_REPLAN
            return RecoveryStrategy.ASK_USER
        
        else:  # UNKNOWN
            return RecoveryStrategy.PARTIAL_REPLAN  # Safe default
    
    def generate_recovery_action(
        self,
        strategy: RecoveryStrategy,
        error_event: ErrorEvent,
        task: Dict,
        remaining_tasks: List[Dict],
        goal: str
    ) -> Dict:
        """Generate specific recovery action for chosen strategy"""
        
        # Get error history to avoid repeating mistakes
        prev_errors_for_task = [
            e for e in self.error_memory
            if e.task_id == task.get("step_id")
        ]
        prev_failures = "\n".join([
            f"• Tried: {e.recovery_action[:100]} → {e.recovery_succeeded}"
            for e in prev_errors_for_task[-3:]
        ])
        
        prompt = f"""
        Generate specific recovery action for an AI agent error.
        
        GOAL: {goal}
        
        FAILED TASK:
        {json.dumps(task, indent=2)}
        
        ERROR: {error_event.error_message}
        ERROR TYPE: {error_event.error_type.value}
        DIAGNOSIS: {error_event.diagnosis}
        CHOSEN STRATEGY: {strategy.value}
        
        PREVIOUS RECOVERY ATTEMPTS FOR THIS TASK:
        {prev_failures or "None — this is the first failure"}
        
        REMAINING TASKS AFTER FAILED ONE:
        {json.dumps([t['title'] for t in remaining_tasks[:5]], indent=2)}
        
        Generate SPECIFIC recovery action.
        Do NOT suggest the same approach as previous failures.
        
        Return JSON based on strategy:
        
        If RETRY: {{"action": "retry", "modifications": "Any parameter changes"}}
        If LOCAL_FIX: {{"action": "replace_task", "new_steps": [{{...}}]}}
        If PARTIAL_REPLAN: {{"action": "replan_remaining", "new_approach": "..."}}
        If FULL_REPLAN: {{"action": "full_replan", "new_strategy": "..."}}
        If SKIP: {{"action": "skip", "impact_mitigation": "..."}}
        If DEGRADE: {{"action": "degrade", "reduced_output": "What we can still provide"}}
        If ASK_USER: {{"action": "ask_user", "question": "Specific clarifying question"}}
        """
        
        response = self.llm.invoke(prompt).content
        if "```json" in response:
            response = response.split("```json")[1].split("```")[0]
        
        return json.loads(response.strip())
    
    def handle_error(
        self,
        error: Exception,
        task: Dict,
        remaining_tasks: List[Dict],
        goal: str,
        retry_count: int = 0
    ) -> Dict:
        """
        Main error handling method.
        Returns recovery action to take.
        """
        
        import uuid
        
        print(f"\n⚠️ ERROR DETECTED in task '{task.get('title')}'")
        print(f"   Message: {str(error)[:100]}")
        
        # STEP 1: CLASSIFY
        error_type, diagnosis = self.classifier.classify(
            error, task, str(remaining_tasks)
        )
        print(f"   Type: {error_type.value}")
        print(f"   Diagnosis: {diagnosis[:100]}...")
        
        # STEP 2: SELECT STRATEGY
        strategy = self.select_strategy(
            error_type, retry_count, len(remaining_tasks)
        )
        print(f"   Strategy: {strategy.value}")
        
        # STEP 3: CREATE ERROR EVENT RECORD
        error_event = ErrorEvent(
            error_id=str(uuid.uuid4())[:8],
            task_id=task.get("step_id", "unknown"),
            task_title=task.get("title", "unknown"),
            error_message=str(error),
            error_traceback=traceback.format_exc(),
            error_type=error_type,
            diagnosis=diagnosis,
            recovery_strategy=strategy,
            recovery_action="",  # Will fill in
            recovery_succeeded=False  # Will update
        )
        
        # STEP 4: GENERATE RECOVERY ACTION
        recovery_action = self.generate_recovery_action(
            strategy, error_event, task, remaining_tasks, goal
        )
        
        error_event.recovery_action = str(recovery_action)
        self.error_memory.append(error_event)
        
        print(f"   Recovery: {recovery_action.get('action', 'unknown')}")
        
        return {
            "error_type": error_type,
            "diagnosis": diagnosis,
            "strategy": strategy,
            "recovery_action": recovery_action,
            "error_event": error_event
        }

class ErrorAwareAgent:
    """Agent with built-in error recovery"""
    
    def __init__(self, llm):
        self.llm = llm
        self.error_recovery = ErrorRecoveryEngine(llm)
    
    def safe_execute_task(
        self,
        task: Dict,
        remaining_tasks: List[Dict],
        goal: str,
        context: str
    ) -> Dict:
        """Execute task with comprehensive error handling"""
        
        retry_count = 0
        max_retries = 3
        
        while retry_count <= max_retries:
            try:
                # Attempt task execution
                prompt = f"""
                Execute: {task['title']}
                Action: {task.get('action', task['title'])}
                Context: {context[:1000]}
                Goal: {goal}
                """
                result = self.llm.invoke(prompt).content
                
                # Mark error as recovered if this was a retry
                if retry_count > 0 and self.error_recovery.error_memory:
                    self.error_recovery.error_memory[-1].recovery_succeeded = True
                
                return {
                    "status": "success",
                    "result": result,
                    "retry_count": retry_count
                }
            
            except Exception as e:
                print(f"\n💥 Task failed (attempt {retry_count + 1})")
                
                # Handle the error
                recovery = self.error_recovery.handle_error(
                    e, task, remaining_tasks, goal, retry_count
                )
                
                strategy = recovery["strategy"]
                
                if strategy == RecoveryStrategy.RETRY:
                    retry_count += 1
                    wait_time = 2 ** retry_count  # Exponential backoff
                    print(f"   ⏳ Retrying in {wait_time}s...")
                    time.sleep(wait_time)
                    continue
                
                elif strategy == RecoveryStrategy.SKIP:
                    print(f"   ⏭️ Skipping task")
                    return {
                        "status": "skipped",
                        "result": None,
                        "recovery": recovery
                    }
                
                else:
                    # All other strategies need plan-level changes
                    return {
                        "status": "requires_replan",
                        "result": None,
                        "recovery": recovery
                    }
        
        return {"status": "exhausted", "result": None}

## 5️⃣ Failure Modes — Error-Driven Replanning

```
❌ FAILURE 1: Misclassification (The Biggest Risk)
   Problem: Transient error treated as logical → unnecessary replan
            Logical error treated as transient → infinite retry
   Example: API returns 500 error (actually a logic problem)
            Classifier: "Transient! Retry!" → Retries 50 times
   Fix: Maintain retry count even for "transient" errors
        After N retries of "transient" → reclassify as logical

❌ FAILURE 2: Error Memory Overflow
   Problem: Error memory grows too large → impacts performance
            Or: Error memory not consulted → same mistakes repeated
   Example: Same API called 10 times despite being down for hours
   Fix: Summarize old error memory
        Mandatory lookup before retrying any previously-failed action

❌ FAILURE 3: Recovery Creates New Errors
   Problem: Recovery action itself fails
            Now you have error within error handling
   Example: REPLAN fails because replanner gets confused
   Fix: Simple fallback for recovery failures:
        "If recovery fails → SKIP + log + continue"
        Never let error handling create infinite error loops

❌ FAILURE 4: Silent Failures
   Problem: Error occurs but isn't caught → reported as success
   Example: Search returns empty results (not an exception)
            Agent treats empty results as successful search
            Continues with no actual information
   Fix: Validate results after every tool call
        "Is this result meaningful or empty/failed?"
        Empty results = soft failure = handle appropriately
```

## 1️⃣ What Is This?

**Simple English:**
Bounded Iterations means **setting a hard limit on how many times the loop can run**.

Without this, loops can run forever.
With it, you guarantee the system eventually stops — no matter what.

```
UNBOUNDED LOOP (DANGEROUS):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
while not goal_achieved:
    think()
    act()
    observe()
    
Problem: If goal_achieved never becomes True → infinite loop!
Real cost: $1,000s of API bills + zero output + crash

BOUNDED LOOP (SAFE):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
for i in range(max_iterations):
    think()
    act()
    observe()
    if goal_achieved: break

Guarantee: ALWAYS stops. At worst gives partial answer.
Real cost: Predictable. Controllable. Professional.
```

## 3️⃣ The Science of Setting Bounds

**This is harder than it looks. Most engineers get it wrong.**

```
WRONG APPROACH 1: Too Low Bound
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
max_iterations = 3

Problem: Complex tasks genuinely need more iterations
Example: Research task needs 3 searches + 2 analyses = 5 steps minimum
         With max=3: agent gets cut off before finishing
         Output is always incomplete

WRONG APPROACH 2: Too High Bound
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
max_iterations = 1000

Problem: Doesn't actually prevent runaway loops

         By then: $50 spent, server overloaded

WRONG APPROACH 3: One-Size-Fits-All
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
max_iterations = 10 for ALL tasks

Problem: Simple tasks get 10 iterations when they need 2
         Complex tasks get cut off at 10 when they need 15

RIGHT APPROACH: Dynamic Bounds
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Task complexity     → Max iterations

Medium (3-5 steps)  → 8-12 iterations
Complex (6+ steps)  → 15-20 iterations
Research task       → 10-15 (many searches needed)

COMPLETE BOUNDING SYSTEM — 5 DIFFERENT LIMITS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   "Do at most N Think→Act→Observe cycles"
   Most basic and most important bound

   "Stop when budget is exhausted"
   Financial safety valve

4. PROGRESS LIMIT
   min_progress_per_N_iterations = 0.1
   "If not making progress, stop trying"
   Prevents spinning in circles
   
5. UNIQUE ACTION LIMIT
   max_unique_actions = max_iterations × 0.5
   "If repeating same actions, stop"
   Detects stuck loops early

COMBINED BOUND CHECK:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

from langchain_openai import ChatOpenAI
from typing import List, Dict, Optional, Tuple
from dataclasses import dataclass, field
from enum import Enum
import time
import hashlib

llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)


# ═══════════════════════════════════════════════════
# STOP REASON ENUM
# ═══════════════════════════════════════════════════
class StopReason(Enum):
    GOAL_ACHIEVED = "goal_achieved"
    ITERATION_LIMIT = "iteration_limit"
    TIME_LIMIT = "time_limit"
    COST_LIMIT = "cost_limit"
    NO_PROGRESS = "no_progress"
    ACTION_LOOP = "action_loop"
    ERROR_LIMIT = "error_limit"
    USER_INTERRUPT = "user_interrupt"


# ═══════════════════════════════════════════════════
# BOUNDS CONFIGURATION
# ═══════════════════════════════════════════════════
@dataclass
class BoundsConfig:
    """All iteration limits in one place"""
    
    # Hard limits (ALWAYS enforced)
    max_iterations: int = 15
    max_time_seconds: float = 300.0    # 5 minutes
    max_api_calls: int = 50
    max_tokens: int = 150_000
    max_errors: int = 5
    
    # Progress limits (detect stuck loops)
    progress_check_window: int = 3      # Check every N iterations
    min_progress_per_window: float = 0.05  # Must improve by 5%
    
    # Loop detection
    action_history_window: int = 4      # Track last N actions
    max_repeated_actions: int = 2       # Stop if action repeated N times
    
    @classmethod
    def for_task_complexity(cls, complexity: str) -> 'BoundsConfig':
        """
        Create bounds appropriate for task complexity.
        Different tasks need different limits!
        """
        
        configs = {
            "simple": cls(
                max_iterations=5,
                max_time_seconds=60.0,
                max_api_calls=10,
                max_tokens=30_000
            ),
            "medium": cls(
                max_iterations=12,
                max_time_seconds=180.0,
                max_api_calls=30,
                max_tokens=80_000
            ),
            "complex": cls(
                max_iterations=20,
                max_time_seconds=600.0,
                max_api_calls=60,
                max_tokens=200_000
            ),
            "research": cls(
                max_iterations=15,
                max_time_seconds=300.0,
                max_api_calls=40,
                max_tokens=150_000,
                progress_check_window=5,  # Check progress less frequently
            ),
            "coding": cls(
                max_iterations=18,
                max_time_seconds=480.0,
                max_api_calls=50,
                max_tokens=180_000,
                max_errors=8   # Code has more expected errors
            )
        }
        
        return configs.get(complexity, cls())  # Default if unknown


# ═══════════════════════════════════════════════════
# BOUNDS TRACKER — Monitors all limits in real-time
# ═══════════════════════════════════════════════════
class BoundsTracker:
    """
    Tracks all resource usage and enforces limits.
    Called after every iteration.
    """
    
    def __init__(self, config: BoundsConfig):
        self.config = config
        
        # Counters
        self.iteration_count: int = 0
        self.api_calls: int = 0
        self.token_count: int = 0
        self.error_count: int = 0
        
        # Timing
        self.start_time: float = time.time()
        
        # Progress tracking
        self.progress_history: List[float] = []  # 0.0 to 1.0 scores
        
        # Action loop detection
        self.recent_actions: List[str] = []
        self.action_hashes: List[str] = []
        
        # Cost tracking
        self.estimated_cost_usd: float = 0.0
        
        # Stop reason (set when we detect should stop)
        self.stop_reason: Optional[StopReason] = None
    
    @property
    def elapsed_seconds(self) -> float:
        return time.time() - self.start_time
    
    @property
    def elapsed_formatted(self) -> str:
        elapsed = self.elapsed_seconds
        if elapsed < 60:
            return f"{elapsed:.1f}s"
        return f"{elapsed/60:.1f}m"
    
    def record_iteration(
        self,
        progress_score: float,       # 0.0-1.0
        action_taken: str,           # What action was performed
        tokens_used: int = 0,        # Tokens in this call
        had_error: bool = False
    ):
        """Record stats for one completed iteration"""
        
        self.iteration_count += 1
        self.api_calls += 1
        self.token_count += tokens_used
        self.progress_history.append(progress_score)
        
        if had_error:
            self.error_count += 1
        
        # Track action for loop detection
        action_hash = hashlib.md5(action_taken.encode()).hexdigest()[:8]
        self.recent_actions.append(action_taken)
        self.action_hashes.append(action_hash)
        
        # Keep only recent window
        window = self.config.action_history_window
        self.recent_actions = self.recent_actions[-window:]
        self.action_hashes = self.action_hashes[-window:]
        
        # Estimate cost (GPT-4o pricing approximately)
        self.estimated_cost_usd += tokens_used * 0.000015
    
    def detect_action_loop(self) -> Tuple[bool, str]:
        """
        Detect if agent is repeating the same actions.
        Returns: (is_looping, evidence)
        """
        
        if len(self.action_hashes) < self.config.action_history_window:
            return False, ""
        
        # Count repeated hashes
        hash_counts = {}
        for h in self.action_hashes:
            hash_counts[h] = hash_counts.get(h, 0) + 1
        
        max_repeats = max(hash_counts.values())
        
        if max_repeats >= self.config.max_repeated_actions:
            # Find the repeated action
            repeated_hash = max(hash_counts, key=hash_counts.get)
            repeated_action = None
            for action, h in zip(self.recent_actions, self.action_hashes):
                if h == repeated_hash:
                    repeated_action = action[:80]
                    break
            
            return True, (
                f"Action repeated {max_repeats} times: "
                f"'{repeated_action}...'"
            )
        
        return False, ""
    
    def detect_no_progress(self) -> Tuple[bool, str]:
        """
        Detect if agent is stuck — not making meaningful progress.
        Returns: (is_stuck, evidence)
        """
        
        window = self.config.progress_check_window
        
        if len(self.progress_history) < window:
            return False, ""
        
        recent_progress = self.progress_history[-window:]
        
        # Check if progress improved by minimum threshold
        progress_delta = max(recent_progress) - min(recent_progress)
        
        # Also check absolute progress level
        avg_progress = sum(recent_progress) / len(recent_progress)
        
        if (progress_delta < self.config.min_progress_per_window and
                avg_progress < 0.3):  # Still far from goal
            return True, (
                f"Progress stuck at {avg_progress:.0%} "
                f"(change: {progress_delta:.1%} over {window} iterations)"
            )
        
        return False, ""
    
    def check_all_limits(self) -> Tuple[bool, Optional[StopReason], str]:
        """
        Check ALL limits. Returns (should_stop, reason, message).
        Called after every iteration.
        """
        
        # 1. ITERATION LIMIT
        if self.iteration_count >= self.config.max_iterations:
            self.stop_reason = StopReason.ITERATION_LIMIT
            return True, StopReason.ITERATION_LIMIT, (
                f"Iteration limit reached: {self.iteration_count}/"
                f"{self.config.max_iterations}"
            )
        
        # 2. TIME LIMIT
        if self.elapsed_seconds >= self.config.max_time_seconds:
            self.stop_reason = StopReason.TIME_LIMIT
            return True, StopReason.TIME_LIMIT, (
                f"Time limit reached: {self.elapsed_formatted} / "
                f"{self.config.max_time_seconds}s"
            )
        
        # 3. API COST LIMIT
        if self.api_calls >= self.config.max_api_calls:
            self.stop_reason = StopReason.COST_LIMIT
            return True, StopReason.COST_LIMIT, (
                f"API call limit reached: {self.api_calls}/"
                f"{self.config.max_api_calls} "
                f"(~${self.estimated_cost_usd:.3f} spent)"
            )
        
        # 4. TOKEN LIMIT
        if self.token_count >= self.config.max_tokens:
            self.stop_reason = StopReason.COST_LIMIT
            return True, StopReason.COST_LIMIT, (
                f"Token limit reached: {self.token_count:,}/"
                f"{self.config.max_tokens:,}"
            )
        
        # 5. ERROR LIMIT
        if self.error_count >= self.config.max_errors:
            self.stop_reason = StopReason.ERROR_LIMIT
            return True, StopReason.ERROR_LIMIT, (
                f"Error limit reached: {self.error_count}/"
                f"{self.config.max_errors} errors"
            )
        
        # 6. ACTION LOOP DETECTION
        is_looping, loop_evidence = self.detect_action_loop()
        if is_looping:
            self.stop_reason = StopReason.ACTION_LOOP
            return True, StopReason.ACTION_LOOP, loop_evidence
        
        # 7. NO PROGRESS DETECTION
        is_stuck, stuck_evidence = self.detect_no_progress()
        if is_stuck:
            self.stop_reason = StopReason.NO_PROGRESS
            return True, StopReason.NO_PROGRESS, stuck_evidence
        
        return False, None, ""
    
    def display_status(self):
        """Print current resource usage"""
        
        print(f"\n   📏 BOUNDS STATUS:")
        print(f"      Iterations: {self.iteration_count}/"
              f"{self.config.max_iterations} "
              f"({self.iteration_count/self.config.max_iterations:.0%})")
        print(f"      Time: {self.elapsed_formatted}/"
              f"{self.config.max_time_seconds}s")
        print(f"      API Calls: {self.api_calls}/"
              f"{self.config.max_api_calls}")
        print(f"      Errors: {self.error_count}/"
              f"{self.config.max_errors}")
        print(f"      Est. Cost: ${self.estimated_cost_usd:.4f}")
        
        if self.progress_history:
            latest_progress = self.progress_history[-1]
            print(f"      Progress: {latest_progress:.0%}")

        print(f"\n⚙️ Bounds configured for '{complexity}' task:")

        print(f"   Max time: {self.bounds_config.max_time_seconds}s")
        print(f"   Max API calls: {self.bounds_config.max_api_calls}")
    
    def _estimate_progress(
        self,
        goal: str,
        current_output: str,
        iteration: int
    ) -> float:
        """Estimate how close we are to goal (0.0-1.0)"""
        
        prompt = f"""
        Estimate goal completion progress (0.0 to 1.0).
        
        Goal: {goal}
        Current output quality/completeness: {current_output[:500]}
        
        Return only a number between 0.0 and 1.0.
        0.0 = No progress at all
        0.5 = Halfway to goal
        1.0 = Goal fully achieved
        
        Number only:
        """
        
        response = fast_llm.invoke(prompt).content.strip()
        try:
            return float(response.split()[0])
        except:
            return min(0.1 * iteration, 0.9)  # Fallback estimate
    
    def _generate_partial_answer(
        self,
        goal: str,
        accumulated_info: str,
        stop_reason: StopReason
    ) -> str:
        """Generate best possible answer with what we have"""
        
        reason_explanations = {
            StopReason.ITERATION_LIMIT: "ran out of iterations",
            StopReason.TIME_LIMIT: "ran out of time",
            StopReason.COST_LIMIT: "reached cost/API limits",
            StopReason.NO_PROGRESS: "was not making sufficient progress",
            StopReason.ACTION_LOOP: "detected a repetitive action loop",
            StopReason.ERROR_LIMIT: "encountered too many errors"
        }
        
        reason_text = reason_explanations.get(
            stop_reason, "reached an unexpected limit"
        )
        
        prompt = f"""
        An AI agent {reason_text} before fully completing its goal.
        
        Goal: {goal}
        
        Information gathered before stopping:
        {accumulated_info[:3000]}
        
        Provide the BEST POSSIBLE answer using available information.
        
        IMPORTANT: 
        - Start with: "Note: This response may be incomplete because..."
        - Include whatever was found
        - Clearly indicate what information might be missing
        - Be honest about limitations
        """
        
        return self.llm.invoke(prompt).content
    
    def run(self, goal: str) -> Dict:
        """Bounded execution loop"""
        
        print(f"\n{'='*60}")
        print(f"🎯 BOUNDED AGENT")
        print(f"Goal: {goal}")
        print(f"{'='*60}")
        
        tracker = BoundsTracker(self.bounds_config)
        accumulated_info = ""
        final_answer = None
        stop_reason = None
        
        while True:
            print(f"\n{'─'*60}")
            print(f"ITERATION {tracker.iteration_count + 1}")
            
            # EXECUTE ONE ITERATION
            start_iter = time.time()
            had_error = False
            
            try:
                # Think
                think_prompt = f"""
                Goal: {goal}
                Information gathered so far: {accumulated_info[-2000:]}
                Iteration: {tracker.iteration_count + 1}
                Remaining iterations: {self.bounds_config.max_iterations - tracker.iteration_count}
                
                What should I do next to achieve the goal?
                If I have enough information, provide the final answer.
                Format: {{"action": "...", "is_final": true/false, "output": "..."}}
                """
                
                response = self.llm.invoke(think_prompt).content
                if "```json" in response:
                    response = response.split("```json")[1].split("```")[0]
                
                action_data = json.loads(response.strip())
                
                current_output = action_data.get("output", "")
                accumulated_info += f"\n\nIteration {tracker.iteration_count + 1}: {current_output[:400]}"
                
                tokens_used = len(think_prompt + response) // 4  # Estimate
                
                # Check if goal achieved
                if action_data.get("is_final", False):
                    final_answer = current_output
                    stop_reason = StopReason.GOAL_ACHIEVED
                    tracker.record_iteration(
                        progress_score=1.0,
                        action_taken=action_data.get("action", ""),
                        tokens_used=tokens_used,
                        had_error=False
                    )
                    print(f"   ✅ GOAL ACHIEVED!")
                    break
                
                # Estimate progress
                progress = self._estimate_progress(
                    goal, accumulated_info, tracker.iteration_count
                )
                
            except Exception as e:
                had_error = True
                progress = (tracker.progress_history[-1] 
                           if tracker.progress_history else 0.0)
                current_output = f"Error: {str(e)[:100]}"
                tokens_used = 0
                action_data = {"action": "error_occurred"}
            
            # Record this iteration
            tracker.record_iteration(
                progress_score=progress,
                action_taken=action_data.get("action", ""),
                tokens_used=tokens_used,
                had_error=had_error
            )
            
            # Show status
            tracker.display_status()
            
            # CHECK ALL BOUNDS
            should_stop, reason, message = tracker.check_all_limits()
            
            if should_stop:
                stop_reason = reason
                print(f"\n🛑 STOPPING: {message}")
                break
        
        # Generate output
        if stop_reason == StopReason.GOAL_ACHIEVED:
            output = final_answer
        else:
            print(f"\n⚠️ Generating partial answer for stop reason: {stop_reason.value}")
            output = self._generate_partial_answer(
                goal, accumulated_info, stop_reason
            )
        
        # Final report
        print(f"\n{'='*60}")
        print(f"📊 EXECUTION REPORT")
        print(f"   Stop reason: {stop_reason.value}")
        print(f"   Iterations: {tracker.iteration_count}")
        print(f"   Time: {tracker.elapsed_formatted}")
        print(f"   API calls: {tracker.api_calls}")
        print(f"   Est. cost: ${tracker.estimated_cost_usd:.4f}")
        print(f"   Errors: {tracker.error_count}")
        print(f"{'='*60}")
        
        return {
            "goal": goal,
            "output": output,
            "stop_reason": stop_reason.value,
            "iterations_used": tracker.iteration_count,
            "time_seconds": tracker.elapsed_seconds,
            "estimated_cost_usd": tracker.estimated_cost_usd,
            "goal_achieved": stop_reason == StopReason.GOAL_ACHIEVED
        }


# Run it!
agent = BoundedAgent(llm, complexity="medium")
result = agent.run("Explain the key differences between RAG and fine-tuning for LLMs")

print(f"\n✅ OUTPUT:\n{result['output'][:500]}...")

## 6️⃣ Failure Modes — Bounded Iterations

```
❌ FAILURE 1: The Cliff Edge Failure
   Problem: Agent runs at full speed → hits limit → STOPS suddenly
   Example: Iteration 14 of 15: 80% done
            Iteration 15: STOPPED — partial answer returned
   Why: No awareness of approaching limit
   Fix: "Urgency escalation" — as limit approaches, agent gets faster
        At 80% of limit: "Start synthesizing what you have"
        At 90% of limit: "STOP gathering, produce answer now"
        At 95% of limit: "Emergency synthesis mode"

❌ FAILURE 2: Wrong Bounds for Task Type
   Problem: Same bounds for all tasks regardless of complexity
   Example: Simple FAQ: max_iterations=20 → wasteful
            Complex research: max_iterations=5 → always incomplete
   Fix: Task complexity classifier BEFORE starting
        Dynamic bounds based on detected complexity

❌ FAILURE 3: Graceful Degradation Not Implemented
   Problem: When limit hit, agent gives NO answer instead of PARTIAL
   Example: "Sorry, I couldn't complete the task" (useless)
   Fix: ALWAYS synthesize best-effort answer from accumulated work
        Partial answer > no answer
        Always explain what was completed and what wasn't

❌ FAILURE 4: Bounds Not Tracked Across Sub-Agents
   Problem: Orchestrator has max=20, but each subagent also has max=20
            Total actual calls = 20 × N subagents = 100+ calls!
   Fix: Shared budget across all agents in a system
        BoundsTracker shared between orchestrator and subagents
        Global token budget, not per-agent budget
```

# 📌 LOOP 5: Convergence Criteria
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 1️⃣ What Is This?

**Simple English:**
Convergence Criteria define **the conditions that signal "the loop should stop because we're done enough"**.

This is different from bounded iterations.
Bounded iterations stop due to **resource limits**.
Convergence criteria stop due to **quality achievement**.

```
BOUNDED ITERATIONS:     "Stop because I ran out of chances"
CONVERGENCE CRITERIA:   "Stop because I achieved good enough quality"

ANALOGY:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

A chef testing their soup:
  Bounded: "I'll taste it 10 times and then serve it"
           → Serves after 10 tastings regardless of quality
           
  Convergence: "I'll taste it until it's good enough"
               → Serves as soon as it meets quality standard
               → Could stop at tasting 3 if it's already great
               → Could taste all 10 if it needs work
               
CONVERGENCE = Stop when QUALITY is high enough
              NOT just when iterations are exhausted
```

---

## 2️⃣ The Deep Challenge — What Does "Done" Mean?

This is one of the hardest problems in AI:

```
OBJECTIVE TASKS (Easy to define convergence):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Sort a list: Done when list is sorted. Binary check.
Find a bug: Done when tests pass. Binary check.
Calculate: Done when result is within epsilon. Numeric check.

SUBJECTIVE TASKS (Hard to define convergence):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Write a great article: When is it "great enough"?
Research a topic: When do you know "enough"?
Improve code quality: When is quality "sufficient"?
Generate creative content: When is it "creative enough"?

THE ENGINEERING CHALLENGE:
For subjective tasks, you need to define:
  1. WHAT to measure
  2. HOW to measure it (often using LLM as judge)
  3. WHAT SCORE means "good enough"
  4. HOW MANY consecutive good scores before stopping

This is hard. Most agents do it badly.
Let's do it properly.
```

---

## 3️⃣ The 6 Types of Convergence Criteria

```
┌──────────────────────────────────────────────────────────────────┐
│              CONVERGENCE CRITERIA TYPES                          │
├───────────────────────┬──────────────────────────────────────────┤
│ CRITERION TYPE        │ HOW TO MEASURE                           │
├───────────────────────┼──────────────────────────────────────────┤
│ 1. GOAL ACHIEVEMENT   │ Binary check: is goal met?               │
│    (Objective)        │ Example: "All tests pass" = True/False   │
│                       │ Easiest to implement correctly           │
├───────────────────────┼──────────────────────────────────────────┤
│ 2. QUALITY THRESHOLD  │ Score >= target                          │
│    (Metric-based)     │ Example: BLEU > 0.8, F1 > 0.9           │
│                       │ Requires measurable quality metric       │
├───────────────────────┼──────────────────────────────────────────┤
│ 3. DELTA CONVERGENCE  │ Change < epsilon                         │
│    (Change-based)     │ "Output barely changed from last time"   │
│                       │ Used when progress slows to zero         │
├───────────────────────┼──────────────────────────────────────────┤
│ 4. LLM JUDGE          │ Evaluator LLM scores output              │
│    (Subjective)       │ "Is this output high quality?" 0-10      │
│                       │ Stop when score >= threshold             │
├───────────────────────┼──────────────────────────────────────────┤
│ 5. CONSENSUS          │ Multiple criteria all agree              │
│    (Multi-criteria)   │ Quality AND completeness AND accuracy    │
│                       │ All must be above threshold to stop      │
├───────────────────────┼──────────────────────────────────────────┤
│ 6. STABILITY          │ N consecutive iterations all high        │
│    (Temporal)         │ Must score > threshold for 3 in a row    │
│                       │ Prevents stopping on a "lucky" iteration │
└───────────────────────┴──────────────────────────────────────────┘
```

---

## 4️⃣ The Delta Convergence Deep Dive

```
DELTA CONVERGENCE — When Improvement Becomes Negligible
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

QUALITY OVER TIME (typical pattern):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Iteration 1: Quality = 2.0 (starting from nothing)
Iteration 2: Quality = 5.5 (big jump! +3.5)
Iteration 3: Quality = 7.2 (good improvement +1.7)
Iteration 4: Quality = 7.9 (smaller improvement +0.7)
Iteration 5: Quality = 8.2 (diminishing returns +0.3)
Iteration 6: Quality = 8.3 (barely changing +0.1)  ← CONVERGENCE POINT
Iteration 7: Quality = 8.35 (negligible +0.05)
Iteration 8: Quality = 8.3 (oscillating ±0.05)

DECISION: After iteration 5-6, quality is converging.
          More iterations give diminishing returns.
          STOP EARLY and save resources!

THE MATH:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

delta_convergence(t) = |quality(t) - quality(t-1)|

If delta_convergence < epsilon for N consecutive iterations:
→ We have converged!

Example:
  epsilon = 0.1 (less than 10% change means converged)
  N = 2 (must hold for 2 consecutive iterations)
  
  Δ between iter 4→5: |8.2 - 7.9| = 0.3 > 0.1 → NOT converged
  Δ between iter 5→6: |8.3 - 8.2| = 0.1 = 0.1 → CONVERGING (1/2)
  Δ between iter 6→7: |8.35 - 8.3| = 0.05 < 0.1 → CONVERGED! (2/2) ✅
  STOP HERE and return quality 8.3
```

from langchain_openai import ChatOpenAI

# ═══════════════════════════════════════════════════
# QUALITY DIMENSIONS
# ═══════════════════════════════════════════════════
@dataclass
class QualityScore:
    """Multi-dimensional quality measurement"""
    
    # Core dimensions (0.0 to 1.0 each)
    completeness: float    # Does it cover all required aspects?
    accuracy: float        # Is information correct?
    clarity: float         # Is it well-expressed and clear?
    relevance: float       # Does it address the actual goal?
    depth: float           # Is there appropriate depth?
    
    # Dimension weights (sum to 1.0)
    weights: Dict[str, float] = field(default_factory=lambda: {
        "completeness": 0.25,
        "accuracy": 0.30,
        "clarity": 0.20,
        "relevance": 0.15,
        "depth": 0.10
    })
    
    @property
    def weighted_score(self) -> float:
        """Weighted composite score (0.0-1.0)"""
        w = self.weights
        return (
            self.completeness * w["completeness"] +
            self.accuracy * w["accuracy"] +
            self.clarity * w["clarity"] +
            self.relevance * w["relevance"] +
            self.depth * w["depth"]
        )
    
    @property
    def weakest_dimension(self) -> Tuple[str, float]:
        """Which dimension needs most improvement?"""
        dims = {
            "completeness": self.completeness,
            "accuracy": self.accuracy,
            "clarity": self.clarity,
            "relevance": self.relevance,
            "depth": self.depth
        }
        weakest = min(dims, key=dims.get)
        return weakest, dims[weakest]
    
    def display(self):
        print(f"      Completeness: {self.completeness:.0%} "
              f"(weight: {self.weights['completeness']:.0%})")
        print(f"      Accuracy:     {self.accuracy:.0%} "
              f"(weight: {self.weights['accuracy']:.0%})")
        print(f"      Clarity:      {self.clarity:.0%} "
              f"(weight: {self.weights['clarity']:.0%})")
        print(f"      Relevance:    {self.relevance:.0%} "
              f"(weight: {self.weights['relevance']:.0%})")
        print(f"      Depth:        {self.depth:.0%} "
              f"(weight: {self.weights['depth']:.0%})")
        print(f"      {'─'*30}")
        print(f"      WEIGHTED:     {self.weighted_score:.0%}")


# ═══════════════════════════════════════════════════
# LLM JUDGE — Evaluates output quality
# ═══════════════════════════════════════════════════
class LLMJudge:
    """
    Uses a separate LLM to evaluate output quality.
    This is the "LLM as evaluator" pattern.
    """
    
    def __init__(self, llm):
        self.llm = llm
    
    def evaluate(self, goal: str, output: str) -> QualityScore:
        """Evaluate output across all quality dimensions"""
        
        prompt = f"""
        You are a rigorous quality evaluator. 
        Be critical and honest. Don't give high scores unless earned.
        
        GOAL: {goal}
        
        OUTPUT TO EVALUATE:
        {output[:2000]}
        
        Score each dimension from 0.0 to 1.0:
        
        COMPLETENESS (0.0-1.0): 
          Does the output cover all important aspects of the goal?
          0.0 = Misses most required content
          0.5 = Covers main points but misses details
          1.0 = Comprehensive coverage of everything needed
          
        ACCURACY (0.0-1.0):
          Is the information factually correct and reliable?
          0.0 = Contains major factual errors
          0.5 = Mostly correct with some errors/unsupported claims
          1.0 = Highly accurate, well-supported
          
        CLARITY (0.0-1.0):
          Is it clear, well-organized, and easy to understand?
          0.0 = Confusing, disorganized, hard to follow
          0.5 = Understandable but could be clearer
          1.0 = Crystal clear, excellent organization
          
        RELEVANCE (0.0-1.0):
          Does it directly address what was asked?
          0.0 = Mostly off-topic
          0.5 = Somewhat relevant but drifts
          1.0 = Perfectly targeted to the goal
          
        DEPTH (0.0-1.0):
          Is there appropriate depth of analysis and insight?
          0.0 = Superficial, surface-level
          0.5 = Adequate but could go deeper
          1.0 = Excellent depth with real insights
        
        Return JSON:
        {{
            "completeness": 0.75,
            "accuracy": 0.80,
            "clarity": 0.85,
            "relevance": 0.90,
            "depth": 0.65,
            "reasoning": "Brief explanation of scores",
            "main_improvement_needed": "The biggest area to improve"
        }}
        """
        
        response = self.llm.invoke(prompt).content
        if "```json" in response:
            response = response.split("```json")[1].split("```")[0]
        
        data = json.loads(response.strip())
        
        return QualityScore(
            completeness=data["completeness"],
            accuracy=data["accuracy"],
            clarity=data["clarity"],
            relevance=data["relevance"],
            depth=data["depth"]
        )


# ═══════════════════════════════════════════════════
# CONVERGENCE DETECTOR — The core logic
# ═══════════════════════════════════════════════════
class ConvergenceDetector:
    """
    Tracks quality scores over time and detects when to stop.
    Implements multiple convergence criteria.
    """
    
    def __init__(
        self,
        quality_threshold: float = 0.80,  # Stop when quality >= 80%
        delta_epsilon: float = 0.02,       # Stop when change < 2%
        stability_window: int = 3,         # Must be stable for 3 iterations
        judge: Optional[LLMJudge] = None
    ):
        self.quality_threshold = quality_threshold
        self.delta_epsilon = delta_epsilon
        self.stability_window = stability_window
        self.judge = judge or LLMJudge(llm)
        
        # History of quality scores
        self.score_history: List[QualityScore] = []
        self.output_history: List[str] = []
        
        # Convergence tracking
        self.stable_iterations: int = 0
        self.is_converged: bool = False
        self.convergence_reason: Optional[str] = None
    
    def add_iteration(
        self,
        goal: str,
        current_output: str
    ) -> Tuple[bool, str, QualityScore]:
        """
        Evaluate current output and check for convergence.
        Returns: (is_converged, reason, quality_score)
        """
        
        # Get quality score from judge
        score = self.judge.evaluate(goal, current_output)
        self.score_history.append(score)
        self.output_history.append(current_output)
        
        iteration = len(self.score_history)
        
        print(f"\n   📊 QUALITY ASSESSMENT (Iteration {iteration}):")
        score.display()
        
        # CRITERION 1: Quality threshold achieved
        if score.weighted_score >= self.quality_threshold:
            
            # CRITERION 6: Stability check — don't stop on lucky iteration
            self.stable_iterations += 1
            
            if self.stable_iterations >= self.stability_window:
                self.is_converged = True
                self.convergence_reason = (
                    f"Quality threshold met: {score.weighted_score:.0%} >= "
                    f"{self.quality_threshold:.0%} for {self.stable_iterations} iterations"
                )
                print(f"\n   ✅ CONVERGED: {self.convergence_reason}")
                return True, self.convergence_reason, score
            else:
                print(f"\n   ⏳ Quality good ({score.weighted_score:.0%}) "
                      f"but need stability "
                      f"({self.stable_iterations}/{self.stability_window})")
        else:
            self.stable_iterations = 0  # Reset stability counter
        
        # CRITERION 3: Delta convergence — barely improving
        if len(self.score_history) >= 3:
            recent_scores = [s.weighted_score for s in self.score_history[-3:]]
            deltas = [
                abs(recent_scores[i] - recent_scores[i-1])
                for i in range(1, len(recent_scores))
            ]
            avg_delta = sum(deltas) / len(deltas)
            
            print(f"   Δ Change (avg last 3): {avg_delta:.1%}")
            
            if (avg_delta < self.delta_epsilon and 
                    score.weighted_score >= 0.60):  # Only if already decent quality
                self.is_converged = True
                self.convergence_reason = (
                    f"Delta convergence: avg improvement {avg_delta:.1%} < "
                    f"epsilon {self.delta_epsilon:.1%}"
                )
                print(f"\n   ✅ CONVERGED (DELTA): {self.convergence_reason}")
                return True, self.convergence_reason, score
        
        # Not converged yet — what needs improvement?
        weakest_dim, weakest_score = score.weakest_dimension
        print(f"   🎯 Focus area: {weakest_dim} ({weakest_score:.0%})")
        
        return False, "Not yet converged", score
    
    def get_improvement_hint(self) -> str:
        """What should the next iteration focus on to converge faster?"""
        
        if not self.score_history:
            return "Start by addressing the core goal"
        
        latest = self.score_history[-1]
        weakest_dim, weakest_score = latest.weakest_dimension
        
        improvement_hints = {
            "completeness": "Add more coverage of missing topics",
            "accuracy": "Verify facts and remove unsupported claims",
            "clarity": "Reorganize and simplify the structure",
            "relevance": "Refocus content on the core goal",
            "depth": "Add more analysis and insight to key points"
        }
        
        hint = improvement_hints.get(weakest_dim, "Improve overall quality")
        return f"Focus on {weakest_dim}: {hint}"
    
    def convergence_trajectory(self) -> str:
        """Describe the quality trajectory over iterations"""
        
        if len(self.score_history) < 2:
            return "Not enough data"
        
        scores = [s.weighted_score for s in self.score_history]
        
        trajectory_lines = []
        for i, score in enumerate(scores):
            bar = "█" * int(score * 20)
            marker = " ✅" if score >= self.quality_threshold else ""
            trajectory_lines.append(
                f"   Iter {i+1}: {bar:<20} {score:.0%}{marker}"
            )
        
        return "\n".join(trajectory_lines)

# CONVERGENCE-DRIVEN AGENT — Full implementation

class ConvergenceAgent:
    """
    Agent that iterates until quality converges.
    Combines all convergence criteria with bounds.
    """
    
    def __init__(
        self,
        llm,
        quality_threshold: float = 0.80,
        max_iterations: int = 10,
        stability_window: int = 2
    ):
        self.llm = llm
        self.max_iterations = max_iterations
        self.detector = ConvergenceDetector(
            quality_threshold=quality_threshold,
            delta_epsilon=0.02,
            stability_window=stability_window
        )
    
    def improve_output(
        self,
        goal: str,
        current_output: str,
        improvement_hint: str,
        iteration: int
    ) -> str:
        """Improve output based on quality assessment"""
        
        prompt = f"""
        Improve this response to better achieve the goal.
        
        GOAL: {goal}
        
        CURRENT RESPONSE:
        {current_output[:2000]}
        
        IMPROVEMENT FOCUS:
        {improvement_hint}
        
        ITERATION: {iteration} (be more thorough as iteration increases)
        
        Provide an IMPROVED response that:
        1. Addresses the improvement focus area
        2. Keeps everything that was already good
        3. Is more complete, accurate, and insightful
        
        Write the full improved response:
        """
        
        return self.llm.invoke(prompt).content
    
    def run(self, goal: str) -> Dict:
        """Convergence-driven iterative improvement"""
        
        print(f"\n{'='*60}")
        print(f"🎯 CONVERGENCE AGENT")
        print(f"Goal: {goal}")
        print(f"Quality target: {self.detector.quality_threshold:.0%}")
        print(f"Max iterations: {self.max_iterations}")
        print(f"{'='*60}")
        
        # INITIAL GENERATION
        print(f"\n{'─'*60}")
        print(f"ITERATION 1: Initial Generation")
        print(f"{'─'*60}")
        
        initial_prompt = f"""
        Provide a response to this goal:
        Goal: {goal}
        
        Write a comprehensive, accurate, and clear response.
        """
        current_output = self.llm.invoke(initial_prompt).content
        
        # Check convergence of initial output
        converged, reason, score = self.detector.add_iteration(
            goal, current_output
        )
        
        iteration = 1
        
        # IMPROVEMENT LOOP
        while not converged and iteration < self.max_iterations:
            
            iteration += 1
            
            print(f"\n{'─'*60}")
            print(f"ITERATION {iteration}: Improvement")
            print(f"{'─'*60}")
            
            # Get hint for what to improve
            hint = self.detector.get_improvement_hint()
            print(f"   Improving: {hint}")
            
            # Improve output
            current_output = self.improve_output(
                goal, current_output, hint, iteration
            )
            
            # Check convergence
            converged, reason, score = self.detector.add_iteration(
                goal, current_output
            )
        
        # Show convergence trajectory
        print(f"\n{'─'*60}")
        print(f"📈 QUALITY TRAJECTORY:")
        print(self.detector.convergence_trajectory())
        
        # Final summary
        final_score = self.detector.score_history[-1]
        
        print(f"\n{'='*60}")
        print(f"📊 CONVERGENCE SUMMARY")
        print(f"   Iterations used: {iteration}")
        print(f"   Converged: {'✅ YES' if converged else '⚠️ NO (limit reached)'}")
        if converged:
            print(f"   Reason: {reason}")
        print(f"   Final quality: {final_score.weighted_score:.0%}")
        
        weakest = final_score.weakest_dimension
        print(f"   Weakest dimension: {weakest[0]} ({weakest[1]:.0%})")
        print(f"{'='*60}")
        
        return {
            "goal": goal,
            "final_output": current_output,
            "iterations_used": iteration,
            "converged": converged,
            "convergence_reason": reason if converged else "max iterations reached",
            "final_score": final_score.weighted_score,
            "score_history": [s.weighted_score for s in self.detector.score_history]
        }


# Run it!

## 6️⃣ Failure Modes — Convergence Criteria

```
❌ FAILURE 1: Threshold Too Low (Premature Convergence)
   Problem: Stopping at 60% quality when user expects 90%
   Example: threshold=0.6 for a technical report
            Agent stops with incomplete, shallow output
            User: "This is terrible!"
   Fix: Calibrate threshold to user expectations
        Test with examples: "What quality would satisfy this user?"

❌ FAILURE 2: Threshold Too High (Never Converges)
   Problem: threshold=0.99 → agent loops until hitting iteration limit
   Example: Quality plateaus at 0.85, never reaches 0.99
            All iterations wasted trying to go from 0.85 to 0.99
   Fix: Use delta convergence AS BACKUP
        "If quality stops improving, stop even below threshold"
        This catches the plateau case

❌ FAILURE 3: Biased Judge
   Problem: LLM judge rates its own generated content too highly
   Example: Generator LLM = GPT-4o, Judge LLM = GPT-4o
            Judge gives 0.9/1.0 to mediocre output
            (Because it "agrees" with itself)
   Fix: Use different judge model than generator
        Use stricter judge system prompt
        Add adversarial evaluation framing

❌ FAILURE 4: Single-Dimension Convergence
   Problem: One dimension meets threshold, others are terrible
   Example: Accuracy = 0.95 (pulls weighted score up)
            Completeness = 0.30 (terrible!)
            Weighted score = 0.75 → converged
            But output is massively incomplete!
   Fix: Require ALL dimensions above minimum floor
        "Converge only if ALL dimensions >= 0.50 AND weighted >= threshold"

❌ FAILURE 5: Oscillation Without Convergence
   Problem: Quality oscillates between iterations
   Example: Quality: 0.78 → 0.85 → 0.72 → 0.88 → 0.75 → ...
            Average is 0.80 but never stable
            Delta check passes sometimes, fails others
   Fix: Use stability window — must be consistently high
        "Only converge if quality > threshold for N consecutive iterations"
        (We implemented this with stable_iterations counter)
```

## 7️⃣ Interview Questions & Strong Answers — ALL 5 Loops

**Q1: What is the Think→Act→Observe loop and why is it foundational?**

> ✅ **Strong Answer:**
> "The Think→Act→Observe loop is the fundamental unit of intelligent agent behavior. Think analyzes the current state and chooses the best next action with an expectation of what will happen. Act executes that action. Observe interprets the result, compares it to expectation, extracts new information, and assesses goal progress. What makes it foundational is the feedback mechanism — each observation feeds into the next Think, creating accumulating intelligence. Without Observe, an agent is blind. Without Think, actions are random. The loop enables adaptive behavior that improves with each iteration."

**Q2: What is the difference between bounded iterations and convergence criteria?**

> ✅ **Strong Answer:**
> "They're complementary safety mechanisms that stop loops for different reasons. Bounded iterations are hard resource limits — stop after N iterations, T seconds, or C API calls regardless of quality. They prevent runaway loops and cost overruns. They're mandatory for every production system. Convergence criteria are quality-based stops — stop when output quality exceeds a threshold, when improvement delta falls below epsilon, or when quality is stable for N consecutive iterations. They enable early stopping when quality is already good enough. In production, you always need both: convergence criteria to stop early when quality is sufficient, and bounds as the ultimate safety net when convergence criteria fail or the task is inherently unsolvable."

**Q3: How would you design an iterative improvement system for a code-writing agent?**

> ✅ **Strong Answer:**
> "I'd implement nested loops: an outer PEER loop that plans code strategy, executes it, evaluates code quality, and revises the approach; and an inner Think→Act→Observe loop that handles individual coding actions. Convergence criteria would be objective — code passes all unit tests, linting score above threshold, coverage above 80%. These are binary/metric checks rather than LLM judges, which is better for code. Bounds would be generous — code debugging genuinely needs many iterations, so max_iterations=18 with 10-minute time limit. Error handling would specifically distinguish between syntax errors (retry with syntax fix), logic errors (replan with different algorithm), and missing dependencies (substitute with available library). The key engineering decision is that the outer loop revises strategy (algorithm choice, architecture), while the inner loop handles implementation details."
