# 🏗️ PILLAR 1: Risk Classification Frameworks

## What Is a Risk Classification Framework?

**Simple English:**
Risk Classification Framework = **A structured system for identifying, categorizing, and scoring every possible risk in your AI system — so you know which risks to fix first, how urgently, and how completely.**

## 🔬 The Risk Matrix — First Principles

Every risk has exactly **two dimensions**:

```
DIMENSION 1: LIKELIHOOD
  How probable is this risk occurring?
  
  1 = Very Unlikely  (once in 10 years)
  2 = Unlikely       (once in 1-2 years)
  3 = Possible       (once in 6 months)
  4 = Likely         (once a month)
  5 = Almost Certain (weekly or more)

─────────────────────────────────────────────

DIMENSION 2: IMPACT (SEVERITY)
  How bad is it if this risk occurs?
  
  1 = Negligible   (minor inconvenience)
  2 = Minor        (small quality drop, fixable)
  3 = Moderate     (user frustration, some harm)
  4 = Major        (significant harm, legal risk)
  5 = Catastrophic (deaths, mass harm, company end)

─────────────────────────────────────────────

RISK SCORE = LIKELIHOOD × IMPACT

1-4   = LOW RISK     → Monitor, document
5-9   = MEDIUM RISK  → Mitigate, review quarterly
10-14 = HIGH RISK    → Urgent action, dedicated owner
15-25 = CRITICAL     → Block deployment, fix immediately
```

```python
# ============================================
# LLM RISK CLASSIFICATION SYSTEM
# Complete risk identification, scoring,
# tracking, and mitigation management
# ============================================

from dataclasses import dataclass, field
from enum import Enum
from typing import List, Optional, Dict
from datetime import datetime, date
import uuid
import json

# ─────────────────────────────────────────
# ENUMS: Risk Categories and Levels
# ─────────────────────────────────────────
class RiskCategory(str, Enum):
    CONTENT     = "content"
    FAIRNESS    = "fairness"
    PRIVACY     = "privacy"
    SECURITY    = "security"
    RELIABILITY = "reliability"
    OPERATIONAL = "operational"
    COMPLIANCE  = "compliance"
    REPUTATIONAL= "reputational"

class RiskLevel(str, Enum):
    LOW      = "low"       # Score 1-4
    MEDIUM   = "medium"    # Score 5-9
    HIGH     = "high"      # Score 10-14
    CRITICAL = "critical"  # Score 15-25

class MitigationStatus(str, Enum):
    IDENTIFIED      = "identified"    # Risk found, not yet assessed
    ASSESSED        = "assessed"      # Scored, awaiting mitigation plan
    IN_PROGRESS     = "in_progress"   # Mitigation being implemented
    MITIGATED       = "mitigated"     # Controls in place
    ACCEPTED        = "accepted"      # Risk accepted with justification
    TRANSFERRED     = "transferred"   # Risk transferred (e.g., to vendor)
    CLOSED          = "closed"        # Risk no longer applicable

# ─────────────────────────────────────────
# CORE DATA MODELS
# ─────────────────────────────────────────
@dataclass
class RiskControl:
    """A specific control that mitigates a risk."""
    control_id: str
    description: str
    control_type: str    # "preventive" / "detective" / "corrective"
    implementation_status: str  # "planned" / "implementing" / "active"
    owner: str
    implementation_date: Optional[date] = None
    effectiveness: Optional[str] = None  # "high" / "medium" / "low"
    evidence_url: str = ""


@dataclass
class RiskItem:
    """
    A single identified risk with full metadata.
    This is the core unit of risk management.
    """
    
    # Identity
    risk_id: str
    created_at: str
    
    # Classification
    title: str
    description: str
    category: RiskCategory
    
    # Scoring (1-5 each)
    likelihood_score: int     # 1=Very Unlikely → 5=Almost Certain
    impact_score: int         # 1=Negligible → 5=Catastrophic
    
    # Computed risk level
    risk_score: int = 0
    risk_level: RiskLevel = RiskLevel.LOW
    
    # Context
    affected_stakeholders: List[str] = field(default_factory=list)
    affected_scenarios: List[str] = field(default_factory=list)
    regulatory_implications: List[str] = field(default_factory=list)
    
    # Mitigation
    mitigation_status: MitigationStatus = MitigationStatus.IDENTIFIED
    controls: List[RiskControl] = field(default_factory=list)
    residual_risk_score: int = 0   # Risk score AFTER controls applied
    
    # Ownership
    risk_owner: str = ""
    reviewer: str = ""
    
    # Dates
    due_date: Optional[date] = None
    last_reviewed: Optional[str] = None
    
    # Evidence
    evidence_links: List[str] = field(default_factory=list)
    related_incidents: List[str] = field(default_factory=list)
    
    def __post_init__(self):
        self.risk_score = self.likelihood_score * self.impact_score
        self.risk_level = self._calculate_level(self.risk_score)
    
    def _calculate_level(self, score: int) -> RiskLevel:
        if score <= 4:  return RiskLevel.LOW
        if score <= 9:  return RiskLevel.MEDIUM
        if score <= 14: return RiskLevel.HIGH
        return RiskLevel.CRITICAL


# ─────────────────────────────────────────
# RISK REGISTRY MANAGER
# ─────────────────────────────────────────
class LLMRiskRegistry:
    """
    Central registry for all LLM system risks.
    Tracks identification, scoring, mitigation, review.
    """
    
    def __init__(self, system_name: str):
        self.system_name = system_name
        self.risks: Dict[str, RiskItem] = {}
        self.db = get_database_connection()
        
        # Pre-populate with standard LLM risks
        self._initialize_standard_risks()
    
    # ─────────────────────────────────────────
    # ADD NEW RISK
    # ─────────────────────────────────────────
    def add_risk(
        self,
        title: str,
        description: str,
        category: RiskCategory,
        likelihood_score: int,
        impact_score: int,
        affected_stakeholders: List[str],
        risk_owner: str,
        mitigation_plan: str = "",
        regulatory_implications: List[str] = None
    ) -> RiskItem:
        """
        Add a new risk to the registry.
        Auto-calculates risk level and assigns ID.
        """
        
        # Validate scores
        if not (1 <= likelihood_score <= 5):
            raise ValueError("Likelihood must be 1-5")
        if not (1 <= impact_score <= 5):
            raise ValueError("Impact must be 1-5")
        
        risk = RiskItem(
            risk_id=f"RISK-{self.system_name[:4].upper()}-{str(uuid.uuid4())[:8].upper()}",
            created_at=datetime.utcnow().isoformat(),
            title=title,
            description=description,
            category=category,
            likelihood_score=likelihood_score,
            impact_score=impact_score,
            affected_stakeholders=affected_stakeholders,
            regulatory_implications=regulatory_implications or [],
            risk_owner=risk_owner,
            mitigation_status=MitigationStatus.IDENTIFIED
        )
        
        self.risks[risk.risk_id] = risk
        self._save_to_db(risk)
        
        # Alert if critical risk!
        if risk.risk_level == RiskLevel.CRITICAL:
            self._send_critical_risk_alert(risk)
        
        print(f"⚠️  Risk registered: {risk.risk_id}")
        print(f"   Title: {risk.title}")
        print(f"   Score: {risk.risk_score}/25 ({risk.risk_level.value.upper()})")
        print(f"   Owner: {risk.risk_owner}")
        
        return risk
    
    # ─────────────────────────────────────────
    # ADD CONTROL TO MITIGATE RISK
    # ─────────────────────────────────────────
    def add_control(
        self,
        risk_id: str,
        control_description: str,
        control_type: str,           # preventive/detective/corrective
        owner: str,
        implementation_date: date = None,
        residual_likelihood: int = None,  # Likelihood AFTER this control
        residual_impact: int = None       # Impact AFTER this control
    ) -> RiskControl:
        """
        Add a mitigation control to a risk.
        Recalculates residual risk score.
        """
        
        risk = self.risks.get(risk_id)
        if not risk:
            raise ValueError(f"Risk {risk_id} not found")
        
        control = RiskControl(
            control_id=f"CTRL-{str(uuid.uuid4())[:8].upper()}",
            description=control_description,
            control_type=control_type,
            implementation_status="planned",
            owner=owner,
            implementation_date=implementation_date
        )
        
        risk.controls.append(control)
        
        # Recalculate residual risk if scores provided
        if residual_likelihood and residual_impact:
            risk.residual_risk_score = residual_likelihood * residual_impact
            
            # Update status if risk is now acceptable
            if risk.residual_risk_score <= 4:
                risk.mitigation_status = MitigationStatus.MITIGATED
            else:
                risk.mitigation_status = MitigationStatus.IN_PROGRESS
        
        self._save_to_db(risk)
        
        print(f"✅ Control added to {risk_id}")
        print(f"   Control: {control_description}")
        print(f"   Residual risk score: {risk.residual_risk_score}/25")
        
        return control
    
    # ─────────────────────────────────────────
    # GENERATE RISK REPORT
    # ─────────────────────────────────────────
    def generate_risk_report(
        self,
        report_type: str = "full",   # "full" / "executive" / "critical_only"
        audience: str = "technical"  # "technical" / "executive" / "board"
    ) -> dict:
        """
        Generate risk report for different audiences.
        Technical team: Full detail.
        Executive: Summary + high/critical only.
        Board: High-level risk appetite statement.
        """
        
        all_risks = list(self.risks.values())
        
        # Sort by risk score (highest first)
        all_risks.sort(key=lambda r: r.risk_score, reverse=True)
        
        # Group by level
        critical = [r for r in all_risks if r.risk_level == RiskLevel.CRITICAL]
        high     = [r for r in all_risks if r.risk_level == RiskLevel.HIGH]
        medium   = [r for r in all_risks if r.risk_level == RiskLevel.MEDIUM]
        low      = [r for r in all_risks if r.risk_level == RiskLevel.LOW]
        
        # Mitigation progress
        total = len(all_risks)
        mitigated = len([r for r in all_risks 
                        if r.mitigation_status in [
                            MitigationStatus.MITIGATED, 
                            MitigationStatus.CLOSED
                        ]])
        
        report = {
            "report_metadata": {
                "system_name": self.system_name,
                "generated_at": datetime.utcnow().isoformat(),
                "report_type": report_type,
                "audience": audience,
                "prepared_by": "AI Risk Management Team",
            },
            
            "executive_summary": {
                "total_risks_identified": total,
                "critical_risks": len(critical),
                "high_risks": len(high),
                "medium_risks": len(medium),
                "low_risks": len(low),
                "mitigation_progress_pct": round(mitigated / total * 100, 1) if total > 0 else 100,
                "overall_risk_status": self._calculate_overall_status(critical, high),
                "key_concerns": [r.title for r in critical[:3]],  # Top 3 concerns
            },
            
            "risk_breakdown": {
                "critical": [self._format_risk(r, audience) for r in critical],
                "high":     [self._format_risk(r, audience) for r in high],
                "medium":   [self._format_risk(r, audience) for r in medium]
                            if report_type == "full" else [],
                "low":      [self._format_risk(r, audience) for r in low]
                            if report_type == "full" else [],
            },
            
            "mitigation_status_summary": {
                "identified": len([r for r in all_risks 
                                   if r.mitigation_status == MitigationStatus.IDENTIFIED]),
                "in_progress": len([r for r in all_risks 
                                    if r.mitigation_status == MitigationStatus.IN_PROGRESS]),
                "mitigated": mitigated,
                "accepted": len([r for r in all_risks 
                                 if r.mitigation_status == MitigationStatus.ACCEPTED]),
            },
            
            "regulatory_risk_summary": self._get_regulatory_risk_summary(all_risks),
            
            "action_required": [
                {
                    "risk_id": r.risk_id,
                    "title": r.title,
                    "owner": r.risk_owner,
                    "due_date": str(r.due_date),
                    "urgency": "IMMEDIATE" if r.risk_level == RiskLevel.CRITICAL else "URGENT"
                }
                for r in critical + high
                if r.mitigation_status not in [
                    MitigationStatus.MITIGATED, MitigationStatus.CLOSED
                ]
            ]
        }
        
        return report
```

# 🏗️ PILLAR 2: Impact Assessment

## What Is an Impact Assessment?

**Simple English:**
Impact Assessment = **A deep investigation into WHO your AI system affects, HOW it affects them, and HOW SEVERELY — before you deploy and after incidents.**

---

## 🌍 Analogy — Environmental Impact Study

```
🏗️ BUILDING A FACTORY = Deploying an LLM System

Before any major construction, developers must complete
an Environmental Impact Assessment (EIA):

→ Who lives nearby? (Identify affected populations)
→ What will change for them? (Identify impacts)
→ How severe is the change? (Measure severity)
→ Can we reduce the harm? (Mitigation)
→ Is there a better location? (Alternatives)
→ What if we do nothing? (Baseline)

Government reviews the EIA BEFORE approving construction.

AI IMPACT ASSESSMENT = Same concept.
Answer the same questions for AI before deploying.
Get approval BEFORE it goes live.
```

---

## 🔬 AI Impact Assessment — First Principles

```
AN AI IMPACT ASSESSMENT MUST ANSWER:

QUESTION 1: WHO IS AFFECTED?
  Direct users: People who use the AI
  Indirect subjects: People AI makes decisions ABOUT
  Third parties: People in the environment
  Vulnerable groups: Children, minorities, disabled, elderly
  
  ↳ RULE: If your AI affects someone's life, 
    they are a stakeholder — even if they never use it.

─────────────────────────────────────────────

QUESTION 2: WHAT ARE THE IMPACTS?
  Benefits: What good does this AI create?
  Harms: What damage can it cause?
  
  Types of harm:
  Physical harm    → AI medical advice causes injury
  Psychological    → AI output causes distress
  Financial        → AI bias causes economic loss
  Privacy          → AI exposes personal information
  Reputational     → AI falsely portrays someone
  Autonomy         → AI manipulates decisions
  Discrimination   → AI treats groups unfairly
  Societal         → AI impacts society broadly

─────────────────────────────────────────────

QUESTION 3: HOW SEVERE?
  Severity scale:
  1. Trivial     → Minor inconvenience
  2. Moderate    → Temporary setback
  3. Significant → Lasting impact, reversible
  4. Severe      → Long-lasting, hard to reverse
  5. Critical    → Irreversible, life-altering

─────────────────────────────────────────────

QUESTION 4: WHO IS MOST VULNERABLE?
  → Groups with less power to protect themselves
  → Groups historically discriminated against
  → People in dependency relationships with AI
  → Children and minors
  → People in crisis situations

─────────────────────────────────────────────

QUESTION 5: WHAT'S THE COUNTERFACTUAL?
  → What happens WITHOUT the AI?
  → Is the AI better or worse than the alternative?
  → Are we replacing human judgment? Should we be?
```

# 🏗️ PILLAR 3: AI Usage Policies

## What Is an AI Usage Policy?

**Simple English:**
AI Usage Policy = **A clear, written set of rules that defines HOW your organization uses AI — what is allowed, what is forbidden, who is responsible, and what happens if rules are broken.**

---

## 🌍 Analogy — Driving Laws

```
🚗 DRIVING LAWS = AI Usage Policy

Without driving laws:
  → Everyone drives however they want
  → Maximum speed: "as fast as your car goes"
  → Lane rules: "whatever feels right"
  → Result: Chaos, crashes, deaths

WITH driving laws:
  → Speed limits: 50 km/h in cities
  → Rules: Stay in lanes, use indicators
  → Requirements: License, insurance, registration
  → Consequences: Fines, license suspension
  → Result: Safer roads for everyone

AI USAGE POLICY = The driving laws for AI.
Without them: Developers do whatever they want.
With them: Clear, safe, accountable AI use.
```

---

## 🔬 Types of AI Usage Policies

```
THERE ARE 3 LEVELS OF AI USAGE POLICIES:

LEVEL 1: EMPLOYEE AI USE POLICY
  → Rules for how employees use AI tools
  → (ChatGPT for work, GitHub Copilot, etc.)
  → "Don't put company secrets in ChatGPT"

LEVEL 2: PRODUCT AI DEVELOPMENT POLICY
  → Rules for teams building AI products
  → "All training data must be consent-approved"
  → "High-risk AI needs AIIA before deployment"

LEVEL 3: DEPLOYED AI SYSTEM POLICY
  → Rules for how deployed AI systems behave
  → "AI must never claim to be human"
  → "AI cannot make final medical decisions"

ALL THREE ARE NEEDED.
A company without all three has governance gaps.
```

## 💻 Document 5: Incident Reporting System — Complete Implementation

```python
# ============================================
# AI INCIDENT MANAGEMENT SYSTEM
# Complete incident lifecycle: detect → 
# report → investigate → remediate → learn
# ============================================

from enum import Enum
from dataclasses import dataclass, field
from typing import List, Optional, Dict
from datetime import datetime, timedelta
import uuid

class IncidentSeverity(str, Enum):
    P1_CRITICAL = "P1"  # Production down / active user harm
    P2_HIGH     = "P2"  # Significant degradation / potential harm
    P3_MEDIUM   = "P3"  # Partial degradation / compliance risk
    P4_LOW      = "P4"  # Minor issue / no immediate user impact

class IncidentStatus(str, Enum):
    DETECTED      = "detected"
    ACKNOWLEDGED  = "acknowledged"  # Someone is looking at it
    INVESTIGATING = "investigating"
    MITIGATING    = "mitigating"    # Active fix in progress
    RESOLVED      = "resolved"      # Issue fixed
    CLOSED        = "closed"        # Post-mortem complete
    LEARNING      = "learning"      # Changes being implemented

class IncidentCategory(str, Enum):
    HALLUCINATION       = "hallucination"
    SAFETY_VIOLATION    = "safety_violation"    # Harmful content
    BIAS_DISCRIMINATION = "bias_discrimination"
    PRIVACY_BREACH      = "privacy_breach"
    SECURITY_ATTACK     = "security_attack"     # Prompt injection, jailbreak
    RELIABILITY         = "reliability"         # Outage, slow response
    COMPLIANCE          = "compliance"          # Regulatory violation
    COST_OVERRUN        = "cost_overrun"
    DATA_QUALITY        = "data_quality"
    OTHER               = "other"


@dataclass
class IncidentTimeline:
    """Timeline entry in incident record."""
    timestamp: str
    actor: str        # Who took this action
    action: str       # What they did
    details: str
    artifacts: List[str] = field(default_factory=list)  # Links to evidence


@dataclass
class AIIncident:
    """
    Complete record of an AI system incident.
    From detection to lessons learned.
    """
    
    # Identity
    incident_id: str
    title: str
    
    # Classification
    severity: IncidentSeverity
    category: IncidentCategory
    affected_system: str
    affected_component: str   # "llm_output" / "rag_retrieval" / "guardrails" etc.
    
    # Discovery
    detected_at: str
    detected_by: str          # "monitoring_alert" / "user_report" / "manual_check"
    reported_by: str
    
    # Impact
    users_affected_count: int
    users_affected_description: str
    business_impact: str
    regulatory_impact: str    # "potential_gdpr_violation" / "none" / etc.
    
    # Description
    incident_description: str
    root_cause: str = ""
    contributing_factors: List[str] = field(default_factory=list)
    
    # Timeline
    acknowledged_at: Optional[str] = None
    resolved_at: Optional[str] = None
    timeline: List[IncidentTimeline] = field(default_factory=list)
    
    # Response
    immediate_actions: List[str] = field(default_factory=list)
    remediation_steps: List[str] = field(default_factory=list)
    
    # Evidence
    log_urls: List[str] = field(default_factory=list)
    screenshot_urls: List[str] = field(default_factory=list)
    langsmith_trace_ids: List[str] = field(default_factory=list)
    
    # Notifications sent
    notifications_sent: Dict[str, str] = field(default_factory=dict)
    regulatory_notification_required: bool = False
    regulatory_notification_sent: Optional[str] = None
    
    # Post-mortem
    status: IncidentStatus = IncidentStatus.DETECTED
    post_mortem_url: str = ""
    lessons_learned: List[str] = field(default_factory=list)
    prevention_actions: List[dict] = field(default_factory=list)
    
    # SLA tracking
    response_sla_met: bool = False
    resolution_sla_met: bool = False


class IncidentManagementSystem:
    """
    Complete AI Incident Management System.
    Handles the full lifecycle of AI incidents.
    """
    
    # SLA targets by severity
    RESPONSE_SLA = {
        IncidentSeverity.P1_CRITICAL: timedelta(minutes=15),
        IncidentSeverity.P2_HIGH:     timedelta(hours=1),
        IncidentSeverity.P3_MEDIUM:   timedelta(hours=4),
        IncidentSeverity.P4_LOW:      timedelta(hours=24)
    }
    
    RESOLUTION_SLA = {
        IncidentSeverity.P1_CRITICAL: timedelta(hours=4),
        IncidentSeverity.P2_HIGH:     timedelta(hours=24),
        IncidentSeverity.P3_MEDIUM:   timedelta(days=7),
        IncidentSeverity.P4_LOW:      timedelta(days=30)
    }
    
    # Notification escalation matrix
    NOTIFICATION_MATRIX = {
        IncidentSeverity.P1_CRITICAL: [
            "on_call_engineer",
            "engineering_manager",
            "vp_engineering",
            "cto",
            "ceo",           # For P1!
            "communications" # PR team for media management
        ],
        IncidentSeverity.P2_HIGH: [
            "on_call_engineer",
            "engineering_manager",
            "vp_engineering"
        ],
        IncidentSeverity.P3_MEDIUM: [
            "ai_team",
            "engineering_manager"
        ],
        IncidentSeverity.P4_LOW: [
            "ai_team"
        ]
    }
    
    # ─────────────────────────────────────────
    # STEP 1: REPORT A NEW INCIDENT
    # ─────────────────────────────────────────
    def report_incident(
        self,
        title: str,
        severity: IncidentSeverity,
        category: IncidentCategory,
        description: str,
        affected_system: str,
        affected_component: str,
        users_affected_count: int,
        users_affected_description: str,
        reported_by: str,
        detected_by: str = "manual_report",
        log_urls: List[str] = None,
        langsmith_trace_ids: List[str] = None
    ) -> AIIncident:
        """
        Create a new incident record.
        Triggers immediate notification cascade.
        """
        
        detected_at = datetime.utcnow().isoformat()
        
        # Assess regulatory impact
        regulatory_impact = self._assess_regulatory_impact(
            category, users_affected_count
        )
        
        incident = AIIncident(
            incident_id=f"INC-{datetime.utcnow().strftime('%Y%m%d')}-{str(uuid.uuid4())[:6].upper()}",
            title=title,
            severity=severity,
            category=category,
            affected_system=affected_system,
            affected_component=affected_component,
            detected_at=detected_at,
            detected_by=detected_by,
            reported_by=reported_by,
            incident_description=description,
            users_affected_count=users_affected_count,
            users_affected_description=users_affected_description,
            business_impact=self._assess_business_impact(severity, users_affected_count),
            regulatory_impact=regulatory_impact,
            regulatory_notification_required=(regulatory_impact != "none"),
            log_urls=log_urls or [],
            langsmith_trace_ids=langsmith_trace_ids or [],
            status=IncidentStatus.DETECTED
        )
        
        # Add initial timeline entry
        incident.timeline.append(IncidentTimeline(
            timestamp=detected_at,
            actor=reported_by,
            action="INCIDENT_REPORTED",
            details=f"Incident reported via {detected_by}. Severity: {severity.value}"
        ))
        
        # Save to database
        self._save_incident(incident)
        
        # IMMEDIATE ACTIONS
        self._trigger_notifications(incident)
        
        # For P1/P2 with privacy impact → check GDPR 72h notification
        if incident.regulatory_notification_required:
            self._initiate_regulatory_notification_assessment(incident)
        
        print(f"🚨 INCIDENT CREATED: {incident.incident_id}")
        print(f"   Severity: {severity.value}")
        print(f"   Title: {title}")
        print(f"   Affected users: {users_affected_count}")
        print(f"   Response SLA: {self.RESPONSE_SLA[severity]}")
        
        return incident
    
    # ─────────────────────────────────────────
    # STEP 2: ACKNOWLEDGE AND ASSIGN
    # ─────────────────────────────────────────
    def acknowledge_incident(
        self,
        incident_id: str,
        acknowledger: str,
        initial_assessment: str,
        assigned_to: str
    ) -> AIIncident:
        """
        Engineer acknowledges incident and takes ownership.
        Tracks SLA compliance.
        """
        
        incident = self._load_incident(incident_id)
        now = datetime.utcnow()
        
        incident.acknowledged_at = now.isoformat()
        incident.status = IncidentStatus.ACKNOWLEDGED
        
        # Check response SLA
        detected_time = datetime.fromisoformat(incident.detected_at)
        response_time = now - detected_time
        incident.response_sla_met = (
            response_time <= self.RESPONSE_SLA[incident.severity]
        )
        
        incident.timeline.append(IncidentTimeline(
            timestamp=now.isoformat(),
            actor=acknowledger,
            action="INCIDENT_ACKNOWLEDGED",
            details=f"Assigned to: {assigned_to}. "
                   f"Initial assessment: {initial_assessment}. "
                   f"Response time: {response_time}. "
                   f"SLA met: {incident.response_sla_met}"
        ))
        
        if not incident.response_sla_met:
            self._send_sla_breach_alert(incident, "response")
        
        self._save_incident(incident)
        return incident
    
    # ─────────────────────────────────────────
    # STEP 3: DOCUMENT INVESTIGATION
    # ─────────────────────────────────────────
    def update_investigation(
        self,
        incident_id: str,
        investigator: str,
        root_cause: str,
        contributing_factors: List[str],
        evidence_found: List[str],
        langsmith_traces: List[str] = None
    ) -> AIIncident:
        """
        Document the investigation findings.
        Root cause analysis.
        """
        
        incident = self._load_incident(incident_id)
        
        incident.root_cause = root_cause
        incident.contributing_factors = contributing_factors
        incident.status = IncidentStatus.INVESTIGATING
        
        if langsmith_traces:
            incident.langsmith_trace_ids.extend(langsmith_traces)
        
        incident.timeline.append(IncidentTimeline(
            timestamp=datetime.utcnow().isoformat(),
            actor=investigator,
            action="ROOT_CAUSE_IDENTIFIED",
            details=f"Root cause: {root_cause}",
            artifacts=evidence_found
        ))
        
        self._save_incident(incident)
        return incident
    
    # ─────────────────────────────────────────
    # STEP 4: IMPLEMENT REMEDIATION
    # ─────────────────────────────────────────
    def document_remediation(
        self,
        incident_id: str,
        engineer: str,
        remediation_action: str,
        remediation_type: str,  # "immediate_hotfix" / "rollback" / "config_change" / "guardrail_update"
        verification_method: str
    ) -> AIIncident:
        """Document each remediation action taken."""
        
        incident = self._load_incident(incident_id)
        incident.status = IncidentStatus.MITIGATING
        
        incident.remediation_steps.append(remediation_action)
        
        incident.timeline.append(IncidentTimeline(
            timestamp=datetime.utcnow().isoformat(),
            actor=engineer,
            action=f"REMEDIATION_APPLIED_{remediation_type.upper()}",
            details=f"Action: {remediation_action}. "
                   f"Verification: {verification_method}"
        ))
        
        self._save_incident(incident)
        return incident
    
    # ─────────────────────────────────────────
    # STEP 5: RESOLVE INCIDENT
    # ─────────────────────────────────────────
    def resolve_incident(
        self,
        incident_id: str,
        resolver: str,
        resolution_summary: str,
        user_notification_sent: bool = False,
        post_mortem_scheduled: bool = False
    ) -> AIIncident:
        """
        Mark incident as resolved.
        Triggers post-mortem scheduling.
        """
        
        incident = self._load_incident(incident_id)
        now = datetime.utcnow()
        
        incident.resolved_at = now.isoformat()
        incident.status = IncidentStatus.RESOLVED
        
        # Check resolution SLA
        detected_time = datetime.fromisoformat(incident.detected_at)
        resolution_time = now - detected_time
        incident.resolution_sla_met = (
            resolution_time <= self.RESOLUTION_SLA[incident.severity]
        )
        
        incident.timeline.append(IncidentTimeline(
            timestamp=now.isoformat(),
            actor=resolver,
            action="INCIDENT_RESOLVED",
            details=f"Resolution: {resolution_summary}. "
                   f"Total time: {resolution_time}. "
                   f"SLA met: {incident.resolution_sla_met}. "
                   f"User notification: {user_notification_sent}"
        ))
        
        # Schedule post-mortem for P1/P2
        if incident.severity in [
            IncidentSeverity.P1_CRITICAL,
            IncidentSeverity.P2_HIGH
        ]:
            self._schedule_post_mortem(incident)
        
        self._save_incident(incident)
        
        print(f"✅ INCIDENT RESOLVED: {incident_id}")
        print(f"   Resolution time: {resolution_time}")
        print(f"   SLA met: {incident.resolution_sla_met}")
        
        return incident
    
    # ─────────────────────────────────────────
    # STEP 6: POST-MORTEM
    # Most important step — prevent recurrence!
    # ─────────────────────────────────────────
    def complete_post_mortem(
        self,
        incident_id: str,
        facilitator: str,
        attendees: List[str],
        lessons_learned: List[str],
        prevention_actions: List[dict],  # [{action, owner, due_date, ticket}]
        timeline_of_events: str,
        blameless_summary: str
    ) -> dict:
        """
        Complete the blameless post-mortem.
        
        BLAMELESS = Focus on SYSTEMS, not PEOPLE.
        "Why did the system allow this to happen?"
        Not "Who made the mistake?"
        
        Goal: Prevent RECURRENCE. Not punishment.
        """
        
        incident = self._load_incident(incident_id)
        
        incident.lessons_learned = lessons_learned
        incident.prevention_actions = prevention_actions
        incident.status = IncidentStatus.CLOSED
        
        # Create prevention tickets
        created_tickets = []
        for action in prevention_actions:
            ticket = self._create_prevention_ticket(
                action=action["action"],
                owner=action["owner"],
                due_date=action["due_date"],
                related_incident=incident_id
            )
            created_tickets.append(ticket)
            action["ticket_id"] = ticket["id"]
        
        incident.timeline.append(IncidentTimeline(
            timestamp=datetime.utcnow().isoformat(),
            actor=facilitator,
            action="POST_MORTEM_COMPLETED",
            details=f"Attendees: {', '.join(attendees)}. "
                   f"Prevention actions: {len(prevention_actions)}. "
                   f"Tickets created: {len(created_tickets)}"
        ))
        
        self._save_incident(incident)
        
        # Add to lessons learned knowledge base
        self._update_lessons_learned_kb(incident)
        
        post_mortem_report = {
            "incident_id": incident_id,
            "title": incident.title,
            "severity": incident.severity,
            "timeline_of_events": timeline_of_events,
            "root_cause": incident.root_cause,
            "contributing_factors": incident.contributing_factors,
            "lessons_learned": lessons_learned,
            "prevention_actions": prevention_actions,
            "tickets_created": created_tickets,
            "blameless_summary": blameless_summary,
            "metrics": {
                "total_duration": self._calculate_incident_duration(incident),
                "users_affected": incident.users_affected_count,
                "response_sla_met": incident.response_sla_met,
                "resolution_sla_met": incident.resolution_sla_met
            }
        }
        
        print(f"📝 POST-MORTEM COMPLETE: {incident_id}")
        print(f"   Prevention actions: {len(prevention_actions)}")
        print(f"   Tickets created: {len(created_tickets)}")
        
        return post_mortem_report
    
    # ─────────────────────────────────────────
    # REGULATORY NOTIFICATION LOGIC
    # GDPR requires 72-hour notification for breaches
    # ─────────────────────────────────────────
    def _assess_regulatory_impact(
        self,
        category: IncidentCategory,
        users_affected: int
    ) -> str:
        
        # GDPR Data Breach → 72h notification required
        if category == IncidentCategory.PRIVACY_BREACH and users_affected > 0:
            return "GDPR_DATA_BREACH_72H_NOTIFICATION_REQUIRED"
        
        # EU AI Act serious incident reporting
        if category == IncidentCategory.SAFETY_VIOLATION and users_affected > 100:
            return "EU_AI_ACT_SERIOUS_INCIDENT_REPORTING"
        
        # HIPAA breach reporting
        if category == IncidentCategory.PRIVACY_BREACH and self._is_hipaa_system():
            return "HIPAA_BREACH_NOTIFICATION_REQUIRED"
        
        return "none"
```

# 💬 Strong Interview Answers

### Q: "How would you classify risks for an LLM medical assistant?"

✅ **Strong Answer:**
> "I'd start with the EU AI Act — a medical diagnostic AI is clearly high-risk, requiring full technical documentation, human oversight, accuracy standards, and registration. Then I'd build a risk matrix covering the 8 LLM risk categories. For a medical AI specifically: content risks score high because hallucinated medical advice can cause physical harm — that's likelihood 3, impact 5, score 15, critical. Demographic bias in clinical accuracy is impact 5 — patients from underrepresented groups getting worse AI diagnosis is catastrophic. Privacy risk from PHI in outputs is critical. I'd require an AI Impact Assessment analyzing all stakeholder groups — especially vulnerable patients like elderly, mentally ill, or low-health-literacy populations. The controls would include: RAG from verified medical databases only, mandatory human physician review of all AI recommendations, PHI removal with Presidio, continuous bias monitoring across demographic groups, and automatic escalation for life-threatening scenarios."

---

### Q: "What is a blameless post-mortem and why does it matter?"

✅ **Strong Answer:**
> "A blameless post-mortem is an incident review that focuses entirely on why the SYSTEM failed — not who made the mistake. The question isn't 'who caused this' but rather 'what in our system, process, or design allowed this to happen?' The reason this matters is psychological safety: if engineers fear punishment when things go wrong, they hide incidents, delay reporting, and avoid taking calculated risks. This makes systems MORE dangerous over time. In contrast, when post-mortems are blame-free, engineers report incidents immediately, share all evidence openly, and propose structural improvements. For LLM systems specifically: if an AI outputs harmful content, the question isn't 'who wrote the bad prompt' — it's 'why did our guardrails miss this? Why didn't our testing catch it? What do we change in the system to prevent recurrence?' The output of every post-mortem should be concrete tickets with owners and due dates, adding to our prevention actions tracker."

# ⚠️ Common Beginner Mistakes

| Mistake | Why It's Wrong | Correct Approach |
|---------|---------------|-----------------|
| "Risk = just make a list of what could go wrong" | No scoring = can't prioritize = everything is treated equally | Risk matrix: Likelihood × Impact = score = prioritization |
| Writing policy no one reads | Policy as theater → no actual behavior change | Mandatory acknowledgment + regular training + enforcement |
| Post-mortem = blaming the developer | Fear prevents honest reporting of incidents | Blameless post-mortem focused on system failures |
| "We'll document after we ship" | Under time pressure → never happens | Documentation is a deployment prerequisite |
| Generic risk register | "AI might make a mistake" is not actionable | Specific risks: "LLM hallucinates drug dosages to clinical staff. Score 15." |
| One-time impact assessment | System changes → risks change | AIIA reviewed annually + after every significant change |
| Incident report = one-line Slack message | Not auditable, no learning, no pattern tracking | Structured incident record with full timeline |
| No named owner per risk | Everybody's responsibility = nobody's responsibility | Every risk has exactly one named owner |
