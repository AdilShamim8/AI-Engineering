# 🏛️ PILLAR 1: MANUAL APPROVAL WORKFLOWS

## What is a Manual Approval Workflow?

**Core Idea:** Before an AI-generated action takes effect, it pauses and waits for a human to say "yes" or "no."

### Simple Analogy:
> Imagine a new bank teller 🏦
> Their first week: manager must approve every transaction over $500.
> After 6 months of perfect record: limit raised to $5,000.
> After 2 years: $50,000.
>
> The AI is that new teller.
> The approval workflow is the manager's sign-off.
> Over time, as trust is built, the AI gets more autonomy.

---

## Synchronous vs. Asynchronous Approvals

```
SYNCHRONOUS APPROVAL:
─────────────────────
User Request → AI Response → ⏸️ WAIT FOR HUMAN → Response to User

• User waits in real time
• Good for: Low-frequency, high-stakes decisions
• Problem: User experience suffers if reviewer is slow
• Example: AI suggests a refund → Manager approves → User sees result


ASYNCHRONOUS APPROVAL:
──────────────────────
User Request → AI Response → 📥 QUEUE → Human reviews later
                                    ↓
                         Notification to user: "Under review"
                                    ↓
                         Human approves → User notified

• User not blocked
• Good for: High-frequency decisions, non-urgent
• Problem: Delay in outcome
• Example: AI content moderation → Reviewer queue → Decision sent later
```

---

## Approval Workflow Design Patterns

### Pattern 1: Single Approver

```
AI Output → [Reviewer] → Approved/Rejected → Effect

Pros:  Simple, fast
Cons:  Single point of failure, bias risk
Use:   Medium-stakes decisions, trusted reviewers
```

### Pattern 2: Multi-Level Approval Chain

```
AI Output → [L1 Reviewer] → [L2 Manager] → [L3 Exec] → Effect
                 ↓                ↓               ↓
            Review in         Review in       Review in
             1 hour            4 hours         24 hours

Level 1: Any team member can approve (stakes < $1,000)
Level 2: Manager approval (stakes $1,000 - $10,000)
Level 3: Executive approval (stakes > $10,000)

Pros:  Proportional oversight to risk
Cons:  Slower, more expensive
Use:   Financial decisions, legal actions
```

### Pattern 3: Consensus Approval

```
AI Output → [Reviewer A] ─┐
           [Reviewer B] ──┤→ Majority Vote → Effect
           [Reviewer C] ─┘

Pros:  Removes individual bias, higher accuracy
Cons:  Expensive (3x human cost), slower
Use:   Medical diagnosis, legal determinations
```

### Pattern 4: Parallel Fast-Track

```
AI Output (risk < threshold) ────────────────────→ Auto-approve
AI Output (risk ≥ threshold) → [Human Review] ──→ Manual decision

Pros:  Low-risk handled automatically (efficiency)
       High-risk gets human attention (safety)
Cons:  Need accurate risk scoring
Use:   Content moderation, fraud detection
```

```python
# ══════════════════════════════════════════════════════════
# MANUAL APPROVAL WORKFLOW ENGINE
# ══════════════════════════════════════════════════════════

import uuid
import time
from enum import Enum
from dataclasses import dataclass, field
from typing import Optional, List, Dict, Callable, Any
from datetime import datetime, timedelta
import json

class ApprovalStatus(Enum):
    PENDING   = "pending"    # Waiting for human review
    APPROVED  = "approved"   # Human approved
    REJECTED  = "rejected"   # Human rejected
    MODIFIED  = "modified"   # Human approved with edits
    EXPIRED   = "expired"    # SLA deadline missed
    ESCALATED = "escalated"  # Sent to higher authority
    AUTO_APPROVED = "auto_approved"  # Risk below threshold

class ApprovalPriority(Enum):
    LOW      = 1   # Review within 24 hours
    MEDIUM   = 2   # Review within 4 hours
    HIGH     = 3   # Review within 1 hour
    CRITICAL = 4   # Review within 15 minutes

@dataclass
class ApprovalRequest:
    """
    A single approval request waiting for human review.
    This is the core unit of the HITL workflow.
    """
    
    # Identity
    request_id: str = field(default_factory=lambda: str(uuid.uuid4()))
    created_at: str = field(default_factory=lambda: datetime.utcnow().isoformat())
    
    # What needs approval
    ai_output: str = ""              # What AI produced
    original_input: str = ""         # What user asked
    context: Dict = field(default_factory=dict)   # Additional context
    action_type: str = ""            # What action this enables
    
    # Risk assessment
    risk_score: float = 0.0          # 0.0 = safe, 1.0 = very risky
    risk_reasons: List[str] = field(default_factory=list)
    confidence_score: float = 0.0    # AI's confidence in output
    
    # Routing
    priority: ApprovalPriority = ApprovalPriority.MEDIUM
    assigned_to: Optional[str] = None     # Reviewer user ID
    assigned_team: Optional[str] = None   # Team queue
    sla_deadline: Optional[str] = None    # Must be reviewed by when
    
    # Approval chain
    required_approvers: int = 1           # How many approvers needed
    current_approvals: int = 0            # How many approved so far
    approval_chain: List[Dict] = field(default_factory=list)
    
    # Status tracking
    status: ApprovalStatus = ApprovalStatus.PENDING
    reviewed_at: Optional[str] = None
    reviewed_by: Optional[str] = None
    reviewer_notes: str = ""
    
    # Output (may be modified by reviewer)
    final_output: Optional[str] = None   # Could differ from ai_output!
    
    # Metadata
    user_id: str = ""
    session_id: str = ""
    organization_id: str = ""

@dataclass
class ReviewDecision:
    """A reviewer's decision on an approval request"""
    reviewer_id: str
    reviewer_name: str
    decision: ApprovalStatus
    notes: str = ""
    modified_output: Optional[str] = None  # If reviewer edits the AI output
    decision_time: str = field(default_factory=lambda: datetime.utcnow().isoformat())
    time_to_review_seconds: float = 0.0

class SLAConfig:
    """SLA (Service Level Agreement) deadlines per priority"""
    
    DEADLINES = {
        ApprovalPriority.LOW:      timedelta(hours=24),
        ApprovalPriority.MEDIUM:   timedelta(hours=4),
        ApprovalPriority.HIGH:     timedelta(hours=1),
        ApprovalPriority.CRITICAL: timedelta(minutes=15),
    }
    
    @classmethod
    def get_deadline(cls, priority: ApprovalPriority) -> str:
        deadline = datetime.utcnow() + cls.DEADLINES[priority]
        return deadline.isoformat()
    
    @classmethod
    def is_expired(cls, request: ApprovalRequest) -> bool:
        if not request.sla_deadline:
            return False
        return datetime.utcnow().isoformat() > request.sla_deadline
    
    @classmethod
    def minutes_until_deadline(cls, request: ApprovalRequest) -> float:
        if not request.sla_deadline:
            return float('inf')
        deadline = datetime.fromisoformat(request.sla_deadline)
        remaining = (deadline - datetime.utcnow()).total_seconds() / 60
        return max(0, remaining)

class ManualApprovalWorkflow:
    """
    Core HITL approval workflow engine.
    
    Manages:
    - Creating approval requests
    - Routing to right reviewers
    - SLA enforcement
    - Multi-level approval chains
    - Editable outputs
    - Audit trails
    """
    
    def __init__(self, storage_backend=None, notification_service=None):
        # In production: use database. Here we use memory.
        self.requests: Dict[str, ApprovalRequest] = {}
        self.reviewer_queues: Dict[str, List[str]] = {}  # team → request_ids
        self.storage = storage_backend
        self.notifications = notification_service
        
        # Callbacks for lifecycle events
        self.on_request_created: List[Callable] = []
        self.on_approved: List[Callable] = []
        self.on_rejected: List[Callable] = []
        self.on_modified: List[Callable] = []
        self.on_expired: List[Callable] = []
    
    def create_approval_request(
        self,
        ai_output: str,
        original_input: str,
        action_type: str,
        risk_score: float,
        risk_reasons: List[str],
        confidence_score: float,
        user_id: str,
        session_id: str,
        org_id: str,
        context: Dict = None,
        priority: ApprovalPriority = ApprovalPriority.MEDIUM,
        required_approvers: int = 1
    ) -> ApprovalRequest:
        """
        Create a new approval request and route it to reviewers.
        This is called when AI decides human review is needed.
        """
        
        # Determine priority based on risk if not specified
        if risk_score >= 0.9:
            priority = ApprovalPriority.CRITICAL
        elif risk_score >= 0.7:
            priority = ApprovalPriority.HIGH
        elif risk_score >= 0.5:
            priority = ApprovalPriority.MEDIUM
        else:
            priority = ApprovalPriority.LOW
        
        request = ApprovalRequest(
            ai_output=ai_output,
            original_input=original_input,
            action_type=action_type,
            risk_score=risk_score,
            risk_reasons=risk_reasons,
            confidence_score=confidence_score,
            user_id=user_id,
            session_id=session_id,
            organization_id=org_id,
            context=context or {},
            priority=priority,
            required_approvers=required_approvers,
            sla_deadline=SLAConfig.get_deadline(priority)
        )
        
        # Route to appropriate review team
        team = self._route_to_team(request)
        request.assigned_team = team
        
        # Save request
        self.requests[request.request_id] = request
        
        # Add to team queue
        if team not in self.reviewer_queues:
            self.reviewer_queues[team] = []
        self.reviewer_queues[team].append(request.request_id)
        
        # Notify reviewers
        self._notify_reviewers(request, team)
        
        # Trigger lifecycle callbacks
        for callback in self.on_request_created:
            callback(request)
        
        print(f"""
📋 APPROVAL REQUEST CREATED
   ID:       {request.request_id[:8]}...
   Action:   {action_type}
   Risk:     {risk_score:.0%}
   Priority: {priority.name}
   Team:     {team}
   SLA:      {SLAConfig.minutes_until_deadline(request):.0f} minutes
        """)
        
        return request
    
    def _route_to_team(self, request: ApprovalRequest) -> str:
        """
        Route request to correct review team.
        Based on action type, risk level, organization.
        """
        
        routing_rules = {
            "medical_advice":    "medical_review_team",
            "financial_action":  "compliance_team",
            "legal_content":     "legal_review_team",
            "content_creation":  "content_moderation_team",
            "user_account":      "trust_safety_team",
            "code_execution":    "security_review_team",
            "data_export":       "privacy_review_team",
        }
        
        # Critical risk always goes to senior team
        if request.risk_score >= 0.9:
            return "senior_review_team"
        
        return routing_rules.get(request.action_type, "general_review_team")
    
    def _notify_reviewers(self, request: ApprovalRequest, team: str):
        """Send notifications to reviewers (Slack, email, dashboard alert)"""
        
        urgency = "🚨 CRITICAL" if request.priority == ApprovalPriority.CRITICAL else \
                  "⚠️ HIGH" if request.priority == ApprovalPriority.HIGH else \
                  "📋 MEDIUM" if request.priority == ApprovalPriority.MEDIUM else "📌 LOW"
        
        message = f"""
{urgency} REVIEW NEEDED
Team: {team}
Request ID: {request.request_id[:8]}
Action: {request.action_type}
Risk Score: {request.risk_score:.0%}
SLA: {SLAConfig.minutes_until_deadline(request):.0f} minutes remaining
Dashboard: https://review.techshop.ai/requests/{request.request_id}
        """
        
        # In production: send to Slack, email, PagerDuty
        print(f"📨 NOTIFICATION SENT TO {team}:\n{message}")
    
    def get_reviewer_queue(self, team: str) -> List[ApprovalRequest]:
        """
        Get pending requests for a review team.
        Sorted by priority and SLA urgency.
        """
        
        request_ids = self.reviewer_queues.get(team, [])
        pending = []
        
        for rid in request_ids:
            request = self.requests.get(rid)
            if request and request.status == ApprovalStatus.PENDING:
                # Auto-expire SLA violations
                if SLAConfig.is_expired(request):
                    self._handle_sla_expiry(request)
                else:
                    pending.append(request)
        
        # Sort: CRITICAL first, then by urgency (least time remaining first)
        pending.sort(
            key=lambda r: (
                -r.priority.value,           # Higher priority first
                SLAConfig.minutes_until_deadline(r)  # Less time = more urgent
            )
        )
        
        return pending
    
    def submit_review_decision(
        self,
        request_id: str,
        decision: ReviewDecision
    ) -> ApprovalRequest:
        """
        Reviewer submits their decision.
        Handles: approve, reject, modify output, escalate.
        """
        
        request = self.requests.get(request_id)
        if not request:
            raise ValueError(f"Request {request_id} not found")
        
        if request.status != ApprovalStatus.PENDING:
            raise ValueError(f"Request already resolved: {request.status}")
        
        # Check SLA
        if SLAConfig.is_expired(request):
            raise ValueError("Request has expired SLA")
        
        # Calculate time to review
        created = datetime.fromisoformat(request.created_at)
        decision.time_to_review_seconds = (datetime.utcnow() - created).total_seconds()
        
        # Record this reviewer's decision
        request.approval_chain.append({
            "reviewer_id": decision.reviewer_id,
            "reviewer_name": decision.reviewer_name,
            "decision": decision.decision.value,
            "notes": decision.notes,
            "time": decision.decision_time,
            "time_to_review_seconds": decision.time_to_review_seconds,
            "modified": decision.modified_output is not None
        })
        
        # Handle different decision types
        if decision.decision == ApprovalStatus.APPROVED:
            request.current_approvals += 1
            
            if request.current_approvals >= request.required_approvers:
                # All required approvals received!
                request.status = ApprovalStatus.APPROVED
                request.final_output = request.ai_output  # Original AI output
                request.reviewed_by = decision.reviewer_id
                request.reviewed_at = decision.decision_time
                request.reviewer_notes = decision.notes
                
                for callback in self.on_approved:
                    callback(request)
                
                print(f"✅ APPROVED: {request_id[:8]}... by {decision.reviewer_name}")
        
        elif decision.decision == ApprovalStatus.MODIFIED:
            # Reviewer approved BUT changed the content
            request.status = ApprovalStatus.MODIFIED
            request.final_output = decision.modified_output   # EDITED output!
            request.reviewed_by = decision.reviewer_id
            request.reviewed_at = decision.decision_time
            request.reviewer_notes = decision.notes
            
            for callback in self.on_modified:
                callback(request, decision.modified_output)
            
            print(f"✏️ APPROVED WITH EDITS: {request_id[:8]}... by {decision.reviewer_name}")
        
        elif decision.decision == ApprovalStatus.REJECTED:
            request.status = ApprovalStatus.REJECTED
            request.final_output = None  # Rejected — no output sent
            request.reviewed_by = decision.reviewer_id
            request.reviewed_at = decision.decision_time
            request.reviewer_notes = decision.notes
            
            for callback in self.on_rejected:
                callback(request)
            
            print(f"❌ REJECTED: {request_id[:8]}... by {decision.reviewer_name}")
        
        elif decision.decision == ApprovalStatus.ESCALATED:
            # Send to senior reviewer
            request.required_approvers = 2  # Now needs senior approval too
            request.assigned_team = "senior_review_team"
            self._notify_reviewers(request, "senior_review_team")
            
            print(f"⬆️ ESCALATED: {request_id[:8]}... to senior team")
        
        return request
    
    def _handle_sla_expiry(self, request: ApprovalRequest):
        """Handle SLA deadline missed — escalate automatically"""
        
        if request.status == ApprovalStatus.PENDING:
            request.status = ApprovalStatus.ESCALATED
            
            # Auto-escalate to senior team
            request.assigned_team = "senior_review_team"
            request.priority = ApprovalPriority.CRITICAL
            
            print(f"⏰ SLA EXPIRED: {request.request_id[:8]}... — Auto-escalating!")
            
            self._notify_reviewers(request, "senior_review_team")
            
            for callback in self.on_expired:
                callback(request)
    
    def get_request_status(self, request_id: str) -> Dict:
        """Get current status of an approval request"""
        
        request = self.requests.get(request_id)
        if not request:
            return {"error": "Request not found"}
        
        return {
            "request_id": request_id,
            "status": request.status.value,
            "priority": request.priority.name,
            "risk_score": request.risk_score,
            "created_at": request.created_at,
            "reviewed_at": request.reviewed_at,
            "reviewed_by": request.reviewed_by,
            "final_output": request.final_output,
            "was_modified": request.status == ApprovalStatus.MODIFIED,
            "reviewer_notes": request.reviewer_notes,
            "sla_minutes_remaining": SLAConfig.minutes_until_deadline(request),
            "approval_chain": request.approval_chain
        }
    
    def get_queue_metrics(self, team: str) -> Dict:
        """Metrics for the review dashboard"""
        
        all_requests = [
            self.requests[rid]
            for rid in self.reviewer_queues.get(team, [])
            if rid in self.requests
        ]
        
        pending = [r for r in all_requests if r.status == ApprovalStatus.PENDING]
        approved = [r for r in all_requests if r.status == ApprovalStatus.APPROVED]
        rejected = [r for r in all_requests if r.status == ApprovalStatus.REJECTED]
        modified = [r for r in all_requests if r.status == ApprovalStatus.MODIFIED]
        
        # Average time to review
        reviewed = approved + rejected + modified
        avg_review_time = 0
        if reviewed:
            times = []
            for r in reviewed:
                if r.approval_chain:
                    times.append(r.approval_chain[-1].get('time_to_review_seconds', 0))
            avg_review_time = sum(times) / len(times) if times else 0
        
        # SLA compliance
        critical_pending = [r for r in pending if r.priority == ApprovalPriority.CRITICAL]
        
        return {
            "team": team,
            "queue_depth": len(pending),
            "total_today": len(all_requests),
            "approved": len(approved),
            "rejected": len(rejected),
            "modified": len(modified),
            "approval_rate": len(approved) / len(reviewed) if reviewed else 0,
            "modification_rate": len(modified) / len(reviewed) if reviewed else 0,
            "avg_review_time_minutes": avg_review_time / 60,
            "critical_pending": len(critical_pending),
            "sla_at_risk": len([
                r for r in pending 
                if SLAConfig.minutes_until_deadline(r) < 30
            ])
        }


# ──────────────────────────────────────
# USAGE EXAMPLE
# ──────────────────────────────────────

workflow = ManualApprovalWorkflow()

# Register lifecycle callbacks
workflow.on_approved.append(
    lambda req: print(f"📢 User {req.user_id} notified: Request approved")
)
workflow.on_rejected.append(
    lambda req: print(f"📢 User {req.user_id} notified: Request rejected — {req.reviewer_notes}")
)
workflow.on_modified.append(
    lambda req, output: print(f"📢 User {req.user_id} receiving modified response")
)
```

# 🏛️ PILLAR 2: ESCALATION TRIGGERS

## What is an Escalation Trigger?

**Core Idea:** A set of automated rules that detect when an AI's output or situation requires human attention — and automatically routes it there.

### Simple Analogy:
> A hospital triage nurse 🏥
> When a patient arrives, she quickly assesses:
> - Headache → Wait room (low priority)
> - Broken arm → Urgent care (medium priority)
> - Chest pain → Emergency now (critical priority)
>
> She doesn't decide the treatment — she decides the **routing**.
> Escalation triggers are your AI system's triage nurse.

---

## Types of Escalation Triggers

```
┌──────────────────────────────────────────────────────────────┐
│              ESCALATION TRIGGER TAXONOMY                      │
│                                                              │
│  TYPE 1: CONFIDENCE-BASED                                    │
│  ─────────────────────────                                   │
│  AI says: "I'm not sure about this"                          │
│  → Low confidence score → Escalate                           │
│  Examples:                                                   │
│  • Model confidence < 0.6 → Human review                     │
│  • Multiple contradictory answers generated                  │

│                                                              │
│  TYPE 2: RULE-BASED                                          │
│  ────────────────────                                        │
│  Specific conditions trigger review:                         │
│  → Dollar amount > $10,000                                   │
│  → Medical terms detected in response                        │
│  → Legal advice phrases detected                             │
│  → Sensitive user demographics involved                      │
│                                                              │
│  TYPE 3: RISK-SCORE BASED                                    │
│  ──────────────────────────                                  │
│  Composite score across multiple factors:                    │
│  → Risk score > threshold → Escalate                         │
│  → Risk from: content + context + user + action              │
│                                                              │
```

## Complete Escalation Trigger Engine

```python
# ══════════════════════════════════════════════════════════
# ESCALATION TRIGGER ENGINE
# Determines when and how to escalate to human review
# ══════════════════════════════════════════════════════════

from dataclasses import dataclass, field
from typing import List, Dict, Optional, Tuple, Callable
from enum import Enum
import re
import statistics

class EscalationLevel(Enum):
    NONE       = 0   # No escalation needed
    SOFT_FLAG  = 1   # Flag for optional review (don't block)
    REVIEW     = 2   # Queue for human review (can proceed while pending)
    HOLD       = 3   # Hold output until reviewed
    BLOCK      = 4   # Block completely pending human decision

@dataclass
class EscalationResult:
    """Result from escalation trigger evaluation"""
    
    escalation_level: EscalationLevel
    triggered_by: List[str]         # Which triggers fired
    confidence_in_decision: float   # How sure we are about escalation
    recommended_team: str           # Which team should review
    recommended_priority: ApprovalPriority
    explanation: str                # Human-readable explanation
    risk_breakdown: Dict            # Detailed risk factors
    
    @property
    def should_escalate(self) -> bool:
        return self.escalation_level.value > 0
    
    @property
    def should_hold(self) -> bool:
        return self.escalation_level.value >= EscalationLevel.HOLD.value

@dataclass
class ConversationContext:
    """Everything we know about this conversation and user"""
    
    # Current request
    user_message: str
    ai_response: str
    model_confidence: float         # 0.0 - 1.0
    
    # Conversation history
    conversation_history: List[Dict] = field(default_factory=list)
    conversation_turn: int = 1
    
    # User information
    user_id: str = ""
    user_tier: str = "free"
    user_role: str = "user"
    user_region: str = "US"
    user_history_risk_score: float = 0.0  # Historical risk from this user
    
    # Action metadata
    action_type: str = "chat"
    financial_amount: Optional[float] = None  # If financial action
    
    # Technical metadata
    model_used: str = "gpt-4"
    response_latency_ms: int = 0
    session_id: str = ""

class EscalationTriggerEngine:
    """
    Evaluates whether AI output needs human review.
    
    Runs multiple trigger checks and combines results
    into a single escalation decision.
    """
    
    def __init__(self):
        self.triggers: List[Callable] = [
            self._check_confidence_trigger,
            self._check_domain_risk_trigger,
            self._check_financial_trigger,
            self._check_vulnerability_trigger,
            self._check_legal_compliance_trigger,
            self._check_output_quality_trigger,
            self._check_behavioral_anomaly_trigger,
            self._check_high_stakes_content_trigger,
        ]
        
        # Configurable thresholds
        self.config = {
            "confidence_threshold_review": 0.60,    # Below = review
            "confidence_threshold_hold": 0.40,      # Below = hold
            "financial_threshold_review": 1_000,    # $ amount for review
            "financial_threshold_hold": 10_000,     # $ amount for hold
            "risk_score_review": 0.5,               # Overall risk for review
            "risk_score_hold": 0.75,                # Overall risk for hold
            "risk_score_block": 0.90,               # Overall risk for block
        }
        
        # High-risk domains that always get reviewed
        self.high_risk_domains = {
            "medical":     ("medical_review_team",    ApprovalPriority.HIGH),
            "legal":       ("legal_review_team",      ApprovalPriority.HIGH),
            "financial":   ("compliance_team",        ApprovalPriority.MEDIUM),
            "mental_health": ("crisis_team",          ApprovalPriority.CRITICAL),
            "suicide":     ("crisis_team",            ApprovalPriority.CRITICAL),
            "violence":    ("trust_safety_team",      ApprovalPriority.HIGH),
            "child_safety":("trust_safety_team",      ApprovalPriority.CRITICAL),
            "security":    ("security_review_team",   ApprovalPriority.HIGH),
        }
    
    def evaluate(self, context: ConversationContext) -> EscalationResult:
        """
        Run all escalation triggers and combine results.
        Returns comprehensive escalation decision.
        """
        
        all_triggered = []
        risk_factors = {}
        max_escalation_level = EscalationLevel.NONE
        recommended_team = "general_review_team"
        recommended_priority = ApprovalPriority.LOW
        
        # Run all triggers
        for trigger_fn in self.triggers:
            try:
                level, reason, team, priority, factors = trigger_fn(context)
                
                if level != EscalationLevel.NONE:
                    all_triggered.append(reason)
                    risk_factors.update(factors)
                    
                    # Take the highest escalation level
                    if level.value > max_escalation_level.value:
                        max_escalation_level = level
                        recommended_team = team
                        recommended_priority = priority
                    
                    # Take highest priority
                    if priority.value > recommended_priority.value:
                        recommended_priority = priority
            
            except Exception as e:
                # Trigger evaluation failed → be safe and escalate
                all_triggered.append(f"trigger_error: {str(e)}")
                if max_escalation_level.value < EscalationLevel.REVIEW.value:
                    max_escalation_level = EscalationLevel.REVIEW
        
        # Build explanation
        if all_triggered:
            explanation = f"Escalation triggered by {len(all_triggered)} factor(s): " + \
                         "; ".join(all_triggered[:3])
        else:
            explanation = "No escalation triggers fired — AI decision appears safe"
        
        # Calculate overall confidence in the escalation decision
        confidence = min(1.0, len(all_triggered) * 0.25 + context.model_confidence * 0.3)
        
        return EscalationResult(
            escalation_level=max_escalation_level,
            triggered_by=all_triggered,
            confidence_in_decision=confidence,
            recommended_team=recommended_team,
            recommended_priority=recommended_priority,
            explanation=explanation,
            risk_breakdown=risk_factors
        )
    
    def _check_confidence_trigger(
        self, context: ConversationContext
    ) -> Tuple[EscalationLevel, str, str, ApprovalPriority, Dict]:
        """Trigger if AI confidence is too low"""
        
        confidence = context.model_confidence
        
        if confidence < self.config["confidence_threshold_hold"]:
            return (
                EscalationLevel.HOLD,
                f"Very low AI confidence: {confidence:.0%}",
                "general_review_team",
                ApprovalPriority.HIGH,
                {"confidence_score": confidence, "confidence_trigger": "hold"}
            )
        
        if confidence < self.config["confidence_threshold_review"]:
            return (
                EscalationLevel.REVIEW,
                f"Low AI confidence: {confidence:.0%}",
                "general_review_team",
                ApprovalPriority.MEDIUM,
                {"confidence_score": confidence, "confidence_trigger": "review"}
            )
        
        return (EscalationLevel.NONE, "", "", ApprovalPriority.LOW, {})
    
    def _check_domain_risk_trigger(
        self, context: ConversationContext
    ) -> Tuple[EscalationLevel, str, str, ApprovalPriority, Dict]:
        """Trigger for high-risk domains (medical, legal, etc.)"""
        
        combined_text = (context.user_message + " " + context.ai_response).lower()
        
        domain_patterns = {
            "medical": [
                r'diagnos(e|is|tic)', r'treatment for', r'symptoms of',
                r'medication|medicine|drug|dose|prescription',
                r'surgery|procedure|therapy', r'cancer|diabetes|heart disease'
            ],
            "mental_health": [
                r'depressed|depression', r'anxiet(y|ies)', r'suicid(e|al)',
                r'self.harm', r'eating disorder', r'mental health crisis'
            ],
            "suicide": [
                r'kill myself', r'end my life', r'want to die',
                r'suicid(e|al)', r'not worth living'
            ],
            "legal": [
                r'is it legal', r'my legal rights', r'sue|lawsuit',
                r'criminal charge', r'contract law', r'legal advice'
            ],
            "financial": [
                r'invest(ment|ing)', r'stock(s|market)', r'crypto',
                r'tax advice', r'financial planning', r'retirement fund'
            ],
            "child_safety": [
                r'\bchild\b.{0,20}(abuse|exploit|harm)',
                r'minor.{0,20}(inappropriate|explicit)',
            ]
        }
        
        for domain, patterns in domain_patterns.items():
            for pattern in patterns:
                if re.search(pattern, combined_text, re.IGNORECASE):
                    team, priority = self.high_risk_domains.get(
                        domain, ("general_review_team", ApprovalPriority.MEDIUM)
                    )
                    
                    # Suicide is always CRITICAL + BLOCK
                    if domain == "suicide":
                        return (
                            EscalationLevel.BLOCK,
                            f"Crisis content detected: {domain}",
                            team, priority,
                            {"domain_risk": domain, "pattern": pattern}
                        )
                    
                    # Child safety is always CRITICAL + BLOCK
                    if domain == "child_safety":
                        return (
                            EscalationLevel.BLOCK,
                            f"Child safety risk: {domain}",
                            team, priority,
                            {"domain_risk": domain, "pattern": pattern}
                        )
                    
                    # Medical, legal, financial → HOLD
                    if domain in ["medical", "legal"]:
                        return (
                            EscalationLevel.HOLD,
                            f"High-risk domain detected: {domain}",
                            team, priority,
                            {"domain_risk": domain, "pattern": pattern}
                        )
                    
                    # Others → REVIEW
                    return (
                        EscalationLevel.REVIEW,
                        f"Sensitive domain: {domain}",
                        team, priority,
                        {"domain_risk": domain}
                    )
        
        return (EscalationLevel.NONE, "", "", ApprovalPriority.LOW, {})
    
    def _check_financial_trigger(
        self, context: ConversationContext
    ) -> Tuple[EscalationLevel, str, str, ApprovalPriority, Dict]:
        """Trigger for financial actions above thresholds"""
        
        amount = context.financial_amount
        if not amount:
            # Try to extract from text
            money_pattern = r'\$([0-9,]+(?:\.[0-9]{2})?)'
            matches = re.findall(money_pattern, context.ai_response)
            if matches:
                try:
                    amount = max([float(m.replace(',', '')) for m in matches])
                except:
                    amount = 0
        
        if amount:
            if amount >= self.config["financial_threshold_hold"]:
                return (
                    EscalationLevel.HOLD,
                    f"Large financial amount: ${amount:,.2f}",
                    "compliance_team",
                    ApprovalPriority.CRITICAL,
                    {"financial_amount": amount, "trigger": "financial_hold"}
                )
            
            if amount >= self.config["financial_threshold_review"]:
                return (
                    EscalationLevel.REVIEW,
                    f"Significant financial amount: ${amount:,.2f}",
                    "compliance_team",
                    ApprovalPriority.HIGH,
                    {"financial_amount": amount, "trigger": "financial_review"}
                )
        
        return (EscalationLevel.NONE, "", "", ApprovalPriority.LOW, {})
    
    def _check_vulnerability_trigger(
        self, context: ConversationContext
    ) -> Tuple[EscalationLevel, str, str, ApprovalPriority, Dict]:
        """Trigger if user may be vulnerable"""
        
        vulnerability_indicators = [
            (r'i\'m scared|i\'m afraid', "fear_detected"),
            (r'i don\'t know what to do', "uncertainty_detected"),
            (r'please help me|i need help desperately', "distress_detected"),
            (r'i\'m (very|really|extremely) (sick|ill|unwell)', "illness_detected"),
            (r'my (child|baby|infant|kid)', "child_involved"),
            (r'elderly|dementia|alzheimer', "vulnerable_adult"),
        ]
        
        combined = (context.user_message + " " + context.ai_response).lower()
        
        for pattern, indicator_type in vulnerability_indicators:
            if re.search(pattern, combined, re.IGNORECASE):
                return (
                    EscalationLevel.REVIEW,
                    f"Potential vulnerable user: {indicator_type}",
                    "trust_safety_team",
                    ApprovalPriority.HIGH,
                    {"vulnerability_indicator": indicator_type}
                )
        
        return (EscalationLevel.NONE, "", "", ApprovalPriority.LOW, {})
    
    def _check_legal_compliance_trigger(
        self, context: ConversationContext
    ) -> Tuple[EscalationLevel, str, str, ApprovalPriority, Dict]:
        """Trigger for regulatory compliance requirements"""
        
        # GDPR Article 22: Right to human review for automated decisions
        if context.action_type in [
            "loan_decision", "insurance_decision", 
            "employment_decision", "account_suspension"
        ]:
            return (
                EscalationLevel.HOLD,
                f"GDPR Article 22: Automated decision requires human review: {context.action_type}",
                "compliance_team",
                ApprovalPriority.HIGH,
                {"compliance_trigger": "GDPR_Article_22", "action": context.action_type}
            )
        
        # HIPAA: Any PHI (Protected Health Information) processing
        phi_patterns = [
            r'patient (name|id|record)',
            r'medical record number',
            r'date of birth|date of service',
            r'social security number',
        ]
        
        combined = (context.user_message + " " + context.ai_response).lower()
        for pattern in phi_patterns:
            if re.search(pattern, combined):
                return (
                    EscalationLevel.HOLD,
                    "HIPAA: PHI detected — requires human oversight",
                    "privacy_review_team",
                    ApprovalPriority.HIGH,
                    {"compliance_trigger": "HIPAA_PHI"}
                )
        
        return (EscalationLevel.NONE, "", "", ApprovalPriority.LOW, {})
    
    def _check_output_quality_trigger(
        self, context: ConversationContext
    ) -> Tuple[EscalationLevel, str, str, ApprovalPriority, Dict]:
        """Trigger if output quality indicators suggest problems"""
        
        response = context.ai_response
        flags = []
        
        # Very short response (may be refusal or error)
        if len(response.strip()) < 20:
            flags.append("suspiciously_short_response")
        
        # Very long response (may be hallucinating or padding)
        if len(response) > 10000:
            flags.append("unusually_long_response")
        
        # Response says "I don't know" type phrases
        uncertainty_phrases = [
            "i'm not sure", "i don't know", "i cannot be certain",
            "i'm unable to confirm", "i cannot verify"
        ]
        uncertainty_count = sum(
            1 for phrase in uncertainty_phrases 
            if phrase in response.lower()
        )
        if uncertainty_count >= 2:
            flags.append(f"high_uncertainty_phrases: {uncertainty_count}")
        
        # Check for hallucination signals (cites specific facts confidently)
        citation_pattern = r'according to.{0,50}(study|research|report|survey)'
        citations = re.findall(citation_pattern, response.lower())
        if len(citations) > 3:
            flags.append(f"many_unverified_citations: {len(citations)}")
        
        if flags:
            return (
                EscalationLevel.SOFT_FLAG,
                f"Output quality concerns: {', '.join(flags)}",
                "quality_review_team",
                ApprovalPriority.LOW,
                {"quality_flags": flags}
            )
        
        return (EscalationLevel.NONE, "", "", ApprovalPriority.LOW, {})
    
    def _check_behavioral_anomaly_trigger(
        self, context: ConversationContext
    ) -> Tuple[EscalationLevel, str, str, ApprovalPriority, Dict]:
        """Trigger if conversation shows anomalous patterns"""
        
        history = context.conversation_history
        
        if not history:
            return (EscalationLevel.NONE, "", "", ApprovalPriority.LOW, {})
        
        anomalies = []
        
        # Conversation is very long (potential manipulation attempt)
        if context.conversation_turn > 20:
            anomalies.append(f"long_conversation: {context.conversation_turn} turns")
        
        # User has high historical risk score
        if context.user_history_risk_score > 0.7:
            anomalies.append(f"high_risk_user_history: {context.user_history_risk_score:.0%}")
        
        # Sudden topic change to sensitive area
        if history:
            previous_topics = " ".join([
                h.get("user_message", "") 
                for h in history[-3:]
            ]).lower()
            
            current_topic = context.user_message.lower()
            
            sensitive_sudden_shifts = [
                (r'(medical|health|symptom)', "medical_topic_shift"),
                (r'(weapon|violence|harm)', "violence_topic_shift"),
                (r'(suicide|self.harm|kill)', "crisis_topic_shift"),
            ]
            
            for pattern, shift_type in sensitive_sudden_shifts:
                if re.search(pattern, current_topic) and not re.search(pattern, previous_topics):
                    anomalies.append(f"sudden_sensitive_topic_shift: {shift_type}")
        
        if anomalies:
            return (
                EscalationLevel.REVIEW,
                f"Behavioral anomaly: {', '.join(anomalies[:2])}",
                "trust_safety_team",
                ApprovalPriority.MEDIUM,
                {"behavioral_anomalies": anomalies}
            )
        
        return (EscalationLevel.NONE, "", "", ApprovalPriority.LOW, {})
    
    def _check_high_stakes_content_trigger(
        self, context: ConversationContext
    ) -> Tuple[EscalationLevel, str, str, ApprovalPriority, Dict]:
        """Trigger for content with irreversible consequences"""
        
        irreversible_actions = {
            r'delete (all|your|the) (data|account|records)':
                ("irreversible_data_deletion", EscalationLevel.HOLD),
            r'wire transfer|bank transfer|send money':
                ("financial_transfer", EscalationLevel.HOLD),
            r'permanent(ly)? (ban|block|suspend)':
                ("permanent_account_action", EscalationLevel.HOLD),
            r'publish|release|announce publicly':
                ("public_publication", EscalationLevel.REVIEW),
            r'terminate|fire|dismiss (the )?(employee|worker|staff)':
                ("employment_action", EscalationLevel.HOLD),
        }
        
        combined = (context.user_message + " " + context.ai_response).lower()
        
        for pattern, (action_type, level) in irreversible_actions.items():
            if re.search(pattern, combined, re.IGNORECASE):
                return (
                    level,
                    f"High-stakes irreversible action: {action_type}",
                    "compliance_team",
                    ApprovalPriority.HIGH,
                    {"irreversible_action": action_type}
                )
        
        return (EscalationLevel.NONE, "", "", ApprovalPriority.LOW, {})
```

# 🏛️ PILLAR 3: EDITABLE OUTPUTS

## What is Editable Output?

**Core Idea:** When a human reviews AI output, they should be able to **correct, improve, or modify** it — not just approve or reject. And every change must be tracked.

### Why This Matters Deeply:

```
WITHOUT EDITABLE OUTPUTS:
──────────────────────────
AI gives wrong medical advice → Reviewer must REJECT → User gets nothing.
AI gives 90% correct advice → Reviewer must REJECT → User gets nothing.
                              OR APPROVE knowing 10% is wrong → Dangerous!

WITH EDITABLE OUTPUTS:
──────────────────────
AI gives 90% correct advice → Reviewer EDITS the 10% → User gets 100% correct answer.
AI gives mostly good legal content → Reviewer removes one risky sentence → User gets safe content.
AI response is good but wrong tone → Reviewer adjusts tone → User gets perfect response.

RESULT: Much higher quality, much higher throughput, feedback data collected!
```

---

## Editable Output Architecture

```
┌──────────────────────────────────────────────────────────────┐
│                EDITABLE OUTPUT FLOW                           │
│                                                              │
│  AI Output Generated                                         │
│         │                                                    │
│         ▼                                                    │
│  Version 1.0 (Original AI)                                   │
│  ┌──────────────────────────────────────────────┐           │
│  │ "You have diabetes. Take metformin 500mg now" │           │
│  └──────────────────────────────────────────────┘           │
```

```python
import difflib

from typing import List, Optional, Dict
from datetime import datetime
import uuid
import json

@dataclass
class OutputVersion:
    """A single version of an AI output"""
    
    version_id: str = field(default_factory=lambda: str(uuid.uuid4()))
    version_number: float = 1.0   # 1.0 = original, 1.1 = first edit, etc.
    
    content: str = ""
    content_hash: str = ""
    
    created_at: str = field(default_factory=lambda: datetime.utcnow().isoformat())
    created_by: str = ""            # "ai" or reviewer_id
    created_by_type: str = "ai"     # "ai" or "human"
    
    change_type: str = ""           # "original", "correction", "improvement", "tone_adjustment"
    change_reason: str = ""         # Why was this change made?
    change_tags: List[str] = field(default_factory=list)
    
    diff_from_previous: Optional[str] = None  # What changed from previous version

@dataclass
class EditableOutput:
    """
    A versioned, editable AI output with full change history.
    This is the core data structure for HITL editing.
    """
    
    output_id: str = field(default_factory=lambda: str(uuid.uuid4()))
    
    # Original AI output
    original_content: str = ""
    model_used: str = ""
    model_confidence: float = 0.0
    
    # Request context

    user_id: str = ""
    session_id: str = ""

    is_finalized: bool = False
    final_version_id: Optional[str] = None

class EditableOutputManager:
    """
    Manages the creation, editing, and tracking of AI outputs.
    
    Core features:
    1. Version control for every AI output
    2. Diff tracking (what changed and why)
    3. Change categorization (for model improvement)
    4. Training feedback pipeline integration
    5. Audit trail for compliance
    """
    
    def __init__(self):
        self.outputs: Dict[str, EditableOutput] = {}
        self.feedback_queue: List[Dict] = []  # For model training
    
    def create_output(
        self,
        content: str,
        model_used: str,
        model_confidence: float,
        original_request: str,
        user_id: str,
        session_id: str
    ) -> EditableOutput:
        """Create initial AI output for review"""
        
        output = EditableOutput(
            original_content=content,
            model_used=model_used,
            model_confidence=model_confidence,
            original_request=original_request,
            user_id=user_id,
            session_id=session_id
        )
        
        # Create version 1.0 (original AI)
        v1 = OutputVersion(
            version_number=1.0,
            content=content,
            content_hash=hashlib.sha256(content.encode()).hexdigest(),
            created_by="ai",
            created_by_type="ai",
            change_type="original",
            change_reason="Initial AI generation"
        )
        output.versions.append(v1)
        
        self.outputs[output.output_id] = output
        return output
    
    def create_edit(
        self,
        output_id: str,
        new_content: str,
        reviewer_id: str,
        reviewer_name: str,
        change_type: str,
        change_reason: str,
        change_tags: List[str] = None
    ) -> OutputVersion:
        """
        Reviewer edits the AI output.
        Creates a new version with diff tracking.
        """
        
        output = self.outputs.get(output_id)
        if not output:
            raise ValueError(f"Output {output_id} not found")
        
        if output.is_finalized:
            raise ValueError("Output is already finalized — cannot edit")
        
        # Get previous version
        previous_version = output.versions[-1]
        
        # Calculate diff
        diff = self._calculate_diff(previous_version.content, new_content)
        
        # Calculate character changes
        chars_changed = sum(
            len(line) for op, line in 
            [(op, line) for op, line in 
             [(op, l) for op, lines in 
              [(op, lines) for op, lines in self._get_diff_operations(
                  previous_version.content, new_content
              )] for l in lines]
             if op in ['+', '-']]
        )
        
        # Create new version
        new_version_number = round(previous_version.version_number + 0.1, 1)
        
        new_version = OutputVersion(
            version_number=new_version_number,
            content=new_content,
            content_hash=hashlib.sha256(new_content.encode()).hexdigest(),
            created_by=reviewer_id,
            created_by_type="human",
            change_type=change_type,
            change_reason=change_reason,
            change_tags=change_tags or [],
            diff_from_previous=diff
        )
        
        output.versions.append(new_version)
        output.edit_count += 1
        output.total_chars_changed += chars_changed
        
        if change_type not in output.categories_of_issues:
            output.categories_of_issues.append(change_type)
        
        # Queue for training feedback
        self._queue_training_feedback(output, previous_version, new_version, reviewer_id)
        
        print(f"""
✏️  EDIT CREATED — Version {new_version_number}
    Editor: {reviewer_name}
    Type: {change_type}
    Reason: {change_reason}
    Characters changed: ~{chars_changed}
        """)
        
        return new_version
    
    def finalize_output(self, output_id: str, version_id: str = None) -> str:
        """
        Mark output as final — ready to send to user.
        Returns the final content.
        """
        
        output = self.outputs.get(output_id)
        if not output:
            raise ValueError(f"Output {output_id} not found")
        
        # Use specified version or latest
        if version_id:
            target_version = next(
                (v for v in output.versions if v.version_id == version_id), 
                None
            )
        else:
            target_version = output.versions[-1]
        
        if not target_version:
            raise ValueError("Version not found")
        
        output.is_finalized = True
        output.final_version_id = target_version.version_id
        
        was_modified = len(output.versions) > 1
        
        print(f"""
✅ OUTPUT FINALIZED
   Output ID: {output_id[:8]}
   Total versions: {len(output.versions)}
   Was modified: {was_modified}
   Edit count: {output.edit_count}
   Issue categories: {output.categories_of_issues}
        """)
        
        return target_version.content
    
    def _calculate_diff(self, old_text: str, new_text: str) -> str:
        """Generate a human-readable diff"""
        
        old_lines = old_text.splitlines()
        new_lines = new_text.splitlines()
        
        diff = difflib.unified_diff(
            old_lines, new_lines,
            fromfile="AI Original",
            tofile="Human Edited",
            lineterm=""
        )
        
        return "\n".join(list(diff))
    
    def _get_diff_operations(self, old_text: str, new_text: str):
        """Get diff operations for character counting"""
        matcher = difflib.SequenceMatcher(None, old_text, new_text)
        operations = []
        for opcode in matcher.get_opcodes():
            tag, i1, i2, j1, j2 = opcode
            if tag == 'delete':
                operations.append(('-', [old_text[i1:i2]]))
            elif tag == 'insert':
                operations.append(('+', [new_text[j1:j2]]))
            elif tag == 'replace':
                operations.append(('-', [old_text[i1:i2]]))
                operations.append(('+', [new_text[j1:j2]]))
        return operations
    
    def _queue_training_feedback(
        self,
        output: EditableOutput,
        original_version: OutputVersion,
        edited_version: OutputVersion,
        reviewer_id: str
    ):
        """
        Queue this edit as training feedback.
        Human corrections = gold-standard training data!
        
        This is how HITL improves the model over time.
        """
        
        feedback = {
            "feedback_id": str(uuid.uuid4()),
            "timestamp": datetime.utcnow().isoformat(),
            
            # Training pair
            "input": output.original_request,
            "original_ai_output": original_version.content,
            "human_corrected_output": edited_version.content,
            
            # Metadata for training
            "model_used": output.model_used,
            "model_confidence": output.model_confidence,
            "change_type": edited_version.change_type,
            "change_reason": edited_version.change_reason,
            "change_tags": edited_version.change_tags,
            "reviewer_id": reviewer_id,
            
            # Quality signal
            "is_correction": edited_version.change_type in [
                "factual_correction", "safety_correction", "compliance_correction"
            ],
            "is_improvement": edited_version.change_type in [
                "tone_improvement", "clarity_improvement", "completeness_improvement"
            ],
            
            # Diff
            "diff": edited_version.diff_from_previous
        }
        
        self.feedback_queue.append(feedback)
        print(f"🔄 Training feedback queued: {feedback['change_type']}")
    
    def get_version_history(self, output_id: str) -> List[Dict]:
        """Get full version history for an output"""
        
        output = self.outputs.get(output_id)
        if not output:
            return []
        
        history = []
        for version in output.versions:
            history.append({
                "version_number": version.version_number,
                "created_by_type": version.created_by_type,
                "created_by": version.created_by,
                "change_type": version.change_type,
                "change_reason": version.change_reason,
                "created_at": version.created_at,
                "content_preview": version.content[:100] + "..." if len(version.content) > 100 else version.content,
                "has_diff": version.diff_from_previous is not None
            })
        
        return history
    
    def get_edit_analytics(self) -> Dict:
        """
        Analytics on human edits — used to improve the AI model.
        Shows: What types of errors does AI make most often?
        """
        
        all_edits = [
            v for output in self.outputs.values()
            for v in output.versions
            if v.created_by_type == "human"
        ]
        
        if not all_edits:
            return {"message": "No human edits yet"}
        
        # Count change types
        change_type_counts = {}
        for edit in all_edits:

                change_type_counts.get(edit.change_type, 0) + 1
        
        # Count change tags
        tag_counts = {}
        for edit in all_edits:
            for tag in edit.change_tags:
                tag_counts[tag] = tag_counts.get(tag, 0) + 1
        
        # Outputs that were modified vs approved as-is
        total_outputs = len(self.outputs)
        modified_outputs = sum(
            1 for o in self.outputs.values() if o.edit_count > 0
        )
        
        return {
            "total_outputs": total_outputs,
            "modified_outputs": modified_outputs,
            "modification_rate": modified_outputs / total_outputs if total_outputs else 0,
            "total_edits": len(all_edits),
            "avg_edits_per_modified_output": len(all_edits) / modified_outputs if modified_outputs else 0,
            "change_type_breakdown": change_type_counts,
            "common_issue_tags": sorted(tag_counts.items(), key=lambda x: -x[1])[:10],
            "training_feedback_queued": len(self.feedback_queue)
        }
```

# 🏛️ PILLAR 4: RISK-BASED ROUTING

## What is Risk-Based Routing?

**Core Idea:** Instead of treating every request the same, calculate a **risk score** and route each request to the appropriate handling path — from fully automated to full human review.

### Simple Analogy:
> Airport security screening ✈️
> 
> Known traveler (TSA PreCheck) → Fast lane → No full scan
> Regular traveler → Standard screening → X-ray
> Flagged by system → Enhanced screening → Manual pat-down + supervisor
> On no-fly list → BLOCK → Law enforcement
>
> Your AI system needs the same tiered routing.

---

## Risk Scoring Framework

```python
# ══════════════════════════════════════════════════════════
# RISK-BASED ROUTING SYSTEM
# Calculate composite risk score → Route appropriately
# ══════════════════════════════════════════════════════════

from dataclasses import dataclass, field
from typing import Dict, List, Tuple, Optional
from enum import Enum
import math

class RoutingDecision(Enum):
    AUTO_APPROVE   = "auto_approve"    # Risk low → send immediately
    SOFT_REVIEW    = "soft_review"     # Flag for optional async review
    ASYNC_REVIEW   = "async_review"    # Queue for review, send provisional response
    SYNC_HOLD      = "sync_hold"       # Hold until reviewed (user waits)
    BLOCK          = "block"           # Don't send, reject request

@dataclass
class RiskFactor:
    """A single risk factor with its score and weight"""
    name: str
    score: float       # 0.0 = no risk, 1.0 = maximum risk
    weight: float      # How much this factor matters
    explanation: str
    
    @property
    def weighted_score(self) -> float:
        return self.score * self.weight

@dataclass
class RiskAssessment:
    """Complete risk assessment for a request"""
    
    factors: List[RiskFactor] = field(default_factory=list)
    overall_score: float = 0.0
    routing_decision: RoutingDecision = RoutingDecision.AUTO_APPROVE
    explanation: str = ""
    recommended_team: str = ""
    recommended_priority: ApprovalPriority = ApprovalPriority.LOW
    
    def add_factor(self, factor: RiskFactor):
        self.factors.append(factor)
        self._recalculate()
    
    def _recalculate(self):
        """Recalculate overall risk as weighted average"""
        if not self.factors:
            self.overall_score = 0.0
            return
        
        total_weight = sum(f.weight for f in self.factors)
        weighted_sum = sum(f.weighted_score for f in self.factors)
        self.overall_score = min(1.0, weighted_sum / total_weight if total_weight > 0 else 0.0)

class RiskBasedRouter:
    """
    Calculates risk score from multiple factors and 
    routes requests to appropriate handling path.
    
    Risk Factors:
    1. Content risk (what is being said)
    2. User risk (who is saying it)
    3. Action risk (what will happen as a result)
    4. Context risk (surrounding circumstances)
    5. Model risk (AI uncertainty)
    """
    
    # Routing thresholds
    THRESHOLDS = {
        RoutingDecision.AUTO_APPROVE:  (0.00, 0.25),   # Risk 0-25% → Auto
        RoutingDecision.SOFT_REVIEW:   (0.25, 0.45),   # Risk 25-45% → Soft flag
        RoutingDecision.ASYNC_REVIEW:  (0.45, 0.65),   # Risk 45-65% → Async queue
        RoutingDecision.SYNC_HOLD:     (0.65, 0.85),   # Risk 65-85% → Hold
        RoutingDecision.BLOCK:         (0.85, 1.00),   # Risk 85-100% → Block
    }
    
    def assess_risk(
        self,
        content: str,
        user_context: Dict,
        action_type: str,
        model_confidence: float,
        escalation_result: EscalationResult = None
    ) -> RiskAssessment:
        """
        Calculate comprehensive risk assessment.
        Combines multiple risk dimensions into single score.
        """
        
        assessment = RiskAssessment()
        
        # ── FACTOR 1: Content Risk (Weight: 0.30) ──
        content_risk = self._score_content_risk(content)
        assessment.add_factor(RiskFactor(
            name="content_risk",
            score=content_risk["score"],
            weight=0.30,
            explanation=content_risk["reason"]
        ))
        
        # ── FACTOR 2: User Risk (Weight: 0.20) ──
        user_risk = self._score_user_risk(user_context)
        assessment.add_factor(RiskFactor(
            name="user_risk",
            score=user_risk["score"],
            weight=0.20,
            explanation=user_risk["reason"]
        ))
        
        # ── FACTOR 3: Action Risk (Weight: 0.25) ──
        action_risk = self._score_action_risk(action_type)
        assessment.add_factor(RiskFactor(
            name="action_risk",
            score=action_risk["score"],
            weight=0.25,
            explanation=action_risk["reason"]
        ))
        
        # ── FACTOR 4: Model Confidence Risk (Weight: 0.15) ──
        # Low confidence = high risk
        confidence_risk = 1.0 - model_confidence
        assessment.add_factor(RiskFactor(
            name="model_confidence_risk",
            score=confidence_risk,
            weight=0.15,
            explanation=f"Model confidence: {model_confidence:.0%} (risk: {confidence_risk:.0%})"
        ))
        
        # ── FACTOR 5: Escalation Trigger Risk (Weight: 0.10) ──
        if escalation_result:
            escalation_risk = escalation_result.escalation_level.value / 4.0  # Normalize 0-4 → 0-1
            assessment.add_factor(RiskFactor(
                name="escalation_trigger_risk",
                score=escalation_risk,
                weight=0.10,
                explanation=f"Escalation triggers: {len(escalation_result.triggered_by)}"
            ))
        
        # Determine routing decision
        assessment.routing_decision = self._determine_routing(assessment.overall_score)
        
        # Determine recommended team and priority
        assessment.recommended_team, assessment.recommended_priority = \
            self._determine_team_and_priority(assessment)
        
        # Build explanation
        top_factors = sorted(
            assessment.factors, 
            key=lambda f: f.weighted_score, 
            reverse=True
        )[:3]
        
        assessment.explanation = (
            f"Overall risk: {assessment.overall_score:.0%} → {assessment.routing_decision.value}. "
            f"Top factors: " + 
            "; ".join([f"{f.name}={f.score:.0%}" for f in top_factors])
        )
        
        return assessment
    
    def _score_content_risk(self, content: str) -> Dict:
        """Score risk based on content"""
        
        content_lower = content.lower()
        score = 0.0
        reasons = []
        
        risk_patterns = {
            # Very high risk
            r'suicide|self.harm|kill myself': (0.95, "crisis content"),
            r'bioweapon|chemical weapon': (0.99, "weapons of mass destruction"),
            r'child.{0,20}(abuse|exploit)': (0.99, "child safety"),
            
            # High risk
            r'diagnos(e|is)|medical treatment': (0.75, "medical advice"),
            r'legal advice|you should sue': (0.70, "legal advice"),
            r'invest(ment|ing) advice': (0.65, "financial advice"),
            r'wire transfer|send money': (0.70, "financial action"),
            
            # Medium risk
            r'personal (data|information)': (0.40, "personal data"),
            r'credit card|bank account': (0.50, "financial data"),
            r'password|login credentials': (0.55, "authentication data"),
            
            # Lower risk
            r'opinion|i think|maybe': (0.10, "opinion content"),
        }
        
        for pattern, (risk_score, reason) in risk_patterns.items():
            if re.search(pattern, content_lower, re.IGNORECASE):
                if risk_score > score:
                    score = risk_score
                    reasons.append(reason)
        
        return {"score": min(1.0, score), "reason": ", ".join(reasons) or "no high-risk content"}
    
    def _score_user_risk(self, user_context: Dict) -> Dict:
        """Score risk based on user characteristics"""
        
        score = 0.0
        reasons = []
        
        # Free tier = slightly more risk (less vetted)
        tier_risk = {"free": 0.15, "pro": 0.05, "enterprise": 0.02}
        tier = user_context.get("tier", "free")
        score += tier_risk.get(tier, 0.15)
        
        # Historical violations
        violations = user_context.get("policy_violations_count", 0)
        if violations > 5:
            score += 0.4
            reasons.append(f"repeated policy violations: {violations}")
        elif violations > 0:
            score += 0.1 * violations
            reasons.append(f"previous violations: {violations}")
        
        # New account
        account_age_days = user_context.get("account_age_days", 0)
        if account_age_days < 1:
            score += 0.2
            reasons.append("brand new account")
        elif account_age_days < 7:
            score += 0.1
            reasons.append("very new account")
        
        # Unverified
        if not user_context.get("email_verified", True):
            score += 0.15
            reasons.append("unverified email")
        
        return {"score": min(1.0, score), "reason": ", ".join(reasons) or "low-risk user"}
    
    def _score_action_risk(self, action_type: str) -> Dict:
        """Score risk based on what action this enables"""
        
        action_risks = {
            # Extremely high
            "military_decision":      (0.99, "military action"),
            "medical_prescription":   (0.95, "medical prescription"),
            "legal_filing":           (0.90, "legal action"),
            
            # Very high
            "financial_transfer":     (0.85, "financial transfer"),
            "account_termination":    (0.80, "account termination"),
            "data_deletion":          (0.80, "irreversible data deletion"),
            
            # High
            "loan_decision":          (0.75, "credit decision"),
            "employment_action":      (0.75, "employment decision"),
            "content_publication":    (0.65, "public content"),
            
            # Medium
            "account_modification":   (0.45, "account change"),
            "subscription_change":    (0.35, "subscription"),
            
            # Low
            "information_lookup":     (0.10, "information only"),
            "chat":                   (0.15, "general chat"),
            "recommendation":         (0.20, "recommendation"),
        }
        
        risk_score, reason = action_risks.get(action_type, (0.20, "unknown action type"))
        return {"score": risk_score, "reason": reason}
    
    def _determine_routing(self, risk_score: float) -> RoutingDecision:
        """Determine routing decision based on risk score"""
        
        for decision, (low, high) in self.THRESHOLDS.items():
            if low <= risk_score < high:
                return decision
        
        return RoutingDecision.BLOCK  # Default to block if uncertain
    
    def _determine_team_and_priority(
        self, 
        assessment: RiskAssessment
    ) -> Tuple[str, ApprovalPriority]:
        """Determine which team should review and at what priority"""
        
        # Find highest-risk factor
        highest_factor = max(assessment.factors, key=lambda f: f.weighted_score)
        
        routing_map = {
            "content_risk":         "content_review_team",
            "user_risk":            "trust_safety_team",
            "action_risk":          "compliance_team",
            "escalation_trigger_risk": "senior_review_team",
        }
        
        team = routing_map.get(highest_factor.name, "general_review_team")
        
        # Priority based on overall score
        if assessment.overall_score >= 0.85:
            priority = ApprovalPriority.CRITICAL
        elif assessment.overall_score >= 0.65:
            priority = ApprovalPriority.HIGH
        elif assessment.overall_score >= 0.45:
            priority = ApprovalPriority.MEDIUM
        else:
            priority = ApprovalPriority.LOW
        
        return team, priority
```

# 🔧 TOOLS DEEP DIVE

## Tool 1: Temporal — Workflow Engine

### What is Temporal?

**Temporal** is a workflow orchestration engine that makes long-running, stateful workflows reliable and fault-tolerant.

### Why It's Perfect for HITL:

```
PROBLEM WITHOUT TEMPORAL:
──────────────────────────
1. AI generates response
2. Create approval request
3. Wait for human (hours/days)
4. Server restarts... 💥
5. State lost!
6. No one knows what was pending.
7. Users never get response.

WITH TEMPORAL:
──────────────
1. AI generates response
2. Start Temporal workflow
3. Workflow durably waits for human (hours/days)
4. Server restarts... ✅
5. Temporal resumes exactly where it left off!
6. Human reviews, approves
7. Workflow continues automatically
8. User gets response
```

```python
@workflow.defn
class HITLApprovalWorkflow:
    """
    Temporal workflow for HITL approval.
    
    This workflow is:
    - DURABLE: survives server restarts
    - STATEFUL: remembers where it is
    - FAULT-TOLERANT: retries failed activities
    - LONG-RUNNING: can wait days for human input
    """
    
    def __init__(self):
        self._review_decision: Optional[ReviewDecision] = None
        self._is_decided = False
    
    @workflow.run
    async def run(self, input_data: HITLWorkflowInput) -> HITLWorkflowOutput:
        """
        Main workflow execution.
        This defines the entire approval process flow.
        """
        
        print(f"\n🔄 HITL WORKFLOW STARTED: {input_data.request_id[:8]}")
        
        # Step 1: Create review ticket
        ticket_id = await workflow.execute_activity(
            create_review_ticket,
            input_data,
            start_to_close_timeout=timedelta(seconds=30)
        )
        
        # Step 2: Send provisional response to user
        await workflow.execute_activity(
            send_provisional_response,
            input_data.user_id,
            "Your request is being reviewed. We'll respond shortly.",
            start_to_close_timeout=timedelta(seconds=30)
        )
        
        # Step 3: Determine SLA deadline based on priority
        sla_map = {
            "CRITICAL": timedelta(minutes=15),
            "HIGH":     timedelta(hours=1),
            "MEDIUM":   timedelta(hours=4),
            "LOW":      timedelta(hours=24),
        }
        sla = sla_map.get(input_data.priority, timedelta(hours=4))
        
        # Step 4: Wait for human decision with SLA enforcement
        print(f"⏳ Waiting for human review (SLA: {sla})...")
        
        # Wait for signal OR timeout
        try:
            await workflow.wait_condition(
                lambda: self._is_decided,
                timeout=sla
            )
            
            # Human made a decision before SLA
            decision = self._review_decision
            print(f"✅ Decision received: {decision.decision.value}")
            
        except asyncio.TimeoutError:
            # SLA expired without decision!
            print(f"⏰ SLA EXPIRED for {input_data.priority} review")
            
            # Escalate to senior team
            await workflow.execute_activity(
                escalate_review,
                ticket_id,
                f"SLA expired for {input_data.priority} priority review",
                start_to_close_timeout=timedelta(seconds=30)
            )
            
            # Wait again with extended deadline for senior review
            try:
                await workflow.wait_condition(
                    lambda: self._is_decided,
                    timeout=timedelta(hours=2)
                )
                decision = self._review_decision
                
            except asyncio.TimeoutError:
                # Even senior review timed out — auto-reject
                decision = ReviewDecision(
                    reviewer_id="system",
                    reviewer_name="Automated System",
                    decision=ApprovalStatus.REJECTED,
                    notes="Auto-rejected due to SLA expiry without review",
                )
        
        # Step 5: Process decision
        final_content = None
        was_modified = False
        
        if decision.decision == ApprovalStatus.APPROVED:
            final_content = input_data.ai_output  # Use original AI output
        
        elif decision.decision == ApprovalStatus.MODIFIED:
            final_content = decision.modified_output  # Use human-edited output
            was_modified = True
        
        elif decision.decision == ApprovalStatus.REJECTED:
            final_content = "I'm sorry, I'm not able to help with that request."
        
        # Step 6: Send final response
        await workflow.execute_activity(
            send_final_response,
            input_data.user_id,
            final_content or "Request could not be processed.",
            decision.decision.value,
            start_to_close_timeout=timedelta(seconds=30)
        )
        
        # Step 7: Log outcome
        outcome = HITLWorkflowOutput(
            final_content=final_content or "",
            status=decision.decision.value,
            reviewed_by=decision.reviewer_id,
            review_notes=decision.notes,
            was_modified=was_modified
        )
        
        await workflow.execute_activity(
            log_workflow_outcome,
            input_data.request_id,
            outcome,
            start_to_close_timeout=timedelta(seconds=30)
        )
        
        print(f"✅ WORKFLOW COMPLETE: {input_data.request_id[:8]} — {outcome.status}")
        return outcome
    
    @workflow.signal
    async def submit_review_decision(self, decision: ReviewDecision):
        """
        SIGNAL: Reviewer submits their decision.
        This is how the review dashboard communicates with the workflow.
        """
        self._review_decision = decision
        self._is_decided = True
        print(f"📨 Review decision received via signal: {decision.decision.value}")
```

```python
    elif review_status == "rejected":
        final_response = "I'm unable to help with that request."
        
    else:
        final_response = "Request could not be processed."
    
    return {
        "final_response": final_response,
        "is_complete": True,
        "messages": [{"role": "system", "content": f"Review complete: {review_status}"}]
    }

def send_final_response_node(state: HITLState) -> dict:
    """Node: Send final response to user"""
    print(f"📤 Sending final response to user {state['user_id']}")
    print(f"   Content: {state['final_response'][:50]}...")
    return {}

# ── ROUTING FUNCTIONS ──

def route_based_on_risk(state: HITLState) -> str:
    """Conditional routing based on risk score"""
    
    routing = state.get("routing_decision", "block")
    
    routing_map = {
        "auto_approve": "auto_approve",
        "soft_review": "auto_approve",      # Still auto for soft review
        "async_review": "request_human_review",
        "sync_hold": "request_human_review",
        "block": "auto_approve",  # Show rejection immediately
    }
    
    next_node = routing_map.get(routing, "request_human_review")
    print(f"   → Routing to: {next_node}")
    return next_node

def check_review_complete(state: HITLState) -> str:
    """Route based on review status"""
    
    review_status = state.get("review_status", "pending")
    
    if review_status == "pending":
        return "wait_for_human_review"  # Keep waiting
    else:
        return "process_human_decision"  # Process the decision

def check_is_complete(state: HITLState) -> str:
    """Check if workflow is complete"""
    if state.get("is_complete", False):
        return "send_final_response"
    return "assess_risk"  # Loop back (shouldn't happen in practice)

# ── BUILD THE GRAPH ──

def build_hitl_graph():
    """Build the LangGraph HITL state machine"""
    
    # Create graph
    graph = StateGraph(HITLState)
    
    # Add nodes
    graph.add_node("generate_ai_response", generate_ai_response)
    graph.add_node("assess_risk", assess_risk)
    graph.add_node("auto_approve", auto_approve)
    graph.add_node("request_human_review", request_human_review)
    graph.add_node("wait_for_human_review", wait_for_human_review)
    graph.add_node("process_human_decision", process_human_decision)
    graph.add_node("send_final_response", send_final_response_node)
    
    # Entry point
    graph.set_entry_point("generate_ai_response")
    
    # Edges (flow)
    graph.add_edge("generate_ai_response", "assess_risk")
    
    # Conditional routing based on risk
    graph.add_conditional_edges(
        "assess_risk",
        route_based_on_risk,
        {
            "auto_approve": "auto_approve",
            "request_human_review": "request_human_review"
        }
    )
    
    graph.add_edge("auto_approve", "send_final_response")
    graph.add_edge("request_human_review", "wait_for_human_review")
    
    # This is the HITL interrupt point
    # Graph pauses here until human provides input
    graph.add_conditional_edges(
        "wait_for_human_review",
        check_review_complete,
        {
            "wait_for_human_review": "wait_for_human_review",
            "process_human_decision": "process_human_decision"
        }
    )
    
    graph.add_edge("process_human_decision", "send_final_response")
    graph.add_edge("send_final_response", END)
    
    # Use memory saver for state persistence
    memory = MemorySaver()
    return graph.compile(
        checkpointer=memory,
        interrupt_before=["wait_for_human_review"]  # Pause here for human input
    )
```

```python
# ══════════════════════════════════════════════════════════
# FEEDBACK PIPELINE
# Turn human corrections into model improvements
# ══════════════════════════════════════════════════════════

from dataclasses import dataclass, field
from typing import List, Dict, Optional
import json
import csv
from datetime import datetime

@dataclass
class TrainingExample:
    """
    A single training example from human feedback.
    Format: (input, bad_ai_output, good_human_output)
    Used for: Fine-tuning, RLHF, DPO training
    """
    
    example_id: str
    
    # The training signal
    input_prompt: str           # What the user asked
    ai_output: str              # What AI generated (potentially wrong)
    human_output: str           # What human corrected it to (the ground truth)
    
    # Context
    model_that_generated: str   # Which model was used
    correction_type: str        # factual, safety, tone, completeness
    correction_tags: List[str]
    
    # Quality metadata
    reviewer_expertise: str     # "medical", "legal", "general"
    confidence_in_correction: float  # Reviewer's confidence 0-1
    
    # Training flags
    use_for_finetuning: bool = True
    use_for_rlhf: bool = True    # Reward model training
    use_for_dpo: bool = True      # Direct Preference Optimization
    
    created_at: str = field(default_factory=lambda: datetime.utcnow().isoformat())

class FeedbackPipeline:
    """
    Collects human corrections and converts them
    into training data for model improvement.
    
    This closes the HITL feedback loop:
    Human corrections → Training data → Better model → Fewer human corrections
    """
    
    def __init__(self, storage_path: str = "feedback_data"):
        self.storage_path = storage_path
        self.examples: List[TrainingExample] = []
        self.pending_export: List[TrainingExample] = []
    
    def collect_correction(
        self,
        input_prompt: str,
        ai_output: str,
        human_output: str,
        model_used: str,
        correction_type: str,
        correction_tags: List[str],
        reviewer_id: str,
        reviewer_expertise: str = "general",
        confidence: float = 1.0
    ) -> TrainingExample:
        """
        Collect a human correction as a training example.
        Called automatically when reviewer modifies AI output.
        """
        
        # Only create training example if there's a meaningful difference
        if ai_output.strip() == human_output.strip():
            print("⚠️ No difference between AI and human output — skipping")
            return None
        
        # Determine training usage based on correction type
        is_safety_correction = correction_type in [
            "safety_correction", "compliance_correction", "harmful_content_removed"
        ]
        
        example = TrainingExample(
            example_id=str(uuid.uuid4()),
            input_prompt=input_prompt,
            ai_output=ai_output,
            human_output=human_output,
            model_that_generated=model_used,
            correction_type=correction_type,
            correction_tags=correction_tags,
            reviewer_expertise=reviewer_expertise,
            confidence_in_correction=confidence,
            # Safety corrections are highest priority for training
            use_for_finetuning=True,
            use_for_rlhf=True,
            use_for_dpo=True
        )
        
        self.examples.append(example)
        self.pending_export.append(example)
        
        print(f"✅ Training example collected: {correction_type}")
        print(f"   AI output length: {len(ai_output)} chars")
        print(f"   Human output length: {len(human_output)} chars")
        
        return example
    
    def export_for_finetuning(self, format: str = "jsonl") -> str:
        """
        Export training examples in format suitable for fine-tuning.
        
        Formats:
        - jsonl: OpenAI fine-tuning format
        - csv: General purpose
        - preference_pairs: For DPO/RLHF training
        """
        
        examples = [e for e in self.examples if e.use_for_finetuning]
        
        if not examples:
            return "No examples to export"
        
        if format == "jsonl":
            return self._export_openai_jsonl(examples)
        elif format == "preference_pairs":
            return self._export_preference_pairs(examples)
        elif format == "csv":
            return self._export_csv(examples)
        else:
            raise ValueError(f"Unknown format: {format}")
    
    def _export_openai_jsonl(self, examples: List[TrainingExample]) -> str:
        """
        Export in OpenAI fine-tuning format (JSONL).
        
        Format:
        {"messages": [
            {"role": "system", "content": "..."},
            {"role": "user", "content": "input"},
            {"role": "assistant", "content": "human_corrected_output"}
        ]}
        """
        
        lines = []
        for example in examples:
            record = {
                "messages": [
                    {
                        "role": "system",
                        "content": "You are a helpful, accurate, and safe AI assistant."
                    },
                    {
                        "role": "user",
                        "content": example.input_prompt
                    },
                    {
                        "role": "assistant",
                        "content": example.human_output  # Ground truth = human output!
                    }
                ],
                "metadata": {
                    "correction_type": example.correction_type,
                    "tags": example.correction_tags,
                    "reviewer_expertise": example.reviewer_expertise,
                    "confidence": example.confidence_in_correction
                }
            }
            lines.append(json.dumps(record))
        
        output = "\n".join(lines)
        
        # Save to file
        filename = f"finetuning_data_{datetime.utcnow().strftime('%Y%m%d_%H%M%S')}.jsonl"
        with open(filename, 'w') as f:
            f.write(output)
        
        print(f"✅ Exported {len(examples)} examples to {filename}")
        return filename
    
    def _export_preference_pairs(self, examples: List[TrainingExample]) -> str:
        """
        Export as preference pairs for RLHF/DPO training.
        
        Format:
        {
            "prompt": "user input",
            "chosen": "human corrected output",  # The GOOD response
            "rejected": "ai original output"      # The BAD response
        }
        """
        
        lines = []
        for example in examples:
            if example.use_for_dpo:
                record = {
                    "prompt": example.input_prompt,
                    "chosen": example.human_output,    # Human = better
                    "rejected": example.ai_output,      # AI = worse
                    "correction_type": example.correction_type,
                    "confidence": example.confidence_in_correction
                }
                lines.append(json.dumps(record))
        
        output = "\n".join(lines)
        
        filename = f"preference_pairs_{datetime.utcnow().strftime('%Y%m%d_%H%M%S')}.jsonl"
        with open(filename, 'w') as f:
            f.write(output)
        
        print(f"✅ Exported {len(lines)} preference pairs to {filename}")
        return filename
    
    def _export_csv(self, examples: List[TrainingExample]) -> str:
        """Export as CSV for analysis"""
        
        filename = f"feedback_data_{datetime.utcnow().strftime('%Y%m%d_%H%M%S')}.csv"
        
        with open(filename, 'w', newline='') as f:
            writer = csv.writer(f)
            writer.writerow([
                "example_id", "correction_type", "input_prompt",
                "ai_output", "human_output", "reviewer_expertise",
                "confidence", "created_at"
            ])
            
            for e in examples:
                writer.writerow([
                    e.example_id, e.correction_type,
                    e.input_prompt[:200],  # Truncate for CSV
                    e.ai_output[:200],
                    e.human_output[:200],
                    e.reviewer_expertise,
                    e.confidence_in_correction,
                    e.created_at
                ])
        
        print(f"✅ Exported {len(examples)} examples to {filename}")
        return filename
    
    def get_improvement_insights(self) -> Dict:
        """
        Analyze feedback to understand where AI needs improvement.
        
        Answers:
        - What types of corrections are most common?
        - Which topics generate most errors?
        - Is the model improving over time?
        """
        
        if not self.examples:
            return {"message": "No feedback data yet"}
        
        # Correction type breakdown
        type_counts = {}
        for example in self.examples:
            t = example.correction_type
            type_counts[t] = type_counts.get(t, 0) + 1
        
        # Tag frequency
        tag_counts = {}
        for example in self.examples:
            for tag in example.correction_tags:
                tag_counts[tag] = tag_counts.get(tag, 0) + 1
        
        # High-confidence corrections (most reliable for training)
        high_confidence = [
            e for e in self.examples 
            if e.confidence_in_correction >= 0.9
        ]
        
        # Safety-critical corrections (highest priority)
        safety_corrections = [
            e for e in self.examples
            if "safety" in e.correction_type or "harmful" in e.correction_type
        ]
        
        return {
            "total_examples": len(self.examples),
            "high_confidence_examples": len(high_confidence),
            "safety_critical_examples": len(safety_corrections),
            "correction_type_breakdown": sorted(
                type_counts.items(), key=lambda x: -x[1]
            ),
            "most_common_issue_tags": sorted(
                tag_counts.items(), key=lambda x: -x[1]
            )[:10],
            "recommendation": self._generate_recommendation(type_counts)
        }
    
    def _generate_recommendation(self, type_counts: Dict) -> str:
        """Generate actionable recommendation for model improvement"""
        
        if not type_counts:
            return "Insufficient data for recommendations"
        
        top_issue = max(type_counts.items(), key=lambda x: x[1])
        issue_type, count = top_issue
        
        recommendations = {
            "safety_correction": f"🚨 {count} safety corrections — consider updating system prompt with stronger safety rules",
            "factual_correction": f"📚 {count} factual errors — consider RAG to ground responses in verified data",
            "tone_improvement": f"🎯 {count} tone issues — consider updating prompt for tone guidelines",
            "completeness_improvement": f"📝 {count} completeness issues — consider increasing max_output_tokens",
            "compliance_correction": f"⚖️ {count} compliance issues — add compliance rules to system prompt",
        }
        
        return recommendations.get(
            issue_type,
            f"Top issue: {issue_type} ({count} occurrences) — investigate patterns in training data"
        )


# ──────────────────────────────────────
```

# 🎤 INTERVIEW QUESTIONS & STRONG ANSWERS

---

### ❓ Q1: "What is Human-in-the-Loop and when would you use it?"

**💪 Strong Answer:**

> "Human-in-the-Loop is an architectural pattern where human judgment is integrated into an AI system's decision-making process at specific points, rather than letting the AI decide everything autonomously.
>
> I think of it as a spectrum — from fully automated to fully manual — and the right position on that spectrum depends on: the stakes of a wrong decision, the regulatory requirements, the frequency of decisions, and the AI system's accuracy.
>
> I'd use HITL for high-stakes domains like medical advice, legal determinations, and large financial actions where wrong decisions have serious consequences. I'd use light-touch review or sampling for medium-risk content. I'd use full automation for low-risk, high-frequency decisions like spam filtering or product recommendations.
>
> Practically, HITL consists of four components: approval workflows that pause AI actions for human sign-off; escalation triggers that automatically route risky situations to humans; editable outputs that let reviewers correct rather than just approve/reject; and risk-based routing that intelligently decides which path each request takes."

---

### ❓ Q2: "How would you design an escalation trigger system?"

**💪 Strong Answer:**

> "Escalation triggers are automated rules that detect when an AI's output needs human review. I'd design a multi-type trigger system covering five areas:
>
> Confidence-based triggers: When model confidence falls below a threshold, say 60%, route to review since low confidence correlates with errors.
>
> Domain-risk triggers: Automatically escalate for medical, legal, financial, or mental health content since these domains have serious consequences and often regulatory requirements.
>
> Financial thresholds: Escalate when financial amounts exceed configured limits — say $1,000 for review, $10,000 for hold.
>
> Behavioral anomaly triggers: Flag unusual patterns like very long conversations, sudden topic shifts to sensitive areas, or users with history of violations.
>
> Compliance triggers: Some decisions legally require human review — GDPR Article 22 mandates human oversight for automated decisions affecting individuals' legal status.
>
> The engine would combine these into a single escalation decision with a priority level, and route to the appropriate specialized team — medical questions to medical reviewers, not general reviewers."

---

### ❓ Q3: "Explain the concept of editable AI outputs and why they matter."

**💪 Strong Answer:**

> "Editable outputs mean that when a human reviews AI output, they can modify it rather than just approve or reject it as-is. This is crucial for three reasons.
>
> First, practicality: if an AI response is 90% correct but 10% problematic, binary approve/reject forces you to reject everything and give the user nothing, or approve something with known issues. Editable outputs let the reviewer fix just the 10%.
>
> Second, quality: human-corrected outputs are typically better than pure AI outputs, combining AI's speed and breadth with human judgment.
>
> Third, model improvement: every edit is a training signal. The original AI output is the 'rejected' response; the human correction is the 'chosen' response. These become preference pairs for RLHF or DPO training, directly improving the model over time.
>
> The key engineering requirements are: diff tracking to see exactly what changed, audit trails for compliance, version control for accountability, and a feedback pipeline to convert corrections into training data automatically."

---

### ❓ Q4: "What is Temporal and why would you use it for HITL workflows?"

**💪 Strong Answer:**

> "Temporal is a durable workflow orchestration engine. It addresses the fundamental challenge of HITL workflows: they need to pause execution for hours or days waiting for human input, and this must be reliable across server restarts, failures, and scaling events.
>
> Without Temporal, you'd need to manually persist workflow state to a database, implement retry logic, handle timeout escalations, and resume workflows after failures — all extremely complex to build correctly.
>
> With Temporal, you define the workflow as code with await statements where human input is needed. Temporal automatically persists state, handles retries of failed activities, and resumes workflows exactly where they left off after any failure.
>
> For HITL specifically, the flow is: AI generates response → Temporal workflow starts → sends notification to reviewer → waits durably for a signal (the reviewer's decision) → processes decision → sends response to user. The workflow might wait 24 hours for a reviewer, and if servers restart in that time, Temporal resumes seamlessly."

---

### ❓ Q5: "How do you prevent reviewer fatigue in a HITL system?"

**💪 Strong Answer:**

> "Reviewer fatigue is when reviewers face so many items that they start approving without careful reading — which defeats the entire purpose of HITL.
>
> Prevention has multiple dimensions. First, smart routing: calibrate risk thresholds so only genuinely risky items reach human review. Too many false positives waste reviewer time and cause fatigue. Use the edit analytics to see if reviewers are finding issues — if modification rate drops to near zero, thresholds may be too loose or reviewers aren't reading.
>
> Second, prioritization: show reviewers the highest-risk, shortest-SLA items first. If they only have time for 10 reviews, those 10 should be the most critical.
>
> Third, tooling: make review fast. Good UI with clear diff highlighting, one-click approvals for obvious cases, keyboard shortcuts, and sensible defaults reduce cognitive load.
>
> Fourth, monitoring: track time-to-review trends. If average review time suddenly drops, reviewers may be rubber-stamping. Random quality audits where you review what reviewers approved can catch this.
>
> Fifth, sampling strategies: for lower-risk tiers, auto-approve but sample 10% for review. This maintains quality signal without reviewing everything."

# 🔨 COMMON BEGINNER MISTAKES

```
❌ MISTAKE 1: Binary approve/reject only (no modify option)
→ Reviewers reject 90%-correct content → users get nothing
→ Or approve 10%-wrong content → users get bad info
✅ FIX: Always implement editable outputs with diff tracking.

──────────────────────────────────────────────────────────────

❌ MISTAKE 2: Same threshold for every use case
→ "All requests above 0.5 risk get reviewed"
→ Medical AI: 0.5 is too low (expensive, slow)
→ Nuclear reactor control: 0.5 is way too high (dangerous)
✅ FIX: Risk thresholds must be calibrated per domain, stakes, and cost.

──────────────────────────────────────────────────────────────

❌ MISTAKE 3: No SLA enforcement
→ Requests pile up in queue
→ Users wait days with no response
→ Reviewers don't feel urgency
✅ FIX: SLA deadlines with automated escalation.
        Dashboard shows "SLA at risk" items prominently.

──────────────────────────────────────────────────────────────

❌ MISTAKE 4: Storing workflow state in memory only
→ Server restarts → all pending workflows lost
→ Users never get their responses
→ Reviewers see empty queue
✅ FIX: Use Temporal for durable workflows, or persist state to DB.

──────────────────────────────────────────────────────────────

❌ MISTAKE 5: Not collecting feedback from edits
→ Reviewers correct the same mistakes every day
→ Model never improves
→ HITL burden never reduces
✅ FIX: Build feedback pipeline from day 1.
        Human corrections = training data = better AI.

──────────────────────────────────────────────────────────────

❌ MISTAKE 6: Sending users nothing while review is pending
→ "Please wait, your request is being reviewed"
→ No timeframe, no provisional info → terrible UX
✅ FIX: Provisional responses + clear ETA communication.
        "Our team is reviewing this. Expected response: 4 hours."

──────────────────────────────────────────────────────────────

❌ MISTAKE 7: All requests go to one generic review team
→ Medical questions reviewed by finance people
→ Compliance issues reviewed by content team
→ Wrong expertise = wrong decisions
✅ FIX: Domain-specific routing to specialized review teams.
```
