# 🏛️ PILLAR 1: CONTENT POLICIES

## What is a Content Policy?

**Simple Definition:**
A content policy is a **written + enforced set of rules** that defines what your AI system is allowed to do and what it must refuse.

### Real-World Analogy:
> Think of a bank teller 🏦
>
> A bank teller has a policy book:
> - "Never give cash without ID" 
> - "Never transfer more than $10,000 without manager approval"
> - "Never discuss another customer's account"
>
> The teller doesn't decide these rules personally.
> The bank (company policy) decides. The teller enforces.
>
> Your AI is the teller.
> Your content policy is the policy book.

## Building a Content Policy Engine

```python
# ══════════════════════════════════════════════════════════
# CONTENT POLICY ENGINE
# A complete system to define, evaluate, and enforce policies
# ══════════════════════════════════════════════════════════

from dataclasses import dataclass, field
from enum import Enum
from typing import List, Dict, Optional, Callable
import re
import json
from datetime import datetime

class PolicyAction(Enum):
    ALLOW = "allow"           # Let it through
    BLOCK = "block"           # Reject completely
    MODIFY = "modify"         # Allow with modifications
    WARN = "warn"             # Allow but add warning
    REQUIRE_REVIEW = "review" # Flag for human review
    REDIRECT = "redirect"     # Send to different handler

class PolicyLevel(Enum):
    GLOBAL = 1       # Highest priority, can't be overridden
    ORGANIZATION = 2 # Company-level rules
    PRODUCT = 3      # App-specific rules
    USER = 4         # User-specific rules (lowest priority)

@dataclass
class PolicyRule:
    """A single policy rule"""
    rule_id: str
    name: str
    description: str
    level: PolicyLevel
    
    # What triggers this rule
    trigger_patterns: List[str] = field(default_factory=list)
    trigger_categories: List[str] = field(default_factory=list)
    trigger_function: Optional[Callable] = None  # Custom logic
    
    # What to do when triggered
    action: PolicyAction = PolicyAction.BLOCK
    message: str = "This request violates our usage policy."
    
    # Who this applies to
    applies_to_roles: List[str] = field(default_factory=list)  # [] = all roles
    applies_to_regions: List[str] = field(default_factory=list)  # [] = all regions
    applies_to_tiers: List[str] = field(default_factory=list)  # [] = all tiers
    
    # Metadata
    active: bool = True
    created_at: str = ""
    expires_at: Optional[str] = None

@dataclass
class UserContext:
    """Context about the user making the request"""
    user_id: str
    role: str              # admin, developer, user, guest
    tier: str              # free, pro, enterprise
    region: str            # US, EU, APAC
    organization_id: str
    custom_attributes: Dict = field(default_factory=dict)

@dataclass
class PolicyEvaluationResult:
    """Result of evaluating a request against all policies"""
    allowed: bool
    action: PolicyAction
    triggered_rules: List[str]
    message: str
    modified_content: Optional[str] = None
    requires_logging: bool = True
    audit_metadata: Dict = field(default_factory=dict)

class ContentPolicyEngine:
    """
    Evaluates requests against a hierarchy of content policies.
    
    How it works:
    1. Load all policy rules (from config, database, etc.)
    2. For each request: evaluate against rules in priority order
    3. Higher priority rules (GLOBAL) override lower priority (USER)
    4. Return enforcement decision
    """
    
    def __init__(self):
        self.rules: List[PolicyRule] = []
        self._load_default_policies()
    
    def _load_default_policies(self):
        """Load built-in global policies that can never be overridden"""
        
        # ── ABSOLUTE BLOCKS (GLOBAL LEVEL) ──
        self.add_rule(PolicyRule(
            rule_id="GLOBAL-001",
            name="Absolute Harm Block",
            description="Block requests for mass casualty content",
            level=PolicyLevel.GLOBAL,
            trigger_patterns=[
                r'bioweapon|chemical weapon|nuclear weapon synthesis',
                r'mass.{0,20}casualt',
                r'attack.{0,30}infrastructure',
            ],
            action=PolicyAction.BLOCK,
            message="This request cannot be processed.",
        ))
        
        self.add_rule(PolicyRule(
            rule_id="GLOBAL-002",
            name="CSAM Block",
            description="Block any child sexual abuse material",
            level=PolicyLevel.GLOBAL,
            trigger_categories=["csam"],
            action=PolicyAction.BLOCK,
            message="This request cannot be processed.",
        ))
        
        # ── ORGANIZATION-LEVEL DEFAULTS ──
        self.add_rule(PolicyRule(
            rule_id="ORG-001",
            name="Medical Advice Disclaimer",
            description="Add disclaimer to medical content",
            level=PolicyLevel.ORGANIZATION,
            trigger_patterns=[
                r'diagnos(e|is|tic)',
                r'should i take.{0,30}(medication|drug|pill)',
                r'medical treatment for',
            ],
            action=PolicyAction.WARN,
            message="⚕️ Note: This is general information only. Please consult a qualified healthcare professional.",
        ))
        
        self.add_rule(PolicyRule(
            rule_id="ORG-002",
            name="Legal Advice Disclaimer",
            description="Add disclaimer to legal content",
            level=PolicyLevel.ORGANIZATION,
            trigger_patterns=[
                r'is it legal to',
                r'can i sue',
                r'my legal rights',
                r'should i sign.{0,20}contract',
            ],
            action=PolicyAction.WARN,
            message="⚖️ Note: This is general information only. Please consult a qualified lawyer.",
        ))
        
        # ── PRODUCT-LEVEL DEFAULTS ──
        self.add_rule(PolicyRule(
            rule_id="PROD-001",
            name="Competitor Discussion Block",
            description="Don't discuss competitors for customer service app",
            level=PolicyLevel.PRODUCT,
            trigger_patterns=[
                r'(amazon|google|microsoft|apple).{0,20}(better|worse|compare)',
                r'switch to.{0,20}competitor',
                r'why is.{0,20}competitor',
            ],
            action=PolicyAction.REDIRECT,
            message="I'm here to help with TechShop specifically. For a broader comparison, I'd suggest checking independent review sites.",
        ))
    
    def add_rule(self, rule: PolicyRule):
        """Add a new policy rule"""
        self.rules.append(rule)
        # Keep rules sorted by priority (GLOBAL first)
        self.rules.sort(key=lambda r: r.level.value)
    
    def _rule_applies_to_user(self, rule: PolicyRule, user: UserContext) -> bool:
        """Check if this rule applies to this specific user"""
        
        # Check role restriction
        if rule.applies_to_roles and user.role not in rule.applies_to_roles:
            return False  # Rule doesn't apply to this role
        
        # Check region restriction
        if rule.applies_to_regions and user.region not in rule.applies_to_regions:
            return False  # Rule doesn't apply to this region
        
        # Check tier restriction
        if rule.applies_to_tiers and user.tier not in rule.applies_to_tiers:
            return False  # Rule doesn't apply to this tier
        
        # Check expiry
        if rule.expires_at:
            if datetime.now().isoformat() > rule.expires_at:
                return False  # Rule has expired
        
        return rule.active
    
    def _rule_triggered(self, rule: PolicyRule, content: str) -> bool:
        """Check if content triggers this rule"""
        
        content_lower = content.lower()
        
        # Check regex patterns
        for pattern in rule.trigger_patterns:
            if re.search(pattern, content_lower, re.IGNORECASE | re.DOTALL):
                return True
        
        # Check custom trigger function
        if rule.trigger_function:
            if rule.trigger_function(content):
                return True
        
        return False
    
    def evaluate(
        self, 
        content: str, 
        user: UserContext,
        content_type: str = "user_input"  # user_input or llm_output
    ) -> PolicyEvaluationResult:
        """
        Evaluate content against all applicable policies.
        Returns enforcement decision.
        """
        
        triggered_rules = []
        highest_priority_action = None
        highest_priority_level = PolicyLevel.USER
        combined_warnings = []
        modified_content = content
        
        for rule in self.rules:
            
            # Skip if rule doesn't apply to this user
            if not self._rule_applies_to_user(rule, user):
                continue
            
            # Skip if content doesn't trigger this rule
            if not self._rule_triggered(content, content):
                continue
            
            triggered_rules.append(rule.rule_id)
            
            # Determine which action wins (higher priority level wins)
            if highest_priority_action is None or rule.level.value < highest_priority_level.value:
                highest_priority_action = rule.action
                highest_priority_level = rule.level
            
            # For BLOCK: immediately return (no need to check other rules)
            if rule.action == PolicyAction.BLOCK and rule.level == PolicyLevel.GLOBAL:
                return PolicyEvaluationResult(
                    allowed=False,
                    action=PolicyAction.BLOCK,
                    triggered_rules=[rule.rule_id],
                    message=rule.message,
                    requires_logging=True,
                    audit_metadata={
                        "blocked_by": rule.rule_id,
                        "rule_level": rule.level.name,
                        "user_id": user.user_id,
                        "timestamp": datetime.now().isoformat()
                    }
                )
            
            # For WARN: collect warning messages
            if rule.action == PolicyAction.WARN:
                combined_warnings.append(rule.message)
            
            # For MODIFY: apply modification
            if rule.action == PolicyAction.MODIFY:
                if rule.trigger_function:
                    modified_content = rule.trigger_function(modified_content)
        
        # No rules triggered
        if not triggered_rules:
            return PolicyEvaluationResult(
                allowed=True,
                action=PolicyAction.ALLOW,
                triggered_rules=[],
                message="",
                modified_content=content,
                requires_logging=False,
                audit_metadata={}
            )
        
        # Determine final decision
        if highest_priority_action == PolicyAction.BLOCK:
            return PolicyEvaluationResult(
                allowed=False,
                action=PolicyAction.BLOCK,
                triggered_rules=triggered_rules,
                message="This request violates our usage policy.",
                requires_logging=True,
                audit_metadata={
                    "user_id": user.user_id,
                    "triggered_rules": triggered_rules,
                    "timestamp": datetime.now().isoformat()
                }
            )
        
        # Warnings: Allow but add disclaimers
        if combined_warnings:
            disclaimer = "\n\n" + "\n".join(combined_warnings)
            return PolicyEvaluationResult(
                allowed=True,
                action=PolicyAction.WARN,
                triggered_rules=triggered_rules,
                message=disclaimer,
                modified_content=modified_content + disclaimer,
                requires_logging=True,
                audit_metadata={
                    "user_id": user.user_id,
                    "warnings_added": combined_warnings,
                    "timestamp": datetime.now().isoformat()
                }
            )
        
        # Default: Allow
        return PolicyEvaluationResult(
            allowed=True,
            action=PolicyAction.ALLOW,
            triggered_rules=triggered_rules,
            message="",
            modified_content=modified_content,
            requires_logging=False,
            audit_metadata={}
        )


# ──────────────────────────────────────
# USAGE EXAMPLE
# ──────────────────────────────────────

engine = ContentPolicyEngine()

# Add a custom product policy
engine.add_rule(PolicyRule(
    rule_id="PROD-CS-001",
    name="Premium Feature Block",
    description="Advanced analytics only for Pro+ tier",
    level=PolicyLevel.PRODUCT,
    trigger_patterns=[r'advanced analytics', r'detailed report', r'full data export'],
    action=PolicyAction.BLOCK,
    message="Advanced analytics is available on Pro and Enterprise plans. Upgrade to access this feature.",
    applies_to_tiers=["free"]  # Only blocks free tier
))

# Test with different users
free_user = UserContext(
    user_id="user_123",
    role="user",
    tier="free",
    region="US",
    organization_id="org_abc"
)

pro_user = UserContext(
    user_id="user_456",
    role="user",
    tier="pro",
    region="EU",
    organization_id="org_abc"
)

# Test: Free user requests advanced analytics
result = engine.evaluate(
    content="Can I get an advanced analytics report?",
    user=free_user
)
print(f"Free user result: {result.allowed} — {result.message}")
# → False — "Advanced analytics is available on Pro and Enterprise plans..."

# Test: Pro user same request
result = engine.evaluate(
    content="Can I get an advanced analytics report?",
    user=pro_user
)
print(f"Pro user result: {result.allowed}")
# → True — allowed!

# Test: Medical question (gets disclaimer)
result = engine.evaluate(
    content="Should I take ibuprofen for my headache?",
    user=free_user
)
print(f"Medical question: {result.action} — {result.message}")
# → WARN — "Note: This is general information only..."
```

## Authentication: OAuth 2.0 + JWT Deep Dive

### What is OAuth 2.0?

**OAuth 2.0** is an industry-standard protocol for **authorization delegation**.

Simple English: *"Let a third-party app access your resources without giving them your password."*

### Real-World Example:
```
You use TechShop's AI assistant.
TechShop wants to verify you're a real Google account user.

WITHOUT OAuth:
─────────────
You give TechShop your Google password.
TechShop logs into Google for you.
❌ TechShop now has your Google password forever. DANGEROUS!

WITH OAuth:
──────────
You click "Login with Google"
You log into Google directly
Google gives TechShop a limited token: "This user is authenticated, here's a token"
TechShop uses that token — never sees your password
✅ Safe, revocable, limited scope
```

### What is JWT (JSON Web Token)?

**JWT** is the **format** of the token that OAuth and other auth systems create.

Think of it like a **secure, tamper-proof ID card** 🪪

```
A JWT looks like this:
────────────────────────────────────────────────────────────
eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.
eyJ1c2VyX2lkIjoiMTIzIiwicm9sZSI6InBybyIsInRpZXIiOiJwcm8iLCJleHAiOjE3MDAwMDAwMDB9.
SflKxwRJSMeKKF2QT4fwpMeJf36POk6yJV_adQssw5c
────────────────────────────────────────────────────────────

Three parts separated by dots (.)

Part 1: HEADER (algorithm info)
Part 2: PAYLOAD (user data)
Part 3: SIGNATURE (tamper detection)
```

### JWT Structure Deep Dive:

```python
import base64
import json
import hmac
import hashlib
import time
from dataclasses import dataclass
from typing import Optional, Dict, List

@dataclass
class JWTPayload:
    """Standard JWT claims for an AI API"""
    # Standard claims
    sub: str           # Subject (user_id)
    iss: str           # Issuer (your company)
    aud: str           # Audience (which API)
    iat: int           # Issued At (timestamp)
    exp: int           # Expiration (timestamp)
    jti: str           # JWT ID (unique token ID for revocation)
    
    # Custom claims for LLMOps
    role: str          # admin, developer, user, guest
    tier: str          # free, pro, enterprise
    org_id: str        # Organization ID
    permissions: List[str]  # Explicit permissions list
    region: str        # User's region (for compliance)
    rate_limit_key: str  # Which rate limit bucket

class JWTManager:
    """
    Create, verify, and decode JWT tokens.
    This is the core of authentication in your AI API.
    """
    
    def __init__(self, secret_key: str):
        self.secret_key = secret_key
    
    def _base64url_encode(self, data: bytes) -> str:
        """Base64 URL-safe encoding (JWT uses this)"""
        return base64.urlsafe_b64encode(data).rstrip(b'=').decode('utf-8')
    
    def _base64url_decode(self, data: str) -> bytes:
        """Base64 URL-safe decoding"""
        padding = 4 - len(data) % 4
        data += '=' * padding
        return base64.urlsafe_b64decode(data)
    
    def create_token(self, payload: JWTPayload) -> str:
        """
        Create a JWT token.
        
        Structure: header.payload.signature
        """
        
        # PART 1: Header
        header = {
            "alg": "HS256",  # HMAC SHA-256 signing algorithm
            "typ": "JWT"     # Token type
        }
        
        # PART 2: Payload (claims)
        payload_dict = {
            "sub": payload.sub,
            "iss": payload.iss,
            "aud": payload.aud,
            "iat": payload.iat,
            "exp": payload.exp,
            "jti": payload.jti,
            "role": payload.role,
            "tier": payload.tier,
            "org_id": payload.org_id,
            "permissions": payload.permissions,
            "region": payload.region,
            "rate_limit_key": payload.rate_limit_key
        }
        
        # Encode header and payload
        header_encoded = self._base64url_encode(
            json.dumps(header, separators=(',', ':')).encode()
        )
        payload_encoded = self._base64url_encode(
            json.dumps(payload_dict, separators=(',', ':')).encode()
        )
        
        # PART 3: Signature (prevents tampering)
        # If someone modifies the payload, signature won't match
        signing_input = f"{header_encoded}.{payload_encoded}"
        signature = hmac.new(
            self.secret_key.encode(),
            signing_input.encode(),
            hashlib.sha256
        ).digest()
        signature_encoded = self._base64url_encode(signature)
        
        return f"{header_encoded}.{payload_encoded}.{signature_encoded}"
    
    def verify_and_decode(self, token: str) -> Optional[Dict]:
        """
        Verify token signature and decode payload.
        Returns None if token is invalid or expired.
        """
        
        try:
            parts = token.split('.')
            if len(parts) != 3:
                raise ValueError("Invalid token format")
            
            header_encoded, payload_encoded, signature_encoded = parts
            
            # STEP 1: Verify signature (has it been tampered with?)
            signing_input = f"{header_encoded}.{payload_encoded}"
            expected_signature = hmac.new(
                self.secret_key.encode(),
                signing_input.encode(),
                hashlib.sha256
            ).digest()
            expected_encoded = self._base64url_encode(expected_signature)
            
            if not hmac.compare_digest(signature_encoded, expected_encoded):
                print("❌ Token signature invalid — possible tampering!")
                return None
            
            # STEP 2: Decode payload
            payload_json = self._base64url_decode(payload_encoded)
            payload = json.loads(payload_json)
            
            # STEP 3: Check expiration
            if payload.get('exp', 0) < time.time():
                print("❌ Token expired!")
                return None
            
            # STEP 4: Check issuer and audience
            if payload.get('iss') != 'techshop-ai':
                print("❌ Invalid token issuer!")
                return None
            
            print("✅ Token valid!")
            return payload
            
        except Exception as e:
            print(f"❌ Token verification failed: {str(e)}")
            return None
    
    def create_user_token(
        self, 
        user_id: str,
        role: str,
        tier: str,
        org_id: str,
        region: str,
        expires_in_hours: int = 24
    ) -> str:
        """Convenience method to create a user token"""
        
        import uuid
        
        # Define permissions based on role + tier
        permissions = self._get_permissions(role, tier)
        
        payload = JWTPayload(
            sub=user_id,
            iss="techshop-ai",
            aud="techshop-api",
            iat=int(time.time()),
            exp=int(time.time()) + (expires_in_hours * 3600),
            jti=str(uuid.uuid4()),  # Unique ID for this token
            role=role,
            tier=tier,
            org_id=org_id,
            permissions=permissions,
            region=region,
            rate_limit_key=f"{tier}_{role}"
        )
        
        return self.create_token(payload)
    
    def _get_permissions(self, role: str, tier: str) -> List[str]:
        """Define what permissions different role+tier combinations get"""
        
        base_permissions = {
            "guest": [
                "ai:chat:basic",
                "ai:read:public_content"
            ],
            "user": [
                "ai:chat:basic",
                "ai:chat:history",
                "ai:read:public_content",
                "ai:upload:documents"
            ],
            "developer": [
                "ai:chat:basic",
                "ai:chat:history",
                "ai:chat:advanced",
```

## Authorization: RBAC vs ABAC

### RBAC = Role-Based Access Control

```
Simple rule: Your ROLE determines your permissions.
"All Admins can do X. All Users can do Y."
```

```python
class RBACSystem:
    """
    Role-Based Access Control for AI API.
    Simple, fast, easy to understand.
    Good for: Most cases
    """
    
    # Define role hierarchy

        "guest": 0,

    # Define what each role can do
    ROLE_PERMISSIONS = {

            "ai.audit_logs": False,

            "ai.manage_users": False,

        role_perms = self.ROLE_PERMISSIONS.get(role, {})
        return role_perms.get(permission, False)

        """Check if user has at least the required role level"""
        user_level = self.ROLE_HIERARCHY.get(user_role, 0)
        required_level = self.ROLE_HIERARCHY.get(required_role, 0)
        return user_level >= required_level
```

### ABAC = Attribute-Based Access Control

```
Complex rule: Multiple ATTRIBUTES determine permissions.
"Users who are 18+, in the US, with Pro tier, 
 who have verified their professional credentials 
 can access medical content."
```

```python
from typing import Any

@dataclass
class AccessRequest:
    """Everything about who wants to do what"""
    # Subject attributes (who is asking)
    subject_id: str
    subject_role: str
    subject_tier: str
    subject_region: str
    subject_age_verified: bool
    subject_professional_verified: bool
    subject_organization_id: str
    
    # Resource attributes (what they want to access)
    resource_type: str    # "medical_content", "financial_data", "admin_panel"
    resource_sensitivity: str  # "public", "internal", "confidential", "restricted"
    resource_owner_org: str    # Which organization owns this resource
    
    # Action attributes (what they want to do)
    action: str  # "read", "write", "delete", "execute", "share"
    
    # Environment attributes (when/where/how)
    time_of_request: str
    ip_address: str
    request_via_api: bool

@dataclass  
class PolicyDecision:
    permitted: bool
    reason: str
    conditions: List[str] = field(default_factory=list)

class ABACSystem:
    """
    Attribute-Based Access Control.
    More flexible than RBAC.
    Good for: Complex, context-sensitive access rules.
    """
    
    def evaluate(self, request: AccessRequest) -> PolicyDecision:
        """
        Evaluate access request against attribute-based policies.
        """
        
        # ── POLICY 1: Cross-organization data isolation ──
        # Users can only access their own org's data
        if (request.resource_type in ["customer_data", "org_data"] and 
            request.subject_organization_id != request.resource_owner_org):
            return PolicyDecision(
                permitted=False,
                reason="Cross-organization data access denied"
            )
        
        # ── POLICY 2: Sensitive medical content ──
        # Medical content: must be professional + age verified + right region
        if request.resource_type == "medical_content":
            if not request.subject_age_verified:
                return PolicyDecision(
                    permitted=False,
                    reason="Age verification required for medical content"
                )
            if not request.subject_professional_verified:
                return PolicyDecision(
                    permitted=True,  # Allow but add disclaimer
                    reason="Non-professional user: disclaimer will be added",
                    conditions=["add_medical_disclaimer", "log_access"]
                )
        
        # ── POLICY 3: Admin panel time restriction ──
        # Admin panel only during business hours for extra security
        if request.resource_type == "admin_panel":
            if request.subject_role != "admin":
                return PolicyDecision(
                    permitted=False,
                    reason="Admin role required for admin panel"
                )
            hour = int(request.time_of_request.split(':')[0])
            if not (8 <= hour <= 18):  # 8 AM to 6 PM only
                return PolicyDecision(
                    permitted=False,
                    reason="Admin panel only accessible during business hours (8 AM - 6 PM)"
                )
        
        # ── POLICY 4: Restricted content tier check ──
        if request.resource_sensitivity == "restricted":
            if request.subject_tier not in ["enterprise"]:
                return PolicyDecision(
                    permitted=False,
                    reason="Enterprise tier required for restricted content"
                )
        
        # ── POLICY 5: Write access requires non-guest role ──
        if request.action in ["write", "delete"] and request.subject_role == "guest":
            return PolicyDecision(
                permitted=False,
                reason="Guest users cannot write or delete content"
            )
        
        # ── POLICY 6: API access requires developer+ ──
        if request.request_via_api and request.subject_role == "user":
            return PolicyDecision(
                permitted=False,
                reason="API access requires Developer tier or above"
            )
        
        # Default: Permit (you can also default to deny for high-security systems)
        return PolicyDecision(
            permitted=True,
            reason="All attribute checks passed",
            conditions=["log_access"] if request.resource_sensitivity != "public" else []
        )
```

# 🏛️ PILLAR 3: RATE LIMITS PER TIER

## What is Rate Limiting?

**Core Idea:** Control how many requests a user can make in a given time period.

### Why is Rate Limiting Critical for AI APIs?

```
COST REALITY OF LLM APIs:
──────────────────────────

GPT-4: ~$0.03 per 1K tokens
Average request: ~2,000 tokens input + 500 tokens output

Cost per request ≈ $0.075 (7.5 cents)

Without rate limits:
• 1 user sends 10,000 requests/hour
• Cost: 10,000 × $0.075 = $750 per hour from ONE user
• Daily: $18,000 from ONE user
• You're bankrupt in days. 💸

With rate limits:
• Free user: max 10 requests/hour
• 10 × $0.075 = $0.75/hour — manageable ✅
```

### Rate Limiting Algorithms:

---

### Algorithm 1: Fixed Window Counter

```
Concept: Count requests in fixed time windows (every minute, every hour)

Example: Max 10 requests per minute
─────────────────────────────────────
00:00 - 00:59: User makes 10 requests → ALLOWED
01:00 - 01:59: Counter resets → User can make 10 more → ALLOWED

Problem: "Burst at window edge"
──────────────────────────────
00:55: User makes 10 requests (allowed)
01:00: Counter resets
01:05: User makes 10 more requests (allowed)
→ User made 20 requests in 10 seconds! 
→ Not truly rate limited at the boundary
```

```python
import time
from collections import defaultdict

class FixedWindowRateLimiter:
    """Simple but has burst problem at window edges"""
    
    def __init__(self):
        self.windows = defaultdict(lambda: {"count": 0, "window_start": 0})
    
    def is_allowed(self, user_id: str, limit: int, window_seconds: int) -> dict:
        current_time = time.time()
        user_window = self.windows[user_id]
        
        # Check if we're in a new window
        if current_time - user_window["window_start"] >= window_seconds:
            user_window["count"] = 0
            user_window["window_start"] = current_time
        
        if user_window["count"] < limit:
            user_window["count"] += 1
            return {
                "allowed": True,
                "remaining": limit - user_window["count"],
                "reset_at": user_window["window_start"] + window_seconds
            }
        
        return {
            "allowed": False,
            "remaining": 0,
            "reset_at": user_window["window_start"] + window_seconds,
            "retry_after": window_seconds - (current_time - user_window["window_start"])
        }
```

### Algorithm 2: Sliding Window (Better)

```
Concept: Track requests in a ROLLING time window, not fixed intervals.

Example: Max 10 requests per 60 seconds
────────────────────────────────────────
Check: "How many requests in the LAST 60 seconds?"
→ Not "how many since minute started" but "rolling 60 seconds"

Solves the burst problem at window edges!
```

```python
from collections import deque
import time

class SlidingWindowRateLimiter:
    """More accurate rate limiting — no burst at window edges"""
    
    def __init__(self):
        # Store timestamp of each request per user
        self.request_times = defaultdict(deque)
    
    def is_allowed(self, user_id: str, limit: int, window_seconds: int) -> dict:
        current_time = time.time()
        user_requests = self.request_times[user_id]
        window_start = current_time - window_seconds
        
        # Remove requests outside the sliding window
        while user_requests and user_requests[0] < window_start:
            user_requests.popleft()
        
        if len(user_requests) < limit:
            user_requests.append(current_time)
            return {
                "allowed": True,
                "remaining": limit - len(user_requests),
                "window_seconds": window_seconds
            }
        
        # Calculate when the oldest request leaves the window
        retry_after = user_requests[0] + window_seconds - current_time
        
        return {
            "allowed": False,
            "remaining": 0,
            "retry_after": round(retry_after, 2),
            "message": f"Rate limit exceeded. Try again in {retry_after:.1f} seconds."
        }
```

### Algorithm 3: Token Bucket (Best for AI APIs)

```
Concept: Each user has a "bucket" of tokens.
- Tokens refill at a steady rate
- Each request costs tokens
- Large requests cost more tokens

Why perfect for AI APIs:
────────────────────────
A 100-token request is cheaper than a 10,000-token request.
Regular rate limits treat them equally (wrong!).
Token bucket can charge different amounts per request size.
```

```python
class TokenBucketRateLimiter:
    """
    Best for AI APIs: 
    - Control cost, not just request count
    - Large requests cost more tokens
    - Natural burst allowance (full bucket at start)
    """
    
    def __init__(self):
        self.buckets = {}  # user_id → bucket state
    
    def _get_bucket(self, user_id: str, capacity: int, refill_rate: float) -> dict:
        """Get or create bucket for user"""
        if user_id not in self.buckets:
            self.buckets[user_id] = {
                "tokens": capacity,  # Start full
                "capacity": capacity,
                "refill_rate": refill_rate,  # tokens per second
                "last_refill": time.time()
            }
        return self.buckets[user_id]
    
    def _refill_bucket(self, bucket: dict) -> dict:
        """Add tokens based on time elapsed"""
        now = time.time()
        elapsed = now - bucket["last_refill"]
        
        # Add tokens for time elapsed
        tokens_to_add = elapsed * bucket["refill_rate"]
        bucket["tokens"] = min(
            bucket["capacity"],  # Can't exceed capacity
            bucket["tokens"] + tokens_to_add
        )
        bucket["last_refill"] = now
        return bucket
    
    def consume(
        self, 
        user_id: str,
        tokens_required: int,
        capacity: int,
        refill_rate: float  # tokens per second
    ) -> dict:
        """
        Try to consume tokens from the bucket.
        tokens_required = how many tokens this request costs.
        
        For AI APIs, calculate based on estimated tokens:
        tokens_required = estimated_input_tokens + estimated_output_tokens
        """
        
        bucket = self._get_bucket(user_id, capacity, refill_rate)
        bucket = self._refill_bucket(bucket)
        
        if bucket["tokens"] >= tokens_required:
            bucket["tokens"] -= tokens_required
            return {
                "allowed": True,
                "tokens_remaining": bucket["tokens"],
                "tokens_used": tokens_required
            }
        
        # Not enough tokens
        time_until_enough = (tokens_required - bucket["tokens"]) / bucket["refill_rate"]
        
        return {
            "allowed": False,
            "tokens_available": bucket["tokens"],
            "tokens_needed": tokens_required,
            "retry_after_seconds": round(time_until_enough, 2),
            "message": f"Insufficient tokens. Retry in {time_until_enough:.1f} seconds."
        }
```

### Complete Tier-Based Rate Limit System

```python
# ══════════════════════════════════════════════════════════

    def __init__(self):

                "allowed": False,
                "limit_type": "request_size",
                "message": f"Request too large. Max {config.max_input_tokens} tokens for {tier} tier.",
                "headers": self._build_headers(config, user_id)
            }
        
        # ── CHECK 2: Concurrent requests ──
        if self.concurrent_requests[user_id] >= config.max_concurrent_requests:
            return {
                "allowed": False,
                "limit_type": "concurrent_requests",
                "message": f"Too many concurrent requests. Max {config.max_concurrent_requests} for {tier} tier.",
                "headers": self._build_headers(config, user_id)
            }
        
        # ── CHECK 3: Requests per minute ──
        rpm_result = self.sliding_limiter.is_allowed(
            f"{user_id}:rpm",
            config.requests_per_minute,
            60  # 60 seconds
        )
        if not rpm_result["allowed"]:
            return {
                "allowed": False,
                "limit_type": "requests_per_minute",
                "message": f"Rate limit: {config.requests_per_minute} requests/minute for {tier} tier.",
                "retry_after": rpm_result.get("retry_after"),
                "headers": self._build_headers(config, user_id)
            }
        
        # ── CHECK 4: Requests per hour ──
        rph_result = self.sliding_limiter.is_allowed(
            f"{user_id}:rph",
            config.requests_per_hour,
            3600  # 1 hour
        )
        if not rph_result["allowed"]:
            return {
                "allowed": False,
                "limit_type": "requests_per_hour",
                "message": f"Hourly rate limit reached. Max {config.requests_per_hour} requests/hour.",
                "retry_after": rph_result.get("retry_after"),
                "headers": self._build_headers(config, user_id)
            }
        
        # ── CHECK 5: Requests per day ──
        rpd_result = self.sliding_limiter.is_allowed(
            f"{user_id}:rpd",
            config.requests_per_day,
            86400  # 24 hours
        )
        if not rpd_result["allowed"]:
            return {
                "allowed": False,
                "limit_type": "requests_per_day",
                "message": f"Daily request limit reached. Resets in 24 hours.",
                "headers": self._build_headers(config, user_id)
            }
        
        # ── CHECK 6: Token budget ──
        token_result = self.token_limiter.consume(
            f"{user_id}:tokens_minute",
            tokens_required=estimated_tokens,
            capacity=config.tokens_per_minute,
            refill_rate=config.tokens_per_minute / 60  # Refill per second
        )
        if not token_result["allowed"]:
            return {
                "allowed": False,
                "limit_type": "token_rate",
                "message": f"Token rate limit exceeded. Your tier allows {config.tokens_per_minute} tokens/minute.",
                "retry_after": token_result.get("retry_after_seconds"),
                "headers": self._build_headers(config, user_id)
            }
        
        # ── CHECK 7: Daily cost budget ──
        estimated_cost = estimated_tokens * 0.00003  # Rough cost estimate
        if self.daily_costs[user_id] + estimated_cost > config.max_daily_cost_usd:
            return {
                "allowed": False,
                "limit_type": "daily_budget",
                "message": f"Daily budget limit reached. Resets in 24 hours.",
                "headers": self._build_headers(config, user_id)
            }
        
        # ── ALL CHECKS PASSED ──
        self.concurrent_requests[user_id] += 1
        return {
            "allowed": True,
            "tier": tier,
            "limits": {
                "requests_per_minute": config.requests_per_minute,
                "requests_per_day": config.requests_per_day,
                "tokens_per_day": config.tokens_per_day
            },
            "headers": self._build_headers(config, user_id)
        }
    
    def request_completed(self, user_id: str, actual_tokens_used: int, tier: str):
        """Call this when request finishes to update usage"""
        self.concurrent_requests[user_id] = max(0, self.concurrent_requests[user_id] - 1)
        actual_cost = actual_tokens_used * 0.00003
        self.daily_costs[user_id] += actual_cost
    
    def _build_headers(self, config: TierConfig, user_id: str) -> dict:
        """Build standard rate limit response headers"""
        return {
            "X-RateLimit-Limit-RPM": str(config.requests_per_minute),
            "X-RateLimit-Limit-RPD": str(config.requests_per_day),
            "X-RateLimit-Remaining-RPM": "see body",
            "X-RateLimit-Reset": str(int(time.time()) + 60),
            "X-Tier": config.tier_name,
        }
```

# 🏛️ PILLAR 4: AUDIT LOGGING

## What is Audit Logging?

**Core Idea:** Every significant action in your AI system must be **recorded with enough detail** that you can reconstruct exactly what happened, who did it, and why.

### Why Audit Logging is Non-Negotiable:

```
LEGAL REQUIREMENT:
──────────────────
GDPR (EU): Must show how personal data was processed
HIPAA (Healthcare): Must log all access to patient data
SOC 2: Must demonstrate access controls work
PCI-DSS (Finance): Must log all access to payment data
→ No logs = No compliance = Massive fines

SECURITY REQUIREMENT:
─────────────────────
Breach happened? Need to know:
• When? (Timestamp)
• Who? (User ID, IP)  
• What? (What they asked/got)
• How? (Attack method)
→ No logs = Can't investigate = Can't fix

BUSINESS REQUIREMENT:
─────────────────────
• Dispute resolution: "I never asked for that!"
• Usage analysis: Which features are used most?
• Cost attribution: Which team is spending the most?
• Quality improvement: What questions are asked often?
```

```python
async def authenticate(
    credentials: HTTPAuthorizationCredentials = Depends(security),
    request: Request = None
) -> dict:
    """
    Verify JWT token from Authorization header.
    Returns decoded user payload if valid.
    """
    
    token = credentials.credentials
    
    # Verify JWT
    payload = jwt_mgr.verify_and_decode(token)
    
    if not payload:
        # Log failed auth
        audit_logger.log_security_event(
            event_type=EventType.SECURITY_AUTH_FAILURE,
            user_id="unknown",
            ip_address=request.client.host if request else "unknown",
            description="Invalid or expired JWT token",
            severity="medium"
        )
        raise HTTPException(
            status_code=401,
            detail="Invalid or expired token",
            headers={"WWW-Authenticate": "Bearer"}
        )
    
    return payload

            headers={

def require_permission(permission: str):
    """Factory function: creates permission check dependency"""
    
    async def check_permission(user_payload: dict = Depends(authenticate)) -> dict:
        user_permissions = user_payload.get('permissions', [])
        
        # Check exact permission or wildcard
        has_permission = (
            permission in user_permissions or
            f"{permission.split('.')[0]}.*" in user_permissions or
            "ai:*" in user_permissions
        )
        
        if not has_permission:
            raise HTTPException(
                status_code=403,
                detail={
                    "error": "insufficient_permissions",
                    "required": permission,
                    "your_tier": user_payload.get('tier'),
                    "message": f"This feature requires '{permission}' permission. Consider upgrading your plan."
                }
            )
        
        return user_payload
    
    return check_permission

@app.post("/v1/ai/chat", response_model=ChatResponse)
async def chat(
    request: Request,
    chat_request: ChatRequest,
    user_payload: dict = Depends(check_rate_limit)  # Includes auth + rate limit
):
    """
    Main AI chat endpoint.
    Pipeline: Auth → Rate Limit → Policy Check → LLM → Policy Check → Log → Response
    """
    
    start_time = time.time()
    user_id = user_payload['sub']
    tier = user_payload['tier']
    org_id = user_payload['org_id']
    ip_address = request.client.host
    
    # ── STEP 1: Policy check on INPUT ──
    user_context = UserContext(
        user_id=user_id,
        role=user_payload['role'],
        tier=tier,
        region=user_payload['region'],
        organization_id=org_id
    )
    
    input_policy_result = policy_engine.evaluate(
        content=chat_request.message,
        user=user_context,
        content_type="user_input"
    )
    
    if not input_policy_result.allowed:
        # Log policy violation
        audit_logger.log_policy_violation(
            user_id=user_id,
            violated_rules=input_policy_result.triggered_rules,
            input_hash=hashlib.sha256(chat_request.message.encode()).hexdigest(),
            action_taken="blocked",
            ip_address=ip_address,
            org_id=org_id
        )
        
        raise HTTPException(
            status_code=400,
            detail={
                "error": "content_policy_violation",
                "message": input_policy_result.message
            }
        )
    
    # ── STEP 2: Call LLM ──
    import openai
    client = openai.OpenAI()
    
    llm_start = time.time()
    
    try:
        llm_response = client.chat.completions.create(
            model="gpt-4",
            messages=[
                {"role": "system", "content": "You are a helpful customer service assistant."},
                {"role": "user", "content": chat_request.message}
            ],
            max_tokens=min(
                chat_request.max_tokens or 500,
                rate_limiter.TIER_CONFIGS[tier].max_output_tokens
            )
        )
        
        response_text = llm_response.choices[0].message.content
        input_tokens = llm_response.usage.prompt_tokens
        output_tokens = llm_response.usage.completion_tokens
        
    except Exception as e:
        audit_logger.log_security_event(
            event_type=EventType.API_ERROR,
            user_id=user_id,
            ip_address=ip_address,
            description=f"LLM call failed: {str(e)}",
            severity="high"
        )
        raise HTTPException(status_code=500, detail="AI service temporarily unavailable")
    
    llm_latency = int((time.time() - llm_start) * 1000)
    
    # ── STEP 3: Policy check on OUTPUT ──
    output_policy_result = policy_engine.evaluate(
        content=response_text,
        user=user_context,
        content_type="llm_output"
    )
    
    final_response = output_policy_result.modified_content or response_text
    was_filtered = output_policy_result.action in [PolicyAction.WARN, PolicyAction.MODIFY]
    
    # ── STEP 4: Calculate cost ──
    cost_per_token = 0.00003  # $0.03 per 1K tokens
    total_cost = (input_tokens + output_tokens) * cost_per_token
    
    # Update usage tracking
    rate_limiter.request_completed(user_id, input_tokens + output_tokens, tier)
    
    # ── STEP 5: Audit log ──
    total_latency = int((time.time() - start_time) * 1000)
    
    audit_logger.log_ai_request(
        user_id=user_id,
        session_id=chat_request.conversation_id or "direct",
        org_id=org_id,
        user_input=chat_request.message,
        llm_response=final_response,
        model="gpt-4",
        input_tokens=input_tokens,
        output_tokens=output_tokens,
        cost_usd=total_cost,
        latency_ms=total_latency,
        tier=tier,
        ip_address=ip_address,
        region=user_payload['region'],
        policy_violations=output_policy_result.triggered_rules,
        guardrails_triggered=output_policy_result.triggered_rules,
        content_filtered=was_filtered,
        status="success"
    )
    
    # ── STEP 6: Return response ──
    return ChatResponse(
        response=final_response,
        conversation_id=chat_request.conversation_id or str(uuid.uuid4()),
        tokens_used=input_tokens + output_tokens,
        cost_usd=round(total_cost, 6),
        filtered=was_filtered
    )
```

```python
import boto3
import json
from datetime import datetime
from typing import Dict, List
import time

class CloudWatchLogger:
    """AWS CloudWatch structured logging for AI audit trails"""
    
    def __init__(self, region: str = "us-east-1"):
        self.client = boto3.client('logs', region_name=region)
        self.log_group = "/ai-api/audit"
        self.log_stream_prefix = "audit"
        self._sequence_tokens = {}  # Track sequence tokens per stream
        self._ensure_log_group()
    
    def _ensure_log_group(self):
        """Create log group if it doesn't exist"""
        try:
            self.client.create_log_group(
                logGroupName=self.log_group,
                tags={
                    "Service": "ai-api",
                    "Environment": "production",
                    "DataType": "audit-logs",
                    "RetentionDays": "2555"  # 7 years for compliance
                }
            )
            
            # Set retention policy (7 years for compliance)
            self.client.put_retention_policy(
                logGroupName=self.log_group,
                retentionInDays=2555  # 7 years
            )
            
            print(f"✅ Created CloudWatch log group: {self.log_group}")
        except self.client.exceptions.ResourceAlreadyExistsException:
            pass  # Already exists — that's fine
    
    def _get_stream_name(self) -> str:
        """Get daily log stream name"""
        return f"{self.log_stream_prefix}/{datetime.utcnow().strftime('%Y/%m/%d')}"
    
    def _ensure_log_stream(self, stream_name: str):
        """Create log stream if it doesn't exist"""
        try:
            self.client.create_log_stream(
                logGroupName=self.log_group,
                logStreamName=stream_name
            )
        except self.client.exceptions.ResourceAlreadyExistsException:
            pass
    
    def log_event(self, event: dict):
        """Send a single log event to CloudWatch"""
        stream_name = self._get_stream_name()
        self._ensure_log_stream(stream_name)
        
        kwargs = {
            "logGroupName": self.log_group,
            "logStreamName": stream_name,
            "logEvents": [{
                "timestamp": int(time.time() * 1000),
                "message": json.dumps(event)
            }]
        }
        
        # Include sequence token if we have one (required for subsequent writes)
        if stream_name in self._sequence_tokens:
            kwargs["sequenceToken"] = self._sequence_tokens[stream_name]
        
        response = self.client.put_log_events(**kwargs)
        
        # Save next sequence token
        if "nextSequenceToken" in response:
            self._sequence_tokens[stream_name] = response["nextSequenceToken"]
    
    def query_logs(
        self,
        start_time: datetime,
        end_time: datetime,
        filter_pattern: str = "",
        limit: int = 100
    ) -> List[dict]:
        """
        Query audit logs with CloudWatch Insights.
        Very powerful — SQL-like query language.
        """
        
        # CloudWatch Insights query
        query = """
        fields @timestamp, event_type, user_id, ip_address, 
               cost_usd, status, policy_violations
        | filter @timestamp >= 1000000000
        | sort @timestamp desc
        | limit 100
        """
        
        if filter_pattern:
            query = f"{query} | filter {filter_pattern}"
        
        # Start query
        response = self.client.start_query(
            logGroupName=self.log_group,
            startTime=int(start_time.timestamp()),
            endTime=int(end_time.timestamp()),
            queryString=query,
            limit=limit
        )
        
        query_id = response['queryId']
        
        # Poll until complete
        while True:
            result = self.client.get_query_results(queryId=query_id)
            if result['status'] in ['Complete', 'Failed', 'Cancelled']:
                break
            time.sleep(0.5)
        
        # Parse results
        events = []
        for result in result.get('results', []):
            event = {}
            for field in result:
                event[field['field']] = field['value']
            events.append(event)
        
        return events
    
    def create_metric_filter(self):
        """
        Create CloudWatch metrics from log patterns.
        Enables alerts when bad things happen!
        """
        
        # Metric: Count policy violations
        self.client.put_metric_filter(
            logGroupName=self.log_group,
            filterName="PolicyViolations",
            filterPattern='{ $.event_type = "ai.policy.violation" }',
            metricTransformations=[{
                "metricName": "PolicyViolationCount",
                "metricNamespace": "AIApi/Safety",
                "metricValue": "1",
                "unit": "Count"
            }]
        )
        
        # Metric: Track costs
        self.client.put_metric_filter(
            logGroupName=self.log_group,
            filterName="RequestCost",
            filterPattern='{ $.event_type = "ai.chat.message" }',
            metricTransformations=[{
                "metricName": "RequestCostUSD",
                "metricNamespace": "AIApi/Costs",
                "metricValue": "$.cost_usd",
                "unit": "None"
            }]
        )
        
        # Metric: Security events
        self.client.put_metric_filter(
            logGroupName=self.log_group,
            filterName="SecurityEvents",
            filterPattern='{ $.event_type = "security.*" }',
            metricTransformations=[{
                "metricName": "SecurityEventCount",
                "metricNamespace": "AIApi/Security",
                "metricValue": "1",
                "unit": "Count"
            }]
        )
        
        print("✅ Metric filters created")
    
    def create_alarm(self, alarm_name: str, metric_name: str, threshold: float):
        """Create CloudWatch alarm for automatic alerting"""
        
        cloudwatch = boto3.client('cloudwatch')
        
        cloudwatch.put_metric_alarm(
            AlarmName=alarm_name,
            AlarmDescription=f"Alert when {metric_name} exceeds {threshold}",
            MetricName=metric_name,
            Namespace="AIApi/Safety",
            Statistic="Sum",
            Period=300,     # 5 minutes
            EvaluationPeriods=1,
            Threshold=threshold,
            ComparisonOperator="GreaterThanThreshold",
            AlarmActions=[
                "arn:aws:sns:us-east-1:123456789:ai-alerts"  # SNS topic
            ],
            TreatMissingData="notBreaching"
        )
```

# 🎤 INTERVIEW QUESTIONS & STRONG ANSWERS

---

### ❓ Q1: "Explain the difference between Authentication and Authorization with an AI API example."

**💪 Strong Answer:**

> "Authentication asks 'who are you?' — it's about verifying identity. In an AI API, this typically means validating a JWT token in the Authorization header. If the token is valid, we know who the user is.
>
> Authorization asks 'what can you do?' — it's about permissions. After knowing who the user is, we check if they have permission to perform the specific action they're requesting. For example, a user with a Free tier can chat, but cannot access the Advanced Analytics endpoint — that's authorization.
>
> In practice: a request comes in, we verify the JWT (authentication), extract the user's role and tier from the token claims, then check if those claims grant permission to the requested endpoint (authorization)."

---

### ❓ Q2: "How would you design a rate limiting system for an LLM API?"

**💪 Strong Answer:**

> "I'd design a multi-dimensional rate limiting system because LLM APIs have unique cost characteristics. Token usage varies wildly — a 100-token request and a 10,000-token request both count as 'one request' with naive counting but cost 100x different amounts.
>
> So I'd layer multiple limits: requests-per-minute to prevent burst abuse, requests-per-day as a daily quota, and critically, token-based limits using a Token Bucket algorithm where large requests consume proportionally more tokens from the bucket. I'd also add a daily cost ceiling as a final safety valve.
>
> These limits would vary by tier — Free users might get 5 requests/minute and 100K tokens/day; Enterprise might get 200 requests/minute and 50M tokens/day.
>
> Implementation would use Redis for distributed rate counting since multiple servers need shared state, and I'd use a sliding window rather than fixed window to prevent burst attacks at window boundaries."

---

### ❓ Q3: "What is JWT and why is it used for API authentication?"

**💪 Strong Answer:**

> "JWT — JSON Web Token — is a self-contained, signed token format. It has three parts: a header (algorithm info), a payload (user claims like user ID, role, permissions, expiry), and a signature that proves the token wasn't tampered with.
>
> It's used for API authentication because it's stateless — the server doesn't need to look up a session in a database for every request. The token itself contains all necessary information, and the signature proves it's genuine. This scales much better than session-based auth.
>
> For an AI API, I'd embed role, tier, permissions, and org ID in the JWT payload. When a request comes in, I verify the signature, check expiry, then use the embedded claims directly for authorization decisions — no database lookup needed."

---

### ❓ Q4: "What do you log in an AI system audit trail and why?"

**💪 Strong Answer:**

> "Audit logging in AI systems needs to balance completeness with privacy. I log: event type and timestamp for when; user ID, session ID, IP address, and org ID for who; endpoint and feature for what action; and for AI specifically — tokens used, cost, model used, latency, policy violations triggered, and whether content was filtered.
>
> Crucially, I do NOT log raw prompts or responses in plaintext — that would be a massive GDPR/HIPAA violation. Instead, I log SHA-256 hashes of the content. This lets you verify if a specific input was sent without storing the actual PII.
>
> Every log entry gets an integrity hash so tampering is detectable. IAM policies should deny even admins the ability to delete audit logs. Retention should meet compliance requirements — often 7 years for financial services.
>
> Practically, I'd send logs to CloudWatch with metric filters for real-time alerting on policy violations, security events, and cost anomalies."

---

### ❓ Q5: "What is the principle of least privilege and how does it apply to AI systems?"

**💪 Strong Answer:**

> "Least privilege means giving every component only the minimum permissions it needs — nothing more. If a service only needs to read S3, it should not have S3 write or delete.
>
> In AI systems, this applies at multiple levels. The application IAM role should only access specific S3 prefixes, specific CloudWatch log groups, and the secrets it actually needs — not all secrets, not all buckets. User JWT tokens should only embed permissions the user actually has, and we should never give 'admin' access just for convenience.
>
> The practical risk is 'privilege creep' — users accumulate permissions over time and they're never revoked. The fix is regular access reviews, automatic expiry of elevated permissions, and quarterly audits.
>
> In IAM specifically, I'd use resource-level restrictions and condition keys like requiring MFA for admin actions and restricting API calls to specific regions."

# 🔨 COMMON BEGINNER MISTAKES

```
❌ MISTAKE 1: Storing secrets in environment variables committed to git
→ API keys in .env files pushed to GitHub.
→ Bots scan GitHub for these in seconds.
✅ FIX: Use AWS Secrets Manager, Azure Key Vault, or GCP Secret Manager.
        Never commit secrets to code.

──────────────────────────────────────────────────────────────

❌ MISTAKE 2: Using the same JWT secret everywhere
→ One compromised service can forge tokens for all services.
✅ FIX: Different signing keys per service, rotate regularly,
        use asymmetric keys (RS256) for better security.

──────────────────────────────────────────────────────────────

❌ MISTAKE 3: In-memory rate limiting with multiple servers
→ Each server has its own counter.
→ User gets N requests per server, bypasses limits easily.
✅ FIX: Centralized Redis store for rate limit counters.
        All servers share the same state.

──────────────────────────────────────────────────────────────

❌ MISTAKE 4: Logging plaintext prompts
→ "User asked: 'My SSN is 123-45-6789, help me with taxes'"
→ Now your audit logs contain user PII.
→ Massive GDPR/HIPAA violation.
✅ FIX: Always hash content before logging.
        Log metadata (length, tokens) not content.

──────────────────────────────────────────────────────────────

❌ MISTAKE 5: No rate limiting on auth endpoints
→ Attacker tries 1 million password combinations.
→ Brute force succeeds eventually.
✅ FIX: Rate limit auth endpoints MORE strictly than regular endpoints.
        Lockout after N failed attempts. CAPTCHA. MFA.

──────────────────────────────────────────────────────────────

❌ MISTAKE 6: Never reviewing audit logs
→ Logs exist but nobody reads them.
→ Attack happens, logs have evidence, but nobody noticed.
✅ FIX: Set up metric filters, alarms, and dashboards.
        Weekly audit log review. Automated anomaly detection.

──────────────────────────────────────────────────────────────

❌ MISTAKE 7: Giving IAM roles to developers "temporarily"
→ "Just for this week" becomes permanent.
→ Privilege creep over months/years.
✅ FIX: All elevated access must have expiry dates.
        Quarterly access reviews mandatory.
        Just-In-Time (JIT) access for sensitive operations.
```
