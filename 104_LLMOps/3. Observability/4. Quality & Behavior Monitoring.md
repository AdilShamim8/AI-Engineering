## 🔬 SECTION 3: First-Principles Breakdown

### 🧱 Building Block 1: What Is a Hallucination at Its Core?

A hallucination is when an LLM generates text that:
1. **Sounds confident and authoritative**
2. **Is not grounded in any real knowledge**
3. **Cannot be verified against any source**
4. **May be completely fabricated**

```
Why do LLMs hallucinate?
─────────────────────────
LLMs are trained to predict the NEXT MOST LIKELY TOKEN.
They are NOT trained to be truthful.
They are NOT trained to say "I don't know."

From the model's perspective:
Input: "What is the capital of France?"
Output: "Paris" ← Correct, in training data

Input: "What is Dr. John Smith's phone number?"
Output: "555-0123" ← HALLUCINATED
                      (model generates plausible phone number
                       because that's what comes after phone numbers)

The model does NOT know the difference between 
"I know this" and "I'm making this up."
It's always just predicting likely next tokens.

This is why hallucinations feel so confident —
the model is generating high-probability text,
it just doesn't correspond to reality.
```

---

### 🧱 Building Block 2: Types of Hallucinations

```
Type 1: FACTUAL HALLUCINATION
──────────────────────────────
Model states false facts confidently.

Example:
User: "When was the Eiffel Tower built?"
AI: "The Eiffel Tower was built in 1892 
     by architect Pierre Moreau."

Truth: Built in 1889 by Gustave Eiffel.
       Two specific facts are wrong.

Type 2: ATTRIBUTION HALLUCINATION
───────────────────────────────────
Model invents fake sources, papers, or quotes.

Example:
User: "Find me research on LLM safety."
AI: "According to Dr. Sarah Chen's 2023 paper 
     'Neural Safety Metrics in Transformer Models' 
     published in Nature AI..."

Truth: This paper, this author, this journal 
       may not exist. Completely invented.
       The model learned "academic citation format"
       and filled in believable-sounding details.

Type 3: CONTEXT HALLUCINATION (Worst in RAG)
──────────────────────────────────────────────
Model ignores the retrieved context and 
answers from its training data instead.
Or WORSE: Makes up information that 
contradicts the retrieved context.

Example:
Retrieved doc: "Our return policy is 30 days."
User: "How many days do I have to return items?"
AI: "You have 90 days to return items." ← WRONG

The model ignored the correct context and 
used a different number from its training.

Type 4: INSTRUCTION HALLUCINATION
───────────────────────────────────
Model ignores your system prompt instructions.

System prompt: "Always respond in formal English."
User: "hey what's up?"
AI: "hey nothing much lol" ← Violated instruction

Type 5: REASONING HALLUCINATION
─────────────────────────────────
Model's chain of thought is wrong, 
leading to a wrong conclusion.

Question: "If I have 5 apples and give away 3, 
           then buy 7 more, how many do I have?"
AI thinking: "5 - 3 = 3, then 3 + 7 = 11"
AI answer: "You have 11 apples."
Truth: 5 - 3 = 2, then 2 + 7 = 9. WRONG.
```

### 🧱 Building Block 3: The RAG Quality Triangle

In RAG systems, quality has **3 distinct failure points:**

```
THE RAG QUALITY TRIANGLE

         Question
            ↓
    ┌───────────────┐
    │   RETRIEVAL   │ ← Failure Point 1
    │   QUALITY     │   "Did we find the RIGHT documents?"
    └───────┬───────┘
            ↓
    ┌───────────────┐
    │   CONTEXT     │ ← Failure Point 2
    │   RELEVANCE   │   "Are the right docs used in the answer?"
    └───────┬───────┘
            ↓
    ┌───────────────┐
    │   ANSWER      │ ← Failure Point 3
    │   FAITHFULNESS│   "Does the answer match the docs?"
    └───────────────┘
            ↓
         Answer

Each point has its own metrics:
Retrieval Quality  → Retrieval precision, recall, MRR
Context Relevance  → Context utilization score
Answer Faithfulness → Groundedness score (does answer come from context?)

The famous RAG evaluation framework RAGAS measures all 3.
```

## 🏛️ COMPONENT 1: Hallucination Tracking

### The 3 Core Hallucination Detection Techniques

```
Technique 1: GROUNDEDNESS CHECK (Best for RAG)
────────────────────────────────────────────────
Question: "Does the answer come from the retrieved context?"

How it works:
1. Take the AI's response
2. Take the retrieved documents
3. Ask: "Is every claim in the response supported by the docs?"

Example:
Retrieved doc: "The product costs $49.99 and ships in 3-5 days."
AI response:   "The product costs $49.99, ships in 3-5 days, 
                and has a 2-year warranty."

Groundedness check:
"$49.99" → ✅ Found in doc
"3-5 days" → ✅ Found in doc
"2-year warranty" → ❌ NOT in doc → HALLUCINATION DETECTED!

Score: 2/3 claims grounded = 0.67 groundedness score

Technique 2: NLI (Natural Language Inference)
──────────────────────────────────────────────
A classification model determines if the response
is ENTAILED by the context (supported),
CONTRADICTS the context (wrong), or
NEUTRAL (not mentioned either way).

Source: "The store closes at 8pm."
Claim:  "The store closes at 9pm."
→ CONTRADICTION → Hallucination!

Claim: "The store has a parking lot."
→ NEUTRAL → Neither confirmed nor denied (potential hallucination)

Technique 3: LLM-AS-JUDGE
───────────────────────────
Use a powerful LLM (GPT-4) to evaluate 
if another LLM's response is grounded.

Prompt to judge:
"Given this context: [context]
 And this response: [response]
 
 Rate the factual accuracy on a scale 0-1.
 Identify any claims NOT supported by the context.
 Format: {score: float, unsupported_claims: [list]}"

Advantages:
→ Understands nuance and paraphrase
→ Can explain WHY something is a hallucination
→ Works for any domain

Disadvantages:
→ Expensive (costs tokens)
→ May itself hallucinate (meta-problem!)
→ Slower than rule-based checks
```

### Hallucination Detection — Complete Implementation

```python
import re
import json
from typing import Optional
from openai import OpenAI
from dataclasses import dataclass
from sentence_transformers import CrossEncoder

@dataclass
class HallucinationResult:
    """Result of one hallucination check"""
    is_hallucination: bool
    confidence: float          # 0.0 to 1.0 (how confident are we?)
    groundedness_score: float  # 0.0 = not grounded, 1.0 = fully grounded
    unsupported_claims: list   # Specific claims not in the context
    method_used: str           # Which detection method was used
    explanation: str           # Human-readable explanation

class HallucinationDetector:
    """
    Multi-method hallucination detection.
    Uses multiple signals for higher confidence.
    """
    
    def __init__(self):
        self.openai_client = OpenAI()
        
        # NLI model for fast local checking
        # Cross-encoder rates: CONTRADICTION / NEUTRAL / ENTAILMENT
        try:
            self.nli_model = CrossEncoder(
                "cross-encoder/nli-deberta-v3-small"
            )
        except Exception:
            self.nli_model = None
            print("⚠️ NLI model not loaded. Using LLM-only detection.")
    
    # ═══ METHOD 1: FAST RULE-BASED CHECK ═══
    
    def check_numerical_consistency(
        self,
        context: str,
        response: str
    ) -> dict:
        """
        Extract all numbers from context and response.
        Check if numbers in response appear in context.
        Fast: no LLM needed.
        """
        
        # Extract all numbers (including decimals, percentages, dates)
        context_numbers = set(
            re.findall(r'\b\d+\.?\d*%?\b', context)
        )
        response_numbers = set(
            re.findall(r'\b\d+\.?\d*%?\b', response)
        )
        
        # Numbers in response but NOT in context = potential hallucination
        suspicious_numbers = response_numbers - context_numbers
        
        # Filter out common harmless numbers (1, 2, 3, etc.)
        significant_suspicious = {
            n for n in suspicious_numbers
            if float(n.replace('%', '')) > 9  # Numbers > 9 are more likely to be facts
        }
        
        return {
            "has_numerical_hallucination": len(significant_suspicious) > 0,
            "suspicious_numbers": list(significant_suspicious),
            "context_numbers": list(context_numbers),
            "response_numbers": list(response_numbers)
        }
    
    # ═══ METHOD 2: NLI-BASED CHECK ═══
    
    def check_nli_entailment(
        self,
        context: str,
        response: str
    ) -> dict:
        """
        Use NLI model to check if response is entailed by context.
        Returns contradiction probability.
        Fast: local model, no API cost.
        """
        
        if not self.nli_model:
            return {"available": False}
        
        # Split response into sentences for granular checking
        sentences = [s.strip() for s in response.split('.') if len(s.strip()) > 20]
        
        results = []
        for sentence in sentences:
            # NLI: Does the context ENTAIL this sentence?
            scores = self.nli_model.predict([(context, sentence)])
            
            # Labels: 0=contradiction, 1=neutral, 2=entailment
            label = scores.argmax()
            confidence = scores.max()
            
            results.append({
                "sentence": sentence,
                "verdict": ["contradiction", "neutral", "entailment"][label],
                "confidence": float(confidence),
                "is_contradiction": label == 0
            })
        
        contradictions = [r for r in results if r["is_contradiction"]]
        
        return {
            "sentence_results": results,
            "contradictions_found": len(contradictions),
            "contradiction_sentences": contradictions,
            "entailment_rate": (
                sum(1 for r in results if r["verdict"] == "entailment")
                / len(results) if results else 0
            )
        }
    
    # ═══ METHOD 3: LLM-AS-JUDGE ═══
    
    async def check_llm_judge(
        self,
        question: str,
        context: str,
        response: str,
        model: str = "gpt-4o"
    ) -> dict:
        """
        Use GPT-4o as a judge to evaluate hallucination.
        Most powerful but most expensive.
        Use on sampled subset of production traffic.
        """
        
        judge_prompt = f"""You are a rigorous fact-checker for an AI system.

Your task: Determine if the AI's RESPONSE is factually grounded 
in the provided CONTEXT.

QUESTION:
{question}

CONTEXT (the only source of truth):
{context}

AI RESPONSE:
{response}

Analyze each claim in the RESPONSE:
1. Is the claim explicitly stated in the CONTEXT? → SUPPORTED
2. Is the claim contradicted by the CONTEXT? → CONTRADICTED (hallucination!)
3. Is the claim not mentioned in the CONTEXT? → UNSUPPORTED (potential hallucination)

Respond with ONLY valid JSON:
{{
  "groundedness_score": <float 0.0-1.0>,
  "verdict": "<GROUNDED|PARTIALLY_GROUNDED|HALLUCINATED>",
  "supported_claims": ["claim1", "claim2"],
  "unsupported_claims": ["claim3"],
  "contradicted_claims": ["claim4"],
  "explanation": "<brief explanation>",
  "confidence": <float 0.0-1.0>
}}"""
        
        response_obj = self.openai_client.chat.completions.create(
            model=model,
            messages=[{"role": "user", "content": judge_prompt}],
            temperature=0,         # Deterministic for evaluation
            response_format={"type": "json_object"}
        )
        
        result = json.loads(response_obj.choices[0].message.content)
        
        return {
            "groundedness_score": result.get("groundedness_score", 0.5),
            "verdict": result.get("verdict", "UNKNOWN"),
            "supported_claims": result.get("supported_claims", []),
            "unsupported_claims": result.get("unsupported_claims", []),
            "contradicted_claims": result.get("contradicted_claims", []),
            "explanation": result.get("explanation", ""),
            "confidence": result.get("confidence", 0.5),
            "judge_model": model,
            "judge_tokens": response_obj.usage.total_tokens
        }
    
    # ═══ COMBINED: MULTI-METHOD CHECK ═══
    
    async def detect(
        self,
        question: str,
        context: str,
        response: str,
        use_llm_judge: bool = True
    ) -> HallucinationResult:
        """
        Run all detection methods and combine results.
        
        Strategy:
        - Always run fast rule-based checks (cheap)
        - Always run NLI if model is available (cheap)
        - Run LLM judge on sampled subset or when fast checks flag issues
        """
        
        signals = []
        all_unsupported = []
        
        # Fast check 1: Numerical consistency
        numerical = self.check_numerical_consistency(context, response)
        if numerical["has_numerical_hallucination"]:
            signals.append({
                "method": "numerical",
                "flag": True,
                "weight": 0.7,
                "evidence": numerical["suspicious_numbers"]
            })
            all_unsupported.extend([
                f"Number {n} not in context"
                for n in numerical["suspicious_numbers"]
            ])
        
        # Fast check 2: NLI
        nli_result = self.check_nli_entailment(context, response)
        if nli_result.get("available", True):
            nli_contradictions = nli_result.get("contradictions_found", 0)
            if nli_contradictions > 0:
                signals.append({
                    "method": "nli",
                    "flag": True,
                    "weight": 0.8,
                    "evidence": nli_result["contradiction_sentences"]
                })
        
        # LLM Judge (optional, expensive)
        llm_result = None
        if use_llm_judge:
            llm_result = await self.check_llm_judge(
                question, context, response
            )
            groundedness = llm_result["groundedness_score"]
            unsupported = llm_result["unsupported_claims"]
            contradicted = llm_result["contradicted_claims"]
            
            all_unsupported.extend(unsupported)
            all_unsupported.extend(contradicted)
            
            if groundedness < 0.7 or contradicted:
                signals.append({
                    "method": "llm_judge",
                    "flag": True,
                    "weight": 1.0,  # Highest weight
                    "evidence": unsupported + contradicted
                })
        
        # Combine signals into final verdict
        if not signals:
            final_score = llm_result["groundedness_score"] if llm_result else 1.0
            is_hallucination = False
            confidence = 0.9
            explanation = "No hallucination signals detected."
        else:
            # Weighted average of flagging signals
            total_weight = sum(s["weight"] for s in signals)
            flag_weight = sum(
                s["weight"] for s in signals if s["flag"]
            )
            flag_ratio = flag_weight / total_weight if total_weight > 0 else 0
            
            final_score = llm_result["groundedness_score"] if llm_result else (1 - flag_ratio)
            is_hallucination = final_score < 0.7
            confidence = min(0.95, 0.5 + flag_ratio * 0.5)
            explanation = (
                f"{len(signals)} detection methods flagged issues. "
                f"Groundedness: {final_score:.2f}"
            )
        
        return HallucinationResult(
            is_hallucination=is_hallucination,
            confidence=confidence,
            groundedness_score=final_score,
            unsupported_claims=list(set(all_unsupported)),
            method_used="+".join(s["method"] for s in signals) or "all_clear",
            explanation=explanation
        )
```

### Hallucination Rate Tracking Dashboard

```python
from collections import deque, defaultdict
from datetime import datetime
import statistics

class HallucinationRateTracker:
    """
    Track hallucination rates over time.
    Detect trends, spikes, and patterns.
    """
    
    def __init__(self, window_hours: int = 24):
        self.window_seconds = window_hours * 3600
        self.detections: deque = deque()
        self.by_feature: dict = defaultdict(deque)
        self.by_model: dict = defaultdict(deque)
    
    def record(
        self,
        is_hallucination: bool,
        groundedness_score: float,
        feature: str,
        model: str,
        trace_id: str
    ):
        record = {
            "timestamp": datetime.now().timestamp(),
            "is_hallucination": is_hallucination,
            "groundedness_score": groundedness_score,
            "feature": feature,
            "model": model,
            "trace_id": trace_id
        }
        
        self.detections.append(record)
        self.by_feature[feature].append(record)
        self.by_model[model].append(record)
        
        self._clean_old_records()
    
    def _clean_old_records(self):
        cutoff = datetime.now().timestamp() - self.window_seconds
        
        while self.detections and self.detections[0]["timestamp"] < cutoff:
            self.detections.popleft()
        
        for key in list(self.by_feature.keys()):
            while (self.by_feature[key] and
                   self.by_feature[key][0]["timestamp"] < cutoff):
                self.by_feature[key].popleft()
        
        for key in list(self.by_model.keys()):
            while (self.by_model[key] and
                   self.by_model[key][0]["timestamp"] < cutoff):
                self.by_model[key].popleft()
    
    def get_report(self) -> dict:
        records = list(self.detections)
        
        if not records:
            return {"status": "no_data"}
        
        total = len(records)
        hallucinations = sum(1 for r in records if r["is_hallucination"])
        rate = (hallucinations / total) * 100
        
        scores = [r["groundedness_score"] for r in records]
        
        # Per-feature breakdown
        feature_breakdown = {}
        for feature, feat_records in self.by_feature.items():
            feat_list = list(feat_records)
            feat_total = len(feat_list)
            feat_hall = sum(1 for r in feat_list if r["is_hallucination"])
            feature_breakdown[feature] = {
                "hallucination_rate_pct": round(
                    (feat_hall / feat_total) * 100, 2
                ) if feat_total > 0 else 0,
                "total_checks": feat_total,
                "avg_groundedness": round(
                    statistics.mean([r["groundedness_score"] 
                                    for r in feat_list]), 3
                )
            }
        
        # Alert level
        if rate >= 20:
            alert = "🔴 CRITICAL — Hallucination rate dangerously high"
        elif rate >= 10:
            alert = "🟠 HIGH — Significant hallucination problem"
        elif rate >= 5:
            alert = "🟡 MODERATE — Worth investigating"
        else:
            alert = "🟢 HEALTHY — Hallucination rate acceptable"
        
        return {
            "window_hours": self.window_seconds / 3600,
            "total_checks": total,
            "hallucination_count": hallucinations,
            "hallucination_rate_pct": round(rate, 2),
            "avg_groundedness_score": round(statistics.mean(scores), 3),
            "min_groundedness_score": round(min(scores), 3),
            "alert_level": alert,
            "by_feature": feature_breakdown,
            "worst_feature": max(
                feature_breakdown,
                key=lambda f: feature_breakdown[f]["hallucination_rate_pct"],
                default=None
            )
        }
```

## 🏛️ COMPONENT 2: Output Validation Failures

### What Is Output Validation?

Output validation is checking that the AI's response:
1. **Follows the format you specified** (JSON, markdown, etc.)
2. **Contains required information** (no missing fields)
3. **Meets length requirements** (not too short, not too long)
4. **Follows business rules** (no competitor names, no PII)
5. **Makes semantic sense** (not gibberish, not off-topic)

```
The difference between hallucination checking and output validation:

Hallucination:  "Is the content FACTUALLY TRUE?"
Output Validation: "Is the content in the RIGHT FORM?"

You need BOTH.

Example:
Response: {"status": "done", "price": "twenty dollars"}

Hallucination check: Is the price accurate? 
Output validation:   Should price be a number, not a string!
                     {"price": 20.00} is correct format
                     {"price": "twenty dollars"} FAILS validation
```

class RelevanceValidator(BaseValidator):
    """Check if response actually answers the question"""
    name = "relevance_check"
    severity = "warning"
    
    def __init__(self, threshold: float = 0.5):
        self.threshold = threshold
        try:
            from sentence_transformers import SentenceTransformer
            self.model = SentenceTransformer("all-MiniLM-L6-v2")
        except Exception:
            self.model = None
    
    def validate(self, response: str, context: dict) -> ValidationResult:
        question = context.get("question", "")
        
        if not question or not self.model:
            return ValidationResult(
                passed=True,
                validator_name=self.name,
                severity="info",
                message="Relevance check skipped (no question or model)"
            )
        
        # Encode question and response
        import numpy as np
        q_embedding = self.model.encode([question])[0]
        r_embedding = self.model.encode([response])[0]
        
        # Cosine similarity
        similarity = np.dot(q_embedding, r_embedding) / (
            np.linalg.norm(q_embedding) * np.linalg.norm(r_embedding)
        )
        
        if similarity < self.threshold:
            return ValidationResult(
                passed=False,
                validator_name=self.name,
                severity="warning",
                message=(
                    f"Response may be irrelevant: "
                    f"similarity={similarity:.3f} < {self.threshold}"
                ),
                details={
                    "similarity_score": float(similarity),
                    "threshold": self.threshold,
                    "question_preview": question[:100]
                }
            )
        
        return ValidationResult(
            passed=True,
            validator_name=self.name,
            severity=self.severity,
            message=f"Response is relevant: similarity={similarity:.3f}",
            details={"similarity_score": float(similarity)}
        )

@dataclass
class ValidationReport:
    """Complete validation report for one response"""
    overall_passed: bool
    total_checks: int
    passed_checks: int
    failed_checks: int
    warning_checks: int
    critical_failures: list[ValidationResult]
    warnings: list[ValidationResult]
    all_results: list[ValidationResult]
    should_serve: bool      # Should this response be sent to user?
    should_retry: bool      # Should we retry the LLM call?
    failure_reason: str     # Human-readable summary

class ValidationPipeline:
    """
    Orchestrate all validators in sequence.
    Decide whether to serve, retry, or fallback.
    Track all failures for monitoring.
    """
    
    def __init__(self, validators: list[BaseValidator]):
        self.validators = validators
        self.failure_history: deque = deque(maxlen=10_000)
    
    def validate(
        self,
        response: str,
        context: dict,
        stop_on_critical: bool = True
    ) -> ValidationReport:
        """
        Run all validators and produce a comprehensive report.
        """
        
        results = []
        critical_failures = []
        warnings = []
        
        for validator in self.validators:
            try:
                result = validator.validate(response, context)
                results.append(result)
                
                if not result.passed:
                    if result.severity == "error":
                        critical_failures.append(result)
                        
                        # Stop early on critical failures (optional)
                        if stop_on_critical:
                            break
                    else:
                        warnings.append(result)
                        
            except Exception as e:
                # Never let a validator crash the pipeline
                results.append(ValidationResult(
                    passed=False,
                    validator_name=validator.name,
                    severity="error",
                    message=f"Validator crashed: {str(e)}",
                    details={"exception": str(e)}
                ))
        
        passed = sum(1 for r in results if r.passed)
        overall_passed = len(critical_failures) == 0
        
        # Decide action
        if critical_failures:
            should_serve = False
            should_retry = any(
                "too short" in f.message.lower() or
                "invalid json" in f.message.lower()
                for f in critical_failures
            )
            failure_reason = "; ".join(f.message for f in critical_failures)
        elif warnings:
            should_serve = True   # Serve but log warnings
            should_retry = False
            failure_reason = f"{len(warnings)} warnings"
        else:
            should_serve = True
            should_retry = False
            failure_reason = ""
        
        report = ValidationReport(
            overall_passed=overall_passed,
            total_checks=len(results),
            passed_checks=passed,
            failed_checks=len(results) - passed,
            warning_checks=len(warnings),
            critical_failures=critical_failures,
            warnings=warnings,
            all_results=results,
            should_serve=should_serve,
            should_retry=should_retry,
            failure_reason=failure_reason
        )
        
        # Track for monitoring
        self.failure_history.append({
            "timestamp": time.time(),
            "overall_passed": overall_passed,
            "failed_validators": [
                f.validator_name for f in critical_failures
            ],
            "warning_validators": [
                w.validator_name for w in warnings
            ]
        })
        
        return report
    
    def get_failure_rate_report(self) -> dict:
        """Analyze which validators fail most often"""
        
        history = list(self.failure_history)
        if not history:
            return {"status": "no_data"}
        
        total = len(history)
        failures = [h for h in history if not h["overall_passed"]]
        
        # Count per-validator failures
        validator_failures = defaultdict(int)
        validator_warnings = defaultdict(int)
        
        for h in history:
            for v in h["failed_validators"]:
                validator_failures[v] += 1
            for v in h["warning_validators"]:
                validator_warnings[v] += 1
        
        return {
            "total_validations": total,
            "overall_failure_rate_pct": round(
                len(failures) / total * 100, 2
            ),
            "validator_failure_rates": {
                v: round(count / total * 100, 2)
                for v, count in sorted(
                    validator_failures.items(),
                    key=lambda x: x[1],
                    reverse=True
                )
            },
            "most_common_failure": max(
                validator_failures,
                key=validator_failures.get,
                default=None
            )
        }

## 🏛️ COMPONENT 3: Guardrail Trigger Rate Monitoring

### What Are Guardrails?

Guardrails are **safety mechanisms** that intercept AI inputs or outputs and:
1. **Block** harmful content from reaching users
2. **Modify** borderline content to be safer
3. **Redirect** off-topic requests back to the intended use case
4. **Alert** your team when safety issues occur

```
Guardrail Types:
─────────────────────────────────────────────────────

INPUT GUARDRAILS (check user message BEFORE LLM):
→ Prompt injection detection
→ Toxic input blocking
→ Off-topic request filtering
→ Rate limiting abusive users
→ PII detection in user input

OUTPUT GUARDRAILS (check LLM response BEFORE user):
→ Harmful content detection
→ Hallucination blocking
→ Business rule enforcement
→ Competitor name removal
→ PII leak prevention
→ Copyright violation detection

SYSTEM GUARDRAILS (protect the system):
→ System prompt protection
→ Jailbreak attempt detection
→ Role confusion prevention
→ Context window overflow prevention
```

### Guardrail Trigger Rate — Why Monitor It?

```
Most teams think about guardrails as "set it and forget it."
This is a MISTAKE.

Guardrail trigger rate tells you CRITICAL things:

High trigger rate on "toxic content":
→ Your app is attracting bad actors
→ Or your AI is generating toxic content unprompted
→ Needs investigation

Suddenly ZERO trigger rate:
→ Your guardrails might be BROKEN
→ Nothing is getting blocked even when it should be
→ Silent failure of safety system

High trigger rate on "off-topic":
→ Users want something your app doesn't support
→ Product opportunity or need for clearer UX

Increasing trigger rate over time:
→ Model behavior is drifting
→ Adversarial users learning to bypass
→ New attack patterns emerging

Per-user trigger rate spikes:
→ Specific user is probing for vulnerabilities
→ Potential security threat
→ Needs immediate review
```

from typing import Optional

class GuardrailAction(Enum):
    ALLOW   = "allow"     # Pass through unchanged
    BLOCK   = "block"     # Block completely, return error
    MODIFY  = "modify"    # Alter the content, pass modified version
    FLAG    = "flag"      # Allow but flag for review
    REDIRECT = "redirect" # Redirect to a different response

@dataclass
class GuardrailTrigger:
    """Record of one guardrail activation"""
    guardrail_name: str
    action_taken: GuardrailAction
    trigger_reason: str
    confidence: float
    user_id: str
    trace_id: str
    timestamp: float
    input_preview: str     # Sanitized preview of what triggered it
    category: str          # "safety", "quality", "business_rule"
    severity: str          # "low", "medium", "high", "critical"

@dataclass  
class GuardrailResult:
    """Result of applying all guardrails to one input/output"""
    should_block: bool
    modified_content: Optional[str]  # If modified, what it became
    triggers: list[GuardrailTrigger]
    final_action: GuardrailAction
    processing_time_ms: float


class GuardrailMonitor:
    """Track all guardrail triggers for analysis"""
    
    def __init__(self, window_hours: int = 24):
        self.window_seconds = window_hours * 3600
        self.all_triggers: deque = deque()
        self.by_guardrail: dict = defaultdict(deque)
        self.by_user: dict = defaultdict(deque)
        self.by_category: dict = defaultdict(deque)
    
    def record_trigger(self, trigger: GuardrailTrigger):
        self.all_triggers.append(trigger)
        self.by_guardrail[trigger.guardrail_name].append(trigger)
        self.by_user[trigger.user_id].append(trigger)
        self.by_category[trigger.category].append(trigger)
        self._clean_old()
    
    def _clean_old(self):
        cutoff = time.time() - self.window_seconds
        
        def clean_deque(d):
            while d and d[0].timestamp < cutoff:
                d.popleft()
        
        clean_deque(self.all_triggers)
        for d in self.by_guardrail.values():
            clean_deque(d)
        for d in self.by_user.values():
            clean_deque(d)
        for d in self.by_category.values():
            clean_deque(d)
    
    def get_report(self, total_requests: int = None) -> dict:
        triggers = list(self.all_triggers)
        
        if not triggers:
            return {"status": "no_triggers_in_window"}
        
        total_triggers = len(triggers)
        
        # Trigger rate per guardrail
        by_guardrail = {}
        for name, guard_triggers in self.by_guardrail.items():
            guard_list = list(guard_triggers)
            by_guardrail[name] = {
                "trigger_count": len(guard_list),
                "block_count": sum(
                    1 for t in guard_list
                    if t.action_taken == GuardrailAction.BLOCK
                ),
                "categories": list(set(t.category for t in guard_list)),
                "avg_confidence": sum(t.confidence for t in guard_list) / len(guard_list)
            }
        
        # Most triggered guardrail
        most_triggered = max(
            by_guardrail,
            key=lambda g: by_guardrail[g]["trigger_count"]
        ) if by_guardrail else None
        
        # Suspicious users (many triggers)
        user_trigger_counts = {
            user: len(list(user_triggers))
            for user, user_triggers in self.by_user.items()
        }
        suspicious_users = [
            user for user, count in user_trigger_counts.items()
            if count >= 5  # 5+ triggers from same user = suspicious
        ]
        
        # Trigger rate (if total requests known)
        trigger_rate = None
        if total_requests and total_requests > 0:
            trigger_rate = (total_triggers / total_requests) * 100
        
        return {
            "window_hours": self.window_seconds / 3600,
            "total_triggers": total_triggers,
            "trigger_rate_pct": trigger_rate,
            "by_action": {
                action.value: sum(
                    1 for t in triggers
                    if t.action_taken == action
                )
                for action in GuardrailAction
            },
            "by_category": {
                cat: len(list(cat_triggers))
                for cat, cat_triggers in self.by_category.items()
            },
            "by_guardrail": by_guardrail,
            "most_triggered_guardrail": most_triggered,
            "suspicious_users": suspicious_users,
            "critical_triggers": sum(
                1 for t in triggers if t.severity == "critical"
            )
        }

                    category=self.category,
                    severity="critical"
                )
                triggers.append(trigger)
                self.monitor.record_trigger(trigger)
        
        duration_ms = (time.perf_counter() - start) * 1000
        
        should_block = len(triggers) > 0
        
        return GuardrailResult(
            should_block=should_block,
            modified_content=None,
            triggers=triggers,
            final_action=GuardrailAction.BLOCK if should_block else GuardrailAction.ALLOW,
            processing_time_ms=duration_ms
        )


class PromptInjectionGuardrail:
    """Detect and block prompt injection attempts"""
    
    name = "prompt_injection_detector"
    category = "security"
    
    INJECTION_PATTERNS = [
        r'ignore\s+(all\s+)?previous\s+instructions',
        r'disregard\s+(your\s+)?(system\s+)?prompt',
        r'you\s+are\s+now\s+(a\s+)?(?:different|new|evil|dan)',
        r'pretend\s+(you\s+are|to\s+be)',
        r'act\s+as\s+if\s+you\s+(have\s+no|don\'t\s+have)',
        r'jailbreak',
        r'developer\s+mode',
        r'do\s+anything\s+now',
        r'\[system\]',
        r'<\|im_start\|>',  # OpenAI special tokens
    ]
    
    def __init__(self, monitor: GuardrailMonitor):
        self.monitor = monitor
    
    async def check_input(
        self,
        user_message: str,
        trace_id: str,
        user_id: str
    ) -> GuardrailResult:
        
        start = time.perf_counter()
        triggers = []
        
        message_lower = user_message.lower()
        
        for pattern in self.INJECTION_PATTERNS:
            if re.search(pattern, message_lower, re.IGNORECASE):
                trigger = GuardrailTrigger(
                    guardrail_name=self.name,
                    action_taken=GuardrailAction.BLOCK,
                    trigger_reason=f"Prompt injection pattern: {pattern}",
                    confidence=0.90,
                    user_id=user_id,
                    trace_id=trace_id,
                    timestamp=time.time(),
                    input_preview=user_message[:80] + "...",
                    category=self.category,
                    severity="high"
                )
                triggers.append(trigger)
                self.monitor.record_trigger(trigger)
        
        duration_ms = (time.perf_counter() - start) * 1000
        should_block = len(triggers) > 0
        
        return GuardrailResult(
            should_block=should_block,
            modified_content=None,
            triggers=triggers,
            final_action=GuardrailAction.BLOCK if should_block else GuardrailAction.ALLOW,
            processing_time_ms=duration_ms
        )


class TopicBoundaryGuardrail:
    """Keep AI focused on its intended purpose"""
    
    name = "topic_boundary"
    category = "business_rule"
    
    OFF_TOPIC_REDIRECT = (
        "I'm specialized in customer support for our products. "
        "For this type of question, I'd recommend consulting "
        "a relevant expert. Is there anything about our products "
        "I can help you with?"
    )
    
    def __init__(
        self,
        allowed_topics: list[str],
        monitor: GuardrailMonitor
    ):
        self.allowed_topics = allowed_topics
        self.monitor = monitor
    
    async def check_input(
        self,
        user_message: str,
        trace_id: str,
        user_id: str
    ) -> GuardrailResult:
        
        # Simple topic check (use intent classifier in production)
        is_off_topic = not any(
            topic.lower() in user_message.lower()
            for topic in self.allowed_topics
        )
        
        # Use LLM to classify in production:
        # is_off_topic = await classify_intent(user_message, self.allowed_topics)
        
        if is_off_topic and len(user_message) > 20:
            trigger = GuardrailTrigger(
                guardrail_name=self.name,
                action_taken=GuardrailAction.REDIRECT,
                trigger_reason="Message appears off-topic",
                confidence=0.6,
                user_id=user_id,
                trace_id=trace_id,
                timestamp=time.time(),
                input_preview=user_message[:80],
                category=self.category,
                severity="low"
            )
            self.monitor.record_trigger(trigger)
            
            return GuardrailResult(
                should_block=True,
                modified_content=self.OFF_TOPIC_REDIRECT,
                triggers=[trigger],
                final_action=GuardrailAction.REDIRECT,
                processing_time_ms=0
            )
        
        return GuardrailResult(
            should_block=False,
            modified_content=None,
            triggers=[],
            final_action=GuardrailAction.ALLOW,
            processing_time_ms=0
        )


# ═══ GUARDRAIL ORCHESTRATOR ═══

class GuardrailOrchestrator:
    """
    Apply all guardrails in the right order.
    Complete pipeline: input → LLM → output
    """
    
    def __init__(self):
        self.monitor = GuardrailMonitor(window_hours=24)
        
        # Initialize all guardrails
        self.injection_guard = PromptInjectionGuardrail(self.monitor)
        self.topic_guard = TopicBoundaryGuardrail(
            allowed_topics=["product", "order", "return", "shipping", "support"],
            monitor=self.monitor
        )
        self.toxicity_guard = ToxicityGuardrail(self.monitor)
    
    async def check_input(
        self,
        user_message: str,
        user_id: str,
        trace_id: str
    ) -> tuple[bool, Optional[str], list]:
        """
        Check user input BEFORE sending to LLM.
        Returns: (should_proceed, override_response, triggers)
        """
        
        all_triggers = []
        
        # 1. Check for prompt injection (CRITICAL — check first)
        injection_result = await self.injection_guard.check_input(
            user_message, trace_id, user_id
        )
        all_triggers.extend(injection_result.triggers)
        
        if injection_result.should_block:
            return False, "I'm unable to process that request.", all_triggers
        
        # 2. Check topic boundary
        topic_result = await self.topic_guard.check_input(
            user_message, trace_id, user_id
        )
        all_triggers.extend(topic_result.triggers)
        
        if topic_result.should_block:
            return False, topic_result.modified_content, all_triggers
        
        return True, None, all_triggers
    
    async def check_output(
        self,
        llm_response: str,
        user_id: str,
        trace_id: str
    ) -> tuple[bool, str, list]:
        """
        Check LLM output BEFORE sending to user.
        Returns: (should_serve, final_response, triggers)
        """
        
        all_triggers = []
        current_response = llm_response
        
        # Check toxicity
        toxicity_result = await self.toxicity_guard.check_output(
            current_response, trace_id, user_id
        )
        all_triggers.extend(toxicity_result.triggers)
        
        if toxicity_result.should_block:
            return False, "I'm unable to provide that response.", all_triggers
        
        return True, current_response, all_triggers
    
    async def process_full_request(
        self,
        user_message: str,
        llm_func,
        user_id: str = "anonymous"
    ) -> dict:
        """
        Full request pipeline with guardrails at both ends.
        """
        
        trace_id = str(uuid.uuid4())
        all_triggers = []
        
        # INPUT GUARDRAILS
        should_proceed, override, input_triggers = await self.check_input(
            user_message, user_id, trace_id
        )
        all_triggers.extend(input_triggers)
        
        if not should_proceed:
            return {
                "response": override,
                "blocked": True,
                "block_stage": "input",
                "triggers": len(all_triggers),
                "trace_id": trace_id
            }
        
        # LLM CALL
        try:
            llm_response = await llm_func(user_message)
        except Exception as e:
            return {
                "response": "I encountered an error. Please try again.",
                "error": str(e),
                "trace_id": trace_id
            }
        
        # OUTPUT GUARDRAILS
        should_serve, final_response, output_triggers = await self.check_output(
            llm_response, user_id, trace_id
        )
        all_triggers.extend(output_triggers)
        
        if not should_serve:
            return {
                "response": final_response,
                "blocked": True,
                "block_stage": "output",
                "triggers": len(all_triggers),
                "trace_id": trace_id
            }
        
        return {
            "response": final_response,
            "blocked": False,
            "triggers": len(all_triggers),
            "guardrail_triggers": [
                {
                    "name": t.guardrail_name,
                    "action": t.action_taken.value,
                    "severity": t.severity
                }
                for t in all_triggers
            ],
            "trace_id": trace_id
        }

### 🔧 Tool 1: RAG Evaluation Frameworks (RAGAS)

**What it is:** RAGAS (Retrieval Augmented Generation Assessment) is the **standard framework** for evaluating RAG systems across multiple quality dimensions.

```
RAGAS evaluates 4 core metrics:

Metric 1: ANSWER FAITHFULNESS
─────────────────────────────
"Does the answer only use information from the retrieved context?"

Score: 0.0 to 1.0
1.0 = Every single claim in the answer is backed by the context
0.0 = Answer is completely fabricated

Formula:
faithfulness = (supported claims) / (total claims in answer)

Metric 2: ANSWER RELEVANCE
────────────────────────────
"Does the answer actually address the question?"

Score: 0.0 to 1.0
Method: Generate questions from the answer, 
        check if they match the original question.
1.0 = Answer perfectly addresses the question
0.0 = Answer is completely irrelevant

Metric 3: CONTEXT PRECISION
─────────────────────────────
"Are the retrieved documents actually useful?"

Score: 0.0 to 1.0
1.0 = All retrieved documents are relevant
0.0 = All retrieved documents are irrelevant

Formula:
precision = (relevant retrieved docs) / (total retrieved docs)

Metric 4: CONTEXT RECALL
──────────────────────────
"Did we retrieve all the necessary documents?"

Score: 0.0 to 1.0
1.0 = All information needed is in retrieved docs
0.0 = Retrieved docs don't contain needed information

Formula:
recall = (claims in answer supported by context) / (total claims in ground truth)
```

class ProductionRAGEvaluator:
    """
    Run RAGAS evaluation on sampled production traffic.
    Track quality metrics over time.
    """
    
    def __init__(self, sample_rate: float = 0.05):
        """
        sample_rate: Evaluate 5% of production requests.
        This balances cost vs coverage.
        """
        self.sample_rate = sample_rate
        self.eval_llm = ChatOpenAI(model="gpt-4o", temperature=0)
        self.eval_embeddings = OpenAIEmbeddings()
        
        # Buffer of requests to evaluate
        self.eval_buffer = []
        self.buffer_size = 20  # Evaluate in batches of 20
        
        # Historical scores
        self.score_history = deque(maxlen=1000)
    
    def should_evaluate(self) -> bool:
        """Determine if this request should be sampled for evaluation"""
        import random
        return random.random() < self.sample_rate
    
    def add_to_buffer(
        self,
        question: str,
        contexts: list[str],
        answer: str,
        trace_id: str
    ):
        """Add a production request to the evaluation buffer"""
        
        if not self.should_evaluate():
            return
        
        self.eval_buffer.append({
            "question": question,
            "contexts": contexts,
            "answer": answer,
            "trace_id": trace_id,
            "timestamp": time.time()
        })
        
        # When buffer is full, evaluate the batch
        if len(self.eval_buffer) >= self.buffer_size:
            asyncio.create_task(self._evaluate_batch())
    
    async def _evaluate_batch(self):
        """Evaluate a batch of production requests"""
        
        batch = self.eval_buffer.copy()
        self.eval_buffer.clear()
        
        if not batch:
            return
        
        dataset = Dataset.from_dict({
            "question": [b["question"] for b in batch],
            "contexts": [b["contexts"] for b in batch],
            "answer": [b["answer"] for b in batch],
        })
        
        try:
            result = evaluate(
                dataset=dataset,
                metrics=[faithfulness, answer_relevancy, context_precision],
                llm=self.eval_llm,
                embeddings=self.eval_embeddings
            )
            
            # Record scores with timestamps
            for i, item in enumerate(batch):
                score_record = {
                    "trace_id": item["trace_id"],
                    "timestamp": item["timestamp"],
                    "faithfulness": float(result["faithfulness"]),
                    "answer_relevancy": float(result["answer_relevancy"]),
                    "context_precision": float(result["context_precision"])
                }
                self.score_history.append(score_record)
            
            # Alert if quality is degrading
            avg_faithfulness = float(result["faithfulness"])
            if avg_faithfulness < 0.7:
                print(f"🚨 QUALITY ALERT: Faithfulness dropped to "
                      f"{avg_faithfulness:.2f}! Investigate immediately.")
                
        except Exception as e:
            print(f"⚠️ RAGAS evaluation failed: {e}")
    
    def get_quality_trend(self) -> dict:
        """Analyze quality score trends"""
        
        history = list(self.score_history)
        if not history:
            return {"status": "no_data"}
        
        recent = history[-50:] if len(history) >= 50 else history
        older = history[-100:-50] if len(history) >= 100 else []
        
        def avg(records, key):
            return sum(r[key] for r in records) / len(records) if records else 0
        
        recent_faith = avg(recent, "faithfulness")
        older_faith = avg(older, "faithfulness") if older else recent_faith
        
        trend = "stable"
        if recent_faith < older_faith - 0.05:
            trend = "degrading"
        elif recent_faith > older_faith + 0.05:
            trend = "improving"
        
        return {
            "recent_faithfulness": round(recent_faith, 3),
            "older_faithfulness": round(older_faith, 3),
            "trend": trend,
            "samples_evaluated": len(history),
            "alert": trend == "degrading"
        }

class CodeSafetyValidator(BaseValidator):
    """
    For coding AI: detect dangerous code patterns.
    """
    name = "code_safety"
    severity = "error"
    
    DANGEROUS_CODE_PATTERNS = [
        r'os\.system\(',
        r'subprocess\.call\(',
        r'eval\(',
        r'exec\(',
        r'__import__\(',
        r'open\(.+[\'"]w[\'"]\)',   # File write

        r'chmod\s+777',            # Insecure permissions
    ]

        code_blocks = re.findall(r'```[\s\S]*?```', response)
        
        if not code_blocks:
            return ValidationResult(
                passed=True,
                validator_name=self.name,
                severity=self.severity,
                message="No code blocks to validate"
            )
        
        code_content = ' '.join(code_blocks)
        found_dangerous = []
        
        for pattern in self.DANGEROUS_CODE_PATTERNS:
            if re.search(pattern, code_content, re.IGNORECASE):
                found_dangerous.append(pattern)
        
        if found_dangerous:
            return ValidationResult(
                passed=False,
                validator_name=self.name,
                severity="error",
                message=(
                    f"Dangerous code pattern detected: "
                    f"{len(found_dangerous)} issues"
                ),
                details={
                    "dangerous_patterns": found_dangerous,
                    "note": "Review code carefully before execution"
                }
            )
        
        return ValidationResult(
            passed=True,
            validator_name=self.name,
            severity=self.severity,
            message="Code safety check passed"
        )

## 📐 SECTION 7: Math Intuition — Quality Scoring

### Understanding Quality Score Formulas

```
RAGAS FAITHFULNESS FORMULA:
────────────────────────────
faithfulness = supported_statements / total_statements_in_answer

Step by step:
1. Extract all factual statements from the answer:
   "The item costs $49" → statement 1
   "Shipping takes 3 days" → statement 2
   "Returns accepted in 30 days" → statement 3
   
2. Check each statement against the retrieved context:
   Statement 1: $49 — found in context ✅
   Statement 2: 3 days — NOT in context (context says 5-7 days) ❌
   Statement 3: 30 days — found in context ✅
   
3. Calculate:
   faithfulness = 2 supported / 3 total = 0.667
   
4. Threshold check:
   0.667 < 0.80 threshold → FAIL (hallucination detected!)


ANSWER RELEVANCY FORMULA:
──────────────────────────
Method: Question generation approach

Step by step:
1. Take the answer
2. Ask an LLM to generate N questions this answer would address:
   Answer: "Returns accepted within 30 days with receipt"
   
   Generated questions:
   Q1: "What is the return period?" 
   Q2: "Do I need a receipt to return?"
   Q3: "Where do I return items?"  ← Not answered
   
3. Calculate cosine similarity between each generated question
   and the ORIGINAL question:
   Original: "How do I return a product?"
   Sim(Q1, Original) = 0.89 ← High relevance
   Sim(Q2, Original) = 0.72 ← Medium relevance
   Sim(Q3, Original) = 0.65 ← Lower relevance
   
4. Average the similarities:
   relevancy = mean(0.89, 0.72, 0.65) = 0.753

5. Threshold check:
   0.753 > 0.70 threshold → PASS ✅
```

### Guardrail Trigger Rate Formula

```
Trigger Rate = (Requests that triggered guardrail) / (Total requests) × 100%

For each guardrail separately:

toxicity_trigger_rate = (toxicity_triggers / total_requests) × 100%
injection_trigger_rate = (injection_triggers / total_requests) × 100%

Healthy baselines (approximate):
toxicity_filter: < 0.1% (1 in 1000)

topic_boundary: < 5% (50 in 1000)

Alerts:

## 💥 SECTION 8: Failure Modes — When Quality Monitoring Breaks

| # | Failure | Root Cause | Detection | Fix |
|---|---|---|---|---|
| 1 | **Evaluating 100% of traffic** | Costs too much — evaluation uses LLM calls | Monitor evaluation costs | Sample 2-5%; increase for high-stakes apps |
| 2 | **Judge model hallucinates** | LLM-as-Judge makes errors too | Use multiple judges, average scores | Ensemble 2-3 judge models; set confidence thresholds |
| 3 | **Validation passes garbage** | Validators too lenient | Track false negative rate | Red-team your validators with known bad examples |
| 4 | **Validator blocks good responses** | Validators too strict | Track false positive rate | Tune thresholds; log all blocked responses |
| 5 | **Quality drift goes unnoticed** | Only spot-checking, no trend analysis | No trend alerts | Set rolling average alerts on quality scores |
| 6 | **Guardrail bypassed** | Adversarial input encodes attack | No red-teaming | Run DeepEval red-teaming monthly |
| 7 | **Evaluation dataset goes stale** | Test cases from 6 months ago don't reflect current usage | Dataset age tracking | Refresh evaluation dataset quarterly |
| 8 | **RAGAS gives perfect scores on bad outputs** | Small, cherry-picked retrieval context | Context quality not checked | Validate context BEFORE evaluation |
| 9 | **Custom validator crashes silently** | Exception in validator code | No error tracking on validators | Wrap all validators in try/except; log exceptions |
| 10 | **Different quality in different languages** | Evaluated only in English | Monolingual eval dataset | Build multilingual evaluation dataset |

## 💬 SECTION 10: Strong Interview Answers

### Answer Q2: RAGAS Framework

> *"RAGAS measures 4 key dimensions of RAG quality. First, Faithfulness — does the answer only contain information that's actually in the retrieved context? It extracts all claims from the answer and checks each one against the context, scoring from 0 to 1. Second, Answer Relevancy — does the response actually address the user's question? It generates questions from the answer and measures their semantic similarity to the original question. Third, Context Precision — are the retrieved documents relevant to the question? High precision means we're not wasting context window on irrelevant docs. Fourth, Context Recall — did we retrieve all necessary information? Low recall means the answer will be incomplete because we didn't find all relevant documents. Together, these 4 metrics diagnose different failure points in the RAG pipeline."*

---

### Answer Q5: Medical AI Safety Monitoring

> *"I'd build 5 layers. Layer 1: Rule-based validators checking for medical claims without disclaimers — any specific dosage, drug interaction, or diagnosis must trigger an automatic disclaimer insertion. Layer 2: NLI-based contradiction detection comparing the response against verified medical knowledge base entries. Layer 3: LLM-as-Judge using a medical expert prompt to rate responses for accuracy and safety on sampled traffic — maybe 10% sampling given the high stakes. Layer 4: Guardrails that completely block any response containing emergency situation language without first providing emergency contact information. Layer 5: Human review queue where any response scoring below 0.8 on safety gets flagged for a human medical professional to review before — or immediately after — reaching the user. I'd track all of these metrics on a real-time dashboard with P99 quality scores and immediate alerting if safety rates drop."*

---

### Answer Q8: Guardrail Trigger Rate of Zero

> *"A guardrail trigger rate of zero is actually suspicious and should be investigated. It could mean two things: either your AI is genuinely well-behaved and users are well-intentioned — which is good — or your guardrails have stopped working due to a bug, a code change, or an adversarial technique that bypasses them. I'd distinguish between these by running synthetic test cases through the system — known examples that should trigger the guardrail — and verifying they still fire correctly. This is analogous to a fire alarm test: you don't assume silence means everything is fine; you periodically test that the alarm still works. A good monitoring system includes 'synthetic probe requests' that deliberately try to trigger each guardrail, run on a schedule, with alerts if they don't fire."*

## ⚠️ SECTION 11: Common Beginner Mistakes

| Mistake | Why Wrong | Right Approach |
|---|---|---|

"""
Production-Grade Quality & Behavior Monitoring System
Combines all components into one coherent system.
"""

import asyncio
import uuid
import time
from dataclasses import dataclass
from typing import Optional

class ProductionQualityMonitor:
    """
    Complete quality monitoring for production LLM systems.
    Hallucination + Validation + Guardrails + Evaluation.
    """
    
    def __init__(self, app_name: str, sample_rate: float = 0.05):
        self.app_name = app_name
        
        # Initialize all subsystems
        self.hallucination_detector = HallucinationDetector()
        self.hallucination_tracker = HallucinationRateTracker()
        
        self.validation_pipeline = build_customer_support_pipeline()
        
        self.guardrail_orchestrator = GuardrailOrchestrator()
        
        self.deepeval_monitor = DeepEvalProductionMonitor(
            sample_rate=sample_rate
        )
        
        # Metrics
        self.total_requests = 0
        self.blocked_by_guardrails = 0
        self.validation_failures = 0
        self.hallucinations_detected = 0
    
    async def process_request(
        self,
        user_message: str,
        user_id: str,
        llm_func,
        retrieve_docs_func,
        feature: str = "chat",
        model: str = "gpt-4o"
    ) -> dict:
        """
        Complete quality-monitored request pipeline.
        Every request goes through:
        1. Input guardrails
        2. Document retrieval
        3. LLM generation
        4. Hallucination detection (sampled)
        5. Output validation
        6. Output guardrails
        7. DeepEval evaluation (sampled)
        """
        
        trace_id = str(uuid.uuid4())
        self.total_requests += 1
        start_time = time.time()
        
        result = {
            "trace_id": trace_id,
            "user_id": user_id,
            "feature": feature,
            "quality_checks": {}
        }
        
        # ═══ STAGE 1: INPUT GUARDRAILS ═══
        
        proceed, override, input_triggers = (
            await self.guardrail_orchestrator.check_input(
                user_message, user_id, trace_id
            )
        )
        
        if not proceed:
            self.blocked_by_guardrails += 1
            result.update({
                "response": override,
                "blocked": True,
                "block_stage": "input",
                "guardrail_triggers": len(input_triggers)
            })
            return result
        
        # ═══ STAGE 2: RETRIEVAL ═══
        
        retrieved_docs = await retrieve_docs_func(user_message)
        context_text = "\n".join(retrieved_docs)
        
        # ═══ STAGE 3: LLM GENERATION ═══
        
        llm_response = await llm_func(user_message, context_text)
        
        # ═══ STAGE 4: HALLUCINATION DETECTION (sampled) ═══
        
        hallucination_result = await self.hallucination_detector.detect(
            question=user_message,
            context=context_text,
            response=llm_response
        )
        
        self.hallucination_tracker.record(
            is_hallucination=hallucination_result.is_hallucination,
            groundedness_score=hallucination_result.groundedness_score,
            feature=feature,
            model=model,
            trace_id=trace_id
        )
        
        if hallucination_result.is_hallucination:
            self.hallucinations_detected += 1
            result["quality_checks"]["hallucination"] = {
                "detected": True,
                "groundedness_score": hallucination_result.groundedness_score,
                "unsupported_claims": hallucination_result.unsupported_claims
            }
            
            # For high-stakes apps: block hallucinated responses
            # For lower-stakes: flag and serve with disclaimer
            if hallucination_result.groundedness_score < 0.5:
                result.update({
                    "response": (
                        "I don't have enough information to answer "
                        "that accurately. Please contact support."
                    ),
                    "blocked": True,
                    "block_stage": "hallucination_detected"
                })
                return result
        
        # ═══ STAGE 5: OUTPUT VALIDATION ═══
        
        validation_report = self.validation_pipeline.validate(
            response=llm_response,
            context={"question": user_message}
        )
        
        result["quality_checks"]["validation"] = {
            "passed": validation_report.overall_passed,
            "checks": validation_report.total_checks,
            "failures": [f.message for f in validation_report.critical_failures]
        }
        
        if not validation_report.should_serve:
            self.validation_failures += 1
            
            if validation_report.should_retry:
                # Try one more time
                llm_response = await llm_func(user_message, context_text)
                validation_report = self.validation_pipeline.validate(
                    llm_response, {"question": user_message}
                )
            
            if not validation_report.should_serve:
                result.update({
                    "response": "I encountered an issue. Please try again.",
                    "blocked": True,
                    "block_stage": "validation_failed"
                })
                return result
        
        # ═══ STAGE 6: OUTPUT GUARDRAILS ═══
        
        should_serve, final_response, output_triggers = (
            await self.guardrail_orchestrator.check_output(
                llm_response, user_id, trace_id
            )
        )
        
        if not should_serve:
            self.blocked_by_guardrails += 1
            result.update({
                "response": final_response,
                "blocked": True,
                "block_stage": "output_guardrail"
            })
            return result
        
        # ═══ STAGE 7: DEEPEVAL (async, doesn't block response) ═══
        
        asyncio.create_task(
            self.deepeval_monitor.evaluate_production_response(
                question=user_message,
                answer=final_response,
                retrieved_context=retrieved_docs,
                trace_id=trace_id
            )
        )
        
        # ═══ FINAL RESULT ═══
        
        total_time = (time.time() - start_time) * 1000
        
        result.update({
            "response": final_response,
            "blocked": False,
            "total_time_ms": round(total_time, 2),
            "guardrail_triggers": len(input_triggers) + len(output_triggers),
            "quality_checks": result["quality_checks"]
        })
        
        return result
    
    def get_health_report(self) -> dict:
        """Overall system quality health report"""
        
        hallucination_report = self.hallucination_tracker.get_report()
        validation_report = self.validation_pipeline.get_failure_rate_report()
        guardrail_report = self.guardrail_orchestrator.monitor.get_report(
            total_requests=self.total_requests
        )
        deepeval_trend = self.deepeval_monitor.get_quality_trend()
        
        return {
            "app_name": self.app_name,
            "total_requests": self.total_requests,
            "hallucination_rate": hallucination_report.get(
                "hallucination_rate_pct", 0
            ),
            "avg_groundedness": hallucination_report.get(
                "avg_groundedness_score", 1.0
            ),
            "validation_failure_rate": validation_report.get(
                "overall_failure_rate_pct", 0
            ),
            "guardrail_block_rate": (
                self.blocked_by_guardrails / max(self.total_requests, 1) * 100
            ),
            "quality_trend": deepeval_trend.get("trend", "unknown"),
            "system_health": self._calculate_health_score(
                hallucination_report, validation_report, guardrail_report
            )
        }
    
    def _calculate_health_score(
        self,
        hallucination_report: dict,
        validation_report: dict,
        guardrail_report: dict
    ) -> str:
        """Overall health: GREEN / YELLOW / RED"""
        
        hall_rate = hallucination_report.get("hallucination_rate_pct", 0)
        val_fail_rate = validation_report.get("overall_failure_rate_pct", 0)
        
        if hall_rate > 15 or val_fail_rate > 20:
            return "🔴 CRITICAL"
        elif hall_rate > 5 or val_fail_rate > 10:
            return "🟡 WARNING"
        else:
            return "🟢 HEALTHY"
```

## 🧠 SECTION 13: Engineer Mindset

```
How a Senior AI Engineer thinks about Quality Monitoring:

Before shipping any LLM feature, I ask:

✅ "What does 'quality' mean for THIS specific use case?"
   Medical AI: No hallucinations ever. Safety first.
   Customer support: Relevant + grounded + professional.
   Code assistant: Syntactically correct + not dangerous.
   → Quality definition changes per domain.

✅ "What is my acceptable hallucination rate?"
   Medical: 0% — zero tolerance
   Customer support: < 2%
   Creative writing: 10%+ is fine
   → Set domain-specific thresholds.

✅ "Which 5% of traffic do I evaluate deeply?"
   → Priority: new features, edge cases, user-reported issues
   → Not: random 5% (misses systematic problems)

✅ "What is my guardrail test protocol?"
   → Weekly synthetic probe tests
   → Monthly red-team evaluation
   → Quarterly full security audit

✅ "What happens when quality drops?"
   → Automated fallback response
   → Human review queue trigger
   → Alert escalation path
   → Rollback plan for prompt/model change

✅ "How do I build a golden test dataset?"
   → Collect real production failures
   → Add adversarial examples
   → Include edge cases from your domain
   → Refresh quarterly

The goal: Your AI fails safely, quietly, and informatively.
Never: "The AI said something horrible and we found out from Twitter."
Always: "We detected the pattern, fixed it in 2 hours, users were protected."
```
